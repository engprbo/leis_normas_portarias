ieeeDesignation

ieeeDesignation ::= stringToken

Used by:

ieeeStandard

Description:

This is the IEEE Standard number or designation, without the year indicator.

Example:

(ieeeStandard "91"
        (year 1984)
        (ieeeSection 3 1 10))

This example shows a reference to IEEE Standard 91-1984, Section 3.1.10, which refers to a negative edge-triggered clock input and could be important information for a timing analyzer or logic synthesis tool.

See also:

ieeeSection

ieeeStandard

ieeeStandard ::= '(' 'ieeeStandard'
	ieeeDesignation
	year
	{ comment | <ieeeSection> } 
	')'

Used by:

schematicGlobalPortAttributes schematicPortAttributes schematicPortClock

Description:

IeeeStandard refers to information provided in an IEEE standard. The designation is a string such as "91", "315" or "Y32.9". The year is usually a part of the standard's name, such as 91-1984. The section is described by a list of integerTokens in ieeeSection.

Example:

(ieeeStandard "91" 
   (year 1984)
   (ieeeSection 3 1 10))

This example defines a reference to IEEE Standard 91-1984, Section 3.1.10.

ifFrame

ifFrame ::= '(' 'ifFrame'
	frameNameDef
	condition
	logicalConnectivity
	{ comment | documentation | <nameInformation> | property | userData } 
	')'

Used by:

logicalConnectivity

Description:

An ifFrame is a frame whose contents are included during hierarchy expansion only if condition evaluates to true.

Example:

(ifFrame IX
   (condition (booleanParameterRef doubleBuffer))
   (logicalConnectivity ...)
)

The contents of IX are included only if doubleBuffer is true.

indexNameDef

indexNameDef ::= nameDef

Used by:

forFrameIndex

Description:

IndexNameDef specifies the name of an index. The indexNameDef must not be the same as the indexNameDef of the index of any for frame in which this for frame is enclosed, either directly or indirectly. This ensures that a reference to for frame index is always unambiguous.

Example:

(forFrame F1 (repetitionCount 32)
   (forFrameIndex J (indexStart 1) (indexStep 1))
   (logicalConnectivity ...)
)

In this example, the name of the forFrame index is J.

See also:

indexValue

indexValue ::= '(' 'indexValue'
	integerToken
	')'

Used by:

forFrameMemberRef instanceMemberRef portMemberRef signalMemberRef

Description:

IndexValue is used to specify a single element of an object.

The index must be greater than or equal to zero. The first element has an index value of zero.

The indexValue must represent a valid reference to a member of the object.

Example:

(portInstanceRef DATA1
   (instanceMemberRef I1 (indexValue 37)))

In this example, the DATA1 port on instance number 37 of I1 is referenced.

instance

instance ::= '(' 'instance'
	instanceNameDef
	clusterRef
	{ booleanParameterAssign | cellPropertyOverride | clusterPropertyOverride 
	| comment | <designator> | <instanceNameGenerator> | 
	instancePortAttributes | <instanceWidth> | integerParameterAssign | 
	<nameInformation> | numberParameterAssign | property | 
	stringParameterAssign | timing | userData } 
	')'

Used by:

logicalConnectivity

Description:

Instance allows a cluster to be referenced within a view of another cell to create the instance hierarchy of a design.

An instance of a cluster means that some mechanism is required to select from that cluster the view which is most appropriate. The configuration of views applicable to a particular design can be specified using clusterConfiguration.

The representation of the instance in a page is achieved by using the construct schematicInstanceImplementation, which selects, in the case of a schematic page, a schematic symbol from the referenced cluster.

In the context of instance, cellRef is required within clusterRef.

The instanceWidth attribute can be used to indicate that the instance is wide. In the context of a schematic view, the wide instance is represented by a single implementation. An object connected to a port of an instance of width greater than one will follow this rule:

Let N equal the product of instance width and the instance port/portBundle width divided by the connecting bus/net width. In level 0, N may be either equal to the instance width, or to one; other values are a semantic error.

A full description of the logical connectivity for these two conditions can be found in the Information Model.

If instanceWidth is greater than one, all attributes of the instance apply equally to each member of the set. This includes properties, instancePortAttributes, propertyOverrides, but excludes nameInformation, which applies to the wide instance as whole.

Example:

(instance nand12 
   (clusterRef C1 (cellRef nand)) ...)

The above example describes an instance named nand12 of the cluster named C1 of the cell named nand.

See also:

schematicInstanceImplementation

instanceConfiguration

instanceConfiguration ::= '(' 'instanceConfiguration'
	instanceNameRef
	clusterConfigurationRef
	')'

Used by:

clusterConfiguration frameConfiguration

Description:

InstanceConfiguration selects a configuration for a particular instance in a view. This is done by referencing a clusterConfiguration within the cluster of the instance referenced by instanceNameRef. Therefore, the name referenced by clusterConfigurationRef must exist in the cluster instantiated by the instance named instanceNameRef.

It is not mandatory to specify an instanceConfiguration for each instance. During the specification of configuration, if an instance has no associated instanceConfiguration, the default cluster configuration of its instantiated cluster is assumed.

If the referenced instance has an instanceWidth greater than one, the configuration applies to all member instances equally.

Example:

(instanceConfiguration BLOCK1
   (clusterConfigurationRef CONFIG1))

See also:

design defaultClusterConfiguration

instanceIndexValue

instanceIndexValue ::= '(' 'instanceIndexValue'
	')'

Used by:

integerExpression

Description:

InstanceIndexValue returns the value of the index of a wide instance. For an instance of instance width N, the instanceIndexValue will return values 0 through N-1.

Example:

(instance I1 ...
   (instanceWidth 4) ...)
...
(connectedSignalIndexGenerator
   (instanceIndexValue))

In this example, the signal indices generated as the instanceIndexValue varies would be 0, 1, 2, 3 and 4.

See also:

connectedSignalIndexGenerator

instanceMemberRef

instanceMemberRef ::= '(' 'instanceMemberRef'
	instanceNameRef
	indexValue
	')'

Used by:

extendInstanceMemberDef portInstanceRef

Description:

InstanceMemberRef references a member of a wide instance. The indexValue must be valid (0 <= indexValue < instanceWidth).

Example:

(instance I1 ...
   (instanceWidth 48) ...)
...
(signalJoined ...
   (portInstanceRef DATA1
      (instanceMemberRef I1 (indexValue 37))) ...)
...

In this example, the DATA1 port on I1's 37th member is referenced in a signalJoined.
