Chapter 3

Reusable objects

 

This chapter describes the concept of reusable objects. The model for the various categories of template such as geometry_macro_template, schematic_figure_macro_template, schematic_master_port_representation_template and schematic_offpageconnector_template can be found in the instantiatable_object_model schema .

3.1 Problem statement

In EDIF Version 2 0 0, there is only one way of defining the re-use of an object via the instantiation process. This is the instance which may be applied to views of a cell. It follows therefore that the need to allow the re-use of a 'dumb graphics' object led to the definition of viewtype graphic which in all respects other than re-usability bears no resemblance to true cell views. This led to the overloading of the view concept. Some of the EDIF Version 2 0 0 views are design-oriented views, e.g. schematic, netlist, masklayout. These have interfaces and ports and can be used to form a design hierarchy. Others are miscellaneous views, e.g. document, graphic. These do not have ports and are not part of a design hierarchy.

There is a need to define a class of objects which have the common characteristic that they are defined once and re-used many times. This could have been met by continued extension of the EDIF view, but this would have resulted in the gross overloading of the view concept.

3.2 Solution

In EDIF Version 3 0 0, the concept of 'reusable object' has been recognised. At present, three types of reusable objects are defined :

a) hierarchical design objects which correspond to cell views

b) instantiable templates which graphically illustrate connectivity structure e.g. offpageconnectors, rippers

c) dumb graphics templates which were handled by graphic views in EDIF Version 2 0 0

3.2.1 Instantiatable templates for schematic views

An instantiatable object is a reusable object which has specific semantics related to the context in which it is used. Occurrences of instantiatable templates appear in the implementation part of cell views. Instantiatable templates are often defined in CAD libraries. Such definitions may not contain occurrences of other instantiatable templates but they may contain occurrences of reusable dumb graphics objects.

At present, the majority of the instantiatable objects in EDIF Version 3 0 0 are targeted at schematic transfer. All schematic instantiatable templates share some common attributes, e.g. background colour, documentation. They may have properties which are displayed on the schematic page. The descriptions of the different types of instantiatable template are given below.

  • schematic_offpageconnector_template and schematic_onpageconnector_template

    A schematic_offpageconnector_template contains information which is used in the display definition of a schematic_offpageconnector on a schematic page. A schematic_onpageconnector_template contains information which is used in the display definition of a schematic_onpageconnector on a schematic page. The schematic_offpageconnectors and schematic_onpageconnectors describe aspects of the structural implementation of the logical connectivity for a given level of hierarchy. Both types of template have a hotspot to which connection is to be made graphically. The hotspot has a schematic_wire_style indicator which gives its suitability for association with a narrow or wide interconnect structure (i.e. schematic_generic_net or schematic_generic_bus). Display slot information may be given to allow the display of the implementation name and the associated interconnect name.

  • schematic_master_port_representation_template and schematic_symbol_port_representation_template

    A schematic_master_port_representation_template contains information which is used in the display definition of a schematic_master_port_representation or a schematic_master_port_bundle_representation on a schematic page. A schematic_symbol_port_representation_template contains information which is used in the display definition of a schematic_symbol_port_representation or a schematic_symbol_port_bundle_representation in an internal_schematic_symbol. Both types of template have a hotspot to which connection is to be made graphically. The hotspot has a schematic_wire_affinity indicator which gives its suitability for association with a narrow or wide interconnect structure (i.e. schematic_generic_net or schematic_generic_bus). In addition, these templates have two indicators : the schematic_port_representation_style identifies whether the associated master port is narrow or wide, the port_direction_indicator gives its suitability for association with an input, output, bidirectional or unspecified direction master port. Display slot information may be specified for the display of the implementation name, the associated port name and various port attributes, such as acload, delay, dcFaninLoad, dcMaxFanin.

  • schematic_global_port_representation_template

    A schematic_global_port_representation_template contains information which is used in the display definition of a schematic_global_port_representation on a schematic page. A schematic_global_port_representation_template has a hotspot to which connection is to be made graphically. The hotspot has a schematic_wire_style indicator which gives its suitability for association with a narrow or wide interconnect structure (i.e. schematic_generic_net or schematic_generic_bus). Display slot information may be given to allow the display of the implementation name and the associated global port name.

  • schematic_ripper_template

    A schematic_ripper_template contains information which is used in the display definition of a schematic_ripper on a schematic page. A schematic_ripper shows that two or more structures (i.e. schematic_generic_nets or schematic_generic_busses) on a schematic page are linked. A schematic_ripper_template has two or more ripper_hotspots to which connections are to be made graphically. A ripper_hotspot has a schematic_wire_style indicator which gives its suitability for association with a narrow or wide interconnect structure. Display slot information may be given to allow the display of the implementation name.

  • schematic_junction_template

    A schematic_junction_template contains information which is used in the display definition of a schematic_net_junction or a schematic_bus_junction on a schematic page. A schematic_net_junction shows that at least two schematic_sub_nets are linked. The related sub_nets belong to the same schematic_generic_net. A schematic_bus_junction shows that at least two schematic_sub_busses are linked. As for schematic_net_junction, the related sub_busses belong to the same schematic_generic_bus. A schematic_junction_template has a hotspot to which connection is to be made graphically. The hotspot has a schematic_wire_affinity indicator which gives its suitability for association with a narrow or wide interconnect structure (i.e. schematic_generic_net or schematic_generic_bus). Display slot information may be given to allow the display of the implementation name.

  • schematic_interconnect_terminator_template

    A schematic_interconnect_terminator_template contains information which is used in the display definition of a schematic_interconnect_terminator on a schematic page. A schematic_interconnect_terminator is used to indicate the end of an interconnect. It is sometimes referred to as a dangling end. It has a hotspot to which connection is to be made graphically. The hotspot has a schematic_wire_affinity indicator which gives its suitability for association with a narrow or wide interconnect structure (i.e. schematic_generic_net or schematic_generic_bus). Display slot information may be given to allow the display of the implementation name.

  • page_title_block_template

    A page_title_block_template contains information which is used in the display definition of a page_title_block on a schematic page. A page_title_block_template allows details about the design to be placed in a special area, e.g. approved date, page number.

  • page_border_template and schematic_symbol_border_template

    A page_border_template contains information which is used in the display definition of a page_border on a schematic page. A schematic_symbol_border_template contains information which is used in the display definition of a schematic_symbol_border for an internal_schematic_symbol.

  • schematic_figure_macro_template

    A schematic_figure_macro_template is a collection of figures and annotation text which are themselves associated with figure_groups. It may contain occurrences of other schematic_figure_macro_templates. Occurrences of schematic_figure_macro_templates are used in the same contexts that graphical primitives (i.e. figure) are used; for example, they can be used to implement nets or busses.

3.2.2 Dumb geometry template

The geometry_macro_template is a collection of geometry primitives (i.e. geometry_element). It may contain occurrences of other geometry_macro_templates. Since a geometry_macro_template is defined without reference to a figure_group, it may only be used within a figure or within another geometry_macro_template definition.
