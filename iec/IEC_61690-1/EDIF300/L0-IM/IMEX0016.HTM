unfinished_view_model

Description:

Some EDIF viewtypes are not defined in the current model. They are pcblayout, logicmodel, behavior, masklayout and symboliclayout viewtypes. The pcblayout model and a new test model are expected to be released in future versions of EDIF.

internal_pcblayout_view

  ENTITY internal_pcblayout_view
      SUBTYPE OF (internal_cell_representation);
    -- will be defined in future version of EDIF
  END_ENTITY;

Description:

An internal_pcblayout_view is a cell_representation which describes a printed circuit board layout. It is not defined in the model.

external_pcblayout_view

  ENTITY external_pcblayout_view
      SUBTYPE OF (external_cell_representation);
    -- will be defined in future version of EDIF
  END_ENTITY;

Description:

An external_pcblayout_view is a pcblayout view found in an external_cell. It is not defined in the model.
