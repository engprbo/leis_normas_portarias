schematic_view_model

Description:

The schematic_view_model schema describes what information can be found in an EDIF schematic view. The schematic view conveys hierarchy, connectivity and implementation information. The hierarchy information describes how a circuit is broken down into a number of cells. The connectivity information defines how circuits are connected. The implementation of a schematic view is split into pages, which form a graphical representation of its structure.

internal_schematic_view

  ENTITY internal_schematic_view
      SUBTYPE OF (internal_cell_representation);
    instances                   : OPTIONAL SET [1:?] OF instance;
    pages                       : OPTIONAL SET [1:?] OF page;
    signals                     : OPTIONAL SET [1:?] OF signal;
    signal_groups               : OPTIONAL SET [1:?] OF signal_group;
    timings                     : OPTIONAL SET [1:?] OF timing;
    total_pages                 : OPTIONAL integer_token;
    units                       : schematic_units;
  WHERE
    valid_instances :
      (* An internal_schematic_view should not contain instances of clusters of
         the containing_cell either directly or indirectly. *)
      not_defined;

    valid_signals :
      (* All signals are disjoint.  That is, only one signal may connect to a 
         particular global_port, instance_member_port or master_port. *)
      not_exists(QUERY(sig1 <* signals |
        there_exists(QUERY(sig2 <* signals - sig1 |
          there_exists(sig1.joined_global_ports * sig2.joined_global_ports)
       OR there_exists(sig1.joined_instance_member_ports
                       * sig2.joined_instance_member_ports)
       OR there_exists(sig1.joined_master_ports * sig2.joined_master_ports)))));
  END_ENTITY;

Description:

An internal_schematic_view is a cell_representation which describes the connectivity of a cell and the representation of the cell on a schematic. The implementation of an internal_schematic_view is split into pages which may contain schematic_busses, schematic_nets and occurrences of various schematic_templates, such as schematic_offpageconnectors, schematic_onpageconnectors, schematic_master_port_representations, schematic_global_port_representations, schematic_rippers, schematic_bus_junctions, schematic_net_junctions and schematic_interconnect_terminators.

internal_schematic_symbol

  ENTITY internal_schematic_symbol
      SUBTYPE OF (internal_cell_representation);
    annotate                        : OPTIONAL BAG [1:?] OF string_display;
    background_colour               : colour;                 
    border                          : OPTIONAL schematic_symbol_border;
    cell_name_display               : OPTIONAL BAG [1:?] OF display;
    cell_property_displays          : OPTIONAL BAG [1:?] OF property_display;
    cluster_property_displays       : OPTIONAL BAG [1:?] OF property_display;
    comment_graphics_info           : OPTIONAL BAG [1:?] OF comment_graphics;
    designator_display              : OPTIONAL BAG [1:?] OF display;
    figures                         : OPTIONAL BAG [1:?] OF figure;
    figure_macros                   : OPTIONAL BAG [1:?] OF
                                      schematic_figure_macro; 
    implementation_name_display_slot: OPTIONAL BAG [1:?] OF display;
    instance_name_display_slot      : OPTIONAL BAG [1:?] OF display;
    instance_width_display_slot     : OPTIONAL BAG [1:?] OF display;
    original_bounding_box           : OPTIONAL rectangle;
    page_size                       : OPTIONAL rectangle;
    symbol_name_display             : OPTIONAL BAG [1:?] OF display;
    symbol_port_representations     : OPTIONAL SET [1:?] OF 
                                      schematic_symbol_port_representation;
    symbol_port_bundle_representations : OPTIONAL SET [1:?] OF 
                                      schematic_symbol_port_bundle_representation;
    symbol_property_displays        : OPTIONAL BAG [1:?] OF property_display;
    units                           : schematic_units;
  WHERE
    valid_cell_property_displays :
      (* The displayed properties are defined in the containing internal_cell.*)
      not_exists(QUERY(cellPropertyDisplay <* cell_property_displays |
        NOT (cellPropertyDisplay.displayed_property
             IN SELF\internal_cell_representation
                .containing_cluster.containing_cell.properties)));

    valid_cluster_property_displays :
      (* The displayed properties are defined in the containing
         internal_cluster. *) 
      not_exists(QUERY(clusterPropertyDisplay <* cluster_property_displays |
        NOT (clusterPropertyDisplay.displayed_property
            IN SELF\internal_cell_representation.containing_cluster.properties)));

    valid_symbol_port_representations :
      (* The symbol_port_representations reference master_ports defined in the
         cluster interface. *) 
      not_exists(QUERY(portRepresentation <* symbol_port_representations |
        NOT (portRepresentation.implemented_master_port
             IN SELF\internal_cell_representation.interface.ports)));

    valid_symbol_port_bundle_representations :
      (* The symbol_port_bundle_representations reference master_port_bundles
         defined in the cluster interface. *) 
      not_exists(QUERY(portRepresentation <* symbol_port_bundle_representations |
        NOT (portRepresentation.implemented_master_port_bundle
             IN SELF\internal_cell_representation.interface.port_bundles)));

    valid_symbol_property_displays :
      (* The displayed properties are defined in the internal_schematic_symbol.*)
      not_exists(QUERY(symbolPropertyDisplay <* symbol_property_displays |
        NOT (symbolPropertyDisplay.displayed_property
             IN SELF\internal_cell_representation.properties)));
  END_ENTITY;

schematic_units

  ENTITY schematic_units;
    hotspot_grid         : OPTIONAL length_value;
    nominal_hotspot_grid : OPTIONAL length_value;
    set_angle            : angle_unit;
    set_capacitance      : capacitance_unit;
    set_distance         : distance_unit;
    set_frequency        : frequency_unit;
    set_time             : time_unit;
    set_voltage          : voltage_unit;
  END_ENTITY;

Description:

The schematic_units is used to set the scaling for a schematic view. In a schematic view, it is appropriate to set an angle scale, a capacitance scale, a distance scale and a timing scale. The hotspot_grid is specified in terms of integer distance value. If the hotspot_grid is not present, it implies the schematic view has no grid specified.

schematic_symbol_border

  ENTITY schematic_symbol_border;
    instantiated_template          : schematic_symbol_border_template;-- reference
    overriding_template_properties : OPTIONAL SET [1:?] OF property_override;
    overriding_template_property_displays : OPTIONAL SET [1:?] OF 
                                            property_display_override;
    template_position              : transform;
  DERIVE
    containing_symbol : internal_schematic_symbol                -- reference
      := usedin_one_role(SELF, 
         'schematic_view_model.internal_schematic_symbol.border');
  WHERE
    containment_constraint :
      (* A schematic_symbol_border belongs to one internal_schematic_symbol. *)
      belongs_to_one(SELF,
        'schematic_view_model.internal_schematic_symbol.border'); 

    valid_overriding_template_properties :
      (* The overridden properties are defined in the instantiated_template. *)
      not_exists(QUERY(valueOverride <* overriding_template_properties |
        NOT (valueOverride.overridden_property
             IN instantiated_template.properties)));

    valid_overriding_template_property_displays :
      (* The overridden properties are defined in the instantiated_template. *)
      not_exists(QUERY(displayOverride<*overriding_template_property_displays |
        NOT (displayOverride.overridden_property
             IN instantiated_template.properties)));
  END_ENTITY;

Description:

A schematic_symbol_border is used directly within an internal_schematic_symbol definition. It is defined by specifying the position and orientation of the occurrence of the referenced schematic_symbol_border_template.

Used by:

internal_schematic_symbol

schematic_symbol_port_representation

  ENTITY schematic_symbol_port_representation;
    instantiated_template  :                                     -- reference
                             schematic_symbol_port_representation_template;
    name                                  : OPTIONAL name_information;
    implemented_master_port               : master_port;         -- reference
    overriding_ac_load_display            : OPTIONAL display_override;
    overriding_dc_fanin_load_display      : OPTIONAL display_override;
    overriding_dc_fanout_load_display     : OPTIONAL display_override;
    overriding_dc_max_fanin_display       : OPTIONAL display_override;
    overriding_dc_max_fanout_display      : OPTIONAL display_override;
    overriding_designator_display         : OPTIONAL display_override;
    overriding_implementation_name_display: OPTIONAL display_name_override;
    overriding_port_name_display          : OPTIONAL display_name_override;
    overriding_template_properties        : OPTIONAL SET [1:?] OF
                                            property_override; 
    overriding_template_property_displays : OPTIONAL SET [1:?] OF
                                            property_display_override; 
    delay_displays                        : OPTIONAL BAG [1:?] OF
                                            port_delay_display; 
    load_delay_displays                   : OPTIONAL BAG [1:?] OF
                                            port_load_delay_display; 
    port_property_displays                : OPTIONAL BAG [1:?] OF
                                            property_display; 
    template_position                     : transform;
  WHERE
    containment_constraint :
      (* A schematic_symbol_port_representation belongs to one
         internal_schematic_symbol. *) 
    belongs_to_one(SELF,
    'schematic_view_model.internal_schematic_symbol.symbol_port_representations');

    valid_overriding_template_properties :
      (* The overridden properties are defined in the instantiated_template. *)
      not_exists(QUERY(valueOverride <* overriding_template_properties |
        NOT (valueOverride.overridden_property
             IN instantiated_template.properties)));

    valid_overriding_template_property_displays :
      (* The overridden properties are defined in the instantiated_template. *)
      not_exists(QUERY(displayOverride<*overriding_template_property_displays |
        NOT (displayOverride.overridden_property
             IN instantiated_template.properties)));

    valid_delay_displays :
      (* The displayed delays are defined in the implemented master_port. *)
      not_exists(QUERY(delayDisplay <* delay_displays |
        NOT (delayDisplay.displayed_delay IN implemented_master_port.delays)));

    valid_load_delay_displays :
      (* The displayed load_delays are defined in the implemented master_port. *)
      not_exists(QUERY(loadDelayDisplay <* load_delay_displays |
        NOT (loadDelayDisplay.displayed_load_delay 
             IN implemented_master_port.load_delays)));

    valid_port_property_displays :
      (* The displayed properties are defined in the implemented_master_port. *)
      not_exists(QUERY(propertyDisplay <* port_property_displays |
        NOT (propertyDisplay.displayed_property
             IN implemented_master_port.properties)));

    matching_direction :
      (* The direction of the implemented_master_port must be compatible with the 
         direction_indicator of the symbol_port_template. *)
      not_defined; 
  END_ENTITY;

Description:

A schematic_symbol_port_representation describes a representation of a master port in an internal_schematic_symbol. It is defined by specifying the position and orientation of the occurrence of the referenced schematic_symbol_port_representation_template.

schematic_global_port_attribute

  TYPE schematic_global_port_attribute 
    = SELECT (schematic_port_ac_power, schematic_port_analog,
              schematic_port_chassis_ground, schematic_port_clock,
              schematic_port_dc_power, schematic_port_earth_ground,  
              schematic_port_ground, schematic_port_non_logical,
              schematic_port_open_collector, schematic_port_open_emitter, 
              schematic_port_power, schematic_port_three_state,
              ieee_external_reference); 
  END_TYPE;

Description:

The schematic_global_port_attribute adds description about a global_port that may be of interest to the receiving system. They are information stored in the originating system, and there are no semantic rules to enforce proper use and connection based on the schematic_global_port_attribute in EDIF.

When used in the context of schematic_global_port_representation_template, it indicates the suitability of the template to represent that type of port.

Used by:

global_port schematic_global_port_representation_template

schematic_port_ground

  ENTITY schematic_port_ground;
    used_by_analog_circuitry    : boolean_token;
  END_ENTITY;

Description:

If a master_port or a global_port has a schematic port attribute of schematic_port_ground, it represents a connection to ground. In this context, ground is the voltage reference of the circuit. It should be used when the sending system does not distinguish the type of ground precisely. The used_by_analog_circuitry attribute is a boolean flag indicating whether or not the designer has intentions for this ground to be used by analog circuitry.

schematic_port_three_state

  ENTITY schematic_port_three_state;
  END_ENTITY;

Description:

If a master_port or a global_port has a schematic port attribute of schematic_port_three_state, it indicates that the port exhibits 3 state conditions. Two of the states are signals equivalent to binary 1 and 0, similar to conventional gates. The third state is a high-impedance state. This means, for all practical purposes, that the circuit behaves as if the output is disconnected. As a consequence, the output cannot affect or be affected by any external signal when it is in a high-impedance state.

ieee_external_reference

  ENTITY ieee_external_reference;
    name    : string_token;
    year    : positive_integer_token;
    section : LIST of integer_token;
  END_ENTITY;

Description:

The ieee_external_reference is used to include a reference to a specific section of a specific IEEE standard. The standards referred to are limited to these section groups of these standards: IEEE 91-1984 -- This standard describes several kinds of input and output ports. usage is currently restricted to 3.1.1 to 3.1.11, 3.3.1 to 3.3.24, 3.3.27 to 3.4.5, and 4.3.2.1 to 4.3.11.1.

IEEE 1149.1-1990 -- This standard describes Boundary scan port types, like TCK, TMS, TDI, TDO, TRST*. The section references are restricted to 3.2 to 3.6 inclusive, which cover the ports just mentioned in the same order.

The LIST of integer forms a section reference: 3 2 1 means section 3.2.1.

Used by:

schematic_global_port_attribute schematic_port_attribute schematic_port_clock
