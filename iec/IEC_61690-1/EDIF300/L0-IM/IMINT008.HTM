Chapter 8

Units

This chapter describes the concept of units. The model for unit can be found in the support_definition_model schema.

8.1 Problem statement

In EDIF Version 2 0 0, the scaling information is defined in the technology section of a library. All cells (and consequently, all views) within the same library are compelled to use the same scale. Sometimes this is inappropriate. For example, it is inappropriate for views of type schematic and of type masklayout to be forced to use the same distance units.

In addition, EDIF Version 2 0 0 acknowledges the existence of two categories of basic units. One category is SI physical units, e.g. meter, kilogram, second and ampere; another category is derived SI units, e.g. siemens, hertz, joule and ohm. There is no way to specify a user-defined unit which is a combination of one or more basic units.

8.2 Solution

In EDIF Version 3 0 0, the solution for units is to :

a) allow the same units to be used in more than one library. They are therefore defined at the edif level,

b) allow definition of user-defined units other than the basic EDIF spplied one,

c) allow units to be chosen based on the type of view.

User definitions may be in terms of EDIF units only. It is not permissible for user-defined units to be defined in terms of other user-defined units. Also, when a cell representation is defined, it is necessary to restrict what kind of units are allowed in that type of cell representation. For example, it is inappropriate to select a unit for distance in a view of type connectivity. Table 8.1 describes what kind of units are allowed in different classes of EDIF object.
