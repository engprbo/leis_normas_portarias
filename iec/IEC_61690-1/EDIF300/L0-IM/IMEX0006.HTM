documentation_model

Description:

The documentation_model schema describes the documentation provided for an object. A documentation may consists of several sections. Each section may have text, diagrams and nested sections.

documentation

  ENTITY documentation;
    background_colour           : colour;                 
    sections                    : OPTIONAL LIST [1:?] OF section;
    status_of_copyright         : OPTIONAL SET [1:?] OF copyright;
    status_of_written           : OPTIONAL SET [1:?] OF written;
    units                       : documentation_units;
  WHERE
    containment_constraint :
      either_belongs_to_one(SELF, 
       ['connectivity_structure_model.connectivity_generic_bus.document',
        'connectivity_structure_model.connectivity_generic_net.document',
        'design_hierarchy_model.design.document',
        'edif_information_model.edif.document',
        'hierarchy_model.cell.document',
        'hierarchy_model.cell_representation.document',
        'hierarchy_model.cluster.document',
        'hierarchy_model.view_group.document',
        'instantiatable_object_model.geometry_macro_template.document',
        'instantiatable_object_model.schematic_template.document',
        'library_model.library.document',
        'schematic_implementation_model.page.document',
        'schematic_implementation_model.schematic_generic_bus.document',
        'schematic_implementation_model.schematic_generic_net.document']);
  END_ENTITY;

Description:

A documentation is used to provide documentation for an object. It may consist of several sections. Each section may have text, diagrams and nested sections.

Used by:

cell cell_representation cluster connectivity_generic_bus connectivity_generic_net design edif geometry_macro_template library page schematic_generic_bus schematic_generic_net schematic_template view_group

documentation_units

  ENTITY documentation_units;
    set_angle                   : angle_unit;
    set_distance                : distance_unit;
  END_ENTITY;

Description:

A documentation_units is used to set the scaling for a documentation. In a documentation, it is appropriate to set an angle scale and a distance scale.

Used by:

documentation physical_scaling

section

  ENTITY section;
    contents : OPTIONAL LIST [1:?] OF section_element;
    title    : string_token;
  WHERE
    containment_constraint :
      (* A section belongs to either one documentation, or another section. *)
      either_belongs_to_one(SELF, 
       ['documentation_model.documentation.sections', 
        'documentation_model.section.sub_sections']);
  END_ENTITY;

Description:

A section is used to divide a document into sections. An EDIF string_token is used to give a title to a section. A section may be nested with other sections. The body of the section is constructed using any number of EDIF string_tokens and diagrams.

Used by:

documentation section_element

section_element

  TYPE section_element
    = SELECT (diagram, section, string_token);
  END_TYPE;

Description:

A section_element describes the element which constitutes the body of a section. It can be a diagram, a string_token or a nested section.

Used by:

section

diagram

  ENTITY diagram;
    annotate                    : OPTIONAL BAG [1:?] OF string_display;
    figures                     : OPTIONAL BAG [1:?] OF figure;
  WHERE
    containment_constraint :
      (* A diagram belongs to one section. *)
      belongs_to_one(SELF, 'documentation_model.section.diagrams');
  END_ENTITY;

Description:

A diagram is used to add graphical information to a section within documentation.

Used by:

section_element
