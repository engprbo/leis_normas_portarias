edif_information_model

Description:

The edif_information_model schema describes the information held by an EDIF file. An EDIF file may contain several designs and several libraries of cell definitions. In EDIF Version 3 0 0, an EDIF file specifies physical_scaling which collects all scaling information. Consequently, it is possible that the same unit can be used in more than one library. In addition, it may specify the interpretation of the data contained in quoted strings.

edif

  ENTITY edif;
    character_encoding          : character_encoding;       
    designs                     : OPTIONAL SET [1:?] OF design;
    document                    : OPTIONAL SET [1:?] OF documentation;
    fonts                       : OPTIONAL SET [1:?] OF font;
    global_ports                : OPTIONAL SET [1:?] OF global_port;
    global_port_bundles         : OPTIONAL SET [1:?] OF global_port_bundle;
    libraries                   : OPTIONAL SET [1:?] OF library;
    name                        : OPTIONAL name_information;
    properties                  : OPTIONAL SET [1:?] OF private_property;
    scaling_information         : OPTIONAL physical_scaling;
    schematic_defaults          : OPTIONAL schematic_required_defaults;
    status_of_copyright         : OPTIONAL SET [1:?] OF copyright;
    status_of_written           : OPTIONAL SET [1:?] OF written;
    unit_definitions            : OPTIONAL SET [1:?] OF unit;
  WHERE
    valid_fonts :
      (* All fonts must have the same set_distance. *)
      not_defined;
  END_ENTITY;

Description:

An edif specifies what kind of information can be found directly in an EDIF file. An EDIF file may contain designs, documentation, units and libraries of cell definitions. An EDIF file allows the same unit to be used in more than one library. In addition, it may specify the interpretation of the data contained in quoted strings.

font

  ENTITY font;
    font_family          : string_token;
    typeface_suffix      : string_token;
    font_capital_height  : length_value;
    font_descent         : length_value;
    font_height          : length_value;
    font_width           : length_value;
    font_styles          : OPTIONAL SET [1:2] OF font_style;
    proportional_font    : boolean_token;
    properties           : OPTIONAL SET [1:?] OF private_property;
    set_distance         : distance_unit;
  WHERE
    containment_constraint :
      (* A font belongs to one edif. *)
      belongs_to_one(SELF, 'edif_information_model.edif.fonts');
  END_ENTITY;

Description:

A font defines the information needed to access font data on a system which defines how text strings are to be rendered. If an exact match for a font cannot be found, information is provided to find a substitute font. When substituting fonts or changing justifications, sufficient information is provided to adjust the text heights, origins and justifications to identify a substitute font.

The font_family defines a string name used to identify a family of typefaces. The typeface_suffix defines a suffix in a typeface name used to identify attributes of the typeface such as bold and italic. The font_capital_height is the height of capital letters. The font_descent is a characteristic of the font. It is the distance between the baseline (the bottom of capital letters) and the bottom of the font bounding box. It is the area in which the bottom parts of letters with descenders, e.g. gjpqy are drawn. The font_height is defined as the distance between the top and bottom of the font bounding box, and is used as the line to line spacing. The font bounding box includes whitespace above and possibly below the characters used in normal line spacing. The font_width defines the average separation of the characters in a rendered string. For fixed pitch fonts, the character separation is the same for all characters. For proportional fonts, this distance varies so the average value defined by the font is used. It is defined as the average of the widths (character to character spacing) of all characters defined in the font. The font_styles indicate that a font contains bold or italic characters. The proportional_font is a boolean flag which indicates whether a font contains proportionally spaced or fixed pitch characters.

font_style

  TYPE font_style
    = ENUMERATION OF (bold_style, italic_style);
  END_TYPE;

Description:

The bold_style indicates that the characters in the font are bold, and when a string is rendered it will be in bold. The italic_style indicates that the characters in the font are italic, and when a string is rendered it will be in italic.

Used by:

font

global_port

  ENTITY global_port;
    name                             : OPTIONAL name_information;
    properties                       : OPTIONAL SET [1:?] OF private_property;
    schematic_global_port_attributes : OPTIONAL SET [1:?] OF
                                       schematic_global_port_attribute; 
  DERIVE
    containing_edif      : edif                                  -- reference
                           := usedin_one_role(SELF, 
                              'edif_information_model.edif.global_ports');
    size                 : INTEGER := 1;
  WHERE
    containment_constraint :
      (* A global_port belongs to one edif. *) 
      belongs_to_one(SELF, 'edif_information_model.edif.global_ports');
  END_ENTITY;

Description:

A global_port is used to establish connectivity across instances within an instance hierarchy without passing signals through the ports of the cell clusters instantiated in the hierarchy. All signals in an instance hierarchy which refer to the same global_port are connected together, unless the global_port is scoped.

Used by:

global_port_bundle

  ENTITY global_port_bundle;
    member_ports : LIST [1:?] OF UNIQUE                          -- reference
                   global_port_or_global_port_bundle;   
    name         : OPTIONAL name_information;
    properties   : OPTIONAL SET [1:?] OF private_property;
  DERIVE
    containing_edif     : edif                                  -- reference
                          := usedin_one_role(SELF, 
                             'edif_information_model.edif.global_port_bundles');
    flattened_port_list : LIST [1:?] OF UNIQUE global_port      -- reference
                          := flatten_global_port_bundle(member_ports);
    size                : INTEGER := SIZEOF(flattened_port_list);
  WHERE
    containment_constraint :
      (* A global_port_bundle belongs to one edif. *) 
      belongs_to_one(SELF, 'edif_information_model.edif.global_port_bundles');

    valid_member_ports_in_same_edif :
      (* All member global_ports or global_port_bundles are defined in the same
         containing_edif. *)
      not_exists(QUERY(memberPort <* member_ports |
        NOT ((memberPort IN containing_edif.global_ports)
             OR (memberPort IN containing_edif.global_port_bundles))));

    valid_member_ports :
      (* A global_port_bundle cannot contain itself either directly or
         indirectly. *) 
      not_defined;
  END_ENTITY;

Description:

A global_port_bundle provides a structuring mechanism to describe a wide global port. The size of a global_port_bundle can be greater than or equal to one. A global_port_bundle can contain nested global_port_bundles.

Used by:

connectivity_generic_bus edif global_port_or_global_port_bundle schematic_generic_bus

flatten_global_port_bundle

  FUNCTION flatten_global_port_bundle
    (bundle_members : LIST OF global_port_or_global_port_bundle) 
       : LIST OF global_port;
    LOCAL
      i, j        : INTEGER;
      position    : INTEGER := 1;
      port_list   : LIST OF global_port := [ ];
      member_list : LIST OF global_port := [ ];
    END_LOCAL;

    REPEAT i := 1 TO SIZEOF(bundle_members);
      IF 'edif_information_model.global_port' IN TYPEOF(bundle_members[i]) THEN
        INSERT(port_list, bundle_members[i], position);
        position := position + 1;
      ELSE
        member_list:=flatten_global_port_bundle(bundle_members[i].member_ports);
        REPEAT j := 1 TO SIZEOF(member_list);
          INSERT(port_list, member_list[j], position);
          position := position + 1;
        END_REPEAT;
      END_IF;
    END_REPEAT;
    RETURN(port_list);
  END_FUNCTION;

Description:

The flatten_global_port_bundle function returns the flattened list of global_ports of a global_port_bundle.

Used by:

global_port_bundle

only_one_instance

  RULE only_one_instance FOR (edif);
  WHERE
    valid_size :
      (* There is only one instance of edif in the information base. *)
      SIZEOF(edif) = 1;
  END_RULE;

Description:

A constraint is required for entity edif to check that there is only one instance of edif in the information base.
