Preface

This document, which consists of the Information Model and the Reference Manual, is the authoritative reference document for EDIF Version 3 0 0. The Information Model defines the semantic content and the Reference Manual defines the syntax for EDIF Level 0 and EDIF Level 1.

The Information Model is written in EXPRESS N14, and is organized into the following sections:

Introduction:
This section provides a general overview of the information model of EDIF Version 3 0 0. It includes a description of the techniques used for modeling various EDIF concepts. It also outlines the purposes of an information model for EDIF.

EDIF Concepts:
This section introduces a general discussion of major topics in EDIF.

EXPRESS Model:
This section provides the information model of EDIF Version 3 0 0 in EXPRESS N14. The information model describes the underlying concepts of EDIF. It is divided into various schemas.

Model Dictionary:
This section gives the complete dictionaries of objects defined in the information model. The descriptions of schemas, entities and types, and of functions are available in separate dictionaries.

Appendices:
This section provides various summaries which help in the understanding of the information model. The summaries include: an introduction to the EXPRESS language, the mapping between the syntax constructs and the objects in the model, and a permuted index.
The Reference Manual is divided into the following sections:
Introduction:
The information within this section provides an overview of EDIF language basics.

Reference:
This section describes, in detail, the constructs of EDIF. This section may be used as a basic reference source. This section is presented in alphabetical order.

BNF:
This section describes the grammar of EDIF in Backus Naur Form (BNF). It may be used by experienced EDIF programmers for initial coding of a parser, and for quick reference while developing translators.

Cross Reference Summary:
This section summarizes the usage of each keyword.

Name Definitions and Scope:
This section summarizes the objects that have name definitions, the scope of these and the places where they are referenced. This section is useful as an aid to writing code to find objects that are referenced.

Syntax Structure Overview:
This section gives an informal overview of the structure of an EDIF file. It is useful to get a feel for how an EDIF file, or a particular keyword, is structured.

Permuted Index:
This section provides a cross reference between all the composite parts of keywords, e.g. all keywords containing the word "Display" are listed together. This is useful to locate keywords with similar or related meaning.

While great care has been taken to ensure accuracy and internal consistency of this document, errors or ambiguous interpretations are possible. If you note any such problems, please inform the EDIF Technical Experts Group.
