parameter_model

Description:

The parameter_model schema defines different types of parameters and parameter_assigns supported by Level 1 EDIF.

parameter

  ENTITY parameter
      ABSTRACT SUPERTYPE OF (ONEOF(boolean_parameter,
                                   integer_parameter,
                                   number_parameter,
                                   string_parameter));
    name          : OPTIONAL name_information;
    default_value : OPTIONAL expression;
  WHERE
    containment_constraint:
      (* A parameter belongs to one cluster_interface. *)
      belongs_to_one(SELF,'hierarchy_model.cluster_interface.parameters');

    valid_default_value:
      (* The default value expression may reference other parameters defined in
         the containing cluster_interface only. *) 
      not_defined;
  END_ENTITY;

Description:

 LEVEL 1
 =======
A parameter is defined within the interface of a cluster. It can be either a boolean_parameter, an integer_parameter, a number_parameter or a string_parameter. A default value may be specified in the definition of a parameter.

Used by:

cluster_interface parameter_assign parameter_display parameter_display_override

boolean_parameter

  ENTITY boolean_parameter
      SUBTYPE OF (parameter);
    SELF\parameter.default_value : OPTIONAL boolean_expression;
  END_ENTITY;

Description:

A boolean_parameter describes a parameter which its value is a boolean_expression.

Used by:

boolean_expression boolean_parameter_assign

parameter_assign

  ENTITY parameter_assign
      ABSTRACT SUPERTYPE OF (ONEOF(boolean_parameter_assign,
                                   integer_parameter_assign,
                                   number_parameter_assign,
                                   string_parameter_assign));
    assigned_parameter : parameter;                              -- reference
    assigned_value     : expression;
  WHERE
    containment_constraint:
      (* A parameter_assign belongs to one instance. *)
      belongs_to_one(SELF,'hierarchy_model.instance.parameter_assigns');

    valid_assigned_value:
      (* The assigned value expression may reference the instance_index of the
         containing instance, the for_frame_indexes of any containing
         for_frames, or other parameters defined in the cluster_interface of
         the containing view. *) 
      not_defined;
  END_ENTITY;

Description:

 LEVEL 1
 =======
A parameter_assign is used within the instance to supply values to parameters defined within the interface of the instantiated cluster.

Used by:

design_hierarchy instance

boolean_parameter_assign

  ENTITY boolean_parameter_assign
      SUBTYPE OF (parameter_assign);
    SELF\parameter_assign.assigned_parameter : boolean_parameter; -- reference
    SELF\parameter_assign.assigned_value     : boolean_expression;
  END_ENTITY;

Description:

A boolean_parameter_assign is used to assign value to a boolean_parameter. The assigned value must be a boolean_expression.

parameter_display

  ENTITY parameter_display;
    displayed_parameter         : parameter;                     -- reference
    name_display                : OPTIONAL BAG [1:?] OF display;
    value_display               : OPTIONAL BAG [1:?] OF display; 
  END_ENTITY;

Description:

 LEVEL 1
 =======
A parameter_display is used to specify display locations and display attributes for the display of parameter value and name.

Used by:

internal_schematic_symbol

parameter_display_override

  ENTITY parameter_display_override;
    displayed_parameter         : parameter;                     -- reference
    overriding_name_display     : display_name_override;
    overriding_value_display    : display_override;
  END_ENTITY;

Description:

 LEVEL 1
 =======
A parameter_display_override is used to override the display locations and display attributes for the display of a parameter value and name.
