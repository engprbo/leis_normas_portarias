connectivity_frame_model

Description:

The connectivity_frame_model schema describes the structural connectivity information of a frame in a connectivity view. That includes definitions of connectivity_frame_bus, connectivity_frame_net and connectivity_frame_ripper.

connectivity_frame_structure

  ENTITY connectivity_frame_structure;
    associated_frame       : frame;                              -- reference
    busses                 : OPTIONAL SET [1:?] OF connectivity_frame_bus;
    nested_frame_structures: OPTIONAL SET [1:?] OF connectivity_frame_structure;
    nets                   : OPTIONAL SET [1:?] OF connectivity_frame_net;
    rippers                : OPTIONAL SET [1:?] OF connectivity_frame_ripper;
  DERIVE
    containing_view : internal_connectivity_view
      := usedin_one_role(SELF, specified_role('connectivity_view_model',
                                              'internal_connectivity_view',
                                              'frame_connectivity_structures'));
    containing_frame_structure : connectivity_frame_structure
      := usedin_one_role(SELF, specified_role('connectivity_frame_model',
                                              'connectivity_frame_structure',
                                              'nested_frame_structures'));
  UNIQUE 
    uniqueness_constraint :
      (* A frame can be associated with at most one
         connectivity_frame_structure. *)
      associated_frame;
  WHERE
    containment_constraint :
      (* A connectivity_frame_structure belongs to one
         internal_connectivity_view or another connectivity_frame_structure. *)
      either_belongs_to_one(SELF,
        [specified_role('connectivity_frame_model',
                        'connectivity_frame_structure',
                        'nested_frame_structures'),
         specified_role('connectivity_view_model',
                        'internal_connectivity_view',
                        'frame_connectivity_structures')]);

    valid_associated_frame :
      (* The associated frame must be defined in the containing view or in the
         associated_frame of the containing connectivity_frame_structure. *)
         (associated_frame IN containing_view.frames)
      OR (associated_frame 
          IN containing_frame_structure.associated_frame.nested_frames);
  END_ENTITY;

Description:

 LEVEL 1
 =======
A connectivity_frame_structure describes the structural connectivity information of a frame in a connectivity view.

Used by:

connectivity_frame_bus connectivity_frame_net connectivity_frame_structure internal_connectivity_view

connectivity_frame_generic_net

  ENTITY connectivity_frame_generic_net
      ABSTRACT SUPERTYPE OF (ONEOF(connectivity_frame_net, 
                                   connectivity_frame_sub_net));
    associated_signal                   : frame_signal;         -- reference
    criticality                         : integer_token;              
    delays                              : OPTIONAL SET [1:?] OF 
                                          interconnect_delay;
    document                            : OPTIONAL SET [1:?] OF documentation;
    joined_global_ports                 : OPTIONAL SET [1:?] OF -- reference
                                          global_port;
    joined_instance_member_port_members : OPTIONAL SET [1:?] OF
                                          instance_member_port_member;
    joined_instance_ports               : OPTIONAL SET [1:?] OF -- reference
                                          instance_port;
    joined_master_ports                 : OPTIONAL SET [1:?] OF -- reference
                                          master_port; 
    joined_master_port_members          : OPTIONAL SET [1:?] OF 
                                          master_port_member;
    joined_rippers                      : OPTIONAL SET [1:?] OF -- reference
                                          connectivity_frame_ripper;
    name                                : OPTIONAL name_information;                 
    properties                          : OPTIONAL SET [1:?] OF property;
    sub_nets                            : OPTIONAL SET [1:?] OF
                                          connectivity_frame_sub_net; 
  WHERE
    valid_sub_nets :
      (* No two connectivity_frame_sub_nets may refer to the same set of ports
         and rippers. *) 
    not_exists(QUERY(net1 <* sub_nets |
      there_exists(QUERY(net2 <* sub_nets - net1 |
        (net1.joined_global_ports = net2.joined_global_ports) 
    AND (net1.joined_instance_member_port_members 
         = net2.joined_instance_member_port_members) 
    AND (net1.joined_instance_ports = net2.joined_instance_ports) 
    AND (net1.joined_master_ports = net2.joined_master_ports) 
    AND (net1.joined_master_port_members
         = net2.joined_master_port_members) 
    AND (net1.joined_rippers = net2.joined_rippers)))));
  END_ENTITY;

Description:

 LEVEL 1
 =======
A connectivity_frame_generic_net can be either a connectivity_frame_net or a connectivity_frame_sub_net. A connectivity_frame_generic_net is used in the model because of the similarity between a connectivity_frame_net and a connectivity_frame_sub_net. A connectivity_frame_net may be divided into connectivity_frame_sub_nets and a connectivity_frame_sub_net itself may also be divided into connectivity_frame_sub_nets. No two connectivity_frame_sub_nets at a given level may join to the same set of ports and rippers.

Used by:

connectivity_frame_ripper connectivity_frame_sub_net

connectivity_frame_net

  ENTITY connectivity_frame_net
      SUBTYPE OF (connectivity_frame_generic_net);
  DERIVE
    containing_frame_structure : connectivity_frame_structure    -- reference
      := usedin_one_role(SELF,
         'connectivity_frame_model.connectivity_frame_structure.nets');
  WHERE
    containment_constraint :
      (* A connectivity_frame_net belongs to a connectivity_frame_structure. *)
      belongs_to_one(SELF,
        'connectivity_frame_model.connectivity_frame_structure.nets');

    valid_associated_signal :
      (* The frame_signal associated with a connectivity_frame_net is defined in
         the associated frame of the containing connectivity_frame_structure. *)
      associated_signal IN
        containing_frame_structure.associated_frame.frame_signals; 

    valid_joined_ports : 
      (* The ports joined by a connectivity_frame_net must be a subset of the
         connectivity of the associated frame_signal. *)  

        (joined_global_ports <= associated_signal.joined_global_ports)
    AND (joined_instance_member_port_members 
         <= associated_signal.joined_instance_member_port_members)
    AND (joined_instance_ports <= associated_signal.joined_instance_ports)
    AND (joined_master_ports <= associated_signal.joined_master_ports)
    AND (joined_master_port_members 
         <= associated_signal.joined_master_port_members);

    valid_joined_rippers :
      (* The joined connectivity_frame_rippers must be defined in the
         containing connectivity_frame_structure. *) 
      joined_rippers <= containing_frame_structure.rippers;
  END_ENTITY;

Description:

 LEVEL 1
 =======
A connectivity_frame_net is defined within a connectivity_frame_structure which describes the structural connectivity information of a frame in a connectivity view. Its associated frame_signal must be defined in the associated frame of the containing connectivity_frame_structure. The global_ports, instance_ports and master_ports joined by a connectivity_frame_net must be a subset of the ones joined by its associated frame_signal. Also, all joined connectivity_frame_rippers must be defined in the containing connectivity_frame_structure.

Used by:

connectivity_frame_structure

connectivity_frame_sub_net

  ENTITY connectivity_frame_sub_net
      SUBTYPE OF (connectivity_frame_generic_net);
  DERIVE
    containing_generic_net : connectivity_frame_generic_net -- reference
      := usedin_one_role(SELF, 
         'connectivity_frame_model.connectivity_frame_generic_net.sub_nets');
  WHERE
    containment_constraint :
      (* A connectivity_frame_sub_net belongs to a
         connectivity_frame_generic_net. *) 
      belongs_to_one(SELF,
        'connectivity_frame_model.connectivity_frame_generic_net.sub_nets');

    valid_associated_signal :
      (* The frame_signal associated with a connectivity_frame_sub_net is the
         same as that of its containing connectivity_frame_generic_net. *)
      associated_signal :=: containing_generic_net.associated_signal;

    valid_joined_ports_and_rippers :
      (* The ports and rippers joined by a connectivity_frame_sub_net must be a
         subset of the ports and rippers joined by its immediately containing 
         connectivity_frame_generic_net. *)

        (joined_global_ports <= containing_generic_net.joined_global_ports)
    AND (joined_instance_member_port_members 
         <= containing_generic_net.joined_instance_member_port_members)
    AND (joined_instance_ports <= containing_generic_net.joined_instance_ports)
    AND (joined_master_ports <= containing_generic_net.joined_master_ports)
    AND (joined_master_port_members 
         <= containing_generic_net.joined_master_port_members)
    AND (joined_rippers <= containing_generic_net.joined_rippers);
  END_ENTITY;

Description:

 LEVEL 1
 =======
A connectivity_frame_sub_net must only join to ports and rippers which are already joined by its immediately containing connectivity_frame_generic_net. In addition, its associated frame_signal must be the same as that of its immediately containing connectivity_frame_generic_net.

Used by:

connectivity_frame_generic_net

connectivity_frame_generic_bus

  ENTITY connectivity_frame_generic_bus
      ABSTRACT SUPERTYPE OF (ONEOF(connectivity_frame_bus, 
                                   connectivity_frame_bus_slice, 
                                   connectivity_frame_sub_bus));
    associated_signal_group             : frame_signal_group;   -- reference
    bus_slices                          : OPTIONAL SET [1:?] OF 
                                          connectivity_frame_bus_slice;
    criticality                         : integer_token;                  
    delays                              : OPTIONAL SET [1:?] OF
                                          interconnect_delay; 
    document                            : OPTIONAL SET [1:?] OF documentation;
    joined_global_ports                 : OPTIONAL SET [1:?] OF -- reference
                                          global_port;
    joined_global_port_bundles          : OPTIONAL SET [1:?] OF -- reference
                                          global_port_bundle;
    joined_instance_member_port_members : OPTIONAL SET [1:?] OF
                                          instance_member_port_member;
    joined_instance_ports               : OPTIONAL SET [1:?] OF -- reference
                                          instance_port;
    joined_instance_port_bundles        : OPTIONAL SET [1:?] OF -- reference
                                          instance_port_bundle;
    joined_local_master_port_groups     : OPTIONAL SET [1:?] OF -- reference
                                          local_master_port_group;
    joined_master_ports                 : OPTIONAL SET [1:?] OF -- reference
                                          master_port; 
    joined_master_port_bundles          : OPTIONAL SET [1:?] OF -- reference
                                          master_port_bundle;           
    joined_master_port_members          : OPTIONAL SET [1:?] OF
                                          master_port_member;
    joined_rippers                      : OPTIONAL SET [1:?] OF -- reference
                                          connectivity_frame_ripper;
    name                                : OPTIONAL name_information;                 
    properties                          : OPTIONAL SET [1:?] OF property;
    sub_busses                          : OPTIONAL SET [1:?] OF
                                          connectivity_frame_sub_bus; 
  DERIVE
    signal_group_size : INTEGER 
      := SIZEOF(associated_signal_group.flattened_signal_list);
  WHERE
    valid_joined_port_size :
      (* All joined global_ports, global_port_bundles,
         local_master_port_groups, master_ports and master_port_bundles must 
         have the same port size as the size of the flattened signal_group. *)

        (not_exists(QUERY(joinedGlobalPort <* joined_global_ports |
           joinedGlobalPort.size <> signal_group_size)))
    AND (not_exists(QUERY(joinedGlobalPortBundle <* joined_global_port_bundles |
           joinedGlobalPortBundle.size <> signal_group_size)))
    AND (not_exists(QUERY(joinedLocalMasterPortGroup 
           <* joined_local_master_port_groups |
           joinedLocalMasterPortGroup.size <> signal_group_size)))
    AND (not_exists(QUERY(joinedMasterPort <* joined_master_ports |
           joinedMasterPort.size <> signal_group_size)))
    AND (not_exists(QUERY(joinedMasterPortBundle <* joined_master_port_bundles |
           joinedMasterPortBundle.size <> signal_group_size)));

    valid_structural_connectivity :
      not_defined;

    valid_bus_slices :
      (* No two bus_slices within a connectivity_frame_generic_bus may reference
         the same frame_signal_group. *)
      not_exists(QUERY(busSlice1 <* bus_slices |
        there_exists(QUERY(busSlice2 <* bus_slices - busSlice1 |
          busSlice1.associated_signal_group :=: 
            busSlice2.associated_signal_group))));

    valid_sub_busses :
      (* No two sub_busses within a connectivity_frame_generic_bus may refer to
         the same set of ports and rippers. *)  
    not_exists(QUERY(bus1 <* sub_busses |
      there_exists(QUERY(bus2 <* sub_busses - bus1 |
        (bus1.joined_global_ports = bus2.joined_global_ports) 
    AND (bus1.joined_global_port_bundles = bus2.joined_global_port_bundles) 
    AND (bus1.joined_instance_member_port_members 
         = bus2.joined_instance_member_port_members) 
    AND (bus1.joined_instance_ports = bus2.joined_instance_ports) 
    AND (bus1.joined_instance_port_bundles = bus2.joined_instance_port_bundles)
    AND (bus1.joined_local_master_port_groups 
         = bus2.joined_local_master_port_groups) 
    AND (bus1.joined_master_ports = bus2.joined_master_ports) 
    AND (bus1.joined_master_port_bundles = bus2.joined_master_port_bundles) 
    AND (bus1.joined_master_port_members = bus2.joined_master_port_members) 
    AND (bus1.joined_rippers = bus2.joined_rippers)))));
  END_ENTITY;

Description:

 LEVEL 1
 =======
A connectivity_frame_generic_bus can be either a connectivity_frame_bus, a connectivity_frame_bus_slice or a connectivity_frame_sub_bus. A connectivity_frame_generic_bus is used in the model because of the similarity between a connectivity_frame_bus, a connectivity_frame_bus_slice and a connectivity_frame_sub_bus. They may all contain connectivity_frame_bus_slices and connectivity_frame_sub_busses. No two connectivity_frame_bus_slices at a given level may be associated with the same frame_signal_group. No two connectivity_frame_sub_busses at a given level may join to the same set of ports and rippers.

Used by:

connectivity_frame_bus_slice connectivity_frame_ripper connectivity_frame_sub_bus

connectivity_frame_bus

  ENTITY connectivity_frame_bus
      SUBTYPE OF (connectivity_frame_generic_bus);
  DERIVE
    containing_frame_structure : connectivity_frame_structure    -- reference
      := usedin_one_role(SELF,
         'connectivity_frame_model.connectivity_frame_structure.busses');
  WHERE
    containment_constraint :
      (* A connectivity_frame_bus belongs to a connectivity_frame_structure. *)
      belongs_to_one(SELF,
        'connectivity_frame_model.connectivity_frame_structure.busses');

    valid_associated_signal_group :
      (* The frame_signal_group associated with a connectivity_frame_bus is
         defined in the associated frame of the containing
         connectivity_frame_structure. *) 
      associated_signal_group IN
        containing_frame_structure.associated_frame.frame_signal_groups; 

    valid_joined_rippers :
      (* The joined connectivity_frame_rippers must be defined in the
         containing connectivity_frame_structure. *) 
      joined_rippers <= containing_frame_structure.rippers;
  END_ENTITY;

Description:

 LEVEL 1
 =======
A connectivity_frame_bus is defined within a connectivity_frame_structure which describes the structural connectivity information of a frame in a connectivity view. Its associated frame_signal_group must be defined in the associated frame of the containing connectivity_frame_structure. A connectivity_frame_bus may be subdivided in two orthogonal ways. It may be divided into connectivity_frame_bus_slices or into connectivity_frame_sub_busses. Also, all joined connectivity_frame_rippers must be defined in the containing connectivity_frame_structure.

Used by:

connectivity_frame_structure

connectivity_frame_bus_slice

  ENTITY connectivity_frame_bus_slice
      SUBTYPE OF (connectivity_frame_generic_bus);
  DERIVE
    containing_generic_bus  : connectivity_frame_generic_bus -- reference
      := usedin_one_role(SELF, 
         'connectivity_frame_model.connectivity_frame_generic_bus.bus_slices');
  WHERE
    containment_constraint :
      (* A connectivity_frame_bus_slice belongs to a
         connectivity_frame_generic_bus.*)  
      belongs_to_one(SELF,
        'connectivity_frame_model.connectivity_frame_generic_bus.bus_slices');

    valid_associated_signal_group :
      (* The frame_signal_group associated with a connectivity_frame_bus_slice
         is a member of the frame_signal_group associated with its immediately
         containing connectivity_frame_generic_bus.*) 
       not_defined;

    valid_joined_rippers :
      (* The joined connectivity_frame_rippers must be defined in the
         containing connectivity_frame_structure. *) 
      not_defined;
  END_ENTITY;

Description:

 LEVEL 1
 =======
A connectivity_frame_bus_slice is used to define part of a connectivity_frame_bus that has a size less than the size of the immediately enclosing connectivity_frame_generic_bus. Its associated frame_signal_group must be a member of the frame_signal_group associated with its immediately containing connectivity_frame_generic_bus. All joined connectivity_frame_rippers must be defined in the containing connectivity_frame_structure.

Used by:

connectivity_frame_generic_bus

connectivity_frame_sub_bus

  ENTITY connectivity_frame_sub_bus
      SUBTYPE OF (connectivity_frame_generic_bus);
  DERIVE
    containing_generic_bus  : connectivity_frame_generic_bus -- reference
      := usedin_one_role(SELF, 
         'connectivity_frame_model.connectivity_frame_generic_bus.sub_busses');
  WHERE
    containment_constraint :
      (* A connectivity_frame_sub_bus belongs to a
         connectivity_frame_generic_bus. *) 
      belongs_to_one(SELF,
        'connectivity_frame_model.connectivity_frame_generic_bus.sub_busses');

    valid_associated_signal_group :
      (* The frame_signal_group associated with a connectivity_frame_sub_bus is
         the same as its containing connectivity_frame_generic_bus. *)
      associated_signal_group :=: containing_generic_bus.associated_signal_group;

    valid_joined_ports_and_rippers :
      (* The ports and rippers joined by a connectivity_frame_sub_bus must be a
         subset of the ones joined by its immediately containing
         connectivity_frame_generic_bus. *)    

        (joined_global_ports <= containing_generic_bus.joined_global_ports)
    AND (joined_global_port_bundles 
         <= containing_generic_bus.joined_global_port_bundles)
    AND (joined_instance_member_port_members 
         <= containing_generic_bus.joined_instance_member_port_members)
    AND (joined_instance_ports <= containing_generic_bus.joined_instance_ports)
    AND (joined_instance_port_bundles 
         <= containing_generic_bus.joined_instance_port_bundles)
    AND (joined_local_master_port_groups 
         <= containing_generic_bus.joined_local_master_port_groups)
    AND (joined_master_ports <= containing_generic_bus.joined_master_ports)
    AND (joined_master_port_bundles 
         <= containing_generic_bus.joined_master_port_bundles)
    AND (joined_master_port_members 
         <= containing_generic_bus.joined_master_port_members)
    AND (joined_rippers <= containing_generic_bus.joined_rippers);
  END_ENTITY;

Description:

 LEVEL 1
 =======
A connectivity_frame_sub_bus has the same size as the connectivity_frame_generic_bus immediately containing it. It associated frame_signal_group is the same as that of its immediately containing connectivity_frame_generic_bus. A connectivity_frame_sub_bus must only join to ports and rippers which are already joined by its immediately containing connectivity_frame_generic_bus.

Used by:

connectivity_frame_generic_bus

connectivity_frame_ripper

  ENTITY connectivity_frame_ripper;
  DERIVE
    related_nets : SET OF connectivity_frame_generic_net         -- reference
     := USEDIN(SELF, 
        'connectivity_frame_model.connectivity_frame_generic_net.joined_rippers');
    related_busses : SET OF connectivity_frame_generic_bus       -- reference
     := USEDIN(SELF, 
        'connectivity_frame_model.connectivity_frame_generic_bus.joined_rippers');
  WHERE
    containment_constraint :
      (* A connectivity_frame_ripper belongs to one
         connectivity_frame_structure. *)  
      belongs_to_one(SELF,
        'connectivity_frame_model.connectivity_frame_structure.rippers');

    valid_related_busses_and_nets :
      (* All related bus/net structures must belong to the same
         connectivity_frame_structure. *) 
      not_defined;
  END_ENTITY;

Description:

A connectivity_frame_ripper is used to define a relationship between net and bus structures in a connectivity_frame_structure.

Used by:
