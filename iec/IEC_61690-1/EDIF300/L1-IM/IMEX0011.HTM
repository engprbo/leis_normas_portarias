geometry_model

Description:

The geometry_model schema describes all geometrical definitions in EDIF. This includes dot, circle, polygon, rectangle, shape, open_shape and path. In addition, property is removed from all geometry definitions; this differs from EDIF Version 2 0 0.

geometry_element

  ENTITY geometry_element
      ABSTRACT SUPERTYPE OF (ONEOF(dot, 
                                   closed_area_element, 
                                   open_element));       
  END_ENTITY;

Description:

A geometry_element describes geometry definition in EDIF. This includes dot, circle, polygon, rectangle, shape, open_shape and path. In addition, property is removed from geometry definition; this differs from EDIF Version 2 0 0.

Used by:

figure internal_geometry_macro_template

dot

  ENTITY dot
      SUBTYPE OF (geometry_element);
    position                    : integer_point;
  END_ENTITY;

Description:

A dot is a geometry_element which is defined by a single point and is intended for use in schematic diagrams and other places where a marker is required. A dot is intended to be used for display purposes only and is not permitted to be used for fabrication.

Used by:

dot_display

closed_area_element

  ENTITY closed_area_element
      ABSTRACT SUPERTYPE OF (ONEOF(circle, polygon, rectangle, shape))
      SUBTYPE OF (geometry_element);
  END_ENTITY;

Description:

A closed_area_element describes a geometry_element which encloses an area. It can be either a circle, a polygon, a rectangle or a shape.

Used by:

closed_area_display

open_element

  ENTITY open_element
      ABSTRACT SUPERTYPE OF (ONEOF(path, open_shape))
      SUBTYPE OF (geometry_element);
  END_ENTITY;

Description:

An open_element describes a geometry_element which does not enclose an area. It can be either a path or an open_shape.

Used by:

path_display

circle

  ENTITY circle 
      SUBTYPE OF (closed_area_element); 
    diameter                    : line_segment;
  END_ENTITY;

Description:

A circle is used to describe a circle which has the specified points at either end of a diameter of the circle. The two points need not be distinct.

polygon

  ENTITY polygon
      SUBTYPE OF (closed_area_element);
    segments                    : LIST [3:?] OF line_segment; 
  WHERE                                                                       
    joined_segments :
      (* All adjacent segments are joined. *)
      connected(segments);

    closed_element : 
      (* The first segment is joined with the last segment. *)
      segments[1].start_point = segments[HIINDEX(segments)].end_point; 

    not_self_intersecting :
      (* A polygon may not intersect or touch itself, nor have coincidence
         segments. *) 
      not_defined; 
  END_ENTITY;

Description:

A polygon represents a figure bounded by line_segments. The number of line_segments must be at least three. A polygon must not intersect or touch itself, nor may it have coincident segments.

rectangle

  ENTITY rectangle
      SUBTYPE OF (closed_area_element);
    diagonal                    : line_segment;
  DERIVE
    segments : LIST [4:4] OF line_segment 
               := find_segments(diagonal.start_point, diagonal.end_point);
  END_ENTITY;

Description:

A rectangle is a four-sided polygon with sides parallel to the axes. It is specified by the end-points of either diagonal.

Used by:

comment_graphics external_schematic_symbol geometry_macro_template internal_schematic_symbol page page_border_template schematic_for_frame_border_template schematic_if_frame_border_template schematic_otherwise_frame_border_template schematic_symbol_border_template schematic_template

shape

  ENTITY shape
      SUBTYPE OF (closed_area_element);
    segments                    : LIST [2:?] OF arc_or_line_segment; 
  WHERE
    joined_segments :
      (* All adjacent segments are joined. *)
      connected(segments);     

    closed_element : 
      (* the first segment is joined with the last segment. *)
      segments[1].start_point = segments[HIINDEX(segments)].end_point; 

    not_self_intersecting :
      (* A shape must not intersect or touch itself, nor have coincidence
         segments. *) 
      not_defined; 
  END_ENTITY;

Description:

A shape is a sequence of connected arcs and line_segments. It is used to describe shapes which are closed by definition. A shape must not intersect or touch itself, nor may its edges be coincident.

path

  ENTITY path
      SUBTYPE OF (open_element);
    segments                    : LIST [1:?] OF line_segment;
  WHERE
    joined_segments :
      (* All adjacent segments are joined. *)
      connected(segments);
  END_ENTITY;

Description:

A path is an open_element which is described by a sequence of connected line_segments. It is open by definition.

open_shape

  ENTITY open_shape
      SUBTYPE OF (open_element);
    segments                    : LIST [1:?] OF arc_or_line_segment;
  WHERE
    joined_segments :
      (* All adjacent segments are joined. *)
      connected(segments);
  END_ENTITY;

Description:

An open_shape is an open_element which is described by a sequence of connected arcs and line_segments. It is open by definition.

arc_or_line_segment

  TYPE arc_or_line_segment
      = SELECT (arc, line_segment);
  END_TYPE;

Description:

An arc_or_line_segment is used to describe the concept of curve in EDIF. Curve is described by a list of arc_or_line_segment.

Used by:

open_shape shape

arc

  ENTITY arc ;
    start_point                 : integer_point;
    through_point               : number_point;
    end_point                   : integer_point;
  WHERE
    distinct_points :
      (* The three points of the arc specification must be distinct. *)
          (start_point.x_coordinate <> through_point.x_coordinate) 
      AND (start_point.y_coordinate <> through_point.y_coordinate) 
      AND (through_point.x_coordinate <> end_point.x_coordinate) 
      AND (through_point.y_coordinate <> end_point.y_coordinate) 
      AND (start_point.x_coordinate <> end_point.x_coordinate)
      AND (start_point.y_coordinate <> end_point.y_coordinate);

    the_three_points_should_not_lie_on_a_straight_line :
      not_defined; 
  END_ENTITY;

Description:

An arc is used in describing shapes with curved edges. It is defined by three points. Each point coordinate is specified in distance value. The point coordinate values of the starting point and the end point of the arc must be integers. The point coordinate values of the middle point of the arc can be given as numbers.

Used by:

arc_or_line_segment

line_segment

  ENTITY line_segment;
    start_point                    : integer_point;
    end_point                      : integer_point;
  END_ENTITY;

Description:

A line_segment is defined by two points which specify the starting point and the end point of a line segment. The starting and the end points need not be distinct.

connected

  FUNCTION connected 
    (segments : LIST OF arc_or_line_segment) : BOOLEAN;
    LOCAL
      i       : INTEGER;
    END_LOCAL;

    REPEAT i := 1 TO HIINDEX(segments)-1;
      IF segments[i].end_point <> segments[i+1].start_point THEN
         RETURN(FALSE);
      END_IF;
    END_REPEAT;
    RETURN(TRUE);  
  END_FUNCTION;

Description:

The connected function accepts a list of arc or line_segment elements as its argument. It checks that the last point of each arc or line_segment element is the same as the first point of the next arc or line_segment element on the list.

Used by:

open_shape path polygon shape

find_segments

  FUNCTION find_segments
    (p1, p2 : integer_point) : AGGREGATE OF line_segment;
    -- points p1, p2 and points p3, p4 are end-points of two diagonals
    LOCAL
      lines  : LIST OF line_segment := [ ];
      p3, p4 : integer_point;
    END_LOCAL;
    p3.x_coordinate := p2.x_coordinate; p3.y_coordinate := p1.y_coordinate;
    p4.x_coordinate := p1.x_coordinate; p4.y_coordinate := p2.y_coordinate;
    lines[1].start_point := p1; lines[1].end_point := p3;
    lines[2].start_point := p3; lines[2].end_point := p2;
    lines[3].start_point := p2; lines[3].end_point := p4;
    lines[4].start_point := p4; lines[4].end_point := p1;
    RETURN(lines);  
  END_FUNCTION;

Description:

The find_segments function accepts two points which are the end-points of a diagonal of a rectangle. It will return the four ordered line_segments which constitute the rectangle.

Used by:

rectangle
