design_hierarchy_model

Description:

The design_hierarchy_model schema describes the annotation data relating to an occurrence hierarchy. A design_hierarchy is defined by choosing the top cluster_configuration. It is annotated by an occurrence_hierarchy_annotate. Interconnects and master ports within the top occurrence can be annotated by interconnect_annotate and master_port_annotate respectively. If further annotation is to be given for occurrences further down in the occurrence hierarchy, occurrence_annotate can be used to specify which occurrence is to be annotated next. Similarly, interconnects and instance ports within an occurrence can be annotated by interconnect_annotate and instance_port_annotate respectively.

design

  ENTITY design;
    design_hierarchies     : OPTIONAL SET [1:?] OF design_hierarchy;
    document               : OPTIONAL SET [1:?] OF documentation;
    name                   : OPTIONAL name_information; 
    properties             : OPTIONAL SET [1:?] OF private_property;
    top_cell               : cell;                               -- reference
    units                  : design_units;
    status_of_copyright    : OPTIONAL SET [1:?] OF copyright;
    status_of_written      : OPTIONAL SET [1:?] OF written;
  WHERE
    containment_constraint :
      (* A design belongs to one edif file. *)
      belongs_to_one(SELF, 'edif_information_model.edif.designs');

    valid_design_hierarchies :
      (* All design_hierarchies start with cluster_configurations which are
         defined in the clusters of the top_cell. *)
      not_exists(QUERY(designHierarchy <* design_hierarchies |
        NOT (designHierarchy.chosen_cluster_configuration.containing_cluster
          IN top_cell.clusters)));
  END_ENTITY;

Description:

A design identifies the cell at the top level of the hierarchy of a particular design within a library. It may have multiple design hierarchies.

design_hierarchy

  ENTITY design_hierarchy;
    chosen_cluster_configuration   : cluster_configuration;      -- reference
    name                           : OPTIONAL name_information;
    occurrence_hierarchy_annotate  : OPTIONAL occurrence_hierarchy_annotate; 
    parameter_assigns              : OPTIONAL SET [1:?] OF

      (* A design_hierarchy belongs to one design. *)
      belongs_to_one(SELF,

    valid_parameter_assigns :
      (* The assigned parameters are defined in the interface of the cluster

A design_hierarchy specifies an expanded occurrence hierarchy by selecting the top cluster_configuration. The chosen cluster_configuration must be defined in the cluster_interface of the top_cell in a design.

occurrence_hierarchy_annotate

  ENTITY occurrence_hierarchy_annotate;
    interconnect_annotates       : OPTIONAL SET [1:?] OF interconnect_annotate;
    leaf_occurrence_annotates    : OPTIONAL SET [1:?] OF leaf_occurrence_annotate;
    master_port_annotates        : OPTIONAL SET [1:?] OF master_port_annotate;
    occurrence_annotates         : OPTIONAL SET [1:?] OF occurrence_annotate;
    overriding_cell_properties   : OPTIONAL SET [1:?] OF property_override;
    overriding_cluster_properties: OPTIONAL SET [1:?] OF property_override;
    overriding_designator        : OPTIONAL string_token;
    overriding_view_properties   : OPTIONAL SET [1:?] OF property_override;
    signal_annotates             : OPTIONAL SET [1:?] OF signal_annotate;
  DERIVE
    chosen_view : cell_representation -- reference
     := containing_design_hierarchy
        .chosen_cluster_configuration.chosen_cell_representation;
    containing_design_hierarchy : design_hierarchy -- reference
     := usedin_one_role(SELF,
        'design_hierarchy_model.design_hierarchy.occurrence_hierarchy_annotate');
  WHERE
    containment_constraint :
      (* An occurrence_hierarchy_annotate belongs to one design_hierarchy. *)
      belongs_to_one(SELF,
        'design_hierarchy_model.design_hierarchy.occurrence_hierarchy_annotate');

    valid_interconnect_annotates :
      (* The annotated interconnects are defined in the chosen_view of the
         top occurrence.  No two interconnect_annotates annotate the same
         interconnect. *)
      not_defined;

    valid_leaf_occurrence_annotates :
      (* The annotated leaf occurrence must reference instance_configurations
         which are defined in the chosen cluster_configuration of the
         containing design_hierarchy. *)
      not_exists(QUERY(leafOccurrenceAnnotate <* leaf_occurrence_annotates |
        NOT (leafOccurrenceAnnotate.chosen_instance_configuration
             IN containing_design_hierarchy.chosen_cluster_configuration
                .instance_configurations)));

    valid_master_port_annotates :
      (* The annotated master_ports are defined in the interface of the
         chosen_view of the top occurrence.  No two master_port_annotates
         annotate the same master_port. *)  
        not_exists(QUERY(portAnnotate <* master_port_annotates |
          NOT (portAnnotate.annotated_port IN chosen_view.interface.ports)))
    AND not_exists(QUERY(portAnnotate1 <* master_port_annotates |
          there_exists(QUERY(portAnnotate2 
            <* master_port_annotates - portAnnotate1 |
            portAnnotate1.annotated_port :=: portAnnotate2.annotated_port))));

    valid_occurrence_annotates :
      (* The next level occurrence_annotates must reference
         instance_configurations which are defined in the chosen
         cluster_configuration of the containing design_hierarchy. *)
      not_exists(QUERY(occurrenceAnnotate <* occurrence_annotates |
        NOT (occurrenceAnnotate.chosen_instance_configuration
             IN containing_design_hierarchy.chosen_cluster_configuration
                .instance_configurations)));

    valid_overriding_cell_properties :
      (* The overridden properties are defined in the containing cell of the
         chosen_view of the top occurrence. *)
      not_exists(QUERY(cellPropertyOverride <* overriding_cell_properties |
        NOT (cellPropertyOverride.overridden_property
             IN chosen_view.containing_cluster.containing_cell.properties)));

    valid_overriding_cluster_properties :
      (* The overridden properties are defined in the containing cluster of the
         chosen_view of the top occurrence. *)
      not_exists(QUERY(clusterPropertyOverride <* overriding_cluster_properties |
        NOT (clusterPropertyOverride.overridden_property
             IN chosen_view.containing_cluster.properties)));

    valid_overriding_view_properties :
      (* The overridden properties are defined in the chosen_view of the top
         occurrence. *)
      not_exists(QUERY(viewPropertyOverride <* overriding_view_properties |
        NOT (viewPropertyOverride.overridden_property 
             IN chosen_view.properties)));

    valid_signal_annotates :
      (* The annotated signals are defined in the chosen_view of the top
         occurrence.  No two signal_annotates annotate the same signal. *)  
      not_defined;
  END_ENTITY;

Description:

An occurrence_hierarchy_annotate is used to annotate the top level occurrence of a design_hierarchy. The view chosen for annotation is specified by the cluster_configuration in the containing design_hierarchy.

Used by:

design_hierarchy

occurrence_annotate

  ENTITY occurrence_annotate;
   chosen_instance_configuration : instance_configuration;     -- reference
   instance_member_index         : integer_token;
   instance_port_annotates       : OPTIONAL SET [1:?] OF instance_port_annotate;
   interconnect_annotates        : OPTIONAL SET [1:?] OF interconnect_annotate;
   leaf_occurrence_annotates     : OPTIONAL SET [1:?] OF leaf_occurrence_annotate;
   new_instance_properties       : OPTIONAL SET [1:?] OF property;
   occurrence_annotates          : OPTIONAL SET [1:?] OF occurrence_annotate;
   overriding_cell_properties    : OPTIONAL SET [1:?] OF property_override;
   overriding_cluster_properties : OPTIONAL SET [1:?] OF property_override;
   overriding_designator         : OPTIONAL string_token;
   overriding_instance_properties: OPTIONAL SET [1:?] OF property_override;
   overriding_view_properties    : OPTIONAL SET [1:?] OF property_override;
   signal_annotates              : OPTIONAL SET [1:?] OF signal_annotate;
  DERIVE
    annotated_instance : instance -- reference
      := chosen_instance_configuration.configured_instance;
    chosen_view_for_annotated_instance : cell_representation -- reference
      := chosen_instance_configuration
         .chosen_cluster_configuration.chosen_cell_representation; 
  WHERE
    containment_constraint :
      (* An occurrence_annotate belongs to either one
         occurrence_hierarchy_annotate or one occurrence_annotate . *)
    either_belongs_to_one(SELF,
     ['design_hierarchy_model.occurrence_hierarchy_annotate.occurrence_annotates',
      'design_hierarchy_model.occurrence_annotate.occurrence_annotates']);

    valid_chosen_instance_configuration :
      (* The chosen instance_configuration must reference an
         expandable_cluster_configuration. *) 
         'hierarchy_model.expandable_cluster_configuration' IN 
            TYPEOF(chosen_instance_configuration.chosen_cluster_configuration);

    valid_instance_port_annotates :
      (* The annotated instance_ports reference the annotated_instance.  No two
         instance_port_annotates annotate the same instance_port. *) 
        not_exists(QUERY(portAnnotate <* instance_port_annotates |
          NOT (portAnnotate.annotated_port.referenced_instance 
               :<>: annotated_instance)))
    AND not_exists(QUERY(portAnnotate1 <* instance_port_annotates |
          there_exists(QUERY(portAnnotate2 
            <* instance_port_annotates - portAnnotate1 |
            portAnnotate1.annotated_port :=: portAnnotate2.annotated_port))));

    valid_interconnect_annotates :
      (* The annotated interconnects are defined in the chosen_view for the
         annotated_instance.  No two interconnect_annotates annotate the same
         interconnect. *)
      not_defined;

    valid_leaf_occurrence_annotates :
      (* The annotated leaf occurrences must reference instance_configurations
         defined in the cluster_configuration which are chosen by the
         instance_configuration. *)
      not_exists(QUERY(leafOccurrenceAnnotate <* leaf_occurrence_annotates |
        NOT (leafOccurrenceAnnotate.chosen_instance_configuration
             IN chosen_instance_configuration
                .chosen_cluster_configuration.instance_configurations)));

    valid_occurrence_annotates :
      (* The next level occurrence_annotates must reference
         instance_configurations defined in the cluster_configuration which are
         chosen by the instance_configuration. *) 
      not_exists(QUERY(occurrenceAnnotate <* occurrence_annotates |
        NOT (occurrenceAnnotate.chosen_instance_configuration
             IN chosen_instance_configuration
                .chosen_cluster_configuration.instance_configurations)));

    valid_overriding_cell_properties :
      (* The overridden properties are defined in the containing cell of the
         instantiated cluster of the annotated_instance. *)
      not_exists(QUERY(cellPropertyOverride <* overriding_cell_properties |
        NOT (cellPropertyOverride.overridden_property
        IN annotated_instance.instantiated_cluster.containing_cell.properties)));

    valid_overriding_cluster_properties :
      (* The overridden properties are defined in the instantiated cluster of
         the annotated_instance. *)
      not_exists(QUERY(clusterPropertyOverride <* overriding_cluster_properties |
        NOT (clusterPropertyOverride.overridden_property
             IN annotated_instance.instantiated_cluster.properties)));

    valid_overriding_instance_properties :
      (* The overridden properties are defined in the annotated_instance. *)
      not_exists(QUERY(instancePropertyOverride <* overriding_instance_properties|
        NOT (instancePropertyOverride.overridden_property 
             IN annotated_instance.properties)));

    valid_overriding_view_properties :
      (* The overridden properties are defined in the chosen_view for the
         annotated_instance. *)
      not_exists(QUERY(viewPropertyOverride <* overriding_view_properties |
        NOT (viewPropertyOverride.overridden_property 
             IN chosen_view_for_annotated_instance.properties)));

    valid_signal_annotates :
      (* The annotated signals are defined in the chosen_view for the
         annotated_instance.  No two signal_annotates annotate the same signal. *)
      not_defined;
  END_ENTITY;

Description:

An occurrence_annotate is used to annotate occurrences of any level (apart from the top level and the leaf level occurrences) in an occurrence hierarchy. It has a reference to an instance_configuration which selects the annotated instance and the chosen view for the annotated instance. It is possible to annotate a member of an instance occurrence in the context of an expanded occurrence hierarchy by specifying the index value of the annotated member. If the width of the annotated instance is N after the expansion, the specified index value must be in the range from 0 to N-1.

  ENTITY master_port_annotate
      ABSTRACT SUPERTYPE OF (ONEOF(input_master_port_annotate, 
                                   output_master_port_annotate,
                                   bidirectional_master_port_annotate, 
                                   unspecified_direction_master_port_annotate)); 
    annotated_port              : master_port;                   -- reference
    annotated_port_member_index : integer_token;
    new_delays                  : OPTIONAL SET [1:?] OF port_delay;
    new_load_delays             : OPTIONAL SET [1:?] OF port_load_delay;
    new_properties              : OPTIONAL SET [1:?] OF property;
    overriding_ac_load          : OPTIONAL capacitance_value;
    overriding_delays           : OPTIONAL SET [1:?] OF port_delay_override;
    overriding_designator       : OPTIONAL string_token;
    overriding_load_delays      : OPTIONAL SET [1:?] OF port_load_delay_override;
    overriding_properties       : OPTIONAL SET [1:?] OF property_override;
  WHERE
    containment_constraint :
      (* A master_port_annotate belongs to one occurrence_hierarchy_annotate. *)
    belongs_to_one(SELF,
    'design_hierarchy_model.occurrence_hierarchy_annotate.master_port_annotates');

    valid_overriding_delays :
      (* The overridden delays are defined in the annotated master_port. *)
      not_exists(QUERY(delayOverride <* overriding_delays |
        NOT (delayOverride.overridden_delay IN annotated_port.delays)));

    valid_overriding_load_delays :
      (* The overridden load_delays are defined in the annotated master_port. *)
      not_exists(QUERY(delayOverride <* overriding_load_delays |
        NOT (delayOverride.overridden_load_delay IN annotated_port.load_delays)));

    valid_overriding_properties :
      (* The overridden properties are defined in the annotated master_port. *)
      not_exists(QUERY(portPropertyOverride <* overriding_properties |
        NOT (portPropertyOverride.overridden_property
             IN annotated_port.properties)));
  END_ENTITY;

It is possible to annotate a member of a master_port occurrence in the context of an expanded occurrence hierarchy by specifying the index value of the annotated member. If the width of the annotated port is N after the expansion, the specified index value must be in the range from 0 to N-1.

instance_port_annotate

  ENTITY instance_port_annotate
      ABSTRACT SUPERTYPE OF (ONEOF(input_instance_port_annotate, 
                                   output_instance_port_annotate,
                                   bidirectional_instance_port_annotate, 
                                   unspecified_direction_instance_port_annotate));
    annotated_port              : instance_port;                 -- reference
    annotated_port_member_index : integer_token;
    new_delays                  : OPTIONAL SET [1:?] OF port_delay;
    new_load_delays             : OPTIONAL SET [1:?] OF port_load_delay;
    new_properties              : OPTIONAL SET [1:?] OF property;
    overriding_ac_load          : OPTIONAL capacitance_value;
    overriding_delays           : OPTIONAL SET [1:?] OF port_delay_override;
    overriding_designator       : OPTIONAL string_token;
    overriding_load_delays      : OPTIONAL SET [1:?] OF port_load_delay_override;
    overriding_properties       : OPTIONAL SET [1:?] OF property_override;
  WHERE
    containment_constraint :
      (* An instance_port_annotate belongs to either one occurrence_annotate or
         one leaf_occurrence_annotate. *) 
    either_belongs_to_one(SELF,
     ['design_hierarchy_model.occurrence_annotate.instance_port_annotates',
      'design_hierarchy_model.leaf_occurrence_annotate.instance_port_annotates']);

    valid_overriding_delays :
      (* The overridden delays are defined in the annotated instance_port or in
         the referenced master_port definition. *)
      not_exists(QUERY(delayOverride <* overriding_delays |
        NOT ((delayOverride.overridden_delay IN annotated_port.new_delays)
              OR (delayOverride.overridden_delay 
                  IN annotated_port.referenced_master_port.delays))));

    valid_overriding_load_delays :
      (* The overridden load_delays are defined in the annotated instance_port
         or in the referenced master_port definition. *)
      not_exists(QUERY(delayOverride <* overriding_delays |
        NOT ((delayOverride.overridden_load_delay 
              IN annotated_port.new_load_delays)
              OR (delayOverride.overridden_load_delay 
                  IN annotated_port.referenced_master_port.load_delays))));

    valid_overriding_properties :
      (* The overridden properties are defined in the annotated_port or in the
         referenced master_port definition. *)
      not_exists(QUERY(portPropertyOverride <* overriding_properties |
        NOT ((portPropertyOverride.overridden_property
              IN annotated_port.new_properties)
              OR (portPropertyOverride.overridden_property
                  IN annotated_port.referenced_master_port.properties))));
  END_ENTITY;

Description:

An instance_port_annotate is used within an occurrence_annotate or a leaf_occurrence_annotate to attach or modify properties and attributes which are associated with an instance_port occurrence within an occurrence hierarchy. It is possible to annotate a member of an instance_port occurrence in the context of an expanded occurrence hierarchy by specifying the index value of the annotated member. If the width of the annotated port is N after the expansion, the specified index value must be in the range from 0 to N-1.

      ['design_hierarchy_model.occurrence_hierarchy_annotate.signal_annotates',
       'design_hierarchy_model.occurrence_annotate.signal_annotates']);

    valid_overriding_properties :
      (* The overridden properties are defined in the annotated_signal. *)
      not_exists(QUERY(signalPropertyOverride <* overriding_properties |
        NOT (signalPropertyOverride.overridden_property
             IN annotated_signal.properties)));
  END_ENTITY;

Description:

A signal_annotate is used to attach or modify properties which are associated with a signal occurrence within an occurrence hierarchy. It is possible to annotate a member of a signal occurrence in the context of an expanded occurrence hierarchy by specifying the index value of the annotated member. If the width of the annotated signal is N after the expansion, the specified index value must be in the range from 0 to N-1.
