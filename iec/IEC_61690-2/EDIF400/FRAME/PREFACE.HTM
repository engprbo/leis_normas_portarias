Preface

This document, which consists of the Information Model and the Reference Manual, is the authoritative reference document for EDIF Version 4 0 0. The Information Model defines the semantic content and the Reference Manual defines the syntax for EDIF Level 0 and EDIF Level 1.

The Information Model is written in EXPRESS (ISO 10303 Part 11), and is organized into the following sections:

Introduction:
This section provides a general overview of the information model of EDIF Version 4 0 0. It includes a description of the techniques used for modeling various EDIF concepts. It also outlines the purposes of an information model for EDIF. This section introduces a general discussion of major topics in EDIF.

EXPRESS Model:
This section provides the information model of EDIF Version 4 0 0 in EXPRESS (ISO 10303 Part 11). The information model describes the underlying concepts of EDIF. It is divided into various schemas.

Appendices:
This section provides various summaries which help in the understanding of the information model. The summaries include an index and a permuted index.
The Reference Manual is divided into the following sections:
Introduction:
The information within this section provides an overview of EDIF language basics.

Reference:
This section describes, in detail, the constructs of EDIF. This section may be used as a basic reference source. This section is presented in alphabetical order.

Index:
This section provides an index of all keywords.

Permuted Index:
This section provides a cross reference between all the composite parts of keywords, e.g. all keywords containing the word "Display" are listed together. This is useful to locate keywords with similar or related meaning.

BNF:
This section describes the grammar of EDIF in Backus Naur Form (BNF). It may be used by experienced EDIF programmers for initial coding of a parser, and for quick reference while developing translators. The BNF files are available in ascii files.

While great care has been taken to ensure accuracy and internal consistency of this document, errors or ambiguous interpretations are possible. If you note any such problems, please inform the EDIF Technical Experts Group.
