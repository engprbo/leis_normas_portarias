5 Expressions

This chapter describes the concept of expression which can be found in the expression_model schema. In Level 1, four types of expression are supported. Expressions are predominantly used for:

  • the width expressions of master_ports, signals, frame_signals and instances

  • the connectivity_tag_generator expressions of mergeable_signals and frame_mergeable_signals

  • the connected_signal_index_generator expressions of instance_port_expressions

  • the instance_name_generator expressions of instances

  • parameter_assign values

  • the control expressions for if_frames and for_frames.

Expressions cannot be evaluated until a specific design hierarchy is expanded.

5.1 Boolean expressions

A boolean_expression describes an expression that evaluates to a boolean. It can be either a boolean_token or a reference to a boolean_parameter. In addition, it can be an expression which includes boolean_expressions, an expression which includes integer_expressions or an expression which includes string_expressions.

The following types of expression have boolean_expressions as their arguments and return a boolean when evaluated. An and_expression returns the logical conjunction of its arguments. A not_expression returns the logical negation of its arguments. An or_expression returns the logical disjunction of its arguments. An xor_expression returns the exclusive or of its arguments.

The following types of expression have integer_expressions as their arguments and return a boolean when evaluated. An integer_equal_expression returns true if its arguments are numerically the same. A less_than_expression returns true if its arguments are monotonically increasing. A less_than_or_equal_to_expression returns true if its arguments are monotonically nondecreasing.

The string_equal_expression is the only boolean_expression which takes string_expressions as its arguments and returns a boolean when evaluated. It returns true if its arguments have the same string length and the same characters in corresponding positions; it returns false otherwise. The strings are compared in a case sensitive manner.

5.2 Integer expressions

An integer_expression describes an expression that evaluates to an integer. It can be either an integer_token, a reference to an integer_parameter or a reference to various types of indexes (i.e. for_frame_index, frame_signal_index, instance_index, port_index or signal_index). In addition, it can be an expression which includes integer_expressions, or an expression which includes string_expression.

The following types of expression have integer_expressions as their arguments and return an integer when evaluated. An absolute_expression returns the absolute value of the argument. An integer_product_expression returns the product of the arguments. An integer_subtract_expression subtracts the subtrahend from the minuend. An integer_sum_expression returns the sum of the arguments. A quotient_expression returns the integer quotient obtained in division of the dividend by the divisor. A remainder_expression returns the integer remainder obtained in a division of the dividend by the divisor.

The string_length_expression is the only integer_expression which takes a string_expression as its argument and return an integer when evaluated. It yields the number of characters in the string which results from the evaluation of its argument.

5.3 Number expressions

A number_expression describes an expression that evaluates to a number. It can be either a number_token or a reference to a number_parameter.

5.4 String expressions

A string_expression describes an expression that evaluates to a string. It can be either a reference to a string_parameter or a string_token. In addition, it can be an expression which involves concatenation, prefixing, suffixing or truncating a string_expression or an expression which converts an integer_expression to its string representation.

The following types of expression have string_expressions as their arguments and return a string when evaluated. A string_concatenate_expressionconcatenates the arguments. A substring_expression returns a string of the given length and offset, extracted from the value of the argument. A string_prefix_expression returns a string of the given length which is the prefix of the argument. A string_suffix_expression returns a string which is the suffix of the argument.

The decimal_to_string_expression is the only string_expression which takes an integer_expression as its argument and return a string when evaluated. It yields the string which is the unsigned decimal representation of the value of the argument.
