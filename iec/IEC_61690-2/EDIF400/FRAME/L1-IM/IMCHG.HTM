Appendix A Summary of changes from Level 0

The Level 1 information model includes objects which are unmodified from the Level 0 information model, objects which exist in the Level 0 information model but are modified in the Level 1 information model and some new objects which are specific to Level 1. This appendix gives a list of changes based on the EDIF Version 4 0 0 Level 0 information model.

A.1 New objects specific to Level 1

The purpose of EDIF Level 1 is to allow the transfer of designs and libraries which contain parameterized cell information or include schematic representations of frames.
