Description:

The edif_information_model schema describes the information held by an EDIF file. An EDIF file may contain several designs and several libraries of cell definitions. font

  ENTITY font 
      SUBTYPE OF (text_font);
    font_capital_height : length_value;
    font_descent        : length_value;
    font_styles         : OPTIONAL SET [1:2] OF font_style;
    proportional_font   : boolean_token;
  END_ENTITY;

Description:

A font defines the information needed to access font data on a system which defines how text strings are to be rendered. If an exact match for a font cannot be found, information is provided to find a substitute font. When substituting fonts or changing justifications, sufficient information is provided to adjust the text heights, origins and justifications to identify a substitute font.

The font_family defines a string name used to identify a family of typefaces. The typeface_suffix defines a suffix in a typeface name used to identify attributes of the typeface such as bold and italic. The font_capital_height is the height of capital letters. The font_descent is a characteristic of the font. It is the distance between the baseline (the bottom of capital letters) and the bottom of the font bounding box. It is the area in which the bottom parts of letters with descenders, e.g. gjpqy are drawn. The font_height is defined as the distance between the top and bottom of the font bounding box, and is used as the line to line spacing. The font bounding box includes whitespace above and possibly below the characters used in normal line spacing. The font_width defines the average separation of the characters in a rendered string. For fixed pitch fonts, the character separation is the same for all characters. For proportional fonts, this distance varies so the average value defined by the font is used. It is defined as the average of the widths (character to character spacing) of all characters defined in the font. The font_styles indicate that a font contains bold or italic characters. The proportional_font is a boolean flag which indicates whether a font contains proportionally spaced or fixed pitch characters.

Used by:

display figure_group schematic_required_defaults

flatten_global_port_bundle

  FUNCTION flatten_global_port_bundle
    (bundle_members : LIST OF UNIQUE global_port_or_global_port_bundle) 
       : LIST OF UNIQUE global_port;
    LOCAL
      i, j        : INTEGER;
      position    : INTEGER := 1;
      port_list   : LIST OF global_port := [ ];
      member_list : LIST OF global_port := [ ];
    END_LOCAL;

    REPEAT i := 1 TO SIZEOF(bundle_members);
      IF 'edif_information_model.global_port' IN TYPEOF(bundle_members[i]) THEN
        INSERT(port_list, bundle_members[i], position);
        position := position + 1;
      ELSE
        member_list:=flatten_global_port_bundle(bundle_members[i].member_ports);
        REPEAT j := 1 TO SIZEOF(member_list);
          INSERT(port_list, member_list[j], position);
          position := position + 1;
        END_REPEAT;
      END_IF;
    END_REPEAT;
    RETURN(port_list);
  END_FUNCTION;

Description:

The flatten_global_port_bundle function returns the flattened list of global_ports of a global_port_bundle.

Used by:

global_port_bundle

non_recursive_global_port_bundle

  FUNCTION non_recursive_global_port_bundle
    (parents, invalidAncestors : SET OF global_port_bundle) : BOOLEAN;
    LOCAL
      descendents : SET OF global_port_bundle := [];
    END_LOCAL;

    REPEAT i := 1 TO SIZEOF(parents);
      descendents := descendents + 
                     QUERY(memberPort <* parents[i].member_ports |
                     'edif_information_model.global_port_bundle'
                     IN TYPEOF(memberPort));
    END_REPEAT;
    invalidAncestors := parents + invalidAncestors;
    RETURN(not_exists(descendents)
           XOR
           (not_exists(descendents * invalidAncestors)
            AND 
            non_recursive_global_port_bundle(descendents, invalidAncestors)));
  END_FUNCTION;

Description:

The non_recursive_global_port_bundle function returns true if a global_port_bundle does not contain members which reference itself. It prevents cyclic definition of a global_port_bundle.

Used by:

global_port_bundle

non_recursive_fabricate_figure_collector

  FUNCTION non_recursive_fabricate_figure_collector
    (parent     : fabricate_figure_collector;
     collectors : SET OF fabricate_figure_collector) : BOOLEAN;
    LOCAL
      collectorType : SET OF STRING;
    END_LOCAL;

    REPEAT i := 1 TO SIZEOF(collectors);
      collectorType := TYPEOF(collectors[i]);
      IF 'edif_information_model.differenced_fabricate_figure_collector'
         IN collectorType THEN
         IF (collectors[i]\differenced_fabricate_figure_collector
                          .initial_geometric_shapes :=: parent)
            OR
            (collectors[i]\differenced_fabricate_figure_collector
                          .subtrahend_geometric_shapes :=: parent)
            OR
            NOT non_recursive_fabricate_figure_collector(parent, 
                 [collectors[i]\differenced_fabricate_figure_collector
                               .initial_geometric_shapes,
                  collectors[i]\differenced_fabricate_figure_collector
                               .subtrahend_geometric_shapes]) THEN
            RETURN(FALSE);
         END_IF;
      ELSE
      IF 'edif_information_model.mirrored_fabricate_figure_collector'
         IN collectorType THEN
         IF (collectors[i]\mirrored_fabricate_figure_collector
                          .initial_geometric_shapes :=: parent)
            OR
            NOT non_recursive_fabricate_figure_collector(parent, 
                 [collectors[i]\mirrored_fabricate_figure_collector
                               .initial_geometric_shapes]) THEN
            RETURN(FALSE);
         END_IF;
      ELSE
      IF 'edif_information_model.resized_fabricate_figure_collector'
         IN collectorType THEN
         IF (collectors[i]\resized_fabricate_figure_collector
                          .initial_geometric_shapes :=: parent)
            OR
            NOT non_recursive_fabricate_figure_collector(parent, 
                 [collectors[i]\resized_fabricate_figure_collector
                               .initial_geometric_shapes]) THEN
            RETURN(FALSE);
         END_IF;
      ELSE
      IF 'edif_information_model.rotated_fabricate_figure_collector'
         IN collectorType THEN
         IF (collectors[i]\rotated_fabricate_figure_collector
                          .initial_geometric_shapes :=: parent)
            OR
            NOT non_recursive_fabricate_figure_collector(parent, 
                 [collectors[i]\rotated_fabricate_figure_collector
                               .initial_geometric_shapes]) THEN
            RETURN(FALSE);
         END_IF;
      ELSE
      IF 'edif_information_model.translated_fabricate_figure_collector'
         IN collectorType THEN
         IF (collectors[i]\translated_fabricate_figure_collector
                          .initial_geometric_shapes :=: parent)
            OR
            NOT non_recursive_fabricate_figure_collector(parent, 
                 [collectors[i]\translated_fabricate_figure_collector
                               .initial_geometric_shapes]) THEN
            RETURN(FALSE);
         END_IF;
      ELSE
      IF 'edif_information_model.unioned_fabricate_figure_collector'
         IN collectorType THEN
         IF there_exists(QUERY(col 
                         <* collectors[i]\unioned_fabricate_figure_collector
                                         .unioned_geometric_shapes |
                         col :=: parent))
            OR
            NOT non_recursive_fabricate_figure_collector(parent, 
                 collectors[i]\unioned_fabricate_figure_collector
                              .unioned_geometric_shapes) THEN
            RETURN(FALSE);
         END_IF;
      END_IF;
      END_IF;
      END_IF;
      END_IF;
      END_IF;
      END_IF;
    END_REPEAT;
    RETURN(TRUE);
  END_FUNCTION;

Description:

A drawing_double_dashed_line_style is used to state that lines, arcs or circles are drawn in a style of dot-dashed lines which is an ever repeating set of (long-dash, gap, short-dash, gap). All gaps are the same size; all short-dashes are the same size; all long-dashes are the same size.
