library_model

Description:

The library_model schema describes what information can be found in an EDIF library. An EDIF library is a grouping of reusable objects. A library contains cell definitions, geometry_macro_templates and various types of instantiatable templates for schematic views. It also includes definitions of figure_groups which are common to all reusable objects in a library.

library

  ENTITY library
      ABSTRACT SUPERTYPE OF (ONEOF(internal_library, external_library));
    background_colour            : colour;                 
    cells                        : OPTIONAL SET [1:?] OF cell;
    document                     : OPTIONAL SET [1:?] OF documentation;
    geometric_attribute_defaults : OPTIONAL SET [1:?] OF 
                                   geometric_attribute_default;
    logic_definitions            : OPTIONAL undefined_type;
    name                         : OPTIONAL name_information; 
    properties                   : OPTIONAL SET [1:?] OF private_property;
    scaling_information          : physical_scaling;
    status_of_copyright          : OPTIONAL SET [1:?] OF copyright;
    status_of_written            : OPTIONAL SET [1:?] OF written;

  (* The following attributes are added for the PCB domain. *)
    bare_board_technologies      : OPTIONAL SET [1:?] OF bare_board_technology;
    connector_parts              : OPTIONAL SET [1:?] OF connector_part;
    electrical_parts             : OPTIONAL SET [1:?] OF electrical_part;
    jumper_parts                 : OPTIONAL SET [1:?] OF jumper_part;
    materials                    : OPTIONAL SET [1:?] OF material;
    mechanical_parts             : OPTIONAL SET [1:?] OF mechanical_part;
    mounting_methods             : OPTIONAL SET [1:?] OF mounting_method;
    mountable_packages           : OPTIONAL SET [1:?] OF mountable_package;
    packages                     : OPTIONAL SET [1:?] OF package;
    sub_layout_definitions       : OPTIONAL SET [1:?] OF sub_layout_definition;

  (* The following attributes are added for the MCM domain. *)
    die_templates                : OPTIONAL SET [1:?] OF die_physical_template;
    mountable_die_templates      : OPTIONAL SET [1:?] OF
                                   mountable_die_physical_template;

  (* The following attributes are added for the technology rule domain. *)
    mountable_package_orientation_rules : OPTIONAL SET [1:?] OF
                                          mountable_package_orientation_rule;
  DERIVE
    containing_edif : edif -- reference
                      := usedin_one_role(SELF, 
                         'edif_information_model.edif.libraries');
  WHERE
    containment_constraint :
      (* A library belongs to one edif file. *)
      belongs_to_one(SELF, 'edif_information_model.edif.libraries');
  END_ENTITY;

Description:

A library is a collection of EDIF design information grouped according to some set of common characteristics. It might be internal or external to the EDIF file. A library contains cell definitions, geometry_macro_templates, and various types of instantiatable templates for schematic views. It also contains the technology information which is shared by all cells within a library. That includes definitions of figure_groups.

Description:

An external_library contains a set of external_cells and external_templates which do not contain any implementation information. The ``stubs'' contained in an external_library indicate that the detailed information is specified externally. Such external information may, for example, make an association with detailed information provided at an earlier time; such information is expected to be known to the receiving system.

geometric_attribute_default

  ENTITY geometric_attribute_default
      ABSTRACT SUPERTYPE OF (ONEOF (figure_group,
                                    pcb_attribute_default,
                                    pcb_drawing_attribute_default));
    default_corner_type              : path_corner_type;      
    default_end_type                 : path_end_type;         
    default_font                     : OPTIONAL text_font; -- reference
    default_horizontal_justification : horizontal_justification;         
    default_text_height              : OPTIONAL length_value;
    default_vertical_justification   : vertical_justification;         
    name                             : OPTIONAL name_information;
    properties                       : OPTIONAL SET [1:?] OF property;
  WHERE
    valid_existence:
      (* A geometric_attribute_default belongs to one library. *)
      belongs_to_one(SELF, 
        'library_model.library.geometric_attribute_defaults');
  END_ENTITY;

Description:

A geometric_attribute_default defines default attributes to be used when geometries or text are displayed or fabricated.

Used by:

Description:

A pcb_drawing_attribute_default provides the display defaults for the pcb drawing.

The default drawing_line_style specifies the style used in drawing lines, arcs or circles within the context of a drawing_figure.
