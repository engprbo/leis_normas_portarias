pcbDiePositionTolerance

pcbDiePositionTolerance ::= '(' 'pcbDiePositionTolerance'
	originPositiveDisplacement
	originNegativeDisplacement
	rotationDisplacement
	')'

Used by:

<pcbMountableDiePhysicalTemplate

Similar Keywords:

pcbDieGeometryTolerance pcbDiePadPositionTolerance pcbDiePositionToleranceWidth pcbDieSizeTolerance pcbDieThicknessTolerance

Constraints:

1. The following constraint applies to this context: All contexts
The rotation displacement values are not less than zero.

2. This construct is illegal in this context: external

Description:

Specifies the die's position tolerance, which is the amount by which a die may vary in placement when the mountable die physical template is used. Such variance is due to the limitations of the insertion/onsertion tool and/or method.

OriginPositiveDisplacement and OriginNegativeDisplacement enable different displacement lengths to be specified for the positive and negative directions.

Example:

(pcbMountableDiePhysicalTemplate PT1
   (pcbMountableDiePhysicalTemplateHeader ...)
   (pcbDiePhysicalTemplateRef DT1)
   (pcbDiePositionTolerance
      (originPositiveDisplacement 20 20)
      (originNegativeDisplacement 5 5)
      (rotationDisplacement  5 5)) ...)

The objects referenced within a pcbDimension must not be defined within two different pcbBoardSubsetExtraDetails, nor may they be in a pcbBoardSubsetExtraDetail and a pcbBoardSubsetDefinition.

Description:

A pcbDimension is a definition of a special form of drawing annotation that is used to indicate:

1. The required sizes or positions (relative to an indicated datum) of features on the PCB or MCM.

2. The required angle between linear features on the PCB or MCM.

A pcbDimension does not specifically define the geometry or text of the annotation. Instead, it defines the requirements for the annotation. An EDA or other system that reads this data would have to interpret the requirements in a way that it understands.

See the descriptions of each dimension type for comprehensive examples and further details.

Example:

(pcbDimension Dim1
   (pcbDimensionHeader
      (pcbDimensionUnits 
         (pcbDimensionDistanceUnit (unitRef mm))) ...)
   (pcbDrawingAttributeDefaultRef Default_Attrs)
   (pcbDimensionSingleLinear ...))
