stringPrefix

stringPrefix ::= '(' 'stringPrefix'
	stringExpression
	substringLength
	')'

Used by:

stringExpression

Similar Keywords:

string

Description:

This returns a specified number of characters from the beginning (left hand side) of stringExpression The number of characters to return, and hence the length of the result is specified by substringLength.

If substringLength is greater than the number of characters in stringExpression, the value of stringExpression is returned. In this case, the number of characters in the stringExpression is also unchanged.

If substringLength is less than or equal to zero, the empty string ("") is returned.

Note that for any string s, the following expression always returns s:

(stringConcatenate (stringPrefix s n) (stringSuffix s n))

Example:

(stringPrefix "abcdef" 4)

The above example yields "abcd".

stringSuffix

stringSuffix ::= '(' 'stringSuffix'
	stringExpression
	substringOffset
	')'

Used by:

stringExpression

Similar Keywords:

string

Description:

This returns a number of characters from the end (right hand side) of stringExpression. The offset (i.e. the number of characters to ignore) from the left hand side of stringExpression is specified by substringOffset.

If substringOffset is greater than the number of characters in stringExpression, the empty string ("") is returned.

If substringOffset is less than or equal to zero, the entire stringExpression is returned.

Example:

(stringSuffix "abcde" 2)

The above example yields "cde". 

(stringSuffix "abcde" 0)

The above example yields "abcde". 

(stringSuffix "abcde" 6)

The above example yields "".

A space or tab character represents itself within string tokens; other white space characters (newline and carriage return) are ignored; these can be included in a string by using encodedCharacter. substring

substring ::= '(' 'substring'
	stringExpression
	substringLength
	substringOffset
	')'

Used by:

stringExpression

Description:

This evaluates to a substring of stringExpression. SubstringLength specifies the length of the substring. The offset (i.e. the number of characters to ignore) from the left hand side of stringExpression is specified by substringOffset.

For (substring S L F), if S has a string length N, then:

1. If F >= N, substring returns "".

2. If L <= 0, substring returns "".

3. If F + L > N, substring returns all the characters from the offset position, and the string returned has a length equal to N - F.

Note that the following two constructs are equivalent:

(substring string length offset)

(stringPrefix (stringSuffix string offset) length)

Example:

(substring "abcdefg" 4 2 )

This yields "cdef".
