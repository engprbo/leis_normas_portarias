pcbBondPadPreTabbed

pcbBondPadPreTabbed ::= '(' 'pcbBondPadPreTabbed'
	pcbTabbedBondPadTemplateRef
	pcbTabbedBondPadTemplatePosition
	pcbBondPadTemplateRef
	fixedScaleTransform
	pcbBondPadPreTabbedTabLead
	')'

Used by:

pcbBondPadType

Similar Keywords:

pcbBondPadPreBumped pcbMountableBondPadPreTabbed pcbMountableBondPadTabbed pcbPad pcbTabbedBondPadTemplate

Constraints:

1. The following constraint applies to this context: All contexts
The enclosing pcbDiePhysicalTemplate must have pcbTabbing.

2. The following constraint applies to this context: All contexts
The referenced pcbBondPadTemplate must be a pcbTabbedBondPadTemplate.

Description:

Defines a pre-tabbed bond pad. It is defined by combining a tabbed bond pad template (off die) with a bond pad template (on die) and a tab lead.

PcbTabbedBondPadTemplatePosition specifies the position of the tabbed bond pad referenced by pcbTabbedBondPadTemplateRef

FixedScaleTransform specifies the position of the bond pad referenced by pcbBondPadTemplateRef.

Example:

(pcbDiePhysicalTemplate STANDARD_INTERFACE
   (pcbDiePhysicalTemplateHeader ...)
   (pcbElectricalBondPad bondpad_001
      (pcbBondPadHeader ...)
      (pcbBondPadPreTabbed
         (pcbTabbedBondPadTemplateRef tbpt_001)
         (pcbTabbedBondPadTemplatePosition
            (fixedScaleTransform (origin (pt 1000 1000))))
         (pcbBondPadTemplateRef bpt_001)
         (fixedScaleTransform (origin (pt 0 0)))
         (pcbBondPadPreTabbedTabLead
            (path (pointList (pt 100 100) (pt 1000 100))) 
            (pcbMaterialRef Silver)))) ...)
