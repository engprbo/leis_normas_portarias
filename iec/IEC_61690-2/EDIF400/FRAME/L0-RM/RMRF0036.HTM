pcbMaterial

pcbMaterial ::= '(' 'pcbMaterial'
	libraryObjectNameDef
	pcbMaterialHeader
	electricalMaterialType
	pcbMaterialType
	')'

Used by:

Similar Keywords:

pcbBondPadAttachmentMaterial pcbDiePassivationMaterial pcbDieSubstrateMaterial pcbDrillRulePlatingMaterial pcbIsMadeOfMaterial pcbMaterialList pcbMaterialRef pcbMaterialUnits pcbMaterialValue pcbNonStandardMaterial pcbPackageBodyMaterial pcbPackageBodyMaterialType pcbStandardMaterial

Description:

Defines a particular physical material in terms of its name and physical properties (e.g. electrical conductivity, thermal conductivity, density, etc.).

Each physical layer of the bare board is constructed from a particular material, and this has a set of properties that are inherited from that material. Many different physical layers constructed of the same material will thus have a common set of physical properties. A material object describes a material in terms of these properties.

Example:

(pcbMaterial Copper
   (pcbMaterialHeader ...)
   (conductiveMaterial)
   (pcbStandardMaterial))
