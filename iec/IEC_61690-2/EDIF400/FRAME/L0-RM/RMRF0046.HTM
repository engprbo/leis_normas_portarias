pcbPhysicalNet

pcbPhysicalNet ::= '(' 'pcbPhysicalNet'
	pcbPhysicalNetNameDef
	pcbPhysicalNetHeader
	{ <pcbInstanceNets> | pcbLayoutFeature | pcbLayoutText | pcbPhysicalNet 
	} 
	')'

Used by:

*pcbBareBoardPhysicalNet *pcbFootprintDefinition *pcbNonSpecificSubLayoutDefinition *pcbPadstackDefinition *pcbPhysicalNet *pcbTestCouponDefinition *pcbToeprintDefinition

Similar Keywords:

pcbAssembledPhysicalNetHeader pcbAssembledPhysicalNetNameCaseSensitive pcbAssembledPhysicalNetNameDef pcbAssembledPhysicalNetNameRef pcbAssembledPhysicalNetRef pcbBareBoardPhysicalNetRef pcbPhysicalNetNameCaseSensitive pcbPhysicalNetNameRef pcbPhysicalNetOccurrenceRef pcbSubLayoutInstancePhysicalNetRef

Description:

Defines a geometrically-connected region of conductive material. A physical net is a collection of layout features (e.g. a trace) and other physical nets. By including other physical nets, a structured approach to the definition of the physical net can be achieved.

If a physical net needs to be repeatedly used in several other physical nets, it can be included in a sublayout definition, then an instance of that definition can be referenced within the physical net by using pcbInstanceNets.

A physical net can also own layout text. The layout text is merely associated with the net; it does not provide functional connectivity.

Physical nets can cross layer boundaries using padstacks that have plated-through holes and using plated-through holes themselves.

Example:

(pcbPhysicalNet net0_1
   (pcbPhysicalNetHeader)
   (pcbLayoutFeature LF1
      (pcbTrace
         (pcbFabricateFigure
            (pcbContributesToFabrication
               (pcbSimpleFabricateFigureCollectorRef 
                  FC1))
            (pcbPhysicalFigure OTHER_NETS
               (geometryElementSet
                  (path
                     (pointList
                        (pt 0 5000)
                        (pt 5000 5000)))
                  (path
                     (pointList
                        (pt 2500 2500)
                        (pt 2500 5000))))))
         (pcbClearanceGeometry)))
   (pcbLayoutFeature LF2
      (pcbPad 
         (pcbPadIntendedUse (pcbPadIntendedUseSignalPositive))
         (pcbFabricateFigure ...
            (pcbPhysicalFigure ...
               (geometryElementSet
                  (rectangle (pt 2400 4900) 
                     (pt 2600 5100)))))
         (pcbClearanceGeometry))))

This defines the physical net shown in the following diagram.

            (path
               (pointList
                  (pt 100 105)
                  (pt 105 105)))))))

In this example, the letter "T" is displayed using the font and other defaults in the pcbGeometricAttributeDefault named STROKE. The pcbPhysicalFigure describes the letter "T" as primitive graphical objects again using the geometric attribute defaults (e.g. pathWidth) in the pcbGeometricAttributeDefault named STROKE
