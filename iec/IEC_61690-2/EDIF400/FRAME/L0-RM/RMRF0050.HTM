Description:

PcbSwapGroup groups together a number of instances in the logical connectivity. An instance within this group can only have its allocation to a component swapped with an instance in the same group.

An instance that belongs to no swap group actually belongs to a universal swap group. It can be swapped only with another instance that is not in a swap group.

Constraints:

1. The following constraint applies to this context: All contexts
When a pcbBareBoardDefinition or a sublayout definition instances a sublayout, that sublayout must have the same bare board technology as the instantiating object.
(See also similar constraint in: pcbBareBoardDefinition, pcbFootprintDefinition, pcbFootprintInstance, pcbNonSpecificSubLayoutDefinition, pcbNonSpecificSubLayoutInstance, pcbPadstackDefinition, pcbPadstackInstance, pcbTestCouponInstance, pcbToeprintDefinition, pcbToeprintInstance)

Description:

Defines a test coupon. A test coupon is a collection of layout items that are used exclusively for testing purposes. They typically consist of the narrowest possible track, tracks that are as close together as allowed by the design technology, the smallest possible holes, etc.

This region of the bare board can be subjected to a series of possibly destructive tests. If this region fails the tests, it is likely that the board as a whole has not been manufactured correctly. If it passes the tests, it does no more than increase the tester's confidence in the state of the rest of the bare board.

The internal nets of a test coupon would normally have no intended functional impact on the printed circuit board.

Example:

(pcbTestCouponDefinition TC_SMD_PADSTACK
   (pcbSubLayoutDefinitionHeader ...)
   (pcbPadstackInstance PS1
      (pcbPadstackDefinitionRef SMD_STACK_TINY)
      (pcbPadstackInstanceTestPointPlace)
      (fixedScaleTransform ...)))
