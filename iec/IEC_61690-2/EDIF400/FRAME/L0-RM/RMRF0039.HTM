pcbMountablePackageOrientationRule

pcbMountablePackageOrientationRule ::= '(' 'pcbMountablePackageOrientationRule'
	pcbRuleNameDef
	pcbMountablePackageSet
	pcbAllowedRotations
	{ property } 
	')'

Used by:

*pcbBareBoardTechnology

Similar Keywords:

pcbMountablePackageOrientationRuleRef

Description:

Specifies the set of allowable angles of orientation for a given set of mountable packages. The orientation angle is measured counter-clockwise as seen from the top side of the board.

The orientation of a mountable package is the angle by which it is rotated when it is instantiated within the context of a component implementation within an assembled board.

Example:

(pcbMountablePackageOrientationRule OR1
   (pcbMountablePackageSet
      (pcbMountablePackageRef DIP14_Dip_Top))
   (pcbAllowedRotations 45 90 135 180 225 270 315))

In this example, the 14-pin DIP mounted on the top side may be oriented at 45-degree increments.
