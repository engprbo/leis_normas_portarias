pcbPinPackage

pcbPinPackage ::= '(' 'pcbPinPackage'

	pcbMechanicalFixing | <pcbPackageBodyMaterial> | 
	<pcbPackageMounting> | <pcbPackageOutlineStyle> | 
	<pcbPackagePinArrangement> | <pcbPackagePinForm> | 
	<pcbPackagePinFormCount> | pcbPackagePinGroup | 
	<pcbPackagePinPitch> | <pcbPackageShape> | pcbPackageTerminalPin }

Used by:

Similar Keywords:

pcbMountablePackageTerminalExtraPin pcbMountablePackageTerminalPreparedPin pcbMountablePinPackage pcbPackagePinArrangementType pcbPackagePinFormButt pcbPackagePinFormCBend pcbPackagePinFormFlat pcbPackagePinFormGullWing pcbPackagePinFormHighCurrentCable pcbPackagePinFormJBend pcbPackagePinFormJInverted pcbPackagePinFormLBend pcbPackagePinFormNoLead pcbPackagePinFormPinPeg pcbPackagePinFormSBend pcbPackagePinFormSolderLug pcbPackagePinFormThroughHole pcbPackagePinFormType pcbPackagePinFormWire pcbPackagePinFormWraparound pcbPackagePinGroupNameCaseSensitive pcbPackagePinGroupNameDef pcbPackagePinGroupNameRef pcbPackagePinGroupPins pcbPackagePinLength pcbPackageTerminalPinRef pcbPinPackageRef

Description:

Describes a package .

A pcbPinPackage defines the mechanical container for a part that has pins for connection. Several parts can refer to the same package. For example, many different parts may make use of the same 14-pin ceramic dual-in-line (DIL) package.

The JEDEC JESD30-A standard acronym for a package can be formed by using the values of the following: pcbPackageShape, pcbPackageBodyMaterial, pcbPackageOutlineStyle, pcbPackagePinArrangement, pcbPackagePinForm, jedecDetailedInformation and from the number of pins.

Many items of information specified within pcbPinPackage can be overridden by pcbMountablePinPackage, which describes a way of mounting the package on a board. The actual specification of how an instance of a package is mounted on the assembled board is specified by the packaged component implementation, which references a mountable package.

Example:

(pcbPinPackage DIP14
   (pcbPackageHeader ...)
   (bodyVolume ...)
   (occupiedSpace ...)
   (pcbPackageBodyMaterial (plasticMaterial))
   (pcbPackageOutlineStyle 
      (pcbPackageOutlineInLinePackage))
   (pcbPackagePinForm 
      (pcbPackagePinFormThroughHole))
   (pcbPackagePinArrangement (pcbPinPositionDual))
   (pcbPackageShape (pcbRectangularBodyProfile))
   (pcbPackagePinPitch 100)
   (pcbPackagePinGroup PG1
      (pcbPackagePinGroupPins
         (pcbPackageTerminalPinRef T1)
         (pcbPackageTerminalPinRef T2)
         ...
         (pcbPackageTerminalPinRef T14))))

This example describes a plastic 14-pin DIL package.
