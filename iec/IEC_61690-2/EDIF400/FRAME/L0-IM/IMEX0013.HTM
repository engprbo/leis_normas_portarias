mcm_die_physical_model

Description:

The mcm_die_physical_model schema describes a die_physical_template which provides information of a die.

die_physical_template

  ENTITY die_physical_template
      ABSTRACT SUPERTYPE OF (ONEOF (external_die_physical_template,
                                    internal_die_physical_template));
    document         : OPTIONAL SET [1:?] OF documentation;
    name             : OPTIONAL name_information;
    pads             : SET [1:?] OF bond_pad;
    previous_version : OPTIONAL die_physical_template; -- reference
    properties       : OPTIONAL SET [1:?] OF property;
    units            : pcb_layout_units;
    written_status   : OPTIONAL SET [1:?] OF written;
  WHERE
    valid_previous_version :
      (* A template cannot be a new version of itself, either directly
         or indirectly. *)
      non_recursive_previous_version(SELF, []);

    valid_written_in_previous_version :
      (* The earliest timestamp of a die_physical_template is later than the
         latest timestamp of its previous version. *)  
      valid_timestamp_in_previous_version(written_status,
                                          previous_version.written_status);
  END_ENTITY;

Description:

A die_physical_template is a template for the physical interaction between a die_electrical_part and an MCM.

Used by:

die_electrical_part die_physical_template internal_mountable_die_physical_template library

internal_die_physical_template

  ENTITY internal_die_physical_template
      SUBTYPE OF (die_physical_template);
    SELF\die_physical_template.pads : SET [1:?] OF internal_bond_pad;
    fiducials                       : OPTIONAL SET [1:?] OF die_fiducial;
    die_tabbing                     : OPTIONAL tabbing;
    body_volume                     : OPTIONAL SET [1:?] OF extrusion_volume;
    occupied_space                  : OPTIONAL SET [1:?] OF extrusion_volume;
    DIE_flatness                    : OPTIONAL length_value;
    DIE_pad_dielectric              : OPTIONAL LIST [1:?] OF material;
    DIE_pad_metal                   : OPTIONAL LIST [1:?] OF material;
    DIE_pad_pitch                   : OPTIONAL length_value;
    DIE_pad_position_tolerance      : OPTIONAL x_y_tolerance;
    DIE_passivation_extent          : OPTIONAL closed_area_element;
    DIE_passivation_material        : OPTIONAL LIST [1:?] OF material;
    DIE_size_tolerance              : OPTIONAL x_y_tolerance;
    DIE_specific_heat_capacity      : OPTIONAL specific_heat_capacity_value;
    DIE_storage_condition           : OPTIONAL DIE_storage_condition;
    DIE_substrate_material          : OPTIONAL LIST [1:?] OF material;
    DIE_thermal_conductivity        : OPTIONAL thermal_conductivity_value;
    DIE_thickness_tolerance         : OPTIONAL length_value;
    DIE_nominal_thermal_dissipation : OPTIONAL power_value;
    DIE_maximum_thermal_dissipation : OPTIONAL power_value;
    DIE_power_cells                 : OPTIONAL SET [1:?] OF DIE_power_cell;
    DIE_power_capacitance           : OPTIONAL capacitance_value;
  WHERE
    valid_existence :
      (* An "internal_die_physical_template" is in an "internal_library" *)
      belongs_to_one (SELF,
        'library_model.internal_library.die_templates');

    valid_body_volume :
      (* The offset_distance of each extrusion_volume must be greater than or
         equal to zero. *)
      not_exists(QUERY(bodyVolume <* body_volume |
        bodyVolume.offset_distance < 0));

    valid_occupied_space :
      (* The offset_distance of each extrusion_volume must be greater than or
         equal to zero.  At least one of the extrusion_volume must have an
         offset_distance equal to zero*)
      not_exists(QUERY(occupiedSpace <* occupied_space |
        occupiedSpace.offset_distance < 0))
      AND
      there_exists(QUERY(occupiedSpace <* occupied_space |
        occupiedSpace.offset_distance = 0));
  END_ENTITY;

Description:

An internal_die_physical_template is a die_physical_template within an internal_library.

The DIE_flatness attribute indicates the distance between the lowest object on the top of the die and the highest object. The DIE_flatness may limit the applicability of certain MCM processes. This attribute has been derived from the DIE format, Section 5.19.

The DIE_pad_dielectric attribute indicates the composition and thickness of the dielectric material under the metal pads. This attribute has been derived from the DIE format, Section 5.35.

The DIE_pad_metal attribute indicates the composition and thickness of the pad metal material. This attribute has been derived from the DIE format, Section 5.36.

The DIE_pad_pitch attribute specifies the minimum pad-to-pad separation on the die. This value is not a rule; it is an additional piece of information for the user of the die. This attribute has been derived from the DIE format, Section 5.37.

The DIE_pad_position_tolerance attribute indicates the tolerance of the placement of the templates within the internal_bond_pads. This attribute has been derived from the DIE format, Section 5.42.

The DIE_passivation_extent attribute specifies the shape of the die passivation over the surface of the die substrate. This attribute has been derived from the DIE format, Section 5.44.

The DIE_passivation_material attribute specifies the thickness and material of the passivation covering the die. This attribute has been derived from the DIE format, Section 5.45.

The DIE_size_tolerance attribute indicates the tolerance in the specified body_volume of the die. This attribute has been derived from the DIE format, Section 5.56.

The DIE_specific_heat_capacity attribute indicates the specific heat capacity of the die substrate material. This value is used for thermal analysis. Note that this value is more accurate than a derived value from the DIE_substrate_material attribute. This attribute has been derived from the DIE format, Section 5.59.

The DIE_storage_condition attribute indicates a set of environmental condition which should be satisfied during the storage of the die before its inclusion in an MCM. This attribute has been derived from the DIE format, Section 5.17.

The DIE_substrate_material attribute indicates the thickness and material out of which the substrate of the die is made. This attribute has been derived from the DIE format, Section 5.61.

The DIE_thermal_conductivity attribute indicates the thermal conductivity of the die substrate material. Note that this value is more accurate than a derived value from the DIE_substrate_material attribute. This attribute has been derived from the DIE format, Section 5.63

The DIE_thickness_tolerance attribute indicates the tolerance in the thickness of the die. This attribute has been derived from the DIE format, Section 5.65. Note that the thickness of the die can be derived from the body_volume attribute.

The DIE_nominal_thermal_dissipation indicates the nominal thermal power dissipation of the die. This attribute has been derived from the DIE format, Section 5.49.

The DIE_maximum_thermal_dissipation indicates the maximum thermal power dissipation of the die. This attribute has been derived from the DIE format, Section 5.48.

The DIE_power_cells attribute indicates specific areas of the die which generate heat. This attribute has been derived from the DIE format, Section 5.47.

The DIE_power_capacitance attribute indicates the frequency dependency of the power dissipation of the die. This attribute has been derived from the DIE format, Section 5.46.

Used by:

internal_bond_pad internal_library

tabbing

  ENTITY tabbing;
    tabbing_material : material_value; -- reference
    tabbing_space    : OPTIONAL SET [1:?] OF extrusion_volume;
  WHERE
    valid_existence :
      (* A tabbing belongs to either one internal_die_physical_template
         or one internal_mountable_die_physical_template. *)
      either_belongs_to_one (SELF,
        ['mcm_die_physical_model.internal_die_physical_template.die_tabbing',
         specified_role('mcm_mountable_die_physical_model',
                        'internal_mountable_die_physical_template',
                        'die_tabbing')]);
  END_ENTITY;

Description:

A tabbing is a block of material which may surround a die and allow access through it for bond_pads.

Used by:

internal_die_physical_template internal_mountable_die_physical_template

internal_bond_pad

  ENTITY internal_bond_pad
      ABSTRACT SUPERTYPE OF (ONEOF (internal_bare_bond_pad,
                                    internal_pre_tabbed_bond_pad,
                                    internal_pre_bumped_bond_pad))
      SUBTYPE OF (bond_pad);
    instantiated_bond_pad_template : bond_pad_template; -- reference
    bond_pad_position              : fixed_scale_transform;
  DERIVE
    containing_die : internal_die_physical_template -- reference
      := usedin_one_role (SELF,
         'mcm_die_physical_model.internal_die_physical_template.pads');
  WHERE
    valid_existence :
      (* An internal_bond_pad belongs to one internal_die_physical_template. *)
      belongs_to_one (SELF,
        'mcm_die_physical_model.internal_die_physical_template.pads');
  END_ENTITY;

Description:

An internal_bond_pad is a bond_pad of an internal_die_physical_template. It is defined by instantiating a bond_pad_template.

Used by:

internal_die_physical_template

internal_bare_bond_pad

  ENTITY internal_bare_bond_pad
      SUBTYPE OF (internal_bond_pad);
    DIE_non_contact_areas : OPTIONAL SET [1:?] OF closed_area_element;
  END_ENTITY;

Description:

An internal_bare_bond_pad is a bare bond pad of an internal_die_physical_template.

The DIE_non_contact_areas specify areas within the geometry of the internal_bare_bond_pad to which contact cannot be made. This concept has been derived from the DIE format Section 5.40. The non-contact areas are specified in the coordinate space of the internal_die_physical_template which contains the internal_bare_bond_pad.

internal_pre_tabbed_bond_pad

  ENTITY internal_pre_tabbed_bond_pad
      SUBTYPE OF (internal_bond_pad);
    instantiated_tabbed_bond_pad_template : -- reference
                                            tabbed_bond_pad_template;
    tabbed_bond_pad_position              : fixed_scale_transform;
    tab_lead                              : open_element;
    tab_lead_material                     : material_value; -- reference
  WHERE
    tabbing_exists :
      (* In order for a bond_pad to be pre-tabbed, the whole die must
        have tabbing. *)
      EXISTS (SELF\internal_bond_pad.containing_die.die_tabbing);
  END_ENTITY;

Description:

An internal_pre_tabbed_bond_pad is a pre-tabbed bond_pad on an "internal_die_physical_template. It is defined by instantiating a tabbed_bond_pad_template.

internal_pre_bumped_bond_pad

  ENTITY internal_pre_bumped_bond_pad
      SUBTYPE OF (internal_bond_pad);
    instantiated_bump_template : solder_bump_template; -- reference
    bump_origin                : integer_point;
  END_ENTITY;

Description:

An internal_pre_bumped_bond_pad is a pre-bumped bond_pad on an internal_die_physical_template. The pad is defined by instantiating a bond_pad_template and the solder bump is defined by instantiating a solder_bump_template.

DIE_power_cell

  ENTITY DIE_power_cell;
    geometry            : closed_area_element;
    thermal_dissipation : power_value;
  WHERE
    valid_existence :
      belongs_to_one (SELF,
      'mcm_die_physical_model.internal_die_physical_template.DIE_power_cells');
  END_ENTITY;

Description:

A DIE_power_cell identifies a potential hot area on the surface of a die. DIE_power_cells provide more detailed information than that specified by the DIE_nominal_thermal_dissipation of an internal_die_physical_template.

This concept has been derived from the DIE format Section 5.47.

Used by:

internal_die_physical_template

A DIE_storage_condition specifies the condition under which a die must be stored before it is assembled into an MCM.

This concept has been derived from the DIE format, Section 5.16.
