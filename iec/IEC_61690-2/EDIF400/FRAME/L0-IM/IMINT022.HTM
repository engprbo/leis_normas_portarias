27 Instantiatable templates for PCB/MCM domain

This chapter describes the templates used in the PCB/MCM domain. The model for the various categories of template are defined in the pcb_mcm_instantiatable_object_model schema.

These templates are used in defining packages, mountable packages and dies:

  • bond_pad_template - is used to define a bond pad (see internal_bond_pad in figure 18.6) on a die.

  • die_fiducial_template - is used to define a fiducial (see die_fiducial in figure 18.5) on a die.

  • physical_figure_macro_template - is a grouping of dumb graphics and text which is intended to be fabricated.

  • pin_template - is used to define a pin (see internal_pin in figure 16.4) in a pin_package.

  • solder_bump_template - is used to define a solder ball (see internal_solder_ball in figure 16.4) in a ball_package. A solder_bump_template can also be used to define a solder bump on a bond pad. In the latter case, the bond pad can be either pre-bumped (see internal_pre_bumped_bond_pad in figure 18.6) or bumped during mounting (see internal_mountable_bumped_bond_pad in figure 18.8).

  • tabbed_bond_pad_template - is used to define a bond pad which is either pre-tabbed (see internal_pre_tabbed_bond_pad in figure 18.6) or tabbed during mounting (see internal_mountable_tabbed_bond_pad in figure 18.8).

  • wirebond_template - is used to define a wirebond (see internal_mountable_wirebonded_bond_pad in figure 18.8) which attaches a bare bond pad on an MCM. A wirebond_template can also be used to define a jumper_wirebond (see figure 24.5).

These templates are used in symbol or drawing definition:

  • bond_pad_drawing_template - is used to define how a bond pad is to be drawn on a die symbol (i.e. mountable_die_physical_template_symbol).

  • drawing_border_template - is used to define a border (see figure 26.1) on a pcb_drawing.

  • drawing_figure_macro_template - is a grouping of dumb graphics and text which is intended to be drawn.

  • drawing_title_block_template - is used to define a title block (see figure 26.2) on a pcb_drawing.

  • package_terminal_drawing_template - is used to define how a package terminal is to be drawn on a mountable_package_symbol which describes a graphical symbol representing a mountable_package.

  • printed_part_terminal_drawing_template - is used to define how a part terminal is to be drawn on a printed_part_symbol which describes a graphical symbol representing a printed part (i.e. printed_electrical_part or printed_connector_part).
