internal_bond_pad_template

  ENTITY internal_bond_pad_template
      SUBTYPE OF (bond_pad_template);
    geometry                       : SET [1:?] OF closed_area_element;
    DIE_geometry_tolerance         : OPTIONAL x_y_tolerance;
    DIE_bond_sites                 : OPTIONAL SET [1:?] OF integer_point;
    DIE_metal_extent               : OPTIONAL closed_area_element;
    DIE_passivation_opening_extent : OPTIONAL closed_area_element;
    intended_mounting              : OPTIONAL bond_pad_intended_mounting;
  END_ENTITY;

Description:

An internal_bond_pad_template is a bond pad template definition found in an internal_library.

The DIE_geometry_tolerance specifies the variability of the geometry. This attribute has been derived from the DIE format Section 5.84.

The DIE_bond_sites attribute specifies the places to which bonds may be connected. This attribute has been derived from the DIE format Section 5.79.

The DIE_metal_extent specifies the area which is occupied by the metal which makes up the bond pad. This value may be differ from the geometry attribute since the latter only indicates the `exposed' pad metal. This attribute has been derived from the DIE format Section 5.80.

The DIE_passivation_opening_extent specifies the passivation opening which is either over or under the actual metal pad. This attribute has been derived from the DIE format Section 5.82.

The intended_mounting specifies how bond_pads which instantiate the internal_bond_pad_template are intended to be mounting. Note that there is no requirement for the actual mounting to match that which is intended.

Used by:

internal_template
