schematic_implementation_model

Description:

The schematic_implementation_model schema describes the structural connectivity and the physical implementation of a schematic view. That includes definitions of schematic_bus, schematic_net, schematic_offpageconnector, schematic_onpageconnector, schematic_master_port_representation, schematic_master_port_bundle_representation, schematic_global_port_representation, schematic_ripper, schematic_bus_junction, schematic_net_junction and schematic_interconnect_terminator. These structures are implemented on a page by specifying the position and orientation of occurrences of various schematic templates specified in the instantiatable_object_model. Bus and net structures are implemented by giving the associated graphics and the display control information to allow the display of names and other attributes, such as criticality and delay.

page

  ENTITY page;
    background_colour             : colour;                 
    border                        : OPTIONAL page_border;
    busses                        : OPTIONAL SET [1:?] OF schematic_bus;
    cell_property_displays        : OPTIONAL SET [1:?] OF property_display;
    cluster_property_displays     : OPTIONAL SET [1:?] OF property_display;
    document                      : OPTIONAL SET [1:?] OF documentation;
    global_port_representations   : OPTIONAL SET [1:?] OF
                                    schematic_global_port_representation; 
    instance_implementations      : OPTIONAL SET [1:?] OF
                                    schematic_instance_implementation; 
    local_port_groups             : OPTIONAL SET [1:?] OF
                                    local_master_port_group;
    master_port_representations   : OPTIONAL SET [1:?] OF
                                    schematic_master_port_representation; 
    master_port_bundle_representations 
                                  : OPTIONAL SET [1:?] OF
                                    schematic_master_port_bundle_representation;
    name                          : OPTIONAL name_information;
    nets                          : OPTIONAL SET [1:?] OF schematic_net;
    offpageconnectors             : OPTIONAL SET [1:?] OF
                                    schematic_offpageconnector; 
    onpageconnectors              : OPTIONAL SET [1:?] OF
                                    schematic_onpageconnector;  
    original_bounding_box         : OPTIONAL rectangle;
    page_comment_graphics         : OPTIONAL SET [1:?] OF page_comment_graphics;
    page_size                     : OPTIONAL rectangle;
    properties                    : OPTIONAL SET [1:?] OF property;
    property_displays             : OPTIONAL SET [1:?] OF property_display;
    rippers                       : OPTIONAL SET [1:?] OF schematic_ripper;
    status_of_copyright           : OPTIONAL SET [1:?] OF copyright;
    status_of_written             : OPTIONAL SET [1:?] OF written;
    title                         : OPTIONAL SET [1:?] OF page_title_block;
    view_property_displays        : OPTIONAL SET [1:?] OF property_display;
  DERIVE
    containing_view : internal_schematic_view -- reference
      := usedin_one_role(SELF, 
         'schematic_view_model.internal_schematic_view.pages');
  WHERE
    containment_constraint :
      (* A page belongs to one internal_schematic_view. *)
      belongs_to_one(SELF,'schematic_view_model.internal_schematic_view.pages');

    valid_instance_implementations :
      (* The implemented instance are defined in the containing view. *)
      not_exists(QUERY(implementation <* instance_implementations |
      NOT (implementation.implemented_instance IN containing_view.instances)));

    valid_cell_property_displays :
      (* The displayed properties are defined in the containing cell. *)
      not_exists(QUERY(cellPropertyDisplay <* cell_property_displays |
        NOT (cellPropertyDisplay.displayed_property IN
             containing_view.containing_cluster.containing_cell.properties)));

    valid_cluster_property_displays :
      (* The displayed properties are defined in the containing
         internal_cluster. *) 
      not_exists(QUERY(clusterPropertyDisplay <* cluster_property_displays |
        NOT (clusterPropertyDisplay.displayed_property
             IN containing_view.containing_cluster.properties)));

    valid_global_port_representations :
      (* The global_port_representations must only reference the global_ports
         or global_port_bundles which are defined in the containing edif. *)
      not_exists(QUERY(globalPortRepresentation <* global_port_representations |
        NOT ((globalPortRepresentation.implemented_global_port
              IN containing_view.containing_cluster.containing_cell
                 .containing_library.containing_edif.global_ports)
              OR
             (globalPortRepresentation.implemented_global_port
              IN containing_view.containing_cluster.containing_cell
                 .containing_library.containing_edif.global_port_bundles))));

    valid_master_port_representations :
      (* The master_port_representations must only reference the master_ports
         which are defined in the interface of the containing cluster. *) 
      not_exists(QUERY(portRepresentation <* master_port_representations |
        NOT (portRepresentation.implemented_master_port
             IN containing_view.interface.ports)));

    valid_master_port_bundle_representations :
      (* The master_port_bundle_representations must only reference the
         master_port_bundles which are defined in the interface of the
         containing cluster or the local_master_port_groups which are defined 
         on the page. *)  
      not_exists(QUERY(portBundleRepresentation 
        <* master_port_bundle_representations |
        NOT ((portBundleRepresentation.implemented_master_port_bundle
             IN containing_view.interface.port_bundles)
             AND (portBundleRepresentation.implemented_master_port_bundle
                  IN local_port_groups))));

    valid_property_displays :
      (* The displayed properties are defined in the page. *)
      not_exists(QUERY(pagePropertyDisplay <* property_displays |
        NOT (pagePropertyDisplay.displayed_property IN properties)));

    valid_view_property_displays :
      (* The displayed properties are defined in the containing
         internal_schematic_view. *) 
      not_exists(QUERY(viewPropertyDisplay <* view_property_displays |
        NOT (viewPropertyDisplay.displayed_property 
             IN containing_view.properties)));

    valid_optional_attributes :
      (* The dependencies of these optional attributes are stated as follows:
         1. A page cannot have instance_implementations if its containing view
            does not define any instances.
         2. A page cannot have cell_property_displays if its containing cell
            does not define any properties.
         3. A page cannot have cluster_property_displays if its containing
            cluster does not define any instances.
         4. A page cannot have global_port_representations if its containing
            edif does not define any global_ports.
         5. A page cannot have master_port_representations or local_port_groups
            if the interface of its containing cluster does not define any
            master_ports. 
         6. A page cannot have master_port_bundle_representations if the
            interface of its containing cluster does not define any
            master_port_bundles. 
         7. A page cannot have property_displays if it does not define any
            properties. 
         8. A page cannot have view_property_displays if its containing view
            does not define any properties. *)

      (EXISTS(containing_view.instances) OR
         NOT EXISTS(instance_implementations))
       AND
      (EXISTS(containing_view.containing_cluster.containing_cell.properties) OR
         NOT EXISTS(cell_property_displays))
       AND
      (EXISTS(containing_view.containing_cluster.properties) OR
         NOT EXISTS(cluster_property_displays))
       AND
      (EXISTS(containing_view.containing_cluster.containing_cell.
              containing_library.containing_edif.global_ports) OR
         EXISTS(containing_view.containing_cluster.containing_cell.
                containing_library.containing_edif.global_port_bundles) OR
         NOT EXISTS(global_port_representations))
       AND
      (EXISTS(containing_view.interface.ports) OR
         NOT EXISTS(master_port_representations) AND
         NOT EXISTS(local_port_groups))
       AND
      (EXISTS(containing_view.interface.port_bundles) OR
         EXISTS(local_port_groups) OR
         NOT EXISTS(master_port_bundle_representations))
       AND
      (EXISTS(properties) OR NOT EXISTS(property_displays))
       AND
      (EXISTS(containing_view.properties) OR
         NOT EXISTS(view_property_displays));
  END_ENTITY;

Description:

A page is used to describe part of the structural connectivity and the implementation of a schematic view. It contains schematic_busses, schematic_nets and occurrences of various schematic_templates, such as schematic_global_port_representations, schematic_master_port_representations, schematic_offpageconnectors, schematic_onpageconnectors, schematic_bus_junctions, schematic_net_junctions, schematic_rippers and schematic_interconnect_terminators. In addition, it may have a page_border and one or more page_title_blocks. A page size can be specified to describe the size of the sheet the page is drawn on.

      (* The overridden properties are defined in the instantiated_template. *)
      not_exists(QUERY(valueOverride <* overriding_template_properties |
        NOT (valueOverride.overridden_property
             IN instantiated_template.properties)));

    valid_overriding_template_property_displays :
      (* The overridden properties are defined in the instantiated_template. *)
      not_exists(QUERY(displayOverride <* overriding_template_property_displays|
        NOT (displayOverride.overridden_property
             IN instantiated_template.properties)));

    valid_delay_displays :
      (* The displayed delays are defined in the implemented master_port. *)
      not_exists(QUERY(delayDisplay <* delay_displays |
        NOT (delayDisplay.displayed_delay IN implemented_master_port.delays)));

    valid_load_delay_displays :
      (* The displayed load_delays are defined in the implemented
         master_port. *) 
      not_exists(QUERY(loadDelayDisplay <* load_delay_displays |
        NOT (loadDelayDisplay.displayed_load_delay 
             IN implemented_master_port.load_delays)));

      not_exists(QUERY(propertyDisplay <* port_property_displays |

             IN implemented_master_port.properties)));

      (* The direction of the implemented_master_port must agree with the 
         direction_indicator of the master_port_template. *)
      (instantiated_template.direction_indicator
        = port_direction_indicator.unrestricted)
      OR
      ((instantiated_template.direction_indicator
         = port_direction_indicator.input)
        AND
        is_typeof(implemented_master_port,'hierarchy_model.input_master_port'))
      OR
      ((instantiated_template.direction_indicator
         = port_direction_indicator.output)
        AND
        is_typeof(implemented_master_port,'hierarchy_model.output_master_port'))
      OR
      ((instantiated_template.direction_indicator
         = port_direction_indicator.bidirectional)
        AND
        is_typeof(implemented_master_port, 
                  'hierarchy_model.bidirectional_master_port'))
      OR
      ((instantiated_template.direction_indicator
         = port_direction_indicator.unspecified)
        AND
        is_typeof(implemented_master_port,
                  'hierarchy_model.unspecified_direction_master_port'));

    valid_optional_attributes :
      (* The dependencies of these optional attributes are stated as follows:
         1. A port representation cannot have overriding_template_properties or
            overriding_template_property_displays if its instantiated template
            does not define any properties. 
         2. A port representation cannot have delay_displays if its implemented

         3. A port representation cannot have load_delay_displays if its
            implemented port does not define any load delays.
         4. A port representation cannot have port_property_displays if its

         NOT EXISTS(overriding_template_property_displays))
       AND
      (EXISTS(implemented_master_port.delays) OR
         NOT EXISTS(delay_displays))
       AND
      (EXISTS(implemented_master_port.load_delays) OR
         NOT EXISTS(load_delay_displays))
       AND
      (EXISTS(implemented_master_port.properties) OR
         NOT EXISTS(port_property_displays));
  END_ENTITY;

        NOT is_typeof(p, 'hierarchy_model.bidirectional_master_port'))))

      not_exists(QUERY(p <* implemented_master_port_bundle.flattened_port_list |
        NOT is_typeof(p, 'hierarchy_model.unspecified_direction_master_port'))))
    OR
    ((instantiated_template.direction_indicator
       = port_direction_indicator.mixed_direction)

      there_exists(QUERY(p1 
         <* implemented_master_port_bundle.flattened_port_list |
        there_exists(QUERY(p2 
          <* implemented_master_port_bundle.flattened_port_list |

            implemented port bundle does not define any load delays.
         4. A port bundle representation cannot have port_property_displays if

         NOT EXISTS(overriding_template_properties) AND
         NOT EXISTS(overriding_template_property_displays))
       AND
      (there_exists(QUERY(p 
          <* implemented_master_port_bundle.flattened_port_list |
          EXISTS(p.delays))) OR
         NOT EXISTS(delay_displays))
       AND
      (there_exists(QUERY(p 
          <* implemented_master_port_bundle.flattened_port_list |
          EXISTS(p.load_delays))) OR
         NOT EXISTS(load_delay_displays))
       AND
      (EXISTS(implemented_master_port_bundle.properties) OR
         NOT EXISTS(port_property_displays));
  END_ENTITY;

Description:

A schematic_generic_bus can be either a schematic_bus, a schematic_bus_slice or a schematic_sub_bus. A schematic_generic_bus is used in the model because of the similarity between a schematic_bus, a schematic_bus_slice and a schematic_sub_bus. They may all contain schematic_bus_slices and schematic_sub_busses. No two schematic_bus_slices at a given level may be associated with the same signal_group. No two schematic_sub_busses at a given level may join to the same set of ports and instantiatable schematic objects. All joined global_ports, global_port_bundles, local_master_port_groups, master_ports and master_port_bundles must be the same size as the flattened signal_group. Each single port of the joined port_bundles must be mentioned in the corresponding signal within the flattened signal_group.

When a wide bus joins to an instance_port or an instance_port_bundle, the pattern of connectivity will be either in the commoned style or in the fanned out style. For the commoned style, the joined instance_ports or instance_port_bundles reference master_ports or master_port_bundles whose port size is the same as the size of the flattened signal_group. For the fanned out style, the joined instance_ports or instance_port_bundles are flattened to lists of instance_member_ports. The length of these lists must be equal to the size of the flattened signal_group.

For example, if a bus structure is associated with a signal_group of size 8, it is valid to use it to join to the following ports of various sizes: 

   global_port_bundle (port_bundle size = 8)
   instance_port in fanned out style (instance size = 8)
   instance_port_bundle in commoned style (port bundle size = 8)
   instance_port_bundle in fanned out style (instance size = 2, 
                                               port_bundle size = 4)
   instance_port_bundle in fanned out style (instance size = 4, 
                                               port_bundle size = 2)
   local_master_port_group (port_group size = 8)
   master_port_bundle (port_bundle size = 8)
