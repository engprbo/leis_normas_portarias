pcb_material_model

Description:

The pcb_material_model schema describes the set of materials which may be used during the construction of a bare board.

material

  ENTITY material
      ABSTRACT SUPERTYPE OF (ONEOF(external_material,
                                   internal_material)
                             AND
                             ONEOF(non_standard_material,
                                   standard_material));
    document        : OPTIONAL SET [1:?] OF documentation;
    electrical_type : material_electrical_type;
    name            : OPTIONAL name_information;
    properties      : OPTIONAL SET [1:?] OF property;
    written_status  : OPTIONAL SET [1:?] OF written;
  WHERE
    valid_existence :
      (* A material belongs to one library. *)
      belongs_to_one(SELF,'library_model.library.materials');
  END_ENTITY;

Description:

A material object describes a particular physical material, in terms of its name and physical properties (e.g. electrical conductivity, relative permittivity, thermal conductivity, density, etc).

Used by:

DIE_metallized_backside_finish internal_die_physical_template internal_physical_layer library material_value plated_drill_rule

external_material

  ENTITY external_material
      SUBTYPE OF (material);
  WHERE
    valid_existence :

      belongs_to_one(SELF,'library_model.external_library.materials');
  END_ENTITY;

An external_material is defined in an external_library.

Used by:

external_library

An internal_material is defined in an internal_library.

Used by:

non_standard_material

  ENTITY non_standard_material
      SUBTYPE OF (material);
    electrical_conductivity : OPTIONAL electrical_conductivity_value;
    relative_permittivity   : OPTIONAL relative_permittivity_value;
    thermal_conductivity    : OPTIONAL thermal_conductivity_value;
    density                 : OPTIONAL density_value;
    specific_heat_capacity  : OPTIONAL specific_heat_capacity_value;
  END_ENTITY;

Description:

A non_standard_material object describes a particular physical material, in terms of its local name (inherited from the material super-entity) and a series of locally-defined material properties.

standard_material

  ENTITY standard_material
      SUBTYPE OF (material);
  END_ENTITY;

Description:

A standard_material describes a material which is assumed to be defined elsewhere, perhaps in a dictionary of standard materials.

The material_electrical_type describes the electrical type of the material.

density_unit

  ENTITY density_unit;
    referenced_unit : unit; -- reference
  WHERE
    valid_existence :
      belongs_to_one(SELF,
        'pcb_material_model.material_units.set_density');

    valid_referenced_unit :
      (* The physical_type of the unit is kilogram per cubic metre. *)
      (SIZEOF(referenced_unit.physical_type) = 2)
       AND
      (SIZEOF(QUERY(physicalType <* referenced_unit.physical_type |
                    (physicalType.basic_unit = physical_unit.kilogram)
                    AND (physicalType.exponent = 1))) = 1)
       AND
      (SIZEOF(QUERY(physicalType <* referenced_unit.physical_type |
                    (physicalType.basic_unit = physical_unit.metre)
                    AND (physicalType.exponent = -3))) = 1);
  END_ENTITY;

Description:

A density_unit specifies a unit which is used for the scaling of density_value. The physical type of the chosen unit is defined in kilogram per cubic metre.

Used by:

material_units

specific_heat_capacity_unit

  ENTITY specific_heat_capacity_unit;
    referenced_unit : unit; -- reference
  WHERE
    valid_existence :
      either_belongs_to_one(SELF,
        ['pcb_material_model.material_units.set_specific_heat_capacity',
         'pcb_mcm_view_model.pcb_layout_units.set_specific_heat_capacity']);

    valid_referenced_unit :
      (* The physical_type of the unit is in joule per kilogram per kelvin. *)
      (SIZEOF(referenced_unit.physical_type) = 3)
       AND
      (SIZEOF(QUERY(physicalType <* referenced_unit.physical_type |
                    (physicalType.basic_unit = physical_unit.joule)
                    AND (physicalType.exponent = 1))) = 1)
       AND
      (SIZEOF(QUERY(physicalType <* referenced_unit.physical_type |
                    (physicalType.basic_unit = physical_unit.kilogram)
                    AND (physicalType.exponent = -1))) = 1)
       AND
      (SIZEOF(QUERY(physicalType <* referenced_unit.physical_type |
                    (physicalType.basic_unit = physical_unit.kelvin)
                    AND (physicalType.exponent = -1))) = 1);
  END_ENTITY;

Description:

A specific_heat_capacity_unit specifies a unit which is used for the scaling of specific_heat_capacity_value. The physical type of the chosen unit is defined in joule per kilogram per kelvin.

Used by:

material_units pcb_layout_units

temperature_unit

  ENTITY temperature_unit;
    referenced_unit : unit; -- reference
  WHERE
    valid_existence :
      belongs_to_one(SELF,
        'pcb_mcm_view_model.pcb_layout_units.set_temperature');

    valid_referenced_unit :
      (* The physical_type of the unit can be celsius, kelvin or fahrenheit. *)
      valid_unit_type(referenced_unit, physical_unit.celsius)
      OR
      valid_unit_type(referenced_unit, physical_unit.fahrenheit)
      OR
      valid_unit_type(referenced_unit, physical_unit.kelvin);
  END_ENTITY;

Description:

A temperature_unit specifies a unit which is used for the scaling of temperature_range. The physical type of the chosen unit can be defined in celsius, kelvin or farenheit.

Used by:

pcb_layout_units
