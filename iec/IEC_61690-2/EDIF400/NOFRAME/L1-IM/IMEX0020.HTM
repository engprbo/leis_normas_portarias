pcb_board_subset_model

Description:

The pcb_board_subset_model schema describes the objects which are used by a pcb_drawing to display a part of a board.

board_subset

  ENTITY board_subset
    ABSTRACT SUPERTYPE OF(ONEOF(board_subset_definition,
                                board_subset_extra_detail));
    construction_figures : OPTIONAL SET [1:?] OF
                           board_subset_construction_figure; 
    dimensioned_figures  : OPTIONAL SET [1:?] OF dimensioned_geometric_figure;
    clipping_outline     : OPTIONAL unfilled_element;
  DERIVE
    containing_assembled_board : assembled_board -- reference
      := usedin_one_role(SELF,
         'pcb_assembled_board_model.assembled_board.drawing_board_subsets');
    containing_bare_board : internal_bare_board_definition -- reference
      := usedin_one_role(SELF,
         specified_role('pcb_sub_layout_model',
                        'internal_bare_board_definition',
                        'drawing_board_subsets'));
  WHERE
    valid_existence:
      (* A board_subset belong to either one assembled_board or one
         internal_bare_board_definition. *) 
    either_belongs_to_one(SELF, 
    ['pcb_assembled_board_model.assembled_board.drawing_board_subsets',
     specified_role('pcb_sub_layout_model',
                    'internal_bare_board_definition',
                    'drawing_board_subsets')]);
  END_ENTITY;

Description:

A board_subset can be either a board_subset_definition or a board_subset_extra_detail.

The clipping_outline attribute can be used in order to display only a part of the board_subset.

Used by:

assembled_board board_subset_placement dimensioned_geometric_figure internal_bare_board_definition

board_subset_definition

  ENTITY board_subset_definition
    SUBTYPE OF(board_subset);
    includes_drawing_figure_collectors   : OPTIONAL SET [1:?] OF
                                           drawing_figure_collector_inclusion;
    includes_fabricate_figure_collectors : OPTIONAL SET [1:?] OF
                                           fabricate_figure_collector_inclusion;
    chosen_component_symbols             : OPTIONAL SET [1:?] OF
                                           component_symbol_selection;
    chosen_drill_symbols                 : OPTIONAL SET [1:?] OF
                                           drill_symbol_selection;
  WHERE
    valid_fabricate_figure_collectors:
      (* The fabricate_figure_collector_inclusions must reference the
         fabricate_figure_collectors which are used in the physical_layers in
         which the containing assembled board or bare board is implemented. *)
      (EXISTS(SELF\board_subset.containing_assembled_board)
       AND
       (not_exists(QUERY(fc <* includes_fabricate_figure_collectors |
          not_exists(QUERY(layer <* SELF\board_subset.containing_assembled_board
                                    .is_based_on.instantiated_bare_board
                                    \sub_layout_definition
                                    .is_implemented_in.layers |
          EXISTS(layer.referenced_figure_collector)
          AND 
          (fc.inclusion_of :=: layer.referenced_figure_collector)))))))
      OR
      (EXISTS(SELF\board_subset.containing_bare_board)
       AND
       (not_exists(QUERY(fc <* includes_fabricate_figure_collectors |
          not_exists(QUERY(layer <* SELF\board_subset.containing_bare_board
                                    \sub_layout_definition
                                    .is_implemented_in.layers |
          EXISTS(layer.referenced_figure_collector)
          AND 
          (fc.inclusion_of :=: layer.referenced_figure_collector)))))));
  END_ENTITY;

Description:

A board_subset_definition is a subset of the components that describe a board. Its main purpose is to allow the visualisation of chosen aspects of the board e.g. tracks or component outlines.

Used by:

component_symbol_selection

component_symbol_selection

  ENTITY component_symbol_selection;
    referenced_component : component_implementation; -- reference
    selected_symbol      : component_symbol; -- reference
  DERIVE
    containing_board_subset : board_subset_definition -- reference
      := usedin_one_role(SELF,
         specified_role('pcb_board_subset_model',
                        'board_subset_definition',
                        'chosen_component_symbols'));
    containing_assembled_board : assembled_board -- reference
      := usedin_one_role(containing_board_subset,
         'pcb_assembled_board_model.assembled_board.drawing_board_subsets');
  WHERE
    valid_existence :
      (* A component_symbol_selection belongs to one
         board_subset_definition. *) 
    belongs_to_one(SELF,
    'pcb_board_subset_model.board_subset_definition.chosen_component_symbols');

    valid_referenced_component :
      (* The referenced component_implementation must be defined in the
         assembled_board which owns the containing board_subset_definition via
         pcb_drawing. *)
      EXISTS(containing_assembled_board.component_implementations)
      AND
      (referenced_component
         IN containing_assembled_board.component_implementations);

    valid_selected_symbol:
      (* If the component_implementation is a
         packaged_component_implementation, then the selected component_symbol
         must be a symbol of the mountable_package used by the
         packaged_component_implementation.  If the component_implementation is
         a die_component_implementation, then the selected component_symbol
         must be a symbol of the mountable_die_physical_template used by the
         die_component_implementation.  If the component_implementation is a
         printed_component_implementation, the selected component_symbol must be
         a symbol of the printed part. *)

     (is_typeof(referenced_component, 
                'pcb_assembled_board_model.packaged_component_implementation')
      AND
      EXISTS(referenced_component\packaged_component_implementation
                                 .uses_mountable_package.symbols)
      AND
      (selected_symbol 
       IN referenced_component\packaged_component_implementation
                              .uses_mountable_package.symbols))
     OR
     (is_typeof(referenced_component,
                'pcb_assembled_board_model.die_component_implementation')
      AND
      EXISTS(referenced_component\die_component_implementation
                                  .mountable_template.symbols)
      AND
      (selected_symbol 
       IN referenced_component\die_component_implementation
                              .mountable_template.symbols))
     OR
     (is_typeof(referenced_component,
      'pcb_assembled_board_model.printed_electrical_component_implementation')
      AND
      EXISTS(referenced_component\printed_electrical_component_implementation
                                 .implemented_component
                                 .instantiated_part.symbols)
      AND
      (selected_symbol 
       IN referenced_component\printed_electrical_component_implementation
                               .implemented_component
                               .instantiated_part.symbols))
     OR
     (is_typeof(referenced_component,
      'pcb_assembled_board_model.printed_connector_component_implementation')
      AND
      EXISTS(referenced_component\printed_connector_component_implementation
                                 .implemented_component
                                 .instantiated_part.symbols)
      AND
      (selected_symbol 
       IN referenced_component\printed_connector_component_implementation
                               .implemented_component
                               .instantiated_part.symbols));
  END_ENTITY;

Description:

A component_symbol_selection chooses a symbol to represent a component on an assembled_board.

Used by:

drill_symbol_selection

  ENTITY drill_symbol_selection;
    referenced_drill : drill_rule; -- reference
    selected_symbol  : drill_symbol; -- reference
  WHERE
    valid_existence :
      (* A drill_symbol_selection belongs to one board_subset_definition. *) 
      belongs_to_one(SELF,
        'pcb_board_subset_model.board_subset_definition.chosen_drill_symbols');

    valid_selected_symbol:
      (* The selected drawing_symbol must be a symbol of the referenced
         drill_rule. *)   
      EXISTS(referenced_drill.symbols)
      AND
      (selected_symbol IN referenced_drill.symbols);
  END_ENTITY;

Description:

A drill_symbol_selection chooses a symbol to represent drilled holes (i.e. conformant_hole) which conform to a particular drill_rule.

Used by:

  DERIVE

      := usedin_one_role(SELF,
         'pcb_board_subset_model.board_subset.dimensioned_figures');

    valid_existence:
      (* A dimensioned_geometric_figure belongs to one board_subset. *) 
      belongs_to_one(SELF,
        'pcb_board_subset_model.board_subset.dimensioned_figures');

         bare_board_definition/assembled_board to which the drawing

layout_feature_occurrence

  ENTITY layout_feature_occurrence;
    within_sub_layout : OPTIONAL sub_layout_occurrence;
    physical_net_path : OPTIONAL physical_net; -- reference
    occurrence_of     : layout_feature;
  WHERE
    valid_physical_net_path:
      (* The physical_net must be within a physical_net within the
         sub_layout_definition specified by the sub_layout_occurrence.
         Note that the physical_net can be enclosed by several other
         physical_nets but it cannot be an instance_net. *)
      check_valid_physical_net_path(SELF);

    valid_layout_feature:
      (* The layout_feature must be within the physical_net. *)
      NOT (EXISTS(physical_net_path)
           AND
           is_typeof(physical_net_path,
                     'pcb_sub_layout_model.internal_physical_net')
           AND
           EXISTS(physical_net_path\internal_physical_net.layout_features)
           AND
           NOT (occurrence_of IN physical_net_path\internal_physical_net
                                 .layout_features));
  END_ENTITY;

Description:

A layout_feature_occurrence is an occurrence of a layout_feature, zero one or more levels down the sub_layout hierarchy and within zero, one or more physical_nets

Used by:

dimensioned_object

valid_sub_layout_occurrence_path

  FUNCTION valid_sub_layout_occurrence_path
    (sublayouts : LIST OF sub_layout_instance) : BOOLEAN;
    LOCAL
      layoutType : SET OF STRING;
    END_LOCAL;
    REPEAT i := 2 TO SIZEOF(sublayouts);
      layoutType := TYPEOF(sublayouts[i-1]);
      IF 'pcb_sub_layout_model.test_coupon_instance' IN layoutType THEN
         IF NOT (sublayouts[i] IN sublayouts[i-1]\test_coupon_instance
                                  .is_defined_by.sub_layouts) THEN
            RETURN(FALSE);
         END_IF;
      ELSE
      IF 'pcb_sub_layout_model.footprint_instance' IN layoutType THEN
         IF NOT ((sublayouts[i] IN sublayouts[i-1]\footprint_instance
                                   .is_defined_by.toeprints) 
                 OR
                 (sublayouts[i] IN sublayouts[i-1]\footprint_instance
                                   .is_defined_by.other_sub_layouts)) THEN
            RETURN(FALSE);
         END_IF;
      ELSE
      IF 'pcb_sub_layout_model.toeprint_instance' IN layoutType THEN
         IF NOT ((sublayouts[i] IN sublayouts[i-1]\toeprint_instance
                                   .is_defined_by.padstacks) 
                 OR
                 (sublayouts[i] IN sublayouts[i-1]\toeprint_instance
                                   .is_defined_by.other_sub_layouts)) THEN
            RETURN(FALSE);
         END_IF;
      ELSE
      IF 'pcb_sub_layout_model.non_specific_sub_layout_instance' 
         IN layoutType THEN
         IF NOT (sublayouts[i] IN sublayouts[i-1]
                                  \non_specific_sub_layout_instance
                                  .is_defined_by.other_sub_layouts) THEN
            RETURN(FALSE);
         END_IF;
      END_IF;
      END_IF;
      END_IF;
      END_IF;
    END_REPEAT;
    RETURN(TRUE);
  END_FUNCTION;

Description:

The valid_sub_layout_occurrence_path function returns true if the definition path of a sub_layout_occurrence is valid. At any level of the definition path, if a sub_layout_instance (sublayouts[i-1]) is followed by another sub_layout_instance (sublayouts[i]), then sublayouts[i] must be defined within the sub_layout_definition from which sublayouts[i-1] is instantiated.

Used by:

sub_layout_occurrence

check_valid_physical_net_path

  FUNCTION check_valid_physical_net_path
    (occ : layout_feature_occurrence) : BOOLEAN;
    LOCAL
      path : LIST [1:?] OF sub_layout_instance;
    END_LOCAL;
    path := occ.within_sub_layout.definition_path;
    REPEAT i := 1 TO SIZEOF(path);
      IF occ.physical_net_path IN path[i].is_defined_by.physical_nets THEN
         RETURN(TRUE);
      END_IF;
    END_REPEAT;
    RETURN(FALSE);
  END_FUNCTION;

Description:

The check_valid_physical_net_path function is used in the layout_feature_occurrence to check that the referenced physical_net must be defined within the sub_layout_definition as specified by the sub_layout_occurrence.

Used by:

layout_feature_occurrence

valid_dimensioned_object

  FUNCTION valid_dimensioned_object
    (fig : dimensioned_geometric_figure) : BOOLEAN;
    LOCAL
      assembledBoard : assembled_board 
                       := fig.containing_board_subset
                             .containing_assembled_board;
      bareBoard      : internal_bare_board_definition
                       := fig.containing_board_subset.containing_bare_board;
      bareBoardDef   : bare_board_definition;
      objects        : SET OF dimensioned_object := fig.within_shown_objects;
      objectType     : SET OF STRING;
    END_LOCAL;
    REPEAT i := 1 TO SIZEOF(objects);
      objectType := TYPEOF(objects[i]);
      IF ('pcb_sub_layout_model.board_outline' IN objectType) THEN
         bareBoardDef := NVL(assembledBoard.is_based_on.instantiated_bare_board,
                             bareBoard);
         IF ('pcb_sub_layout_model.internal_bare_board_definition' 
             IN TYPEOF(bareBoardDef)) THEN
             IF objects[i] :<>: bareBoardDef\internal_bare_board_definition
                                            .outline THEN 
               RETURN(FALSE);
             END_IF;
         END_IF;
      ELSE
      IF ('pcb_sub_layout_model.plane' IN objectType) THEN 
         bareBoardDef := NVL(assembledBoard.is_based_on.instantiated_bare_board,
                             bareBoard);
         IF ('pcb_sub_layout_model.internal_bare_board_definition' 
             IN TYPEOF(bareBoardDef)) THEN
             IF NOT (objects[i].containing_physical_net 
                     IN bareBoardDef\internal_bare_board_definition
                                    .physical_nets) THEN
                RETURN(FALSE);
             END_IF;
         END_IF;
      ELSE
      IF ('pcb_sub_layout_model.probe_point' IN objectType) THEN 
         bareBoardDef := NVL(assembledBoard.is_based_on.instantiated_bare_board,
                             bareBoard);
         IF ('pcb_sub_layout_model.internal_bare_board_definition' 
             IN TYPEOF(bareBoardDef)) THEN
             IF NOT (objects[i] IN bareBoardDef\internal_bare_board_definition
                                               .probe_points) THEN 
               RETURN(FALSE);
             END_IF;
         END_IF;
      ELSE
      IF ('pcb_assembled_board_model.component_implementation' 
          IN objectType) THEN 
         IF NOT EXISTS(assembledBoard) THEN
            RETURN(FALSE);
         ELSE 
         IF objects[i].containing_board :<>: assembledBoard THEN
            RETURN(FALSE);
         END_IF;
         END_IF;
      ELSE
      IF ('pcb_assembled_board_model.component_terminal_implementation'
          IN objectType) THEN 
         IF NOT EXISTS(assembledBoard) THEN
            RETURN(FALSE);
         ELSE 
         IF objects[i].containing_implementation.containing_board 
            :<>: assembledBoard THEN
            RETURN(FALSE);
         END_IF;
         END_IF;
      ELSE
      IF ('pcb_assembled_board_model.jumper_connection' IN objectType) THEN 
         IF NOT EXISTS(assembledBoard) THEN
            RETURN(FALSE);
         ELSE 
         IF objects[i].containing_net.containing_board :<>: assembledBoard THEN
            RETURN(FALSE);
         END_IF;
         END_IF;
      ELSE
      IF ('pcb_board_subset_model.board_subset_construction_figure' 
          IN objectType) THEN
         IF NOT (objects[i] 
                 IN fig.containing_board_subset.construction_figures) THEN
            RETURN(FALSE);
         END_IF;
      ELSE
      IF ('pcb_board_subset_model.board_subset_extra_detail_figure' 
          IN objectType) THEN
         IF ('pcb_board_subset_model.board_subset_definition'
             IN TYPEOF(fig.containing_board_subset)) THEN
             RETURN(FALSE);
         ELSE
         IF NOT (objects[i] IN fig.containing_board_subset
                                  \board_subset_extra_detail.details) THEN
            RETURN(FALSE);
         END_IF;
         END_IF;
      ELSE
      IF ('pcb_board_subset_model.sub_layout_occurrence' IN objectType) THEN 
         bareBoardDef := NVL(assembledBoard.is_based_on.instantiated_bare_board,
                             bareBoard);
         IF NOT (objects[i].definition_path[1] IN bareBoardDef.sub_layouts) THEN
            RETURN(FALSE);
         END_IF;
      ELSE
      IF ('pcb_board_subset_model.layout_feature_occurrence' IN objectType) THEN
         bareBoardDef := NVL(assembledBoard.is_based_on.instantiated_bare_board,
                             bareBoard);
         IF EXISTS(objects[i].within_sub_layout) THEN
            IF NOT (objects[i].within_sub_layout.definition_path[1] 
                    IN bareBoardDef.sub_layouts) THEN
               RETURN(FALSE);
            END_IF;
         ELSE
         IF EXISTS(objects[i].physical_net_path) THEN
            IF NOT (objects[i].physical_net_path 
                    IN bareBoardDef.physical_nets) THEN
               RETURN(FALSE);
            END_IF;
         ELSE
         IF ('pcb_sub_layout_model.internal_bare_board_definition' 
             IN TYPEOF(bareBoardDef)) THEN
            IF NOT (objects[i].occurrence_of 
                    IN bareBoardDef\internal_bare_board_definition
                                   .layout_features) THEN
               RETURN(FALSE);
            END_IF;
         END_IF;
         END_IF;
         END_IF;
      END_IF;
      END_IF;
      END_IF;
      END_IF;
      END_IF;
      END_IF;
      END_IF;
      END_IF;
      END_IF;
      END_IF;
    END_REPEAT;
    RETURN(TRUE);       
  END_FUNCTION;

Description:

The valid_dimensioned_object function returns true if all dimensioned objects are defined within the drawing or within the bare board/assembled board which contains the drawing.

Used by:

dimensioned_geometric_figure
