mcm_mountable_die_physical_model

Description:

The mcm_mountable_die_physical_model describes a mountable_die_physical_template which provides mounting information of a die_physical_template.

mountable_die_physical_template

  ENTITY mountable_die_physical_template
      ABSTRACT SUPERTYPE OF (ONEOF (external_mountable_die_physical_template,
                                    internal_mountable_die_physical_template));
    document       : OPTIONAL SET [1:?] OF documentation;
    mountable_pads : SET [1:?] OF mountable_bond_pad;
    name           : OPTIONAL name_information;
    properties     : OPTIONAL SET [1:?] OF property;
    symbols        : OPTIONAL SET [1:?] OF
                     mountable_die_physical_template_symbol;
    units          : pcb_layout_units;
    written_status : OPTIONAL SET [1:?] OF written;
  END_ENTITY;

Description:

A mountable_die_physical_template is the manner in which a die_physical_template may be mounted on an MCM.

Used by:

die_component_implementation embedded_die_placement library

Description:

Used by:

internal_mountable_die_physical_template

  ENTITY internal_mountable_die_physical_template
      SUBTYPE OF (mountable_die_physical_template);
    SELF\mountable_die_physical_template.mountable_pads
        : SET [1:?] OF internal_mountable_bond_pad;
    SELF\mountable_die_physical_template.symbols
        : OPTIONAL SET [1:?] OF internal_mountable_die_physical_template_symbol;
    referenced_die_physical_template : die_physical_template; -- reference
    flipped                          : boolean_token;
    die_tabbing                      : OPTIONAL tabbing;
    side_of_mounting                 : mounting_side;
    auxiliary_components             : OPTIONAL SET [1:?] OF
                                       auxiliary_component; 
    body_volume                      : OPTIONAL SET [1:?] OF extrusion_volume;
    occupied_space                   : OPTIONAL SET [1:?] OF extrusion_volume;
    position_tolerance               : OPTIONAL die_position_tolerance;
    DIE_backside_finish              : OPTIONAL DIE_backside_finish;
    DIE_bonding_sequence             : OPTIONAL LIST [2:?] OF SET [1:?] OF
                                       internal_mountable_bond_pad; -- reference
    DIE_sealing_condition            : OPTIONAL DIE_environmental_condition;
    DIE_attachment_condition         : OPTIONAL DIE_environmental_condition;
    DIE_bonding_condition            : OPTIONAL DIE_environmental_condition;
  WHERE
    valid_existence :
      (* An internal_mountable_die_physical_template belongs to one
         internal_library. *)
      belongs_to_one (SELF,
        'library_model.internal_library.mountable_die_templates');
  
    valid_tabbing :
      (* A die_physical_template cannot be tabbed during mounting if
         it is already tabbed. *)
      NOT (EXISTS (die_tabbing) 
           AND
           is_typeof(referenced_die_physical_template,
                     'mcm_die_physical_model.internal_die_physical_template')
           AND
           EXISTS (referenced_die_physical_template
                   \internal_die_physical_template.die_tabbing));

    valid_pad_match :
      (* There is a mountable_bond_pad for each bond_pad. *)
      SIZEOF(mountable_pads) = SIZEOF(referenced_die_physical_template.pads);
  
    valid_mounting_side :
      (* A die cannot be mounted on the side of an MCM. *)
      side_of_mounting <> mounting_side.edge;

    valid_bonding_pads :
      (* The bonding sequence must reference pads from the template. *)
      not_exists(QUERY(sequence <* DIE_bonding_sequence |
        NOT (sequence <= mountable_pads)));

    valid_bonding_sequence_pads :
      (* The bonding sequence specifies pads of the template *)
      not_exists(QUERY(sequence <* DIE_bonding_sequence |
        there_exists(QUERY(pad <* sequence |
           NOT (pad IN mountable_pads)))));

    unique_bonding_sequence_pads :
      (* A pad cannot be mentioned in the bonding sequence more than once *)
      not_exists(QUERY(bondPadSet1 <* DIE_bonding_sequence |
        there_exists(QUERY(bondPadSet2 <* DIE_bonding_sequence |
          (bondPadSet1 :<>: bondPadSet2)
          AND
          there_exists(bondPadSet1 * bondPadSet2)))));
  END_ENTITY;

Description:

An internal_mountable_die_physical_template is a mountable_die_physical_template within an internal_library.

The DIE_backside_finish attribute indicates the coating of the backside of the die. This attribute has been derived from the DIE format, Section 5.8.

The DIE_bonding_sequence attribute indicates the order in which mountable_bond_pads are to be connected to the MCM. The members of a set of mountable_bond_pads should all be bonded before any members of a set later in the list. This attribute has been derived from the DIE format, Section 5.10.

The DIE_sealing_condition attribute indicates the environmental condition which should be met during the sealing of the die within any container. This attribute has been derived from the DIE format, Section 5.14.

The DIE_attachment_condition attribute indicates the environmental condition which should be met during the die attachment process. This attribute has been derived from the DIE format, Section 5.13.

The DIE_bonding_condition attribute indicates the environmental condition which should be met during the die bonding process. This attribute has been derived from the DIE format, Section 5.12.

Used by:

internal_library internal_mountable_bond_pad internal_mountable_die_physical_template_symbol

die_position_tolerance

  ENTITY die_position_tolerance;
    origin_positive_x_displacement : integer_distance_value;
    origin_positive_y_displacement : integer_distance_value;
    origin_negative_x_displacement : integer_distance_value;
    origin_negative_y_displacement : integer_distance_value;
    rotation_positive_displacement : angle_value;
    rotation_negative_displacement : angle_value;
  WHERE
    valid_existence :
      belongs_to_one (SELF,
        specified_role('mcm_mountable_die_physical_model',
                       'internal_mountable_die_physical_template',
                       'position_tolerance'));

    valid_displacements :
      (* The displacement values are not less than zero.  Note that the
         negative displacement is absolute. *)
      (origin_positive_x_displacement >= 0)
      AND
      (origin_negative_x_displacement >= 0)
      AND
      (origin_positive_y_displacement >= 0)
      AND
      (origin_negative_y_displacement >= 0)
      AND
      (rotation_positive_displacement >= 0)
      AND
      (rotation_negative_displacement >= 0);
  END_ENTITY;

Description:

An die_position_tolerance is the amount by which a die may vary in placement when a given internal_mountable_die_physical_template is used. Such variance is due to the limitations of the insertion/onsertion tool and/or method.

Used by:

internal_mountable_die_physical_template

  ENTITY internal_mountable_bond_pad
      ABSTRACT SUPERTYPE OF (ONEOF (internal_mountable_bare_bond_pad,
                                    internal_mountable_pre_tabbed_bond_pad,
                                    internal_mountable_pre_bumped_bond_pad,
                                    internal_mountable_tabbed_bond_pad,
                                    internal_mountable_bumped_bond_pad,
                                    internal_mountable_wirebonded_bond_pad))
      SUBTYPE OF (mountable_bond_pad);
    mounted_bond_pad    : bond_pad; -- reference
    attachment_material : material_value;
    contact_area        : closed_area_element;
  DERIVE
    mountable_die : internal_mountable_die_physical_template -- reference
      := usedin_one_role(SELF,
           specified_role('mcm_mountable_die_physical_model',
                          'internal_mountable_die_physical_template',
                          'mountable_pads'));
  UNIQUE
    uniqueness_constraint :
      mounted_bond_pad, mountable_die;
  WHERE
    valid_existence :
      (* A internal_mountable_bond_pad belongs to one
         internal_mountable_die_physical_template. *)
      belongs_to_one (SELF,
           specified_role('mcm_mountable_die_physical_model',
                          'internal_mountable_die_physical_template',
                          'mountable_pads'));
  
    valid_bond_pad :
      (* The bond_pad must be associated with the mounted die. *)
      mounted_bond_pad IN mountable_die.referenced_die_physical_template.pads;
  END_ENTITY;

DIE_backside_finish

  TYPE DIE_backside_finish 
    = SELECT (DIE_enumerated_backside_finish,
              DIE_metallized_backside_finish);
  END_TYPE;

Description:

A DIE_backside_finish is the manner in which the die backside is finished.

The DIE_backside_finish is crucial to understanding possible die attachment mechanisms, thermal properties of attachment and the electrical connectivity needs for biasing purposes.

The concept of a DIE_backside_finish has been derived from the DIE format Section 5.8.

Used by:

internal_mountable_die_physical_template

DIE_enumerated_backside_finish

  TYPE DIE_enumerated_backside_finish 
    = ENUMERATION OF (DIE_polished,
                      DIE_lapped);
  END_TYPE;

Description:

A DIE_enumerated_backside_finish indicates that the backside of a die is the natural bulk material and that it has been polished or lapped as appropriate.

This concept has been derived from the DIE format Section 5.8

Used by:

DIE_backside_finish

DIE_environmental_condition

  ENTITY DIE_environmental_condition;
    environmental_properties : OPTIONAL SET [1:?] OF property;
    maximum_duration         : time_value;
    pressure                 : pressure_range;
    relative_humidity        : relative_humidity_value;
    temperature              : temperature_range;
    voltage_differential     : voltage_value;
  WHERE
    valid_existence :
      (* A DIE_environmental_condition belongs to one
         internal_mountable_die_physical_template. *)
      either_belongs_to_one (SELF,
        [specified_role('mcm_mountable_die_physical_model',
                        'internal_mountable_die_physical_template',
                        'DIE_sealing_condition'),
         specified_role('mcm_mountable_die_physical_model',
                        'internal_mountable_die_physical_template',
                        'DIE_attachment_condition'),
         specified_role('mcm_mountable_die_physical_model',
                        'internal_mountable_die_physical_template',
                        'DIE_bonding_condition')]);

    valid_voltage_differential :
      (* The voltage_value is non-negative. *)
      non_negative_minomax_value(voltage_differential.range);
  END_ENTITY;

Description:

A DIE_environmental_condition specifies the environmental condition which must be specified when a die is stored, sealed or bonded together with a maximum duration for those conditions.

This concept has been derived from the DIE format Sections 5.12, 5.13 and 5.14.

Used by:

internal_mountable_die_physical_template

internal_mountable_die_physical_template_symbol

  ENTITY internal_mountable_die_physical_template_symbol
    SUBTYPE OF(mountable_die_physical_template_symbol);
    associated_figures                      : OPTIONAL SET [1:?] OF
                                              drawing_figure; 
    associated_figure_macros                : OPTIONAL SET [1:?] OF
                                              drawing_figure_macro;
    associated_text                         : OPTIONAL SET [1:?] OF
                                              drawing_text; 
    component_designator_drawing_slot       : OPTIONAL SET [1:?] OF
                                              drawing_text_display;
    component_name_drawing_slot             : OPTIONAL SET [1:?] OF
                                              drawing_text_display;
    die_template_name_drawing               : OPTIONAL SET [1:?] OF
                                              drawing_text_display;
    die_template_property_drawings          : OPTIONAL SET [1:?] OF
                                              property_drawing;
    mountable_die_template_name_drawing     : OPTIONAL SET [1:?] OF
                                              drawing_text_display;
    mountable_die_template_property_drawings: OPTIONAL SET [1:?] OF
                                              property_drawing;
    mountable_bond_pad_representations      : SET [1:?] OF
                                              mountable_bond_pad_representation;
    part_name_drawing_slot                  : OPTIONAL SET [1:?] OF
                                              drawing_text_display;
  DERIVE
    containing_template : internal_mountable_die_physical_template -- reference
      := usedin_one_role(SELF,
           specified_role('mcm_mountable_die_physical_model',
                          'internal_mountable_die_physical_template',
                          'symbols'));
  WHERE
    valid_die_template_property_drawings:
      (* The referenced properties must belong to the die_physical_template
         referenced by the internal_mountable_die_physical_template that uses
         this symbol. *)
      not_exists(QUERY(propDraw <* die_template_property_drawings |
        NOT (propDraw.drawn_property IN
             containing_template.referenced_die_physical_template.properties)));

    valid_mountable_die_template_property_drawings:
      (* The referenced properties must be defined in the
         internal_mountable_die_physical_template that contains this symbol. *)
      not_exists(QUERY(propDraw <* mountable_die_template_property_drawings |
        NOT( propDraw.drawn_property IN containing_template.properties)));

    valid_optional_attributes :
      (* The dependencies of these optional attributes are stated as follows:
         1. A symbol cannot have die_template_property_drawings if the
            referenced die_physical_template does not define any properties.
         2. A symbol cannot have mountable_die_template_property_drawings if
            its containing mountable template does not define any
            properties. *) 
      (EXISTS(containing_template.referenced_die_physical_template.properties)
        OR NOT EXISTS(die_template_property_drawings))
      AND
      (EXISTS(containing_template.properties) OR
        NOT EXISTS(mountable_die_template_property_drawings));
  END_ENTITY;

Description:

An internal_mountable_die_physical_template_symbol describes the symbol associated to an internal_mountable_die_physical_template. In order to display the bond pads it uses bond_pad_drawing_templates which are defined in a library.

Used by:

mountable_bond_pad_representation

  ENTITY mountable_bond_pad_representation;
    drawn_bond_pad        : internal_mountable_bond_pad; -- reference
    instantiated_template : bond_pad_drawing_template; -- reference
    bond_pad_property_drawings           : OPTIONAL SET [1:?] OF
                                           property_drawing; 
    mountable_bond_pad_property_drawings : OPTIONAL SET [1:?] OF
                                           property_drawing;  
    template_position                    : fixed_scale_transform;
  DERIVE
    containing_symbol : -- reference
                        internal_mountable_die_physical_template_symbol 
                        := usedin_one_role(SELF,
                           specified_role('mcm_mountable_die_physical_model',
                             'internal_mountable_die_physical_template_symbol',
                             'mountable_bond_pad_representations'));
  UNIQUE
    unique_representation:
      (* In a given symbol, a mountable bond pad has at most one
         representation. *) 
      drawn_bond_pad, containing_symbol;
  WHERE
    valid_existence:
      (* A mountable_bond_pad_representation belongs to one
         internal_mountable_die_physical_template_symbol. *)
      belongs_to_one(SELF,
        specified_role('mcm_mountable_die_physical_model',
                       'internal_mountable_die_physical_template_symbol',
                       'mountable_bond_pad_representations'));

    valid_drawn_bond_pad:
      (* The referenced mountable_bond_pad must be defined in the
         internal_mountable_die_physical_template which contains the symbol. *)
      drawn_bond_pad IN
        containing_symbol.containing_template.mountable_pads;

    valid_bond_pad_property_drawings :
      (* The drawn properties are defined in the bond_pad referenced by the
         mountable_bond_pad. *) 
      not_exists(QUERY(propertyDrawing <* bond_pad_property_drawings |
        NOT (propertyDrawing.drawn_property
             IN drawn_bond_pad.mounted_bond_pad.properties)));

    valid_mountable_bond_pad_property_drawings:
      (* The drawn properties must be defined in the referenced
         mountable_bond_pad. *) 
      not_exists(QUERY(propertyDrawing <* mountable_bond_pad_property_drawings |
        NOT (propertyDrawing.drawn_property 
             IN drawn_bond_pad\mountable_bond_pad.properties)));

    valid_optional_attributes :
      (* The dependencies of these optional attributes are stated as follows:
         1. A bond pad representation cannot have bond_pad_property_drawings
            if the drawn bond pad does not define any properties. 
         2. A bond pad representation cannot have
            mountable_bond_pad_property_drawings if the drawn mountable bond
            pad does not define any properties. *)
      (EXISTS(drawn_bond_pad.mounted_bond_pad.properties)
         OR NOT EXISTS(bond_pad_property_drawings))
      AND
      (EXISTS(drawn_bond_pad\mountable_bond_pad.properties)
         OR NOT EXISTS(mountable_bond_pad_property_drawings));
  END_ENTITY;

Description:

A mountable_bond_pad_representation describes an instance of a bond_pad_drawing_template. The transform gives the position of the template within the symbol that uses this representation.

Used by:

internal_mountable_die_physical_template_symbol
