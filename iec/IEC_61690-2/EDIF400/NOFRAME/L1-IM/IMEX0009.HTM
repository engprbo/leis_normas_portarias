expression_model

Description:

The expression_model schema describes different types of expressions supported by Level 1 EDIF. That includes definitions of boolean_expression, integer_expression, number_expression and string_expression.

expression

  TYPE expression
    = SELECT (boolean_expression, integer_expression, number_expression,
              string_expression);
  END_TYPE;

Description:

 LEVEL 1
 =======
An expression can be either a boolean_expression, an integer_expression, a number_expression or a string_expression.

Used by:

parameter parameter_assign

boolean_expression

  TYPE boolean_expression
    = SELECT (and_expression, boolean_parameter, boolean_token,
              integer_equal_expression, less_than_expression, 
              less_than_or_equal_to_expression, not_expression, or_expression,
              string_equal_expression, xor_expression); 
  END_TYPE;

Description:

 LEVEL 1
 =======
A boolean_expression describes an expression that evaluates to a boolean.

Used by:

and_expression

  ENTITY and_expression;
    arguments : SET OF boolean_expression;
  END_ENTITY;

Description:

 LEVEL 1
 =======
An and_expression represents a boolean_expression that when evaluated returns the logical conjunction of its arguments. It is false if any of its arguments evaluate to false; otherwise it returns true.

Used by:

 LEVEL 1
 =======
A not_expression represents a boolean_expression that when evaluated returns the logical negation of its argument. It is true if its argument evaluates to false; otherwise it returns false.

Description:

 LEVEL 1
 =======
An or_expression represents a boolean_expression that when evaluated returns the logical disjunction of its arguments. It is true if any of its arguments evaluate to true; otherwise it returns false.

 LEVEL 1
 =======
A xor_expression represents a boolean_expression that when evaluated returns the exclusive or of its arguments. It is true if an odd number of the arguments evaluate to true; otherwise it returns false.

A string_equal_expression represents a boolean_expression that when evaluated returns true if its arguments have the same string length and the same characters in corresponding positions (the strings are compared in a case sensitive manner); it returns false otherwise.

quotient_expression

  ENTITY quotient_expression;
    dividend    : integer_expression;
    divisor     : integer_expression;
  END_ENTITY;

Description:

 LEVEL 1
 =======
A quotient_expression is an integer_expression that when evaluated returns the integer quotient obtained in a division of the dividend by the divisor. After design expansion, the divisor must evaluate to a positive integer. 

  The quotient value must satisfy the following conditions: 
   a. dividend = quotient * divisor + remainder
   b. 0 <= remainder < divisor

 The remainder value must satisfy the following conditions: 
   a. dividend = quotient * divisor + remainder
   b. 0 <= remainder < divisor

Description:

 LEVEL 1
 =======
A string_length_expression is an integer_expression. It has a single argument of type string_expression. On expansion it yields the number of characters in the string which results from the evaluation of the string_expression.

Used by:

integer_expression

instance_index

  ENTITY instance_index;
  END_ENTITY;

Description:

 LEVEL 1
 =======
An instance_index is an integer_expression that when evaluated returns a different integer for each expanded instance occurrence. It is used in the definition of the instance_name_generator attribute of a variable width instance. For example, if the width expression of an instance is 3, during the expansion 3 instance occurrences will be created and each has different instance_index value, i.e. 0, 1 and 2.

Used by:

string_concatenate_expression

  ENTITY string_concatenate_expression;
    arguments : LIST OF string_expression;
  END_ENTITY;

Description:

 LEVEL 1
 =======
A string_concatenate_expression is a string_expression which concatenates the arguments together. The first argument contributes to the left of the resulting string, the last to the right.

Used by:

string_expression

substring_expression

  ENTITY substring_expression;
    argument     : string_expression;
    given_length : integer_expression;
    offset       : integer_expression;
  END_ENTITY;

Description:

 LEVEL 1
 =======
A substring_expression is a string_expression. On expansion, it returns a string of the given length with the given offset, extracted from the value of the argument. The result is less than the given length if the argument is of insufficient size.

Used by:

string_expression

string_prefix_expression

  ENTITY string_prefix_expression;
    argument     : string_expression;
    given_length : integer_expression;
  END_ENTITY;

Description:

 LEVEL 1
 =======
A string_prefix_expression is a string_expression. On expansion, it returns a string of the given length which is a prefix of the argument. If the length is evaluated to be a non-positive integer, it returns the empty string. On the other hand, if the length is evaluated to be a value greater than the length of the argument string, then the argument is returned.

Used by:

string_expression

string_suffix_expression

  ENTITY string_suffix_expression;
    argument  : string_expression;
    offset    : integer_expression;
  END_ENTITY;

Description:

 LEVEL 1
 =======
A string_suffix_expression is a string_expression. On expansion, it returns a string which is a suffix of the argument. The offset argument specifies the number of characters to remove from the left. If the offset is evaluated to be a non-positive integer, it returns the argument. On the other hand, if the offset is evaluated to be a value greater than the length of the argument string, then the empty string is returned.

Used by:

string_expression

decimal_to_string_expression

  ENTITY decimal_to_string_expression;
    argument             : integer_expression;
    minimum_field_length : integer_expression;
  END_ENTITY;

Description:

 LEVEL 1
 =======
A decimal_to_string_expression is a string_expression. On expansion, it returns a string which is the unsigned decimal representation of the value of the argument. The argument gives a non-negative integer when evaluated. The result string contains no sign character and is padded with zero characters on the left if necessary.

Used by:

string_expression

valid_boolean_expression

  FUNCTION valid_boolean_expression
    (exps           : AGGREGATE:intype OF boolean_expression;
     parameters     : SET OF parameter;
     frameIndexes   : SET OF for_frame_index;
     invalidIndexes : SET OF STRING) : BOOLEAN;
    LOCAL
      expType : SET OF STRING;
    END_LOCAL;

    REPEAT i := 1 TO SIZEOF(exps);
      expType := TYPEOF(exps[i]);
      IF there_exists(expType * invalidIndexes) THEN
         RETURN(FALSE);
      ELSE
      IF 'expression_model.and_expression' IN expType THEN
         IF NOT valid_boolean_expression(exps[i].arguments,
                parameters,frameIndexes,invalidIndexes) THEN
            RETURN(FALSE);
         END_IF;
      ELSE
      IF 'parameter_model.boolean_parameter' IN expType THEN
         IF NOT (exps[i] IN parameters) THEN
            RETURN(FALSE);
         END_IF;
      ELSE
      IF 'expression_model.integer_equal_expression' IN expType THEN
         IF NOT valid_integer_expression(exps[i].arguments,
                 parameters,frameIndexes,invalidIndexes) THEN
            RETURN(FALSE);
         END_IF;
      ELSE
      IF 'expression_model.less_than_expression' IN expType THEN
         IF NOT valid_integer_expression(exps[i].arguments,
                 parameters,frameIndexes,invalidIndexes) THEN
            RETURN(FALSE);
         END_IF;
      ELSE
      IF 'expression_model.less_than_or_equal_to_expression' IN expType THEN
         IF NOT valid_integer_expression(exps[i].arguments,
                 parameters,frameIndexes,invalidIndexes) THEN
            RETURN(FALSE);
         END_IF;
      ELSE
      IF 'expression_model.not_expression' IN expType THEN
         IF NOT valid_boolean_expression([exps[i].argument],
                parameters,frameIndexes,invalidIndexes) THEN
            RETURN(FALSE);
         END_IF;
      ELSE
      IF 'expression_model.or_expression' IN expType THEN
         IF NOT valid_boolean_expression(exps[i].arguments,
                parameters,frameIndexes,invalidIndexes) THEN
            RETURN(FALSE);
         END_IF;
      ELSE
      IF 'expression_model.string_equal_expression' IN expType THEN
         IF NOT valid_string_expression(exps[i].arguments,
                parameters,frameIndexes,invalidIndexes) THEN
            RETURN(FALSE);
         END_IF;
      ELSE
      IF 'expression_model.xor_expression' IN expType THEN
         IF NOT valid_boolean_expression(exps[i].arguments,
                parameters,frameIndexes,invalidIndexes) THEN
            RETURN(FALSE);
         END_IF;
      END_IF;
      END_IF;
      END_IF;
      END_IF;
      END_IF;
      END_IF;
      END_IF;
      END_IF;
      END_IF;
      END_IF;
    END_REPEAT;
    RETURN(TRUE);
  END_FUNCTION;

Description:

The valid_boolean_expression function checks if the boolean_expressions are correct in the context of where they are defined, e.g. the condition expression of a if_frame. A boolean_expression may contain references to parameters and various types of indexes (such as for_frame_index, frame_signal_index, instance_index, port_index and signal_index). The function returns true if the boolean_expressions do not contain incorrect references.

The parameters argument specifies a set of valid parameters for the expression. The frameIndexes argument specifies a set of valid for_frame_indexes for the expression. The invalidIndexes argument specifies the names of the invalid indexes for the expression.

Used by:

boolean_parameter boolean_parameter_assign

valid_string_expression

  FUNCTION valid_string_expression
    (exps           : AGGREGATE:intype OF string_expression;
     parameters     : SET OF parameter;
     frameIndexes   : SET OF for_frame_index;
     invalidIndexes : SET OF STRING) : BOOLEAN;
    LOCAL
      expType : SET OF STRING;
    END_LOCAL;

    REPEAT i := 1 TO SIZEOF(exps);
      expType := TYPEOF(exps[i]);
      IF there_exists(expType * invalidIndexes) THEN
         RETURN(FALSE);
      ELSE
      IF 'expression_model.decimal_to_string_expression' IN expType THEN
         IF NOT valid_integer_expression
                ([exps[i].argument,exps[i].minimum_field_length],
                 parameters,frameIndexes,invalidIndexes) THEN
            RETURN(FALSE);
         END_IF;
      ELSE
      IF 'expression_model.string_concatenate_expression' IN expType THEN
         IF NOT valid_string_expression(exps[i].arguments,
                parameters,frameIndexes,invalidIndexes) THEN
            RETURN(FALSE);
         END_IF;
      ELSE
      IF 'parameter_model.string_parameter' IN expType THEN
         IF NOT (exps[i] IN parameters) THEN
            RETURN(FALSE);
         END_IF;
      ELSE
      IF 'expression_model.string_prefix_expression' IN expType THEN
         IF NOT valid_string_expression([exps[i].argument],
                parameters,frameIndexes,invalidIndexes) OR 
            NOT valid_integer_expression([exps[i].given_length],
                parameters,frameIndexes,invalidIndexes) THEN
            RETURN(FALSE);
         END_IF;
      ELSE
      IF 'expression_model.string_suffix_expression' IN expType THEN
         IF NOT valid_string_expression([exps[i].argument],
                parameters,frameIndexes,invalidIndexes) OR 
            NOT valid_integer_expression([exps[i].offset],
                parameters,frameIndexes,invalidIndexes) THEN
            RETURN(FALSE);
         END_IF;
      ELSE
      IF 'expression_model.substring_expression' IN expType THEN
         IF NOT valid_string_expression([exps[i].argument],
                parameters,frameIndexes,invalidIndexes) OR 
            NOT valid_integer_expression([exps[i].given_length,exps[i].offset],
                parameters,frameIndexes,invalidIndexes) THEN
            RETURN(FALSE);
         END_IF;
      END_IF;
      END_IF;
      END_IF;
      END_IF;
      END_IF;
      END_IF;
      END_IF;
    END_REPEAT;
    RETURN(TRUE);
  END_FUNCTION;

Description:

The valid_string_expression function checks if the string_expressions are correct in the context of where they are defined, e.g. the port name generator expression of a master_port. A string_expression may contain references to parameters and various types of indexes (such as for_frame_index, frame_signal_index, instance_index, port_index and signal_index). The function returns true if the string_expressions do not contain incorrect references.

The parameters argument specifies a set of valid parameters for the expression. The frameIndexes argument specifies a set of valid for_frame_indexes for the expression. The invalidIndexes argument specifies the names of the invalid indexes for the expression.
