unfinished_view_model

Description:

Some EDIF viewtypes are not defined in the current model. They are logicmodel, behavior, masklayout and symboliclayout viewtypes. A new test model are expected to be released in future versions of EDIF.

internal_masklayout_view

  ENTITY internal_masklayout_view
      SUBTYPE OF (internal_cell_representation);
    -- not yet defined
  END_ENTITY;

Description:

An internal_masklayout_view is a cell_representation which describes an integrated circuit layout. It is not defined in the model.
