pcb_package_model

Description:

The pcb_package_model is used to define packages. Usually the information is acquired from other parties, e.g. data sheet information about component packages.

package

  ENTITY package
      ABSTRACT SUPERTYPE OF (ONEOF(ball_package,
                                   mechanical_package,
                                   pin_package)
                             AND
                             ONEOF(external_package,
                                   internal_package));
    document           : OPTIONAL SET [1:?] OF documentation;
    mechanical_fixings : OPTIONAL SET [1:?] OF mechanical_fixing;
    name               : OPTIONAL name_information;
    previous_version   : OPTIONAL package; -- reference
    properties         : OPTIONAL SET [1:?] OF property;
    terminals          : OPTIONAL SET [1:?] OF package_terminal;
    units              : pcb_layout_units;
    written_status     : OPTIONAL SET [1:?] OF written;
  DERIVE
    terminal_count : INTEGER := SIZEOF(terminals);
  WHERE
    valid_existence :
      (* A package belongs to one library. *)
      belongs_to_one(SELF, 'library_model.library.packages');

    valid_previous_version :
      (* A package cannot be a new version of itself, either directly or
         indirectly. *)
      non_recursive_previous_version(SELF, []);

    valid_written_in_previous_version :
      (* The earliest timestamp of a package is later than the latest
         timestamp of its previous version. *)  
      valid_timestamp_in_previous_version(written_status,
                                          previous_version.written_status);
  END_ENTITY;

Description:

A package is the collection of the mechanical data of a set of physically similar components (e.g. dimensions, etc). It can be either a ball_package or a pin_package. It specifies a collection of package_terminals which are referenced by mountable_package_terminals in a mountable_package which uses the package.

Used by:

internal_jumper_part internal_mountable_package library package packaged_connector_part packaged_electrical_part

external_package

  ENTITY external_package
      ABSTRACT SUPERTYPE OF (ONEOF(external_ball_package,
                                   external_mechanical_package,
                                   external_pin_package))
      SUBTYPE OF (package);
    SELF\package.mechanical_fixings : OPTIONAL SET [1:?] OF
                                      external_mechanical_fixing;

  WHERE
    valid_existence :
      (* An external_package belongs to one external_library. *)
      belongs_to_one(SELF,'library_model.external_library.packages');
  END_ENTITY;

      ABSTRACT SUPERTYPE OF (ONEOF(external_mechanical_package,
                                   internal_mechanical_package))
      SUBTYPE OF (package);

internal_pin_package

  ENTITY internal_pin_package
      SUBTYPE OF (internal_package, pin_package);
    SELF\package.terminals      : OPTIONAL SET [1:?] OF internal_pin;
    SELF\pin_package.pin_groups : OPTIONAL SET [1:?] OF internal_pin_group;
    outline_style               : package_outline_style;
    mounting_class              : package_mounting_class;
    pin_arrangement_type        : OPTIONAL pin_arrangement;
    pin_form_count              : OPTIONAL positive_integer_token;
    pin_form_type               : OPTIONAL pin_form;
  WHERE
    valid_pin_groups :
      (* Any internal_pin referenced by an internal_pin_group cannot be also
         referenced by another internal_pin_group. *)
      not_exists(QUERY(pinGroup1 <* pin_groups |
        there_exists(QUERY(pinGroup2 <* pin_groups - pinGroup1 |
          there_exists(pinGroup1.referenced_pins
                       * pinGroup2.referenced_pins)))));

    valid_pin_form_count :
      (* The pin_form_count value should be less than or equal to the number of
         terminals of the package. *)
      pin_form_count <= SELF\package.terminal_count;

    valid_optional_attributes :
      (* The dependencies of these optional attributes are stated as follows:
         1. A pin package cannot have pin groups if it does not define any
            pins. *)
      EXISTS(terminals) OR NOT EXISTS(pin_groups);
  END_ENTITY;

Description:

A pin_group is a collection of package pins. All of the package pins referenced by a given pin_group object are intended to be mounted onto a bare board in a particular manner (e.g. on the same side of the bare board as the package body). This sort of information is useful during the mounting process.

Used by:

internal_pin_group

  ENTITY internal_pin_group
      SUBTYPE OF (pin_group);
    referenced_pins : SET [1:?] OF internal_pin; -- reference
  DERIVE
    containing_package : internal_pin_package -- reference
      := usedin_one_role(SELF,
         'pcb_package_model.internal_pin_package.pin_groups');
  WHERE
    valid_existence :
      (* An internal_pin_group belongs to an internal_pin_package. *)
      belongs_to_one(SELF, 
        'pcb_package_model.internal_pin_package.pin_groups');

    valid_referenced_pins :
      (* All referenced pins are defined in the containing package. *)
      referenced_pins <= containing_package.terminals;
  END_ENTITY;

Description:

An internal_pin_group describes a pin_group in an internal_pin_package.
