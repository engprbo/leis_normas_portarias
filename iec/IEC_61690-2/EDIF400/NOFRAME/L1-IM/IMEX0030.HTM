pcb_technology_model

Description:

The pcb_technology_model schema describes the technology of a single bare board. A bare_board_technology is the set of data which guides a designer (or CAD system) in such a way as to crate a layout which is fully manufacturable in a particular manner. In addition, it fully describes the physical structure of a bare board.

bare_board_technology

  ENTITY bare_board_technology
      ABSTRACT SUPERTYPE OF (ONEOF(external_bare_board_technology,
                                   internal_bare_board_technology));
    document         : OPTIONAL SET [1:?] OF documentation;
    drill_rules      : OPTIONAL SET [1:?] OF drill_rule;
    name             : OPTIONAL name_information;
    layers           : SET [1:?] OF physical_layer;
    previous_version : OPTIONAL bare_board_technology; -- reference
    properties       : OPTIONAL SET [1:?] OF property;
    technology_rules : OPTIONAL SET [1:?] OF technology_rule;
    units            : pcb_layout_units;
    written_status   : OPTIONAL SET [1:?] OF written;
  DERIVE
    containing_library : library -- reference
      := usedin_one_role(SELF,
         'library_model.library.bare_board_technologies');
  WHERE
    valid_existence :
      (* A bare_board_technology belongs to one library. *)
      belongs_to_one(SELF,'library_model.library.bare_board_technologies');

    valid_previous_version :
      (* A bare_board_technology cannot be a new version of itself, either
         directly or indirectly. *)
      non_recursive_previous_version(SELF, []);

    valid_written_in_previous_version :
      (* The earliest timestamp of a bare_board_technology is later than the
         latest timestamp of its previous version. *)  
      valid_timestamp_in_previous_version(written_status,
                                          previous_version.written_status);
  END_ENTITY;

Description:

A bare_board_technology is that set of data which (a) guides a designer (or CAD system) in such a way as to create a PCB layout which is fully manufacturable in a particular manner, and (b) fully describes the physical structure of a bare board.

physical_layer

  ENTITY physical_layer
        ABSTRACT SUPERTYPE OF (ONEOF (conducting_layer, 
                                      non_conducting_layer)
                               AND
                               ONEOF (external_physical_layer,
                                      internal_physical_layer));
    document                    : OPTIONAL SET [1:?] OF documentation;
    name                        : OPTIONAL name_information;
    properties                  : OPTIONAL SET [1:?] OF property;
    referenced_figure_collector : -- reference
                                  OPTIONAL fabricate_figure_collector; 
  DERIVE
    containing_technology : bare_board_technology -- reference
      := usedin_one_role(SELF,
         'pcb_technology_model.bare_board_technology.layers');
    positive_contributing_collectors : -- reference
                                       SET OF simple_fabricate_figure_collector
      := physical_layer_contributing_collectors(referenced_figure_collector,
                                                TRUE);
    negative_contributing_collectors : -- reference
                                       SET OF simple_fabricate_figure_collector
      := physical_layer_contributing_collectors(referenced_figure_collector, 
                                                FALSE);
 WHERE
    valid_existence : 
      (* A physical_layer belongs to one bare_board_technology. *)
      belongs_to_one(SELF,'pcb_technology_model.bare_board_technology.layers');

    valid_referenced_figure_collector :
      (* The referenced fabricate_figure_collector must be defined in the
         containing edif. *)
      referenced_figure_collector 
      IN containing_technology
         .containing_library
         .containing_edif.fabricate_figure_collectors;
  END_ENTITY;

Description:

A physical_layer is either: a sheet of a single material that is (1) applied to a layer of dielectric or other material, or (2) the dielectric material itself. A physical layer is composed of a particular material, which may be specific (e.g. 24 K gold) or general (e.g. etched metal), and which can be described using positive artwork exclusively.

All physical_layer objects share a common, arbitrary coordinate space.

Used by:

bare_board_cavity bare_board_technology component_region_realisation_rule component_signal_layer_realisation_rule embedded_die_placement_region internal_physical_layer_technology_rule layout_shape trace

Description:

A conducting_layer is a physical_layer which is (expected to be) conductive in nature. A conducting_layer must be fabricated under a specific set of constraints, depending on the type of material that makes up the conducting_layer.

internal_physical_layer

  ENTITY internal_physical_layer
      SUBTYPE OF (physical_layer);
    is_made_of : OPTIONAL material; -- reference
    thickness  : OPTIONAL toleranced_distance;
  WHERE
    valid_material :
    (* If it is a conducting_layer, then the referenced material must be
       conducting.  Otherwise, if it is a non_conducting_layer, then the
       referenced material must be non-conducting. *)

    (('pcb_technology_model.conducting_layer' IN TYPEOF(SELF))
    AND (is_made_of.electrical_type = material_electrical_type.conductive))
    XOR
    (('pcb_technology_model.non_conducting_layer' IN TYPEOF(SELF))
    AND (is_made_of.electrical_type <  material_electrical_type.conductive));

    valid_stack_use :
      (* An internal_physical_layer must form part of the layup of the
         bare_board_technology.  i.e. it must be referenced by exactly
         one stacked_layer_group or exactly one co_planar_layer_group. *)

      SIZEOF(USEDIN(SELF,
        'pcb_technology_model.stacked_layer_group.stacked_objects'))
      +
      SIZEOF(USEDIN(SELF,
        'pcb_technology_model.co_planar_layer_group.co_planar_objects')) = 1;
  END_ENTITY;

An internal_physical_layer is a physical_layer belonged to an internal_bare_board_technology.

stacked_layer_group

  ENTITY stacked_layer_group;
    stacked_objects : LIST [2:?] OF stack_object;
  DERIVE
    containing_technology : internal_bare_board_technology -- reference
      := containing_technology_of_stacked_layer_group(SELF);
    containing_layer_group : co_planar_layer_group -- reference
      := usedin_one_role(SELF,
         'pcb_technology_model.co_planar_layer_group.co_planar_objects');
  WHERE
    valid_existence :
      (* A stacked_layer_group belongs to one
         internal_bare_board_technology or to one co_planar_layer_group. *)
      either_belongs_to_one(SELF,
       ['pcb_technology_model.internal_bare_board_technology.layer_stack',
        'pcb_technology_model.co_planar_layer_group.co_planar_objects']);

    valid_layers :
      (* The physical_layers which are stacked are defined in the
         bare_board_technology which contains the stacked_layer_group. *)
      not_exists(QUERY(stackedObject <* stacked_objects |
        ('pcb_technology_model.internal_physical_layer' 
          IN TYPEOF(stackedObject))
        AND
        NOT (stackedObject IN containing_technology.layers)));

    non_recursive :
      (* A stacked_layer_group cannot own itself indirectly. *)
      non_recursive_stacked_layer_group([SELF],[]);
  END_ENTITY;

Description:

A stacked_layer_group is an ordered group of physical_layers or co_planar_layer_group which are placed one below another. The first stack_object is closest to the top of the board.

Used by:

co_planar_layer_group co_planar_object internal_bare_board_technology

stack_object

  TYPE stack_object
    = SELECT (co_planar_layer_group,
              internal_physical_layer);  -- reference
  END_TYPE;

Description:

A stack_object is an object which can be stacked to form part of the layup of a board. It is either an internal_physical_layer or a co_planar_layer_group. Note that it cannot be a stacked_layer_group. By means of this limitation, EDIF ensures that there is only one mechanism for specifying a given layup.

Used by:

stacked_layer_group

containing_technology_of_stacked_layer_group

  FUNCTION containing_technology_of_stacked_layer_group
    (stackedLayerGroup : stacked_layer_group) : internal_bare_board_technology;
    LOCAL
      found : LOGICAL := FALSE;
      containing_technology : internal_bare_board_technology;
      containing_co_planar_group : co_planar_layer_group;
    END_LOCAL;

    REPEAT WHILE found=FALSE;
      IF belongs_to_one(stackedLayerGroup,
         'pcb_technology_model.internal_bare_board_technology.layer_stack') THEN
         containing_technology := usedin_one_role(stackedLayerGroup,
           'pcb_technology_model.internal_bare_board_technology.layer_stack');
         found := TRUE;
      ELSE
        containing_co_planar_group := usedin_one_role(stackedLayerGroup,
           'pcb_technology_model.co_planar_layer_group.co_planar_objects');
        stackedLayerGroup := containing_co_planar_group.containing_layer_group;
      END_IF;
    END_REPEAT;
    RETURN(containing_technology);
  END_FUNCTION;

Description:

The containing_technology_of_stacked_layer_group returns the internal_bare_board_technology containing the stacked_layer_group.

Used by:

stacked_layer_group

non_recursive_stacked_layer_group

  FUNCTION non_recursive_stacked_layer_group
    (parents, invalidAncestors : SET OF stacked_layer_group) : BOOLEAN;
    LOCAL
      i, j                : INTEGER;
      descendents         : SET OF stacked_layer_group := [];
      coPlanarLayerGroups : LIST OF co_planar_layer_group;
    END_LOCAL;

    REPEAT i := 1 TO SIZEOF(parents);
      coPlanarLayerGroups := QUERY(member <* parents[i].stacked_objects |
                                   'pcb_technology_model.co_planar_layer_group'
                                   IN TYPEOF(member));
      REPEAT j := 1 TO SIZEOF(coPlanarLayerGroups);
        descendents := descendents +
                       QUERY(member <* coPlanarLayerGroups[j].co_planar_objects|
                             'pcb_technology_model.stacked_layer_group'
                             IN TYPEOF(member));
      END_REPEAT;
    END_REPEAT;
    invalidAncestors := parents + invalidAncestors;
    RETURN(not_exists(descendents)
           XOR
           (not_exists(descendents * invalidAncestors)
            AND 
            non_recursive_stacked_layer_group(descendents, invalidAncestors)));
  END_FUNCTION;

Description:

The non_recursive_stacked_layer_group function returns true if a stacked_layer_group does not contain members which reference itself. It prevents cyclic definition of a stacked_layer_group.

Used by:

stacked_layer_group

co_planar_layer_group

  ENTITY co_planar_layer_group;
    co_planar_objects : SET [2:?] OF co_planar_object;
  DERIVE
    containing_layer_group : stacked_layer_group -- reference
      := usedin_one_role(SELF,
         'pcb_technology_model.stacked_layer_group.stacked_objects');
  WHERE
    valid_existence :
      (* A co_planar_layer_group belongs to one stacked_layer_group. *)
      belongs_to_one(SELF,
        'pcb_technology_model.stacked_layer_group.stacked_objects');

    valid_layers :
      (* The physical_layers which are co-planar are defined in the
         bare_board_technology which indirectly contains the
         co_planar_layer_group. *)
      not_exists(QUERY(coPlanarObject <* co_planar_objects |
        ('pcb_technology_model.internal_physical_layer' 
          IN TYPEOF(coPlanarObject))
        AND
        NOT (coPlanarObject 
             IN containing_layer_group.containing_technology.layers)));

    non_recursive :
      (* A co_planar_layer_group cannot own itself indirectly. *)
      non_recursive_co_planar_layer_group([SELF],[]);
  END_ENTITY;

Description:

A co_planar_layer_group is an unordered group of physical_layers or stacked_layer_group which are in the same z-plane.

Used by:

stack_object stacked_layer_group

It is either an internal_physical_layer or a stacked_layer_group. Note that it cannot be a co_planar_layer_group. By means of this limitation, EDIF ensures that there is only one mechanism for specifying a given layup.

non_recursive_co_planar_layer_group

  FUNCTION non_recursive_co_planar_layer_group
    (parents, invalidAncestors : SET OF co_planar_layer_group) : BOOLEAN;
    LOCAL
      i, j               : INTEGER;
      descendents        : SET OF co_planar_layer_group := [];
      stackedLayerGroups : SET OF stacked_layer_group;
    END_LOCAL;

    REPEAT i := 1 TO SIZEOF(parents);
      stackedLayerGroups := QUERY(member <* parents[i].co_planar_objects |
                                 'pcb_technology_model.stacked_layer_group'
                                 IN TYPEOF(member));
      REPEAT j := 1 TO SIZEOF(stackedLayerGroups);
        descendents := descendents +
                       QUERY(member <* stackedLayerGroups[j].stacked_objects |
                             'pcb_technology_model.co_planar_layer_group'
                             IN TYPEOF(member));
      END_REPEAT;
    END_REPEAT;
    invalidAncestors := parents + invalidAncestors;
    RETURN(not_exists(descendents)
           XOR
           (not_exists(descendents * invalidAncestors)
            AND 
            non_recursive_co_planar_layer_group(descendents, 
                                                invalidAncestors)));
  END_FUNCTION;

Description:

The non_recursive_co_planar_layer_group function returns true if a co_planar_layer_group does not contain members which reference itself. It prevents cyclic definition of a co_planar_layer_group.

internal_drill_rule

  ENTITY internal_drill_rule
      SUBTYPE OF (drill_rule);
    SELF\drill_rule.symbols
      : OPTIONAL SET [1:?] OF internal_drill_symbol;
    drilled_from        : SET [1:?] OF internal_physical_layer; -- reference
    drilled_to          : SET [1:?] OF internal_physical_layer; -- reference
    intermediate_layers : OPTIONAL LIST [1:?] OF SET [1:?] OF
                          internal_physical_layer;  -- reference
    hole_size           : toleranced_distance;
  DERIVE
    containing_technology : internal_bare_board_technology -- reference
      := usedin_one_role(SELF,
         'pcb_technology_model.internal_bare_board_technology.drill_rules');
  WHERE
    valid_existence :
      (* An internal_drill_rule belongs to one
         internal_bare_board_technology.*)  
      belongs_to_one(SELF,
        'pcb_technology_model.internal_bare_board_technology.drill_rules');

    valid_drilled_from :
      (* The drilled from layers must be defined in the
         bare_board_technology. *)
      not_exists(QUERY(layer <* drilled_from |
        NOT (layer IN containing_technology.layers)));
  
    valid_drilled_to :
      (* The drilled_to physical_layers must be defined in the
         bare_board_technology. *)
      not_exists(QUERY(layer <* drilled_to |
        NOT (layer IN containing_technology.layers)));
  
    valid_intermediate_layers :
      (* The intermediate physical_layers must be defined in the
         bare_board_technology. *)
      not_exists(QUERY(layerSet <* intermediate_layers |
        there_exists(QUERY(layer <* layerSet |
          NOT (layer IN containing_technology.layers)))));
  
    valid_from_to_planarity :
      (* The drilled_from and drilled_to physical_layers must be
         stacked on each other i.e. they cannot be directly or indirectly
         co-planar. *)
      NOT co_planar_layer_set(drilled_from, drilled_to);
  
    valid_first_intermediate :
      (* The first intermediate physical_layers must not be directly or
         indirectly co-planar with the drilled_from physical_layers. *)
      NOT co_planar_layer_set(drilled_from, intermediate_layers[1]);
  
    valid_last_intermediate :
      (* The last intermediate physical_layers must not be directly or
         indirectly co-planar with the drilled_to physical_layers. *)
      NOT co_planar_layer_set(drilled_to,
          intermediate_layers[SIZEOF(intermediate_layers)]);
  
    valid_intermediate_list :
      (* No member of the intermediate list may be directly or
         indirectly co-planar with a member of the preceding set. *)
      NOT co_planar_intermediate_layer_set(intermediate_layers);
  
    valid_stacking :
      (* The drilled_from physical_layers must be closer to the top of
         the board layup than the drilled_to and closer than the first
         intermediate set.  In addition each set of
         physical_layers in the intermediate list must be closer to
         the top of the board layup than members of the next set and
         closer than members of the drilled_to set.  Note that this
         does not mandate a choice of how a foundry is to drill the
         hole; it ensures that there is only one mechanism for
         specifying a given piece of information within EDIF. *)

      check_drill_rule_layer_stack(containing_technology.layer_stack,
                                   drilled_from, drilled_to,
                                   intermediate_layers);
  
    valid_from_set :
      (* The members of the drilled_from set must be directly within a
         co_planar_layer_group and it must be the same
         co_planar_layer_group. *) 
      co_planar_layer(drilled_from);

    valid_to_set :
      (* The members of the drilled_to set must be directly within a
         co_planar_layer_group and it must be the same co_planar_layer_group. *)
      co_planar_layer(drilled_to);

    valid_intermediate_sets :
      (* The members of each intermediate set must be directly within a
         co_planar_layer_group and it must be the same co_planar_layer_group.
         Note that this only applies within a given set not to the whole
         intermediate list. *)
      not_exists(QUERY(layerSet <* intermediate_layers |
        NOT co_planar_layer(layerSet)));
  END_ENTITY;

Description:

An internal_drill_rule is a drill_rule defined in an internal_bare_board_technology. There are no manufacturing semantics associated with drilled_from and drilled_to physical_layers i.e. the internal_drill_rule specifies what to manufacture rather than how. * Note that the sets of physical_layer are allowed in order to enable a choice of physical_layers to be specified. Where there is a choice, the physical_layers must be directly in the same co_planar_layer_group.

co_planar_layer

  FUNCTION co_planar_layer
    (layers : SET OF internal_physical_layer) : BOOLEAN;
    LOCAL
      layerGroups : SET OF co_planar_layer_group := [ ];
    END_LOCAL;
    IF (SIZEOF(layers) = 1) THEN
       RETURN(TRUE);
    ELSE
       REPEAT i := 1 TO SIZEOF(layers);
         layerGroups := layerGroups + 
           USEDIN(layers[i], 
           'pcb_technology_model.co_planar_layer_group.co_planar_objects');
       END_REPEAT;
       RETURN(SIZEOF(layerGroups)=1);
    END_IF;
  END_FUNCTION;

Description:

The co_planar_layer function accepts a set OF layers as argument and returns true if all members of the layer set are directly within a co_planar_layer_group.

Used by:

internal_drill_rule

co_planar_layer_set

  FUNCTION co_planar_layer_set
    (layerSet1, layerSet2 : SET OF internal_physical_layer) : BOOLEAN;
    LOCAL
      parentGroup1 : SET OF co_planar_layer_group := [ ];
      parentGroup2 : SET OF co_planar_layer_group := [ ];
    END_LOCAL;

    REPEAT i := 1 TO SIZEOF(layerSet1);
      parentGroup1 := parentGroup1 
                      + enclosing_co_planar_group(layerSet1[i]);
    END_REPEAT;

    REPEAT i := 1 TO SIZEOF(layerSet2);
      parentGroup2 := parentGroup2
                      + enclosing_co_planar_group(layerSet2[i]); 
    END_REPEAT;

    RETURN(not_exists(parentGroup1 * parentGroup2));
  END_FUNCTION;

Description:

The co_planar_layer_set function returns true if the two layer sets are not co-planar, either directly or indirectly.

Used by:

internal_drill_rule

co_planar_intermediate_layer_set

  FUNCTION co_planar_intermediate_layer_set
    (layerSets : LIST OF SET OF internal_physical_layer) : BOOLEAN;
    REPEAT i := 1 TO SIZEOF(layerSets)-1;
      IF co_planar_layer_set(layerSets[i], layerSets[i+1]) THEN
         RETURN(TRUE);
      END_IF;
    END_REPEAT;
    RETURN(FALSE);
  END_FUNCTION;

Description:

The co_planar_intermediate_layer_set accepts a list of layer set as argument and returns true if any two adjacent members of the list are co-planar, either directly or indirectly.

Used by:

enclosing_co_planar_group

  FUNCTION enclosing_co_planar_group
    (layer : internal_physical_layer) : SET OF co_planar_layer_group;
    LOCAL
      containingCoPlanar : co_planar_layer_group;
      containingStack    : stacked_layer_group;
      result             : SET OF co_planar_layer_group := [ ];
      topStack           : BOOLEAN := FALSE;
    END_LOCAL;

    IF belongs_to_one(layer,
       'pcb_technology_model.co_planar_layer_group.co_planar_objects') THEN
       containingCoPlanar := usedin_one_role(layer,
         'pcb_technology_model.co_planar_layer_group.co_planar_objects');
    ELSE
       containingStack := usedin_one_role(layer,
         'pcb_technology_model.stacked_layer_group.stacked_objects');
    END_IF;

    REPEAT WHILE topStack = FALSE;
      IF EXISTS(containingCoPlanar) THEN
         result := result + containingCoPlanar;
         containingStack := containingCoPlanar.containing_layer_group;
      ELSE 
      IF EXISTS(containingStack) THEN
         IF belongs_to_one(containingStack,
         'pcb_technology_model.internal_bare_board_technology.layer_stack') THEN
            topStack := TRUE;
         ELSE
            containingCoPlanar := containingStack.containing_layer_group;
         END_IF;
      END_IF;
      END_IF;
    END_REPEAT;

    RETURN(result);
  END_FUNCTION;

Description:

The enclosing_co_planar_group function returns all the co_planar_layer_groups which contain the layer, either directly or indirectly.

check_drill_rule_layer_stack

  FUNCTION check_drill_rule_layer_stack
    (layup : stacked_layer_group;
     drillFrom, drillTo : SET OF internal_physical_layer;
     drillThru : LIST OF SET OF internal_physical_layer) : BOOLEAN;

    LOCAL
      fromPos, thruPos, toPos : INTEGER;
    END_LOCAL;

    -- In a drill rule, all drill-from layers must be co-planar with each oher
    -- and so are all drill-to layers.  Hence, it is not necssary to compute
    -- the layer position of each layer within the board layup.  It is 
    -- sufficient to check the layer position of the first element of each
    -- layer set only. 

    fromPos := find_layer_position_in_layer_stack(layup, drillFrom[1]);
    toPos   := find_layer_position_in_layer_stack(layup, drillTo[1]);

    IF toPos <= fromPos THEN
       RETURN(FALSE);
    ELSE
       REPEAT i := 1 TO SIZEOF(drillThru);
         thruPos := find_layer_position_in_layer_stack(layup, drillThru[i][1]);
         IF NOT ({fromPos < thruPos < toPos}) THEN
            RETURN(FALSE);
         ELSE
            fromPos := thruPos;
         END_IF;
       END_REPEAT;
    END_IF;
    RETURN(TRUE);
  END_FUNCTION;

Description:

The check_drill_rule_layer_stack returns true if the drill layers of a drill rule agree with the layup of the board. The set of drill-from layers must be closer to the top of the board layup then the set of drill-to layers and closer than the first set of drill-thru layers. Each subsequent set of drill-thru layers must be closer than the next set of drill-thru layers and closer than the set of drill-to layers.

Used by:

internal_drill_rule

find_layer_position_in_layer_stack

  FUNCTION find_layer_position_in_layer_stack
    (layup : stacked_layer_group; layer : internal_physical_layer) : INTEGER;
    LOCAL
      layerStack   : LIST OF stack_object := layup.stacked_objects;
      coPlanarObjs : SET OF co_planar_object;
    END_LOCAL;
    REPEAT i := 1 TO SIZEOF(layerStack);
      IF is_typeof(layerStack[i],
                   'pcb_technology_model.internal_physical_layer') THEN
         IF layerStack[i] :=: layer THEN
            RETURN(i);
         END_IF;
      ELSE
        -- layerStack[i] is a co-planar group
        coPlanarObjs := layerStack[i].co_planar_objects;
        REPEAT j := 1 TO SIZEOF(coPlanarObjs);
          IF is_typeof(coPlanarObjs[j],
                       'pcb_technology_model.internal_physical_layer') THEN
             IF coPlanarObjs[j] :=: layer THEN
                RETURN(i);
             END_IF;
          ELSE
          IF find_layer_position_in_layer_stack(coPlanarObjs[j], layer) > 0 THEN
             RETURN(i);
          END_IF;
          END_IF;
        END_REPEAT;
      END_IF;
    END_REPEAT;
    RETURN(0);
  END_FUNCTION;

Description:

The find_layer_position_in_layer_stack returns the position of a layer within a stacked_layer_group. It returns zero if a layer is not defined within a stacked_layer_group, either directly or indirectly.

Example: Suppose a stacked_layer_group SG1 stacks three objects: layer L1, layer L2 and co-planar layer-group CG1. CG1 contains three objects: layer L3, layer L4 and stacked layer-group SG2. SG2 stacks two layers: layer L5 and layer L6. The following function calls return: 

 find_layer_position_in_layer_stack(SG1, L1) returns 1.
 find_layer_position_in_layer_stack(SG1, L2) returns 2.
 find_layer_position_in_layer_stack(SG1, L3) returns 3.
 find_layer_position_in_layer_stack(SG1, L4) returns 3.
 find_layer_position_in_layer_stack(SG1, L5) returns 3.
 find_layer_position_in_layer_stack(SG1, L6) returns 3.
 find_layer_position_in_layer_stack(SG2, L5) returns 1.
 find_layer_position_in_layer_stack(SG2, L6) returns 2.

Description:

An internal_technology_rule describes the manufacture rules and clearance rules for an "internal_bare board technology".

The minimum_acid_trap_angle specifies the minimum angle that must be formed by a trace when it enters a pad in order to avoid the formation of an "acid trap" (a place where acid can be trapped during the bare board manufacturing process).

The minimum_sliver_width specifies the minimum width of sliver that can be successfully manufactured on a bare board. A sliver is a non-beneficial thin shard of material which is too thin to be self-sustaining.

There are a number of clearance rules which specify the minimum and the optimum spacings between artifacts of particular types. For clearance rules, a surface_mount_pad means a pad on a surface-mounted pin place, a through_hole_pad means a pad on a through-hole-mounted pin place, a via_pad means a pad on a via and a trace means a trace segment. The optimum spacing is what the designer prefers but it can be violated providing the minimum spacing is followed. Optimum spacings are specific to the auto-routing process therefore only trace_to_layout_shape, trace_to_surface_mount_pad, trace_to_through_hole_pad, trace_to_trace or trace_to_via_pad can have optimum spacings.

For trace_to_via_pad clearance, the rule is applied by determining the distance between the edge of the trace nearest the via, and the pad of the via on the layer containing the trace.

For hole_to_board_edge, trace_to_board_edge, surface_mount_pad_to_board_edge, through_hole_pad_to_board_edge, via_pad_to_board_edge and layout_shape_to_board_edge, they specify how far inside the inner edge of the board objects must be located. The purpose is to assure that the profiling tool (which a board is cut out of a sheet) does not damage the electrical artifacts within the board.

For via_pad_to_via_pad clearance, the rule is applied by determining the distance between the edge of any pad on one via and the edge of the pad on the other via on the same layer.

The check_on_same_net flag indicates whether or not clearance rules should be applied on objects from the same physical_net. An example might be a zig-zag trace in which the minimum trace-to-trace spacing is preserved between adjacent edges of different segments of the same trace.

The trace_grid is a recommendation to put traces on the grid. It is not an EDIF error to be off grid, nor is it a design error to be off grid.

physical_layer_contributing_collectors

  FUNCTION physical_layer_contributing_collectors
    (ffc : fabricate_figure_collector;
     positive : BOOLEAN) : SET OF simple_fabricate_figure_collector;
    LOCAL
      result : SET OF simple_fabricate_figure_collector := [];
    END_LOCAL;

    IF is_typeof(ffc, 
       'edif_information_model.simple_fabricate_figure_collector') THEN
       IF positive THEN
          result := [ffc\simple_fabricate_figure_collector];
       ELSE
          result := [];
       END_IF;
    END_IF;

    IF is_typeof(ffc, 
       'edif_information_model.differenced_fabricate_figure_collector') THEN
       result := physical_layer_contributing_collectors
                 (ffc\differenced_fabricate_figure_collector
                     .initial_geometric_shapes, positive)
                 +
                 physical_layer_contributing_collectors 
                 (ffc\differenced_fabricate_figure_collector
                     .subtrahend_geometric_shapes, NOT positive);
    END_IF;

    IF is_typeof(ffc, 
       'edif_information_model.mirrored_fabricate_figure_collector') THEN
       result := physical_layer_contributing_collectors 
                 (ffc\mirrored_fabricate_figure_collector
                     .initial_geometric_shapes, positive);
    END_IF;

    IF is_typeof(ffc, 
       'edif_information_model.resized_fabricate_figure_collector') THEN
       result := physical_layer_contributing_collectors 
                 (ffc\resized_fabricate_figure_collector
                     .initial_geometric_shapes, positive);
    END_IF;

    IF is_typeof(ffc,
       'edif_information_model.rotated_fabricate_figure_collector') THEN
       result := physical_layer_contributing_collectors 
                 (ffc\rotated_fabricate_figure_collector
                     .initial_geometric_shapes, positive);
    END_IF;

    IF is_typeof(ffc, 
       'edif_information_model.translated_fabricate_figure_collector') THEN
       result := physical_layer_contributing_collectors 
                 (ffc\translated_fabricate_figure_collector
                     .initial_geometric_shapes, positive);
    END_IF;

    IF is_typeof(ffc, 
       'edif_information_model.unioned_fabricate_figure_collector') THEN
       REPEAT i := 1 TO SIZEOF (ffc\unioned_fabricate_figure_collector
                                   .unioned_geometric_shapes);
         result := result + physical_layer_contributing_collectors 
                            (ffc\unioned_fabricate_figure_collector
                                .unioned_geometric_shapes[i], positive);
       END_REPEAT;
    END_IF;

    RETURN (result);

  END_FUNCTION;

Description:

The physical_layer_contributing_collectors function returns the set of simple_fabricate_figure_collectors which make a positive or negative contribution to the fabricate_figure_collector specified. The required contribution is specified by the positive parameter.

Used by:

physical_layer
