pcb_mountable_package_model

Description:

The pcb_mountable_package_model describes the ways in which packages can be mounted onto a bare board.

mountable_package

  ENTITY mountable_package
      ABSTRACT SUPERTYPE OF (ONEOF(external_mountable_package,
                                   internal_mountable_package));
    document            : OPTIONAL SET [1:?] OF documentation;
    mountable_fixings   : OPTIONAL SET [1:?] OF mountable_mechanical_fixing;
    mountable_terminals : OPTIONAL SET [1:?] OF mountable_package_terminal;
    name                : OPTIONAL name_information;
    properties          : OPTIONAL SET [1:?] OF property;
    symbols             : OPTIONAL SET [1:?] OF mountable_package_symbol;
    units               : pcb_layout_units;
    written_status      : OPTIONAL SET [1:?] OF written;
  WHERE
    valid_existence :
      (* A mountable_package belongs to one library. *) 
      belongs_to_one(SELF,'library_model.library.mountable_packages');
  END_ENTITY;

Description:

A mountable_package object describes a particular package prepared for mounting in a particular way on a bare board.

Used by:

internal_mountable_pin_package

  ENTITY internal_mountable_pin_package
      SUBTYPE OF (internal_mountable_package);
    SELF\mountable_package.mountable_terminals
        : OPTIONAL SET [1:?] OF internal_mountable_pin;
    SELF\internal_mountable_package.referenced_package 
        : pin_package;
    referenced_mounting_method : mounting_method; -- reference
    overriding_pin_form        : OPTIONAL pin_form;
    overriding_mounting_class  : OPTIONAL package_mounting_class;
    overriding_terminal_pitch  : OPTIONAL length_value;
    pin_group_mountings        : OPTIONAL SET [1:?] OF pin_group_mounting;
    default_pin_mounting       : pin_mounting;
  WHERE
    valid_pin_group_mountings :
      (* All referenced pin_groups are defined in the referenced
         pin_package. *) 
      not_exists(QUERY(pinGroupMounting <* pin_group_mountings |
         NOT (pinGroupMounting.referenced_pin_group
              IN referenced_package.pin_groups)));

    valid_optional_attributes :
       (* The dependencies of these optional attributes are stated as follows:
          1. Pin_group_mountings cannot be defined if the mounted pin package
             does not define any pin_groups. *)
       EXISTS(referenced_package.pin_groups) OR
         NOT EXISTS(pin_group_mountings);
  END_ENTITY;

Description:

An internal_mountable_pin_package describes how a pin_package is mounted. It records the change in pin pattern (if any) of a pin_package when mounted onto the bare board in a particular way.

An internal_extra_mountable_pin describes an extra mountable pin for an internal_mountable_pin_package. These extra mountable pins refer to no pin in the pin_package which is mounted. An example would be the case where a 14-DIP component is mounted into an 18-pin socket (i.e. 4 of the socket pins would be the extra pins in this case).

pin_mounting

  TYPE pin_mounting
    = ENUMERATION OF (top_side,
                      bottom_side,
                      both_sides, 
                      through_board,
                      socketed,
                      unmounted);
  END_TYPE;

Description:

A pin_mounting describes the side of the mountable pin, with respect to the mountable_package body. A value of top_side indicates that pins are mounted to the top side of the bare board. A value of both_sides indicates that pins are mounted in unplated holes and the electrical contact between the circuit connected to the top of the pin and the circuit connected to the bottom of the pin is achieved by the pin itself. Therefore the pin must be electrically connected at the top side and at the bottom side. A value of through_board indicates that pins are mounted in plated holes and the electrical contact between the circuit connected to the top of the board and the circuit connected to the bottom of the board is achieved by the plating rather than the pin.

Used by:

internal_mountable_pin internal_mountable_pin_package pin_group_mounting

mountable_package_orientation_rule

  ENTITY mountable_package_orientation_rule;
    allowed_rotations             : SET [1:?] OF angle_value;
    properties                    : OPTIONAL SET [1:?] OF property;
    referenced_mountable_packages : SET [1:?] OF mountable_package; -- reference
  WHERE
    valid_existence :
      (* A mountable_package_orientation_rule belongs to one library. *)
      belongs_to_one(SELF,
        'library_model.library.mountable_package_orientation_rules');
  END_ENTITY;

Description:

PCB assembly processes and tools need to know how to place components onto the bare board. Most of that information can be found in the mountable_package entity. A mountable_package_orientation_rule further defines assembly information by specifying the allowable angles of rotation for a mountable_package. The rotation angle is measured counter-clockwise as seen from the top side of the board.

EXAMPLE: 14-Pin Surface Mount Technology (SMT) Dual In Line Packages (DIPs) on the top side (non-solder) may be rotated at 45 degrees increments.

Used by:

assembled_board library

internal_mountable_package_symbol

  ENTITY internal_mountable_package_symbol
    SUBTYPE OF(mountable_package_symbol);
    associated_figures                  : OPTIONAL SET [1:?] OF drawing_figure;
    associated_figure_macros            : OPTIONAL SET [1:?] OF
                                          drawing_figure_macro; 
    associated_text                     : OPTIONAL SET [1:?] OF drawing_text;
    component_designator_drawing_slot   : OPTIONAL SET [1:?] OF
                                          drawing_text_display;
    component_name_drawing_slot         : OPTIONAL SET [1:?] OF
                                          drawing_text_display;
    mountable_package_name_drawing      : OPTIONAL SET [1:?] OF
                                          drawing_text_display;
    mountable_package_property_drawings : OPTIONAL SET [1:?] OF
                                          property_drawing;
    mountable_fixing_representations    : OPTIONAL SET [1:?] OF
                                          mountable_fixing_representation;
    mountable_terminal_representations  : OPTIONAL SET [1:?] OF
                                          mountable_terminal_representation;
    package_name_drawing                : OPTIONAL SET [1:?] OF
                                          drawing_text_display;
    package_property_drawings           : OPTIONAL SET [1:?] OF
                                          property_drawing;
    part_name_drawing_slot              : OPTIONAL SET [1:?] OF
                                          drawing_text_display;
  DERIVE
    containing_package : internal_mountable_package -- reference
      := usedin_one_role(SELF,
           'pcb_mountable_package_model.internal_mountable_package.symbols');
  WHERE
    valid_mountable_package_property_drawings:
      (* The referenced properties must belong to the mountable package that
         contains this symbol. *) 
      not_exists(QUERY(propertyDrawing <* mountable_package_property_drawings |
                 NOT(propertyDrawing.drawn_property IN
                     containing_package.properties)));

    valid_package_property_drawings:
      (* The referenced properties must belong to the package referenced by the
         mountable_package which contains this symbol *) 
      not_exists(QUERY(propertyDrawing <* package_property_drawings |
                 NOT(propertyDrawing.drawn_property IN
                     containing_package.referenced_package.properties)));

    valid_optional_attributes :
      (* The dependencies of these optional attributes are stated as follows:
         1. A symbol cannot have mountable_package_property_drawings if its
            containing mountable_package does not define any properties.
         2. A symbol cannot have package_property_drawings if the package
            referenced from the mountable_package does not define any
            properties. *) 
      (EXISTS(containing_package.properties) OR 
         NOT EXISTS(mountable_package_property_drawings))
      AND
      (EXISTS(containing_package.referenced_package.properties) OR
        NOT EXISTS(package_property_drawings));
  END_ENTITY;

Description:

An internal_mountable_package_symbol is a representation of a mountable_package within an internal_library.

mountable_terminal_representation

  ENTITY mountable_terminal_representation;
    drawn_terminal        : internal_mountable_package_terminal; -- reference
    instantiated_template : package_terminal_drawing_template; -- reference
    mountable_terminal_property_drawings : OPTIONAL SET [1:?] OF
                                           property_drawing; 
    template_position     : fixed_scale_transform;
  DERIVE
    containing_symbol : internal_mountable_package_symbol -- reference
      := usedin_one_role(SELF,
           specified_role('pcb_mountable_package_model',
                          'internal_mountable_package_symbol',
                          'mountable_terminal_representations'));
  UNIQUE
    unique_representation:
      (* In a given symbol, a mountable terminal has a unique
         representation. *) 
      drawn_terminal, containing_symbol;
  WHERE
    valid_existence:
      (* A mountable_terminal_representation belongs to one
         internal_mountable_package_symbol. *)
      belongs_to_one(SELF,
        specified_role('pcb_mountable_package_model',
                       'internal_mountable_package_symbol',
                       'mountable_terminal_representations'));

    valid_drawn_terminal:
      (* The drawn mountable_package_terminal must be defined in the
         mountable_package which owns the symbol. *)
      EXISTS(containing_symbol.containing_package.mountable_terminals)
      AND
      (drawn_terminal IN
         containing_symbol.containing_package.mountable_terminals);

    valid_mountable_terminal_property_drawings :
      (* The drawn properties must be defined in the referenced
         mountable_package_terminal. *)
      not_exists(QUERY(propertyDrawing <* mountable_terminal_property_drawings |
        NOT (propertyDrawing.drawn_property 
             IN drawn_terminal\mountable_package_terminal.properties)));

    valid_drawing_template_type:
      (* The template type should be consistent with the terminal type.  If the
         drawn terminal is an internal_prepared_mountable_pin or an
         internal_mountable_solder_ball,  the indicator value of the template
         must be either prepared_terminal or unrestricted.  If the drawn
         terminal is an internal_extra_mountable_pin, the indicator value of
         the template must be either extra_terminal or unrestricted. *)

      (is_typeof(drawn_terminal,
                 'pcb_mountable_package_model.internal_prepared_mountable_pin')
       OR
       is_typeof(drawn_terminal,
                 'pcb_mountable_package_model.internal_mountable_solder_ball')
       AND
       ((instantiated_template.terminal_indicator = 
         package_terminal_drawing_template_indicator.prepared_terminal)
        OR
        (instantiated_template.terminal_indicator = 
         package_terminal_drawing_template_indicator.unrestricted)))
      OR
      (is_typeof(drawn_terminal,
                 'pcb_mountable_package_model.internal_extra_mountable_pin')
       AND
       ((instantiated_template.terminal_indicator = 
         package_terminal_drawing_template_indicator.extra_terminal)
        OR
        (instantiated_template.terminal_indicator = 
         package_terminal_drawing_template_indicator.unrestricted)));

    valid_optional_attributes :
      (* The dependencies of these optional attributes are stated as follows:
         1. A terminal representation cannot have
            mountable_terminal_property_drawings if its referenced terminal
            does not define any properties. *)
      EXISTS(drawn_terminal\mountable_package_terminal.properties) OR
        NOT EXISTS(mountable_terminal_property_drawings);
  END_ENTITY;
