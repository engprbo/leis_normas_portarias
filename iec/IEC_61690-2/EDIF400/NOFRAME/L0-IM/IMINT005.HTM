7 Names

This chapter describes the concept of names associated with design objects. The model for name_information can be found in the support_definition_model schema. The name_information of an object provides a primary name_set which should be used to name the object in the target system if possible. The name_set consists of different types of name defined as follows:

  • original_name

This is the name of an object, exactly as it is specified in the source system. An original_name may be machine generated, rather than created by a human. If a name is machine generated, it can be changed with no effect on the human users of this object, except for back annotation purposes.

Many systems use special characters and sub-strings embedded within an object name to indicate information about the object, e.g. logical complement, boolean relationships, dimensionality, bit ranges or indices. A name_structure is used to specify in detail the structural parts of a name without the use of special characters. It should be used if the sending system uses the name structure to specify the structure of the design object.

  • display_name

This is the name which will get displayed for an object.

In addition, the name_information may give aliases which are considered to be secondary names of the object.
