design_management_model

Description:

The design_management_model schema provides the design management information. It records a history of modifications. It provides the information needed to trace back to the origin or the owner of the data, and also identifies the software or program name which was responsible for creating the data.

valid_date

  FUNCTION valid_date 
    (yy, mm, dd : positive_integer_token) : LOGICAL;
    LOCAL
      leap_year : LOGICAL;
      valid     : LOGICAL;
    END_LOCAL;
    leap_year := (yy mod 4 = 0) AND ((yy mod 100 <> 0) OR (yy mod 400 = 0)); 
    CASE mm OF  
      1, 3, 5, 7, 8, 10, 12 : valid := dd <= 31;
      4, 6, 9, 11           : valid := dd <= 30;
      2                     : IF leap_year THEN
                                 valid := dd <= 29;
                              ELSE
                                 valid := dd <= 28;
                              END_IF;
      OTHERWISE             : valid := false;
    END_CASE;
    RETURN(valid);        
  END_FUNCTION;

Description:

The valid_date function checks every instance of date. It is used to check whether the day, month and year fields constitute a valid date or not.

Used by:

date

valid_timestamp_in_previous_version

  FUNCTION valid_timestamp_in_previous_version
    (current, previous : SET OF written) : BOOLEAN;
    LOCAL
      earliestTime, latestTime : time_stamp;
    END_LOCAL;
    IF EXISTS(current) AND EXISTS(previous) THEN
       earliestTime := current[1].date;
       REPEAT i := 2 TO SIZEOF(current);
         IF compare_timestamp(current[i].date, earliestTime) < 0 THEN
            earliestTime := current[i].date;
         END_IF;
       END_REPEAT;

       latestTime := previous[1].date;
       REPEAT i := 2 TO SIZEOF(previous);
         IF compare_timestamp(previous[i].date, latestTime) > 0 THEN
            latestTime := previous[i].date;
         END_IF;
       END_REPEAT;

       RETURN(compare_timestamp(earliestTime, latestTime) >= 0);
    ELSE
       RETURN(TRUE);
    END_IF;
  END_FUNCTION;

Description:

The valid_timestamp_in_previous_version function accepts two sets of written as arguments. It returns true if the earliest timestamp in the first argument (i.e. current) is later than the latest timestamp in the second argument (i.e. previous).

Used by:

bare_board_technology cell_representation die_physical_template mounting_method package part sub_layout_definition

compare_timestamp

  FUNCTION compare_timestamp
    (d1, d2 : time_stamp) : REAL;
    RETURN((d1.recorded_date.year   - d2.recorded_date.year)   * 1.E10 +
           (d1.recorded_date.month  - d2.recorded_date.month)  * 1.E8  +
           (d1.recorded_date.day    - d2.recorded_date.day)    * 1.E6  +
           (d1.recorded_time.hour   - d2.recorded_time.hour)   * 1.E4  +
           (d1.recorded_time.minute - d2.recorded_time.minute) * 1.E2  +
           (d1.recorded_time.second - d2.recorded_time.second));
  END_FUNCTION;

Description:

The compare_timestamp compares two time_stamps. It returns a negative number if d1 is earlier than d2, 0 if d1 is equal to d2 and a positive number if d1 is later than d2.
