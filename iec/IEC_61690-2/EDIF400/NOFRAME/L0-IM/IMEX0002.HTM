connectivity_view_model

Description:

The connectivity_view_model schema describes what information can be found in an EDIF connectivity view. The connectivity view conveys hierarchical and connectivity information. The hierarchy information describes how a circuit is broken down into a number of sub-circuits. The connectivity information defines how circuits are connected. No details of connectivity implementation are specified in a connectivity view.

internal_connectivity_view

  ENTITY internal_connectivity_view
      SUBTYPE OF (internal_cell_representation);
    busses            : OPTIONAL SET [1:?] OF connectivity_bus;
    instances         : OPTIONAL SET [1:?] OF instance;
    local_port_groups : OPTIONAL SET [1:?] OF local_master_port_group;
    nets              : OPTIONAL SET [1:?] OF connectivity_net;
    rippers           : OPTIONAL SET [1:?] OF connectivity_ripper;
    signals           : OPTIONAL SET [1:?] OF signal;
    signal_groups     : OPTIONAL SET [1:?] OF signal_group;
    timings           : OPTIONAL SET [1:?] OF timing;
    units             : connectivity_units;
  WHERE
    valid_instances :
      (* An internal_connectivity_view should not contain instances of clusters
         of the containing_cell either directly or indirectly. *) 
      non_recursive_cell(SELF\cell_representation.containing_cluster
                             .containing_cell, instances);

    valid_signals :
      (* All signals are disjoint.  That is only one signal may connect to a 
         particular global_port, instance_member_port or master_port. *)
      not_exists(QUERY(sig1 <* signals |
        there_exists(QUERY(sig2 <* signals - sig1 |
          there_exists(sig1.joined_global_ports * sig2.joined_global_ports)
       OR there_exists(sig1.joined_instance_member_ports 
                       * sig2.joined_instance_member_ports)
       OR there_exists(sig1.joined_master_ports * sig2.joined_master_ports)))));

    valid_optional_attributes :
       (* The dependencies of these optional attributes are stated as follows:
          1. Nets cannot be defined if there are no signals defined. 
          2. Busses cannot be defined if there are no signal_groups defined.
          3. Signal_groups cannot be defined if there are no signals defined. *)
       (EXISTS(signals) OR NOT EXISTS(nets))
        AND
       (EXISTS(signal_groups) OR NOT EXISTS(busses))
        AND
       (EXISTS(signals) OR NOT EXISTS(signal_groups));
  END_ENTITY;

Description:

An internal_connectivity_view is a cell representation which describes connectivity. It conveys hierarchy information and connectivity information. The hierarchy information describes how a circuit is broken down into a number of cells. The connectivity information defines how circuits are connected. No connectivity implementation details are specified in an internal_connectivity_view.

Used by:

connectivity_bus connectivity_bus_slice connectivity_net connectivity_ripper

external_connectivity_view

  ENTITY external_connectivity_view
      SUBTYPE OF (external_cell_representation);
    units : connectivity_units;
  END_ENTITY;

Description:

An external_connectivity_view is a connectivity view found in an external_cell.

connectivity_units

  ENTITY connectivity_units;
    set_capacitance : capacitance_unit;
    set_time        : time_unit;
  WHERE
    valid_existence :
      either_belongs_to_one(SELF,
      ['connectivity_view_model.external_connectivity_view.units',
       'connectivity_view_model.internal_connectivity_view.units',
       'edif_information_model.physical_scaling.default_connectivity_units']);
  END_ENTITY;

Description:

A connectivity_units is used to set the scaling for a connectivity view. In a connectivity view, it is appropriate to set a capacitance scale and a timing scale.

Used by:

external_connectivity_view internal_connectivity_view physical_scaling
