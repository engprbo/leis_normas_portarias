17 Mountable packages

This chapter describes the concept of mountable packages. The model for mountable_package can be found in the pcb_mountable_package_model schema. A mountable_package is a collection of rules about how to mount a given package (see chapter 16) according to a certain mounting_method. It records the changes in the positions of the package pins with respect to each other, depending on the method of mounting. It also records the additional components that should be added to the assembly parts list to achieve this mounting. Figure 17.3 shows the model of mountable_package. A mountable_package describes the consequences of mounting a particular package with a particular mounting_method. Within a package, each package_terminal has a unique location, with respect to the package origin. When the package is mounted in a certain way, the positions of the package terminals may be altered. Hence, a mountable_package has a set of mountable_package_terminals and mountable_mechanical_fixings. Each mountable_package_terminal defines the location of a terminal within a mountable_package, relative to the origin of the mountable_package. A mountable_package description is either internal (i.e. internal_mountable_package) or external (i.e. external_mountable_package) to an EDIF file. An internal_mountable_package specifies a complete description of a mountable package. It specifies the mounted package and also records the extra discrete (mechanical or connector) components that should be added to achieve this mounting. Each mountable_package may refer to one or more auxiliary_components, each one of which is used as an additional component when mounting a particular package in a particular way. As shown in figure 16.3, a package can be a pin_package, a ball_package or a mechanical_package. A similar distinction also applies to mountable_package. An internal_mountable_pin_package describes the result of mounting a pin_package; an internal_mountable_ball_package describes the result of mounting a ball_package; an internal_mountable_mechanical_package describes the result of mounting a mechanical_package.

Figure 17.3: The model of mountable_package

Figure 17.4 shows the model of mountable_package_terminal. Just as a mountable_package description is either internal or external to an EDIF file, a similar concept applies to its mountable_package_terminal. An internal_mountable_package_terminal specifies a complete description of how to mount a package_terminal. As shown in figure 16.4, a package_terminal can be either a pin or a solder_ball. A similar distinction also applies to the terminals of a mountable_package. An internal_mountable_package_terminal can be either a pin (i.e. internal_mountable_pin) or a solder ball (i.e. internal_mountable_solder_ball). An internal_mountable_pin belongs to an internal_mountable_pin_package and it may or may not correspond to a pin of the mounted pin_package. For example, it is possible to mount a 14-pin package into an 18-pin socket, in which case, the mountable package owns 4 mountable pins which correspond to no package pin. Hence, an internal_mountable_pin is divided into two categories. An internal_prepared_mountable_pin describes the result of mounting a package pin; whereas an internal_extra_mountable_pin describes an extra pin which is added for the mounting purpose.

Figure 17.4: The model of mountable_package_terminal

Figure 17.5 shows the model of auxiliary_component. An auxiliary_component can be either an auxiliary_mechanical_component or an auxiliary_connector_component. An auxiliary_mechanical_component refers to a mechanical_part (see section 19.3) as an extra piece of the assembly (e.g. a protective cover and securing clip on a small daughter board). An auxiliary_connector_component refers to a packaged_connector_part (see section 19.2) to be used as an additional component for mounting (e.g. a socket). The component being mounted into the socket makes reference to a mountable_package, which in turn refers to an auxiliary_connector_component. The auxiliary_connector_component refers to a packaged_connector_part which describes the socket.
