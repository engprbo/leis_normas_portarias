instantiatable_object_model

Description:

The instantiatable_object_model schema describes a class of reusable templates which are defined once and may be used many times. Some templates can be used in many view types, for example, geometry_macro_template. Some other templates may only be used in certain view types. For example, schematic_offpageconnector_template, schematic_master_port_representation_template and schematic_ripper_template may be used in schematic views only.

schematic_template

  ENTITY schematic_template
      ABSTRACT SUPERTYPE OF 
        (ONEOF(page_border_template,
               page_title_block_template,
               schematic_figure_macro_template,
               schematic_global_port_representation_template,
               schematic_junction_template,
               schematic_master_port_representation_template,
               schematic_offpageconnector_template,
               schematic_onpageconnector_template,
               schematic_ripper_template,
               schematic_symbol_port_representation_template,
               schematic_interconnect_terminator_template,
               schematic_symbol_border_template));
    background_colour     : colour;                 
    document              : OPTIONAL SET [1:?] OF documentation;
    name                  : OPTIONAL name_information;
    original_bounding_box : OPTIONAL rectangle;
    properties            : OPTIONAL SET [1:?] OF property; 
    property_displays     : OPTIONAL SET [1:?] OF property_display;
    status_of_copyright   : OPTIONAL SET [1:?] OF copyright;
    status_of_written     : OPTIONAL SET [1:?] OF written;
    units                 : schematic_units;
  WHERE
    valid_property_displays :
      (* The displayed properties are defined in the template. *)
      not_exists(QUERY(templatePropertyDisplay <* property_displays |
        NOT (templatePropertyDisplay.displayed_property IN properties)));

    valid_optional_attributes :
      (* The dependencies of these optional attributes are stated as follows:
         1. A template cannot have property_displays if it does not define any
            properties. *)
      EXISTS(properties) OR NOT EXISTS(property_displays);
  END_ENTITY;

Description:

A schematic_template represents a template which can be used in schematic views only, for example, schematic_master_port_representation_template, schematic_offpageconnector_template. A schematic_template has abstraction information such as background colour and scales used in the template definition.

Description:

A schematic_offpageconnector_template contains information which is used in the definition of an offpageconnector on a schematic page.

Used by:

schematic_offpageconnector

external_schematic_offpageconnector_template

  ENTITY external_schematic_offpageconnector_template
      SUBTYPE OF (schematic_offpageconnector_template);
  END_ENTITY;

Description:

An external_schematic_offpageconnector_template is an offpageconnector template definition found in an external_library. It may be used in schematic views only. It has abstraction information such as hotspot and scales used in the template definition. Since an external template is not allowed to contain implementation information, it does not have any associated graphics or display slot details.

ripper_hotspot

  ENTITY ripper_hotspot;
    hotspot_name              : OPTIONAL name_information;
    hotspot_name_display_slot : OPTIONAL SET [1:?] OF display;
    position                  : integer_point;
    wire_affinity             : schematic_wire_affinity;
  DERIVE
    containing_template : schematic_ripper_template -- reference
      := usedin_one_role(SELF,
         'instantiatable_object_model.schematic_ripper_template.hotspots');
    containing_ripper   : schematic_ripper -- reference
      := usedin_one_role(SELF,
         'schematic_implementation_model.schematic_ripper.hotspots');
  WHERE
    containment_constraint :
      (* A ripper_hotspot belongs to either one schematic_ripper_template or
         one schematic_ripper. *)
      either_belongs_to_one(SELF,
      ['instantiatable_object_model.schematic_ripper_template.hotspots',
       'schematic_implementation_model.schematic_ripper.hotspots']);
  END_ENTITY;

Description:

A ripper_hotspot is a named hotspot on a schematic_ripper. The schematic_wire_style indicator defines whether the hotspot is suitable to be joined to a narrow or a wide interconnect structure.

Used by:

schematic_generic_bus schematic_generic_net schematic_ripper schematic_ripper_template

non_recursive_schematic_figure_macro_template

  FUNCTION non_recursive_schematic_figure_macro_template
    (parent  : internal_schematic_figure_macro_template;
     members : SET OF schematic_figure_macro) : BOOLEAN;

    REPEAT i := 1 TO SIZEOF(members);
      IF 'instantiatable_object_model.internal_schematic_figure_macro_template'
         IN TYPEOF(members[i].instantiated_template) THEN
         IF parent :=: members[i].instantiated_template THEN
            RETURN(FALSE);
         ELSE
           IF NOT non_recursive_schematic_figure_macro_template
                  (parent, members[i].instantiated_template
                           \internal_schematic_figure_macro_template
                           .associated_figure_macros) THEN
              RETURN(FALSE);
           END_IF;
         END_IF;
      END_IF;
    END_REPEAT;
    RETURN(TRUE);
  END_FUNCTION;

Description:

The non_recursive_schematic_figure_macro_template function returns true if an internal_schematic_figure_macro_template does not contain schematic_figure_macros which reference itself. It prevents cyclic definition of an internal_schematic_figure_macro_template.

Used by:

internal_schematic_figure_macro_template

point_inside_geometry_macro

  FUNCTION point_inside_geometry_macro
    (pt : point; element : geometry_macro) : BOOLEAN;
     IF 'instantiatable_object_model.internal_geometry_macro_template'
        IN TYPEOF(element.instantiated_template) THEN
        IF there_exists(QUERY(geometry 
                              <* element.instantiated_template
                                        \internal_geometry_macro_template
                                        .geometries |
                        point_inside_geometry_element(pt, geometry))) THEN
           RETURN(TRUE);
        END_IF;
        IF there_exists(QUERY(geometryMacro
                              <* element.instantiated_template
                                        \internal_geometry_macro_template
                                        .geometry_macros |
                        point_inside_geometry_macro(pt, geometryMacro))) THEN
           RETURN(TRUE);
        END_IF;
     ELSE
        RETURN(TRUE);
     END_IF;
     RETURN(FALSE);
  END_FUNCTION;

Description:

The point_inside_geometry_macro returns true if a point lies inside a geometry_macro.
