15 Bare board technologies

This chapter describes the "technology" of a bare board. The model for bare_board_technology can be found in the pcb_technology_model schema. A bare_board_technology is the set of data which (a) guides a designer (or CAD system) in such a way as to create a layout which is fully manufacturable in a particular manner, and (b) fully describes the physical structure of a bare board.

A bare_board_technology defines a collection of physical_layers which represents the final layered construction of a complete bare board. It can be either an external_bare_board_technology or an internal_bare_board_technology. Only internal_bare_board_technology contains information on how physical_layers are stacked to form the layup of a board. A stacked_layer_group is an ordered list of internal_physical_layers or co_planar_layer_groups, arranged in a vertical stack. Figure 15.1 shows an example of a simple stacked_layer_group. A co_planar_layer_group is an unordered group of internal_physical_layers and stacked_layer_groups in the same z-plane. Figure 15.2 shows an example of a co_planar_layer_group. 15.1 Physical layers

A physical_layer can be either a conducting_layer or a non_conducting_layer. An internal_physical_layer describes the physical data for a layer. It contains information such as the thickness of the layer and the material (see chapter 14) of which the layer is made. It is important to note that a physical layer represents a potential for material, not actual material. That is, if no artifacts contribute to the physical layer (through associated fabricate_figure_collectors, see chapter 22), then there will be no material in that physical layer. 15.2 Drill rules

A bare_board_technology may define a set of drill_rules which indicate the preferred method of creating holes for cross-layer connections or for securing purposes. A plated_drill_rule is a type of drill_rule which specifically applies to the manufacture of plated through holes. It indicates the material that is to be used to plate the inside of holes in order to make them conductive. Similarly, a non_plated_drill_rule is a drill_rule which specifically applies to the manufacture of unplated holes. Figure 15.5 shows the model of drill_rule.
