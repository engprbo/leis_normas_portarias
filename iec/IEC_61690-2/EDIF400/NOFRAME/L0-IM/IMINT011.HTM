16 Packages

This chapter describes the concept of packages. The model for package can be found in the pcb_package_model schema. Usually package information is acquired from other parties, e.g. data sheet information about component packages.

A package describes a single physical package description. It is not intended to have any electrical function in itself. A package can be a pin_package, a ball_package or a mechanical_package. An example of a pin_package (a "14-Pin Ceramic Dual In Line" package) is shown in figure.16.1 and an example of a ball_package is shown in figure 16.2.

Figure 16.1: An example of a pin_package (J14)

Figure 16.2: An example of a ball_package

The model of package is shown in figure 16.3. A package description is either internal (i.e. internal_package) or external (i.e. external_package) to an EDIF file. An internal_package specifies a complete description of a package, containing information such as body_volume and occupied_space. A package contains a collection of package_terminals which are used for electrical connection and a collection of mechanical_fixings which are used for mechanical securing purposes. For pin_packages, the package_terminals are pins; whereas for ball_packages, the package_terminals are solder_balls. However, mechanical_packages should only contain mechanical_fixings and hence are not allowed to define any package_terminals.

Figure 16.3: The model of package

The model of package_terminal is shown in figure 16.4. An internal_pin describes the physical data for a pin within a pin_package. It instantiates a pin_template which contains information like contact area and length. Similarly, an internal_solder_ball describes the physical data for a solder ball within a ball_package. It instantiates a solder_bump_template which contains information like bump height and diameter. In addition, a package may specify a collection of pin_groups. All of the package pins referenced by a pin_group are intended to be mounted onto a bare board in the same manner.

Figure 16.4: The model of package_terminal

The model of mechanical_fixing is shown in figure 16.5.An internal_mechanical_fixing specifies the contact area which the mechanical fixing interacts with the mounting side of the board.
