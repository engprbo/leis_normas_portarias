8 Units

This chapter describes the concept of units. The model for unit can be found in the support_definition_model schema.

In EDIF Version 4 0 0, the solution for units is to:

  • allow the same units to be used in more than one library. They are therefore defined in the edif level,

  • allow definition of user-defined units other than the basic EDIF supplied ones,

  • allow units to be chosen based on the type of the view.

User-defined units must be defined in terms of EDIF units only. It is not permissible for user-defined units to be defined in terms of other user-defined units. Also, when a cell representation is defined, it is necessary to restrict what kind of units are allowed in that type of cell representation. For example, it is inappropriate to select a unit for distance in a view of type connectivity. Table 8.1 describes what kind of units are allowed in different classes of EDIF object.

In EDIF Version 4 0 0, five additional basic units are included. They are candela, celsius, degree, fahrenheit, and mole. It is acknowledged that the SI unit for angle is radian; however for practical engineering usage, degree is more widely used by engineers.
