hierarchy_model

Description:

The hierarchy_model schema describes the hierarchical information of a cell which is the basic unit of design. A cell can have multiple views of the same type. Views and symbols which share the same interface are grouped into a cluster. Views and symbols may also be grouped into a view_group to indicate a particularly close relationship to each other.

cell

  ENTITY cell
      ABSTRACT SUPERTYPE OF (ONEOF(internal_cell, 
                                   external_cell));
    clusters            : OPTIONAL SET [1:?] OF cluster;
    document            : OPTIONAL SET [1:?] OF documentation;
    name                : OPTIONAL name_information;
    properties          : OPTIONAL SET [1:?] OF property;
    status_of_copyright : OPTIONAL SET [1:?] OF copyright;
    status_of_written   : OPTIONAL SET [1:?] OF written;
    view_groups         : OPTIONAL SET [1:?] OF view_group;             
  DERIVE
    containing_library : library -- reference
                         := usedin_one_role(SELF, 
                            'library_model.library.cells');
  END_ENTITY;

Description:

A cell contains clusters which may be instantiated later in another cell to build a design hierarchy. A cell is allowed to have multiple symbols as well as multiple views of the same type. Views and symbols which share the same interface are grouped into a cluster. Views and symbols may also be grouped into a view_group to indicate a particularly close relationship to each other. A cell is classified into internal_cell and external_cell.

Used by:

cluster design library view_group

cluster

  ENTITY cluster
      ABSTRACT SUPERTYPE OF (ONEOF(internal_cluster,
                                   external_cluster));
    cell_representations   : OPTIONAL SET [1:?] OF cell_representation;
    cluster_configurations : OPTIONAL SET [1:?] OF cluster_configuration;
    document               : OPTIONAL SET [1:?] OF documentation;
    name                   : OPTIONAL name_information;
    interface              : cluster_interface;
    properties             : OPTIONAL SET [1:?] OF property;
    status_of_copyright    : OPTIONAL SET [1:?] OF copyright;
    status_of_written      : OPTIONAL SET [1:?] OF written;
  DERIVE
    containing_cell : cell -- reference
                      := usedin_one_role(SELF, 
                         'hierarchy_model.cell.clusters');
  WHERE
    valid_cluster_configurations :
      (* All expandable_cluster_configurations must choose cell_representations
         which are defined in the cluster, and the chosen cell_representations
         must be view representations. *)
    not_exists(QUERY(configuration <* 
      QUERY(config <* cluster_configurations |
      is_typeof(config, 'hierarchy_model.expandable_cluster_configuration')) |
      (NOT (configuration\expandable_cluster_configuration
            .chosen_cell_representation IN cell_representations))
       OR
      ((TYPEOF(configuration\expandable_cluster_configuration
               .chosen_cell_representation)
        * -- set intersection operator
        ['schematic_view_model.internal_schematic_symbol',
         'schematic_view_model.external_schematic_symbol']) = [])));

    valid_optional_attributes :
       (* The dependencies of these optional attributes are stated as follows:
          1. A cluster cannot have expandable_cluster_configurations if it does
             not define any cell_representations. *)
       EXISTS(cell_representations) OR 
         not_exists(QUERY(config <* cluster_configurations |
         is_typeof(config, 
                   'hierarchy_model.expandable_cluster_configuration')));
  END_ENTITY;

Description:

A cluster is a group of views and symbols which have the same interface. Those views and symbols must belong to the same cell.

expandable_cluster_configuration

  ENTITY expandable_cluster_configuration
      SUBTYPE OF (cluster_configuration);
    chosen_cell_representation : cell_representation;               -- reference
    global_port_scopes         : OPTIONAL SET [1:?] OF global_port; -- reference
    instance_configurations    : OPTIONAL SET [1:?] OF instance_configuration;
    unconfigured_instances     : OPTIONAL SET [1:?] OF unconfigured_instance;
  WHERE
    valid_instance_configurations :
      (* Each instance defined within the chosen cell_representation must be
         either given an instance_configuration or chosen to be unconfigured. *)
      not_exists(QUERY(instanceConfiguration <* instance_configurations |
        there_exists(QUERY(unconfiguredInstance <* unconfigured_instances |
          instanceConfiguration.configured_instance
          :=: unconfiguredInstance.referenced_instance))));

    valid_chosen_cell_representation :
      (* The chosen cell_representation must be a view. *)
      NOT (is_typeof(chosen_cell_representation, 
                     'schematic_view_model.internal_schematic_symbol')
           OR 
           is_typeof(chosen_cell_representation,
                     'schematic_view_model.external_schematic_symbol'));

    valid_global_port_scopes :
      (* The referenced global_ports are defined in the containing edif. *)
      global_port_scopes  <= containing_cluster.containing_cell
                             .containing_library.containing_edif.global_ports;
  END_ENTITY;

Description:

An expandable_cluster_configuration gives enough information to expand the hierarchy from that point onwards. It chooses which view to look at and then for each instance of that view, it is either given an instance_configuration or defines that instance as unconfigured. Global_port_scopes are established on global_ports in an occurrence hierarchy. If a global_port is scoped, this indicates that any references to that global_port within the occurrence hierarchy are connected together, except in any lower branch that scopes the same global_port.

Used by:

instance_configuration unconfigured_instance

leaf_configuration

  ENTITY leaf_configuration
      SUBTYPE OF (cluster_configuration);
  END_ENTITY;

Description:

A leaf_configuration specifies that there is no further substructure in an expanded design. If an instance is given an instance_configuration which points to a leaf_configuration, it means that there is no further structure in the design tree below that instance.

instance_configuration

  ENTITY instance_configuration;
    configured_instance          : instance;              -- reference
    chosen_cluster_configuration : cluster_configuration; -- reference
  DERIVE
    containing_configuration : expandable_cluster_configuration -- reference
    := usedin_one_role(SELF,
    'hierarchy_model.expandable_cluster_configuration.instance_configurations');
  UNIQUE
    uniqueness_constraint :
    (* There is only one instance_configuration for a particular instance
       within the containing expandable_cluster_configuration. *)
    configured_instance, containing_configuration;
  WHERE
    valid_existence :
      (* An instance_configuration belongs to one
         expandable_cluster_configuration. *)
    belongs_to_one(SELF,
    'hierarchy_model.expandable_cluster_configuration.instance_configurations');

    valid_configured_instance :
      (* The configured instance must be defined in the chosen
         cell_representation of the containing
         expandable_cluster_configuration. *)
      configured_instance.containing_view
      :=: containing_configuration.chosen_cell_representation;

    valid_chosen_cluster_configuration :
      (* The chosen cluster_configuration is defined in the instantiated
         cluster of the chosen instance. *) 
      EXISTS(configured_instance.instantiated_cluster.cluster_configurations)
      AND
      (chosen_cluster_configuration IN 
         configured_instance.instantiated_cluster.cluster_configurations);
  END_ENTITY;

Description:

An instance_configuration selects a cluster_configuration for an instance. The chosen cluster_configuration is defined in the instantiated cluster of the configured instance.

Used by:

expandable_cluster_configuration leaf_occurrence_annotate occurrence_annotate

    := usedin_one_role(SELF,
    'hierarchy_model.expandable_cluster_configuration.unconfigured_instances');
  UNIQUE
    uniqueness_constraint :
    (* There is only one unconfigured_instance for a particular instance within
       the containing expandable_cluster_configuration. *)
    referenced_instance, containing_configuration;
  WHERE
    valid_existence :
      (* An unconfigured_instance belongs to one
         expandable_cluster_configuration. *)
    belongs_to_one(SELF,
    'hierarchy_model.expandable_cluster_configuration.unconfigured_instances');

    valid_referenced_instance :
      (* The referenced instance must be defined in the chosen
         cell_representation of the containing
         expandable_cluster_configuration. *)
      referenced_instance.containing_view
      :=: containing_configuration.chosen_cell_representation;
  END_ENTITY;

view_group

  ENTITY view_group
      SUPERTYPE OF (ONEOF(internal_view_group,
                          external_view_group));
    cell_representations : OPTIONAL SET [1:?] OF             -- reference
                           cell_representation;
    document             : OPTIONAL SET [1:?] OF documentation;
    name                 : OPTIONAL name_information;
    nested_view_groups   : OPTIONAL SET [1:?] OF view_group; -- reference
    properties           : OPTIONAL SET [1:?] OF private_property;
    reason               : OPTIONAL string_token;
  DERIVE
    containing_cell : cell -- reference
                      := usedin_one_role(SELF, 
                         'hierarchy_model.cell.view_groups');
  WHERE
    valid_cell_representations :
      (* All member views and symbols are defined in the containing cell of the
         view_group. *) 
      not_exists(QUERY(memberCellRepresentation <* cell_representations |
        memberCellRepresentation.containing_cluster.containing_cell 
        :<>: containing_cell));

    valid_nested_view_groups :
      (* All cell_representations within nested_view_groups must belong to the
         containing cell of the view_group. *)
      not_exists(QUERY(viewGroup <* nested_view_groups |
        viewGroup.containing_cell :<>: containing_cell));
  END_ENTITY;

Description:

A view_group is a group of views and symbols which belong to the same cell. There are various reasons for grouping. It is used to express a relationship between any number of views of any type.

Used by:

cluster_interface

  ENTITY cluster_interface;
    designator            : OPTIONAL string_token;
    joined_port_sets      : OPTIONAL SET [1:?] OF joined_port_set;
    must_join_port_sets   : OPTIONAL SET [1:?] OF must_join_port_set;
    permutables           : OPTIONAL SET [1:?] OF permutable_relationship;
    port_bundles          : OPTIONAL SET [1:?] OF master_port_bundle;
    ports                 : OPTIONAL SET [1:?] OF master_port;
    timings               : OPTIONAL SET [1:?] OF timing;
    units                 : cluster_interface_units;
    weak_joined_port_sets : OPTIONAL SET [1:?] OF weak_joined_port_set;
  DERIVE
    containing_cluster : cluster -- reference
                         := usedin_one_role(SELF, 
                            'hierarchy_model.cluster.interface');
  WHERE
    containment_constraint :
      (* A cluster_interface belongs to one cluster. *) 
      belongs_to_one(SELF, 'hierarchy_model.cluster.interface');

    valid_permutables :
      (* A port may be referenced at most once within a permutable or
         non_permutable in an interface. *)
      not_exists(QUERY(port <* ports |
       (SIZEOF(USEDIN(port, 'hierarchy_model.permutable_port_set.members'))
        +
        SIZEOF(USEDIN(port, 'hierarchy_model.non_permutable_port_set.members'))
       ) > 1));

    valid_port_relationships :
      (* A port may be referenced at most once in joined, must_join and
         weak_joined. *)
      not_exists(QUERY(port <* ports |
      (SIZEOF(USEDIN(port, 'hierarchy_model.joined_port_set.member_ports'))
       +
       SIZEOF(USEDIN(port, 'hierarchy_model.must_join_port_set.member_ports'))
       +
       SIZEOF(USEDIN(port, 'hierarchy_model.weak_joined_port_set.member_ports'))
      ) > 1));

    valid_optional_attributes :
       (* The dependencies of these optional attributes are stated as follows:
          1. A cluster_interface cannot have joined_port_sets,
             must_join_port_sets, weak_joined_port_sets, permutables or
             port_bundles if it does not define any ports. *)
       EXISTS(ports) OR
         NOT EXISTS(joined_port_sets) AND NOT EXISTS(must_join_port_sets) AND
         NOT EXISTS(permutables) AND NOT EXISTS(port_bundles) AND
         NOT EXISTS(weak_joined_port_sets);
  END_ENTITY;

Description:

A cluster_interface defines objects which can be seen and relationships which must hold for all views and symbols within a cluster. It includes definitions of master_ports and master_port_bundles.

Used by:

cell_representation cluster local_master_port_group master_port master_port_bundle

master_port

  ENTITY master_port
      ABSTRACT SUPERTYPE OF (ONEOF(input_master_port, 
                                   output_master_port,
                                   bidirectional_master_port, 
                                   unspecified_direction_master_port)); 
    ac_load                   : OPTIONAL capacitance_value;
    default_connection        : OPTIONAL global_port; -- reference
    delays                    : OPTIONAL SET [1:?] OF port_delay;
    designator                : OPTIONAL string_token;
    load_delays               : OPTIONAL SET [1:?] OF port_load_delay;
    name                      : OPTIONAL name_information;
    properties                : OPTIONAL SET [1:?] OF property;
    schematic_port_attributes : OPTIONAL SET [1:?] OF schematic_port_attribute;
    unused_internally         : boolean_token;
  DERIVE
    containing_interface : cluster_interface -- reference
                           := usedin_one_role(SELF, 
                              'hierarchy_model.cluster_interface.ports');
    size                 : INTEGER := 1;
  WHERE
    containment_constraint :
      (* A master_port belongs to one cluster_interface. *)
      belongs_to_one(SELF, 'hierarchy_model.cluster_interface.ports');

    valid_default_connection :
      (* The referenced global_port must be defined in the containing edif. *)
      default_connection 
        IN containing_interface.containing_cluster.containing_cell.
           containing_library.containing_edif.global_ports;

    valid_unused :
      (* If a master_port is unused internally, it is not allowed to have a
         default_connection. *) 
      NOT (unused_internally AND EXISTS(default_connection));
  END_ENTITY;

Description:

A master_port can be defined within the interface of a cluster of a cell. The size of a master_port is always one. A master_port may optionally have a direction characteristic, which can be input, output or bidirectional. It also has information about its external load capacitance, delays for the given set of transitions and its designator name. The unused_internally attribute is a boolean flag indicating whether or not the master_port is being used by the views. If a master_port is declared to be unused, it indicates that this port may be used by the instantiating view for any purpose without influencing the operation of the cell in any way. The default_connection indicates a connection to a global_port which is to be made if no other connection is specified for the port when the cluster is instantiated. If a master_port is defined to be unused, it is not allowed to have a default_connection.

Used by:

board_terminal cluster_interface connectivity_generic_bus connectivity_generic_net instance_member_port instance_port joined_port_set local_master_port_group master_port_annotate master_port_bundle master_port_or_master_port_bundle must_join_port_set non_permutable_port_set part_function_terminal permutable_port_set schematic_generic_bus schematic_generic_net schematic_master_port_representation schematic_symbol_port_representation signal weak_joined_port_set

input_master_port

  ENTITY input_master_port
      SUBTYPE OF (master_port);                                     
    dc_fanout_load : OPTIONAL load_value;
    dc_max_fanin   : OPTIONAL load_value;
  END_ENTITY;

Description:

An input_master_port describes an input port which is defined in the interface. The signal information flows into the cell at an input_master_port. The dc_fanout_load attribute specifies the amount contributed by an input_master_port towards the fan-out load of any connected output or bidirectional port. The dc_max_fanin attribute specifies an upper bound for the sum of all dc_fanin_loads of all output or bidirectional ports which drive the given input port.

Used by:

input_instance_port input_master_port_annotate

master_port_bundle

  ENTITY master_port_bundle;
    member_ports : LIST [1:?] OF UNIQUE -- reference
                   master_port_or_master_port_bundle;
    name         : OPTIONAL name_information;
    properties   : OPTIONAL SET [1:?] OF property;
  DERIVE
    containing_interface : cluster_interface -- reference
                           := usedin_one_role(SELF, 
                              'hierarchy_model.cluster_interface.port_bundles');
    flattened_port_list  : LIST OF UNIQUE master_port -- reference
                           := flatten_master_port_bundle(member_ports);
    size                 : INTEGER := SIZEOF(flattened_port_list);
  WHERE
    containment_constraint :
      (* A master_port_bundle belongs to one cluster_interface. *)

      (* All member master_ports or master_port_bundles are defined in the

      not_exists(QUERY(port <* member_ports |

    valid_size :
      (* The size of the flattened master_port list must be greater than

      size >= 1;

Description:

A master_port_bundle can be defined within the interface of a cluster of a cell. It provides a structuring mechanism of master_ports. The size of a master_port_bundle is greater than or equal to one. A master_port_bundle can contain nested master_port_bundles.

Used by:

flatten_master_port_bundle

  FUNCTION flatten_master_port_bundle
    (bundle_members : LIST OF UNIQUE master_port_or_master_port_bundle) 
       : LIST OF UNIQUE master_port;
    LOCAL
      i, j        : INTEGER;
      position    : INTEGER := 1;
      port_list   : LIST OF master_port := [ ];
      member_list : LIST OF master_port := [ ];
    END_LOCAL;

    REPEAT i := 1 TO SIZEOF(bundle_members);

instance_port_bundle

  ENTITY instance_port_bundle;
    referenced_instance           : instance;           -- reference
    referenced_master_port_bundle : master_port_bundle; -- reference
    new_properties                : OPTIONAL SET [1:?] OF property;
    overriding_properties         : OPTIONAL SET [1:?] OF property_override;
  DERIVE
    flattened_port_list : LIST [1:?] OF UNIQUE instance_member_port
                          := flatten_instance_port_bundle(SELF);
    size                : INTEGER := SIZEOF(flattened_port_list);
  UNIQUE
    uniqueness_constraint :
      (* There is only one instance_port_bundle for a particular
         master_port_bundle on an instance. *)
      referenced_master_port_bundle, referenced_instance;
  WHERE
    valid_port_and_instance :
      (* The referenced master_port_bundle must be defined in the interface of
         the instantiated cluster of the referenced instance. *)
    EXISTS(referenced_instance.instantiated_cluster.interface.port_bundles)
    AND
    (referenced_master_port_bundle IN 
       referenced_instance.instantiated_cluster.interface.port_bundles);

    valid_overriding_properties :
      (* The overridden properties are defined in the referenced
         master_port_bundle. *) 
      not_exists(QUERY(propertyOverride <* overriding_properties |
        NOT (propertyOverride.overridden_property
             IN referenced_master_port_bundle.properties)));

    valid_optional_attributes :
      (* The dependencies of these optional attributes are stated as follows:
         1. An instance_port_bundle cannot have overriding_properties if its
            referenced port bundle does not define any properties. *)
      EXISTS(referenced_master_port_bundle.properties) OR
        NOT EXISTS(overriding_properties);
  END_ENTITY;

flatten_instance_port_bundle

  FUNCTION flatten_instance_port_bundle
    (instancePortBundle : instance_port_bundle) 
      : LIST [1:?] OF UNIQUE instance_member_port;
    LOCAL
      masterPortList : LIST OF UNIQUE master_port
        := instancePortBundle.referenced_master_port_bundle.flattened_port_list;
      memberSize     : INTEGER 
                       := instancePortBundle.referenced_instance.width *
                          instancePortBundle.referenced_master_port_bundle.size;
      members        : LIST [1:memberSize] OF UNIQUE instance_member_port;
    END_LOCAL;

    REPEAT i := 1 TO instancePortBundle.referenced_instance.width;
      REPEAT j := 1 TO SIZEOF(masterPortList);
      members[i*j].referenced_instance := instancePortBundle
                                          .referenced_instance;
      members[i*j].referenced_instance_member_index := i DIV 1;
      members[i*j].referenced_master_port := masterPortList[j];
      END_REPEAT;
    END_REPEAT;
    RETURN(members);
  END_FUNCTION;

Description:

The flatten_instance_port_bundle function returns the flattened list of instance_member_ports of an instance_port_bundle. When flattened, the size of the list must be equal to the product of the referenced instance width and the referenced master_port_bundle size.

non_recursive_cell

  FUNCTION non_recursive_cell
    (containingCell : cell;
     instances      : SET OF instance) : BOOLEAN;
    LOCAL
      views    : SET OF cell_representation;
      viewType : SET OF STRING;
    END_LOCAL;

    REPEAT i := 1 TO SIZEOF(instances);
      IF containingCell :=: instances[i].instantiated_cluster.containing_cell
         THEN RETURN(FALSE);
      ELSE
         views := instances[i].instantiated_cluster.cell_representations;
         REPEAT j := 1 TO SIZEOF(views);
           viewType := TYPEOF(views[j]);
           IF 'connectivity_view_model.internal_connectivity_view' 
              IN viewType THEN
              IF NOT non_recursive_cell(containingCell,
                     views[j]\internal_connectivity_view.instances) THEN
                 RETURN(FALSE);
              END_IF;
           ELSE
           IF 'schematic_view_model.internal_schematic_view' IN viewType THEN
              IF NOT non_recursive_cell(containingCell,
                     views[j]\internal_schematic_view.instances) THEN
                 RETURN(FALSE);
              END_IF;
           ELSE
           IF 'pcb_mcm_view_model.internal_pcb_mcm_view' IN viewType THEN
              IF NOT non_recursive_cell(containingCell,
                     views[j]\internal_pcb_mcm_view.instances) THEN
                 RETURN(FALSE);
              END_IF;
           END_IF;
           END_IF;
           END_IF;
         END_REPEAT;
      END_IF;
    END_REPEAT;
    RETURN(TRUE);
  END_FUNCTION;

Description:

The non_recursive_cell function returns true if a cell does not contain instances of itself, either directly or indirectly.

Used by:

internal_connectivity_view internal_pcb_mcm_view internal_schematic_view
