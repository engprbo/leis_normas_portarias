logical_connectivity_model

Description:

The logical_connectivity_model schema describes what logical connectivity information can be found in an EDIF view. The logical connectivity of a view may include signals and signal_groups. A signal is defined as a named object which lists all the global_ports, instance_ports and master_ports which are electrically common at a given level of hierarchy. A signal_group provides a grouping mechanism for signals. It does not modify connectivity.

signal

  ENTITY signal;
    joined_global_ports   : OPTIONAL SET [1:?] OF global_port;   -- reference
    joined_instance_member_ports                                 -- reference
                          : OPTIONAL SET [1:?] OF instance_member_port;
    joined_master_ports   : OPTIONAL SET [1:?] OF master_port;   -- reference
    name                  : OPTIONAL name_information;  
    properties            : OPTIONAL SET [1:?] OF property;
  DERIVE
    containing_cluster : cluster -- reference
                         := containing_view.containing_cluster;
    containing_edif    : edif -- reference
      := containing_cluster.containing_cell.containing_library.containing_edif;
    containing_view    : cell_representation -- reference
      := usedin_any_one_role(SELF,
         ['connectivity_view_model.internal_connectivity_view.signals',
          'pcb_mcm_view_model.internal_pcb_mcm_view.signals',
          'schematic_view_model.internal_schematic_view.signals']);
  WHERE
    containment_constraint :
      (* A signal belongs to either one internal_connectivity_view, one
         internal_pcb_mcm_view or one internal_schematic_view. *) 
      either_belongs_to_one(SELF, 
       ['connectivity_view_model.internal_connectivity_view.signals',
        'pcb_mcm_view_model.internal_pcb_mcm_view.signals',
        'schematic_view_model.internal_schematic_view.signals']);

    valid_joined_global_ports :
      (* All joined global_ports are defined in the containing edif of the
         signal. *) 
      joined_global_ports <= containing_edif.global_ports;

    valid_joined_instance_member_ports :
      (* All joined instance_member_ports refer to the instances in the
         containing view of the signal.  No joined instance_member_port is
         unused externally. *) 
      not_exists(QUERY(port <* joined_instance_member_ports |
        NOT (usedin_any_one_role(port.referenced_instance,
               ['connectivity_view_model.internal_connectivity_view.instances',
                'pcb_mcm_view_model.internal_pcb_mcm_view.instances',
                'schematic_view_model.internal_schematic_view.instances']) 
              :<>: containing_view)))
      AND
      not_exists(QUERY(port <* joined_instance_member_ports |
        NOT (find_instance_port(port.referenced_master_port,
                                port.referenced_instance).unused_externally)));

    valid_joined_master_ports :
      (* All joined master_ports are defined in the interface of the cluster
         containing the signal.  No joined master_port is unused internally. *)
      (joined_master_ports <= containing_cluster.interface.ports)
        AND
      not_exists(QUERY(port <* joined_master_ports | port.unused_internally));

    valid_optional_attributes :
       (* The dependencies of these optional attributes are stated as follows:
          1. A signal cannot join any global_ports if there are no global_ports
             defined in the containing edif.  
          2. A signal cannot join any instance_member_ports if there are no
             instances defined in the containing view.
          3. A signal cannot join any master_ports if there are no master_ports
             defined in the containing cluster. *)
       (EXISTS(containing_edif.global_ports) OR NOT EXISTS(joined_global_ports))
       AND
       ((is_typeof(containing_view, 
                   'connectivity_view_model.internal_connectivity_view')
         AND EXISTS(containing_view\internal_connectivity_view.instances)) OR
        (is_typeof(containing_view, 
                   'pcb_mcm_view_model.internal_pcb_mcm_view')
         AND EXISTS(containing_view\internal_pcb_mcm_view.instances)) OR
        (is_typeof(containing_view, 
                   'schematic_view_model.internal_schematic_view')
         AND EXISTS(containing_view\internal_schematic_view.instances)) OR
         NOT EXISTS(joined_instance_member_ports))
       AND
       (EXISTS(containing_cluster.interface.ports) OR 
          NOT EXISTS(joined_master_ports));
  END_ENTITY;

Description:

A signal is defined as a named object which lists all the master_ports, instance_member_ports and global_ports which are electrically common at a given level of hierarchy. It is always one-bit wide.

There is no constraint to force distinct instance_member_ports to be part of the same signal, even when their corresponding master_ports are defined in the same cluster_interface and are shorted together. Hence, on an instance of a cluster containing master_ports which are interface joined, it is legal for connections to be made to the corresponding instance_member_ports by either a single signal or by distinct signals.

signal_group

  ENTITY signal_group;
    members    : LIST [1:?] OF signal_or_signal_group; -- reference
    name       : OPTIONAL name_information;  
    properties : OPTIONAL SET [1:?] OF private_property;
  DERIVE
    containing_view : cell_representation -- reference
      := usedin_any_one_role(SELF, 
         ['connectivity_view_model.internal_connectivity_view.signal_groups',
          'pcb_mcm_view_model.internal_pcb_mcm_view.signal_groups',
          'schematic_view_model.internal_schematic_view.signal_groups']);
    flattened_signal_list : LIST OF signal -- reference
                            := flatten_signal_group(members);
  UNIQUE
    unique_members :
      (* No two signal_groups have the same structure of members. *)
      members;
  WHERE
    containment_constraint :
      (* A signal_group belongs to either one internal_connectivity_view, one
         internal_pcb_mcm_view or one internal_schematic_view. *) 
      either_belongs_to_one(SELF, 
       ['connectivity_view_model.internal_connectivity_view.signal_groups',
        'pcb_mcm_view_model.internal_pcb_mcm_view.signal_groups',
        'schematic_view_model.internal_schematic_view.signal_groups']);

    valid_members :
      (* All member signals or signal_groups are defined in the containing view 
         of the signal_group. *)
      not_exists(QUERY(member <* members |
        member.containing_view :<>: containing_view));

    non_recursive_constraint :
      (* A signal_group cannot contain itself either directly or indirectly. *)
      not_recursive_signal_group([SELF], [SELF]);

    valid_flattened_signal_list :
      (* The size of the flattened signal list must be greater that one. *)
      SIZEOF(flattened_signal_list) >= 1;
  END_ENTITY;

Description:

A signal_group is defined as a named object which provides a grouping mechanism for signals. This provides a basis for the structured connectivity.

flatten_signal_group

  FUNCTION flatten_signal_group
    (signal_group_members : LIST OF signal_or_signal_group) : LIST OF signal;
    LOCAL
      position    : INTEGER := 1;
      signal_list : LIST OF signal := [ ];
      member_list : LIST OF signal := [ ];
    END_LOCAL;

    REPEAT i := 1 TO SIZEOF(signal_group_members);
      IF 'logical_connectivity_model.signal' 
        IN TYPEOF(signal_group_members[i]) THEN
        INSERT(signal_list, signal_group_members[i], position);
        position := position + 1;
      ELSE
        member_list := flatten_signal_group(signal_group_members[i].members);
        REPEAT j := 1 TO SIZEOF(member_list);
          INSERT(signal_list, member_list[j], position);
          position := position + 1;
        END_REPEAT;
      END_IF;
    END_REPEAT;
    RETURN(signal_list);
  END_FUNCTION;

Description:

The flatten_signal_group function returns the flattened list of signals of a signal_group.

not_recursive_signal_group

  FUNCTION not_recursive_signal_group 
    (parents, invalid_ancestors : SET OF signal_group) : BOOLEAN;
    LOCAL
      i, j        : INTEGER;
      descendants : SET OF signal_group := [ ];
    END_LOCAL;
    REPEAT i := 1 TO HIINDEX(parents);
      REPEAT j := 1 TO HIINDEX(parents[i].members);
        IF 'logical_connectivity_model.signal_group' 
           IN TYPEOF(parents[i].members[j]) THEN
         descendants := descendants + parents[i].members[j];
        END_IF;
      END_REPEAT;
    END_REPEAT;
    RETURN
     (not_exists(descendants) OR
       (not_exists(descendants * invalid_ancestors) AND
         not_recursive_signal_group(descendants, parents + invalid_ancestors)));
  END_FUNCTION;

Description:

The not_recursive_signal_group function returns true if a signal_group does not contain members which reference itself. It prevents cyclic definition of a signal_group.

signal_group_member

  FUNCTION signal_group_member
    (member, parent : signal_group) : BOOLEAN;
    LOCAL
      is_member : BOOLEAN := FALSE;
      i         : INTEGER;
    END_LOCAL;
    IF member IN parent.members THEN
       RETURN(TRUE);
    ELSE
       i := 1;
       REPEAT WHILE (is_member = FALSE) AND (i <= SIZEOF(parent.members));
         IF ('logical_connectivity_model.signal_group' 
             IN TYPEOF(parent.members[i])) THEN
            is_member := signal_group_member(member, parent.members[i]);
         ELSE
            i := i + 1;
         END_IF;
       END_REPEAT;
       RETURN(is_member);
    END_IF;
  END_FUNCTION;

Description:

The signal_group_member function returns true if a signal_group is a member of another signal_group, either directly or indirectly.
