connectivity_structure_model

Description:

The connectivity_structure_model schema describes the structural connectivity information of a connectivity view. That includes definitions of connectivity_bus, connectivity_net and connectivity_ripper.

connectivity_generic_net

  ENTITY connectivity_generic_net
      ABSTRACT SUPERTYPE OF (ONEOF(connectivity_net, 
                                   connectivity_sub_net));
    associated_signal     : signal;                              -- reference
    criticality           : integer_token;              
    delays                : OPTIONAL SET [1:?] OF interconnect_delay;
    document              : OPTIONAL SET [1:?] OF documentation;
    joined_global_ports   : OPTIONAL SET [1:?] OF global_port;   -- reference
    joined_instance_member_ports                                 -- reference
                          : OPTIONAL SET [1:?] OF instance_member_port;
    joined_instance_ports : OPTIONAL SET [1:?] OF instance_port; -- reference
    joined_master_ports   : OPTIONAL SET [1:?] OF master_port;   -- reference
    joined_rippers        : OPTIONAL SET [1:?] OF                -- reference
                            connectivity_ripper;
    name                  : OPTIONAL name_information;
    properties            : OPTIONAL SET [1:?] OF property;
    sub_nets              : OPTIONAL SET [1:?] OF connectivity_sub_net;
  WHERE
    valid_sub_nets :
      (* No two connectivity_sub_nets may refer to the same set of ports and
         rippers. *)
    not_exists(QUERY(net1 <* sub_nets |
      there_exists(QUERY(net2 <* sub_nets - net1 |
        (net1.joined_global_ports = net2.joined_global_ports) 
    AND (net1.joined_instance_member_ports 
         = net2.joined_instance_member_ports)
    AND (net1.joined_instance_ports = net2.joined_instance_ports) 
    AND (net1.joined_master_ports = net2.joined_master_ports) 
    AND (net1.joined_rippers = net2.joined_rippers)))));
  END_ENTITY;

Description:

A connectivity_generic_net can be either a connectivity_net or a connectivity_sub_net. A connectivity_generic_net is used in the model because of the similarity between a connectivity_net and a connectivity_sub_net. A connectivity_net may be divided into connectivity_sub_nets and a connectivity_sub_net itself may also be divided into connectivity_sub_nets. No two connectivity_sub_nets at a given level may join to the same set of ports and rippers.

connectivity_ripper connectivity_sub_net referenced_interconnect

connectivity_net

  ENTITY connectivity_net
      SUBTYPE OF (connectivity_generic_net);
  DERIVE
    containing_view : internal_connectivity_view -- reference
      := usedin_one_role(SELF,
         'connectivity_view_model.internal_connectivity_view.nets');
  WHERE
    containment_constraint :
      (* A connectivity_net belongs to one internal_connectivity_view. *)
      belongs_to_one(SELF, 
        'connectivity_view_model.internal_connectivity_view.nets');

    valid_associated_signal :
      (* The signal associated with a connectivity_net is defined in the
         containing internal_connectivity_view. *)
      associated_signal IN containing_view.signals; 

    valid_joined_instance_ports :
      (* The same instance_member_port cannot be referenced more than once
         within a net.  The instance_member_ports joined implicitly by
         instance_ports must not overlap with the set of instance_member_ports
         joined explicitly by the net. *)
      not_exists(QUERY(joinedInstancePort <* joined_instance_ports |
        there_exists(QUERY(joinedMemberPort 
                           <* joinedInstancePort.flattened_port_list |
          joinedMemberPort IN joined_instance_member_ports))));

    valid_joined_ports : 
      (* The ports joined by a connectivity_net must be a subset of the
         connectivity of the associated signal of the connectivity_net. *)

        (joined_global_ports <= associated_signal.joined_global_ports)
    AND (joined_instance_member_ports 
         <= associated_signal.joined_instance_member_ports)
    AND not_exists(QUERY(joinedInstancePort <* joined_instance_ports |
          there_exists(QUERY(joinedInstanceMemberPort 
                             <* joinedInstancePort.flattened_port_list |
            NOT (joinedInstanceMemberPort
                 IN associated_signal.joined_instance_member_ports)))))
    AND (joined_master_ports <= associated_signal.joined_master_ports);

    valid_joined_rippers :
      (* The rippers joined by a connectivity_net must be defined in the
         containing internal_connectivity_view. *)
      joined_rippers <= containing_view.rippers;

    valid_optional_attributes :
       (* The dependencies of these optional attributes are stated as follows:
          1. A net cannot join any global_ports if its signal does not join any
             global_ports. 
          2. A net cannot join any instance_member_ports or instance_ports if
             its signal does not join any instance_member_ports.
          3. A net cannot join any master_ports if its signal does not join any
             master_ports.
          4. A net cannot join any rippers if its containing view does not
             define any rippers. *)
       (EXISTS(associated_signal.joined_global_ports) OR 
          NOT EXISTS(joined_global_ports))
        AND
       (EXISTS(associated_signal.joined_instance_member_ports) OR 
          NOT EXISTS(joined_instance_member_ports) AND
          NOT EXISTS(joined_instance_ports))
        AND
       (EXISTS(associated_signal.joined_master_ports) OR 
          NOT EXISTS(joined_master_ports))
        AND
       (EXISTS(containing_view.rippers) OR 
          NOT EXISTS(joined_rippers));
  END_ENTITY;

Description:

A connectivity_net is defined as a structured representation of connectivity in a connectivity view. It is only allowed in an internal_connectivity_view. Its associated signal must be defined in its containing view. The global_ports, instance_member_ports and master_ports joined by a connectivity_net must be a subset of the ones joined by its associated signal. Also, all joined connectivity_rippers must be defined in the containing view. If a connectivity_net joins to a port on an instance, then the list of instance_member_ports joined implicitly must be a subset of the instance_member_ports joined by its associated signal.

Used by:

internal_connectivity_view

connectivity_sub_net

  ENTITY connectivity_sub_net
      SUBTYPE OF (connectivity_generic_net);
  DERIVE
    containing_generic_net : connectivity_generic_net -- reference
      := usedin_one_role(SELF, 
         'connectivity_structure_model.connectivity_generic_net.sub_nets');
  WHERE
    containment_constraint :
      (* A connectivity_sub_net belongs to one connectivity_generic_net. *)
      belongs_to_one(SELF, 
        'connectivity_structure_model.connectivity_generic_net.sub_nets');

    valid_associated_signal :
      (* The signal associated with a connectivity_sub_net is the same as its
         immediately containing connectivity_generic_net. *) 
      associated_signal :=: containing_generic_net.associated_signal;

    valid_joined_ports_and_rippers :
      (* The ports and rippers joined by a connectivity_sub_net must be a
         subset of the ports and rippers joined by its immediately containing
         connectivity_generic_net. *) 

        (joined_global_ports <= containing_generic_net.joined_global_ports)
    AND (joined_instance_member_ports 
         <= containing_generic_net.joined_instance_member_ports)
    AND (joined_instance_ports <= containing_generic_net.joined_instance_ports)
    AND (joined_master_ports <= containing_generic_net.joined_master_ports)
    AND (joined_rippers <= containing_generic_net.joined_rippers);

    valid_optional_attributes :
       (* The dependencies of these optional attributes are stated as follows:
          1. A sub-net cannot join any global_ports if its containing
             net/sub-net does not join any global_ports.
          2. A sub-net cannot join any instance_member_ports if its containing
             net/sub-net does not join any instance_member_ports.
          3. A sub-net cannot join any instance_ports if its containing
             net/sub-net does not join any instance_ports.
          4. A sub-net cannot join any master_ports if its containing
             net/sub-net does not join any master_ports.
          5. A sub-net cannot join any rippers if its containing net/sub-net
             does not join any rippers. *)
       (EXISTS(containing_generic_net.joined_global_ports) OR 
          NOT EXISTS(joined_global_ports))
        AND
       (EXISTS(containing_generic_net.joined_instance_member_ports) OR 
          NOT EXISTS(joined_instance_member_ports))
        AND
       (EXISTS(containing_generic_net.joined_instance_ports) OR 
          NOT EXISTS(joined_instance_ports))
        AND
       (EXISTS(containing_generic_net.joined_master_ports) OR 
          NOT EXISTS(joined_master_ports))
        AND
       (EXISTS(containing_generic_net.joined_rippers) OR 
          NOT EXISTS(joined_rippers));
  END_ENTITY;

Description:

A connectivity_sub_net must only join to ports and rippers which are already joined by its immediately containing connectivity_generic_net. In addition, its associated signal must be the same as that of its immediately containing connectivity_generic_net.

Used by:

connectivity_generic_net

connectivity_generic_bus

  ENTITY connectivity_generic_bus
      ABSTRACT SUPERTYPE OF (ONEOF(connectivity_bus, 
                                   connectivity_bus_slice, 
                                   connectivity_sub_bus));
    associated_signal_group         : signal_group; -- reference
    bus_slices                      : OPTIONAL SET [1:?] OF
                                      connectivity_bus_slice; 
    criticality                     : integer_token;                   
    delays                          : OPTIONAL SET [1:?] OF interconnect_delay;
    document                        : OPTIONAL SET [1:?] OF documentation;
    joined_global_ports             : OPTIONAL SET [1:?] OF -- reference
                                      global_port;
    joined_global_port_bundles      : OPTIONAL SET [1:?] OF -- reference
                                      global_port_bundle;
    joined_instance_member_ports    : OPTIONAL SET [1:?] OF -- reference
                                      instance_member_port;
    joined_instance_ports           : OPTIONAL SET [1:?] OF -- reference
                                      instance_port; 
    joined_instance_port_bundles    : OPTIONAL SET [1:?] OF -- reference
                                      instance_port_bundle;
    joined_local_master_port_groups : OPTIONAL SET [1:?] OF -- reference
                                      local_master_port_group;
    joined_master_ports             : OPTIONAL SET [1:?] OF -- reference
                                      master_port;   
    joined_master_port_bundles      : OPTIONAL SET [1:?] OF -- reference
                                      master_port_bundle;
    joined_rippers                  : OPTIONAL SET [1:?] OF -- reference
                                      connectivity_ripper;
    name                            : OPTIONAL name_information;
    properties                      : OPTIONAL SET [1:?] OF property;
    sub_busses                      : OPTIONAL SET [1:?] OF
                                      connectivity_sub_bus;
  DERIVE
    commoned_ports : SET OF instance_port
      := QUERY(instancePort <* joined_instance_ports |    
               instancePort.referenced_master_port.size = signal_group_size);
    commoned_port_bundles : SET OF instance_port_bundle
      := QUERY(instancePortBundle <* joined_instance_port_bundles |
               instancePortBundle.referenced_master_port_bundle.size
               = signal_group_size);
    fanned_out_ports : SET OF instance_port
      := QUERY(instancePort <* joined_instance_ports |
               instancePort.size = signal_group_size);
    fanned_out_port_bundles : SET OF instance_port_bundle
      := QUERY(instancePortBundle <* joined_instance_port_bundles |
               instancePortBundle.size = signal_group_size);
    signal_group_size : INTEGER 
      := SIZEOF(associated_signal_group.flattened_signal_list);
  WHERE
    valid_joined_port_size :
      (* All joined global_ports, global_port_bundles, instance_member_ports,
         local_master_port_groups, master_ports and master_port_bundles must
         have the same port size as the size of the flattened signal_group. *)

        (not_exists(QUERY(joinedGlobalPort <* joined_global_ports |
           joinedGlobalPort.size <> signal_group_size)))
    AND (not_exists(QUERY(joinedGlobalPortBundle <* joined_global_port_bundles |
           joinedGlobalPortBundle.size <> signal_group_size)))
    AND (not_exists(QUERY(joinedInstanceMemberPort 
           <* joined_instance_member_ports |
           joinedInstanceMemberPort.size <> signal_group_size)))
    AND (not_exists(QUERY(joinedLocalMasterPortGroup 
           <* joined_local_master_port_groups |
           joinedLocalMasterPortGroup.size <> signal_group_size)))
    AND (not_exists(QUERY(joinedMasterPort <* joined_master_ports |
           joinedMasterPort.size <> signal_group_size)))
    AND (not_exists(QUERY(joinedMasterPortBundle <* joined_master_port_bundles |
           joinedMasterPortBundle.size <> signal_group_size)));
     
    valid_joined_instance_port :
      (* All instance_ports and instance_port_bundles must be either joined in
         the commoned style or in the fanned out style. *)

        (joined_instance_ports
         = (commoned_ports + fanned_out_ports))
    AND (joined_instance_port_bundles
         = (commoned_port_bundles + fanned_out_port_bundles));

    valid_structural_connectivity :
      check_structural_connectivity
       (associated_signal_group.flattened_signal_list,
        commoned_ports,
        commoned_port_bundles,
        fanned_out_ports,
        fanned_out_port_bundles,
        joined_global_ports,
        joined_global_port_bundles,
        joined_instance_member_ports,
        joined_local_master_port_groups,
        joined_master_ports,
        joined_master_port_bundles);

    valid_bus_slices :
      (* No two bus_slices within a connectivity_generic_bus may refer to the
         same signal_group. *)
      not_exists(QUERY(busSlice1 <* bus_slices |
        there_exists(QUERY(busSlice2 <* bus_slices - busSlice1 |
          busSlice1.associated_signal_group :=: 
            busSlice2.associated_signal_group))));

    valid_sub_busses :
      (* No two sub_busses within a connectivity_generic_bus may refer to the
         same set of ports and rippers. *)

    not_exists(QUERY(bus1 <* sub_busses |
      there_exists(QUERY(bus2 <* sub_busses - bus1 |
        (bus1.joined_global_ports = bus2.joined_global_ports) 
    AND (bus1.joined_global_port_bundles = bus2.joined_global_port_bundles) 
    AND (bus1.joined_instance_member_ports = bus2.joined_instance_member_ports)
    AND (bus1.joined_instance_ports = bus2.joined_instance_ports) 
    AND (bus1.joined_instance_port_bundles = bus2.joined_instance_port_bundles)
    AND (bus1.joined_local_master_port_groups 
         = bus2.joined_local_master_port_groups) 
    AND (bus1.joined_master_ports = bus2.joined_master_ports) 
    AND (bus1.joined_master_port_bundles = bus2.joined_master_port_bundles) 
    AND (bus1.joined_rippers = bus2.joined_rippers)))));
  END_ENTITY;

Description:

A connectivity_generic_bus can be either a connectivity_bus, a connectivity_bus_slice or a connectivity_sub_bus. A connectivity_generic_bus is used in the model because of the similarity between a connectivity_bus, a connectivity_bus_slice and a connectivity_sub_bus. They may all contain connectivity_bus_slices and connectivity_sub_busses. No two connectivity_bus_slices at a given level may be associated with the same signal_group. No two connectivity_sub_busses at a given level may join to the same set of ports and rippers. All joined global_ports, global_port_bundles, instance_member_ports, local_master_port_groups, master_ports and master_port_bundles must be the same size as the flattened signal_group. Each single port of the joined port_bundles must be mentioned in the corresponding signal within the flattened signal_group.

When a wide bus joins to an instance_port or an instance_port_bundle, the pattern of connectivity will be either in the commoned style or in the fanned out style. For the commoned style, the joined instance_ports or instance_port_bundles reference master_ports or master_port_bundles whose port size is the same as the size of the flattened signal_group. For the fanned out style, the joined instance_ports or instance_port_bundles are flattened to lists of instance_member_ports. The length of these lists must be equal to the size of the flattened signal_group.

For example, if a bus structure is associated with a signal_group of size 8, it is valid to use it to join to the following ports of various sizes: 

   global_port_bundle (port_bundle size = 8)
   instance_port in fanned out style (instance size = 8)
   instance_port_bundle in commoned style (port bundle size = 8)
   instance_port_bundle in fanned out style (instance size = 2, 
                                               port_bundle size = 4)
   instance_port_bundle in fanned out style (instance size = 4, 
                                               port_bundle size = 2)
   local_master_port_group (port_group size = 8)
   master_port_bundle (port_bundle size = 8)

Used by:

  ENTITY connectivity_bus
      SUBTYPE OF (connectivity_generic_bus);

      (* A connectivity_bus belongs to one internal_connectivity_view. *)
      belongs_to_one(SELF, 
        'connectivity_view_model.internal_connectivity_view.busses');

    valid_associated_signal_group :
      (* The signal_group associated with a connectivity_bus is defined in the
         containing internal_connectivity_view. *) 
      associated_signal_group IN containing_view.signal_groups;

    valid_joined_local_master_port_groups :
      (* The joined local_master_port_groups must be defined in the containing

      joined_local_master_port_groups <= containing_view.local_port_groups;

    valid_joined_rippers :
      (* Rippers joined by a connectivity_bus must be defined in the

      joined_rippers <= containing_view.rippers;

       (* The dependencies of these optional attributes are stated as follows:
          1. A bus cannot join any local_master_port_groups if its containing
             view does not define any local_master_port_group.

       (EXISTS(containing_view.local_port_groups) OR
          NOT_EXISTS(joined_local_master_port_groups))
        AND
       (EXISTS(containing_view.rippers) OR 
          NOT EXISTS(joined_rippers));
  END_ENTITY;

Description:

A connectivity_bus is defined as a structured representation of the connectivity of a connectivity view. It is only allowed in an internal_connectivity_view. Its associated signal_group must be defined in its containing view. A connectivity_bus may be subdivided in two orthogonal ways. It may be divided into connectivity_bus_slices or into connectivity_sub_busses. Also, all joined connectivity_rippers must be defined in the containing view.

connectivity_bus_slice

  ENTITY connectivity_bus_slice
      SUBTYPE OF (connectivity_generic_bus);
  DERIVE
    containing_generic_bus : connectivity_generic_bus -- reference
      := usedin_one_role(SELF, 
         'connectivity_structure_model.connectivity_generic_bus.bus_slices');
    containing_view : internal_connectivity_view -- reference
                      := containing_view_of_connectivity_bus_structure(SELF);
  WHERE
    containment_constraint :
      (* A connectivity_bus_slice belongs to one connectivity_generic_bus. *)
      belongs_to_one(SELF, 
        'connectivity_structure_model.connectivity_generic_bus.bus_slices');

    valid_associated_signal_group :
      (* The signal_group associated with a connectivity_bus_slice is a member
         of the signal_group associated with its immediately containing
         connectivity_generic_bus.*)  
      signal_group_member(associated_signal_group,
                          containing_generic_bus.associated_signal_group);

    valid_joined_local_master_port_groups :
      (* The joined local_master_port_groups must be defined in the containing
         internal_connectivity_view. *)
      joined_local_master_port_groups <= containing_view.local_port_groups;

    valid_joined_rippers :
      (* Rippers joined by a connectivity_bus_slice must be defined in the
         containing internal_connectivity_view. *)
      joined_rippers <= containing_view.rippers;

    valid_optional_attributes :
       (* The dependencies of these optional attributes are stated as follows:
          1. A bus-slice cannot join any local_master_port_groups if its
             containing view does not define any local_master_port_group.
          2. A bus-slice cannot join any rippers if its containing view does
             not define any rippers. *)
       (EXISTS(containing_view.local_port_groups) OR
          NOT_EXISTS(joined_local_master_port_groups))
        AND
       (EXISTS(containing_view.rippers) OR 
          NOT EXISTS(joined_rippers));
  END_ENTITY;

Description:

A connectivity_bus_slice is used to define part of a connectivity_bus that has a size less than the size of the immediately enclosing connectivity_generic_bus. Its associated signal_group must be a member of the signal_group associated with its immediately containing connectivity_generic_bus. All joined connectivity_rippers must be defined in the containing view.

  ENTITY connectivity_sub_bus
      SUBTYPE OF (connectivity_generic_bus);
  DERIVE
    containing_generic_bus : connectivity_generic_bus -- reference

    AND (joined_master_port_bundles 
         <= containing_generic_bus.joined_master_port_bundles)
    AND (joined_rippers <= containing_generic_bus.joined_rippers);

       (* The dependencies of these optional attributes are stated as follows:
          1. A sub-bus cannot join any global_ports if its containing
             bus/bus-slice/sub-bus does not join any global_ports.
          2. A sub-bus cannot join any global_port_bundles if its containing
             bus/bus-slice/sub-bus does not join any global_port_bundles.
          3. A sub-bus cannot join any instance_member_ports if its containing
             bus/bus-slice/sub-bus does not join any instance_member_ports.
          4. A sub-bus cannot join any instance_ports if its containing
             bus/bus-slice/sub-bus does not join any instance_ports.
          5. A sub-bus cannot join any instance_port_bundles if its containing
             bus/bus-slice/sub-bus does not join any instance_port_bundles.
          6. A sub-bus cannot join any local_master_port_groups if its
             containing bus/bus-slice/sub-bus does not join any
             local_master_port_groups. 
          7. A sub-bus cannot join any master_ports if its containing
             bus/bus-slice/sub-bus does not join any master_ports.
          8. A sub-bus cannot join any master_port_bundles if its containing
             bus/bus-slice/sub-bus does not join any master_port_bundles.
          9. A sub-bus cannot join any rippers if its containing
             bus/bus-slice/sub-bus does not join any rippers. *)

       (EXISTS(containing_generic_bus.joined_global_ports) OR
          NOT EXISTS(joined_global_ports))
        AND
       (EXISTS(containing_generic_bus.joined_global_port_bundles) OR
          NOT EXISTS(joined_global_port_bundles))
        AND
       (EXISTS(containing_generic_bus.joined_instance_member_ports) OR
          NOT EXISTS(joined_instance_member_ports))
        AND
       (EXISTS(containing_generic_bus.joined_instance_ports) OR
          NOT EXISTS(joined_instance_ports))
        AND
       (EXISTS(containing_generic_bus.joined_instance_port_bundles) OR
          NOT EXISTS(joined_instance_port_bundles))
        AND
       (EXISTS(containing_generic_bus.joined_local_master_port_groups) OR
          NOT EXISTS(joined_local_master_port_groups))
        AND
       (EXISTS(containing_generic_bus.joined_master_ports) OR
          NOT EXISTS(joined_master_ports))
        AND
       (EXISTS(containing_generic_bus.joined_master_port_bundles) OR
          NOT EXISTS(joined_master_port_bundles))
        AND
       (EXISTS(containing_generic_bus.joined_rippers) OR
          NOT EXISTS(joined_rippers));
  END_ENTITY;

Its associated signal_group is the same as that of its immediately containing connectivity_generic_bus. A connectivity_sub_bus must only join to ports and rippers which are already joined by its immediately containing connectivity_generic_bus.

check_structural_connectivity

  FUNCTION check_structural_connectivity
    (signalList            : LIST OF signal;
     commonedPorts         : SET OF instance_port;
     commonedPortBundles   : SET OF instance_port_bundle;
     fannedOutPorts        : SET OF instance_port;
     fannedOutPortBundles  : SET OF instance_port_bundle;
     globalPorts           : SET OF global_port;
     globalPortBundles     : SET OF global_port_bundle;
     instanceMemberPorts   : SET OF instance_member_port;
     localMasterPortGroups : SET OF local_master_port_group;
     masterPorts           : SET OF master_port;
     masterPortBundles     : SET OF master_port_bundle) : BOOLEAN;
    LOCAL
      currentSignal        : signal;
      instanceIndex, portIndex, signalIndex : INTEGER;
      signalGroupSize      : INTEGER := SIZEOF(signalList);
      validConnectivity    : BOOLEAN := TRUE;
    END_LOCAL;

    REPEAT signalIndex := 1 TO SIZEOF(signalList);
      currentSignal := signalList[signalIndex];

      REPEAT portIndex := 1 TO SIZEOF(commonedPortBundles);
        REPEAT instanceIndex := 0 TO 
            commonedPortBundles[portIndex].referenced_instance.width - 1;
          IF NOT (commonedPortBundles[portIndex]
                 .flattened_port_list[signalIndex+signalGroupSize*instanceIndex]
                  IN currentSignal.joined_instance_member_ports) THEN
             validConnectivity := FALSE;
          END_IF;
        END_REPEAT;
      END_REPEAT; -- check all instance_port_bundles joined in commoned style

      REPEAT portIndex := 1 TO SIZEOF(fannedOutPorts);
        IF NOT (fannedOutPorts[portIndex].flattened_port_list[signalIndex]
                IN currentSignal.joined_instance_member_ports) THEN
           validConnectivity := FALSE;
        END_IF;
      END_REPEAT; -- check all instance_ports joined in fanned out style

      REPEAT portIndex := 1 TO SIZEOF(fannedOutPortBundles);
        IF NOT (fannedOutPortBundles[portIndex].flattened_port_list[signalIndex]
                IN currentSignal.joined_instance_member_ports) THEN
           validConnectivity := FALSE;
        END_IF;
      END_REPEAT; -- check all instance_port_bundles joined in fanned out style

      REPEAT portIndex := 1 TO SIZEOF(globalPortBundles);
        IF NOT (globalPortBundles[portIndex].flattened_port_list[signalIndex]
                IN currentSignal.joined_global_ports) THEN
           validConnectivity := FALSE;
        END_IF;
      END_REPEAT; -- check all global_port_bundles

      REPEAT portIndex := 1 TO SIZEOF(localMasterPortGroups);
        IF NOT (localMasterPortGroups[portIndex]
                .flattened_port_list[signalIndex]
                IN currentSignal.joined_master_ports) THEN
           validConnectivity := FALSE;
        END_IF;
      END_REPEAT; -- check all local_master_port_groups

      REPEAT portIndex := 1 TO SIZEOF(masterPortBundles);
        IF NOT (masterPortBundles[portIndex].flattened_port_list[signalIndex]
                IN currentSignal.joined_master_ports) THEN
           validConnectivity := FALSE;
        END_IF; 
      END_REPEAT; -- check all master_port_bundles

    END_REPEAT;  -- check all signals
    
    RETURN(not_exists(QUERY(commonedInstancePort <* commonedPorts |
             there_exists(QUERY(instanceMemberPort 
                                <* commonedInstancePort.flattened_port_list |
               NOT (instanceMemberPort 
                    IN signalList[1].joined_instance_member_ports)))))
       AND (globalPorts <= signalList[1].joined_global_ports)
       AND (instanceMemberPorts <= signalList[1].joined_instance_member_ports)
       AND (masterPorts <= signalList[1].joined_master_ports)
       AND validConnectivity);
  END_FUNCTION;

  ENTITY connectivity_ripper;
  DERIVE
    containing_view : internal_connectivity_view     -- reference
      := usedin_one_role(SELF,
         'connectivity_view_model.internal_connectivity_view.rippers');
    related_nets : SET OF connectivity_generic_net   -- reference
      := convert_bag_to_set(USEDIN(SELF, 
      'connectivity_structure_model.connectivity_generic_net.joined_rippers'));
    related_busses : SET OF connectivity_generic_bus -- reference
      := convert_bag_to_set(USEDIN(SELF, 
      'connectivity_structure_model.connectivity_generic_bus.joined_rippers'));
  WHERE
    containment_constraint :
      (* A connectivity_ripper belongs to one internal_connectivity_view. *)
      belongs_to_one(SELF, 
        'connectivity_view_model.internal_connectivity_view.rippers');

    valid_related_busses_and_nets :
      (* All related bus/net structures must belong to the same view.  For each
         related bus/net structure, there exists at least another bus/net
         structure which shares at least one common signal. *)
      not_exists(QUERY(net <* related_nets |
        containing_view_of_connectivity_net_structure(net)
        :<>: containing_view))
      AND
      not_exists(QUERY(bus <* related_busses |
        containing_view_of_connectivity_bus_structure(bus)
        :<>: containing_view))
      AND
      not_exists(QUERY(bus1 <* related_busses |
        not_exists(QUERY(net <* related_nets |
          net.associated_signal 
          IN bus1.associated_signal_group.flattened_signal_list))
        AND
        not_exists(QUERY(bus2 <* related_busses - bus1 |
          there_exists(QUERY(sig 
                       <* bus2.associated_signal_group.flattened_signal_list |
          sig IN bus1.associated_signal_group.flattened_signal_list))))));

    valid_related_busses_size :
      (* A connectivity_ripper must be connected by at least one
         connectivity_generic_bus. *)
      SIZEOF(related_busses) >= 1;
  END_ENTITY;

  FUNCTION containing_view_of_connectivity_net_structure

         netStructure := usedin_one_role(netStructure,
         'connectivity_structure_model.connectivity_generic_net.sub_nets');

           'connectivity_view_model.internal_connectivity_view.nets'));

  FUNCTION containing_view_of_connectivity_bus_structure
    (busStructure : connectivity_generic_bus) : internal_connectivity_view;
    LOCAL
      busType : SET OF STRING := [ ];
    END_LOCAL;

    REPEAT UNTIL ('connectivity_structure_model.connectivity_bus' 
                  IN busType);
      busType := TYPEOF(busStructure);
      IF 'connectivity_structure_model.connectivity_bus_slice' IN busType THEN
         busStructure := usedin_one_role(busStructure,
         'connectivity_structure_model.connectivity_generic_bus.bus_slices');
      ELSE
      IF 'connectivity_structure_model.connectivity_sub_bus' IN busType THEN
         busStructure := usedin_one_role(busStructure,
         'connectivity_structure_model.connectivity_generic_bus.sub_busses');
      END_IF;
      END_IF;
    END_REPEAT;

    RETURN(usedin_one_role(busStructure,
           'connectivity_view_model.internal_connectivity_view.busses'));
  END_FUNCTION;
