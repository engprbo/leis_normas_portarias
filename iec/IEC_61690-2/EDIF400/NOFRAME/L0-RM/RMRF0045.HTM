pcbPadstackDefinition

pcbPadstackDefinition ::= '(' 'pcbPadstackDefinition'
	libraryObjectNameDef
	pcbSubLayoutDefinitionHeader
	{ pcbLayoutFeature | pcbLayoutText | <pcbNameFabrication> | 
	pcbPhysicalNet | pcbPropertyFabrication } 
	')'

Used by:

*external *library

Similar Keywords:

pcbPadstackDefinitionRef

Constraints:

1. The following constraint applies to this context: All contexts
When a pcbBareBoardDefinition or a sublayout definition instances a sublayout, that sublayout must have the same bare board technology as the instantiating object.
(See also similar constraint in: pcbBareBoardDefinition, pcbFootprintDefinition, pcbFootprintInstance, pcbNonSpecificSubLayoutDefinition, pcbNonSpecificSubLayoutInstance, pcbPadstackInstance, pcbTestCouponDefinition, pcbTestCouponInstance, pcbToeprintDefinition, pcbToeprintInstance)

2. The following constraint applies to this context: All contexts
A pcbPadstackDefinition must contain at least one pcbPad within a pcbLayoutFeature.

Description:

Defines a padstack. A padstack object describes a feature of a bare board that primarily provides for vertical connection between the conducting layers of the bare board. A padstack is usually a collection of pads on many different physical layers, and often has a plated-through hole passing through the pads.

A padstack definition describes an equipotential padstack if it owns precisely one physical net.

Example:

(pcbPadstackDefinition THRU_4LAYERS
   (pcbSubLayoutDefinitionHeader ...)
   (pcbPhysicalNet ONLYONE ...
      (pcbLayoutFeature L1_PAD
         (pcbPad ...))
      (pcbLayoutFeature L2_PAD
         (pcbPad ...))
      (pcbLayoutFeature L3_PAD
         (pcbPad ...))
      (pcbLayoutFeature L4_PAD
         (pcbPad ...))
      (pcbLayoutFeature THRU_HOLE
         (pcbConformantHole
            (pcbHoleCrossSection
               (circleByCenter (pt 0 0) 71120))
            (pcbDrillRuleRef DR1)
            (pcbPlatedThroughHole)))))

Description:

Defines an instance of a padstack definition.

PcbPadstackInstanceIntendedUsage specifies the purpose of the padstack.

The position of the instance is specified by fixedScaleTransform if the definition is in an internal library.

A padstack instance is at the same electrical potential throughout, if it contains only one internal net.

Example:

(pcbPadstackInstance PS21
   (pcbPadstackDefinitionRef PS_ALL_LAYERS)
   (pcbPadstackInstanceRoutingViaPlace)
   (fixedScaleTransform (origin (pt 100 100))))

pcbPartPreviousVersion

pcbPartPreviousVersion ::= '(' 'pcbPartPreviousVersion'
	pcbPartRef
	')'

Used by:

<pcbPartHeader

Similar Keywords:

pcbPackagePreviousVersion previousVersion version

Description:

References a previous version of a part. The part must be of the same type as the enclosing part definition (i.e. a packaged electrical part, a printed electrical part or a mechanical part).

Example:

(pcbPackagedElectricalPart PRT1
   (pcbPartHeader (pcbPartUnits ...)
      (nameInformation (primaryName "LL-20-0000"))
      (pcbPartPreviousVersion 
         (pcbPartRef OLD_PRT1))) ...)

This example references a previous version of a packaged electrical part named OLD_PRT1.
