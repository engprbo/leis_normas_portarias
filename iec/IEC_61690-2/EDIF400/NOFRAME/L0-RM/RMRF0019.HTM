pcbBoardSubsetPlacement

pcbBoardSubsetPlacement ::= '(' 'pcbBoardSubsetPlacement'
	pcbBoardSubsetPlacementNameDef
	pcbBoardSubsetRef
	uniformScaleTransform
	( pcbBoardSubsetPlacementScaled | pcbBoardSubsetPlacementUnscaled )
	{ <pcbClippingOutlineDrawn> | pcbDrawingFigure } 
	')'

Used by:

*pcbDrawing

Similar Keywords:

pcbBoardSubsetDefinition pcbBoardSubsetPlacementNameRef pcbBoardSubsetPlacementRef

Constraints:

1. The following constraint applies to this context: All contexts
The absolute values of scaleX and scaleY within transform must be equal.

Description:

Defines how a board subset is placed on a drawing.

Transform specifies the position of the board subset on the drawing. Units are as specified in pcbDrawingUnits in pcbDrawingHeader.

The board subset can be scaled by using pcbBoardSubsetPlacementScaled.

PcbClippingOutlineDrawn indicates whether the clipping outline should be displayed on the drawing.

PcbDrawingFigure can describe a collection of geometrical shapes that are associated with the board subset placement.

Example:

(pcbBoardSubsetPlacement BSP1
   (pcbBoardSubsetRef BS1)
   (uniformScaleTransform ...)
   (pcbBoardSubsetPlacementUnscaled) ...)

pcbBoardTerminal

pcbBoardTerminal ::= '(' 'pcbBoardTerminal'
	pcbBoardTerminalNameDef
	portRef
	pcbBoardTerminalConnectorComponentTerminalRef
	')'

Used by:

*pcbPackagedConnectorComponent *pcbPrintedConnectorComponent

Description:

Specifies a terminal for the assembled board. This is associated with a master port of the containing cluster interface, referenced by portRef. The board terminal is realized by a terminal of a connector component on the board.

Example:

(pcbPrintedConnectorComponent EDGEC1
   (pcbPrintedConnectorPartRef EC_411_23)
   (pcbComponentHeader)
   (pcbBoardTerminal E1
      (portRef VCC)
      (pcbBoardTerminalConnectorComponentTerminalRef F3)))

In this example, the master port VCC is represented by the board terminal E1 which is terminal F3 of the containing connector component.

pcbBondPadNameCaseSensitive

pcbBondPadNameCaseSensitive ::= '(' 'pcbBondPadNameCaseSensitive'
	booleanToken
	')'

Used by:

<nameCaseSensitivity

Similar Keywords:

pcbPad

Description:

Defines whether or not the strings contained within nameInformation for items with a pcbBondPadNameDef are to be considered as case sensitive. The default is that names are case sensitive. Following normal precedence rules, this applies to the entire EDIF data if this form occurs in edifHeader, or to the entire library if it occurs in libraryHeader.

See clusterNameCaseSensitive for an example.
