pcbComponentRealizationRule

pcbComponentRealizationRule ::= '(' 'pcbComponentRealizationRule'
	pcbRuleNameDef
	pcbComponentSet
	{ pcbComponentRegionRealizationRule | property } 
	')'

Used by:

*pcbAssembledBoard

Similar Keywords:

pcbComponentAssemblyRule pcbComponentOrientationRule pcbComponentSignalLayerRealizationRule pcbComponentSignalRealizationRule

Description:

A pcbComponentRealizationRule specifies the exclusion of specified types of layout items, e.g. vias, from parts of the bare board. The exclusion areas are typically due to the presence of one or more components, which can be referenced from the component realization rule within pcbComponentSet.

The actual areas are specified within pcbComponentRegionRealizationRule.

Example:

(pcbComponentRealizationRule
   RULE_U1
   (pcbComponentSet
      (pcbComponentRef U1_IMP))
   (pcbComponentRegionRealizationRule
      R1
      (pcbPhysicalLayerSet
         (pcbPhysicalLayerRef LAYER2)
         (pcbPhysicalLayerRef LAYER3))
      (rectangle (pt 100 150) (pt 200 300))
      (pcbKeepOutItems
         (pcbHoleClass)
         (pcbViaClass))))

In this example, due to the presence of the component implementation U1_IMP, holes and vias should be kept out of the specified rectangle on layers LAYER2 and LAYER3.

pcbComponentRegionRealizationRule

pcbComponentRegionRealizationRule ::= '(' 'pcbComponentRegionRealizationRule'
	pcbRuleNameDef
	pcbPhysicalLayerSet
	closedAreaElement
	pcbKeepOutItems
	{ property } 
	')'

Used by:

*pcbComponentRealizationRule

Similar Keywords:

pcbComponentAssemblyRuleRegion pcbComponentSignalRealizationRule

Description:

A pcbComponentRegionRealizationRule specifies an exclusion zone (closedAreaElement) and layers (pcbPhysicalLayerSet) for the enclosing pcbComponentRealizationRule. It indicates the types of layout items, e.g. vias, which must be kept out of the region on the given layers.

If any of the implementations of the components reference footprint instances, then it should be noted that the exclusion of items does not apply to items defined or referenced within these footprint instances. Similarly, in the case of a component which has an embedded die implementation, the exclusion does not apply to items within the footprint instance referenced by the corresponding embedded die placement.

Example:

(pcbComponentRegionRealizationRule
   R1
   (pcbPhysicalLayerSet
      (pcbPhysicalLayerRef LAYER2)
      (pcbPhysicalLayerRef LAYER3))
   (rectangle (pt 100 150) (pt 200 300))
   (pcbKeepOutItems
      (pcbHoleClass)
      (pcbViaClass)))

In this example, holes and vias should be kept out of the specified rectangle on layers LAYER2 and LAYER3.

pcbComponentSignal

pcbComponentSignal ::= '(' 'pcbComponentSignal'
	pcbComponentSignalNameDef
	pcbComponentTerminalJoined
	{ <nameInformation> | pcbComponentTerminalList | 
	pcbComponentTerminalSet | property } 
	')'

Used by:

*pcbMcmImplementation

Similar Keywords:

pcbComponentSignalLayerRealizationRule pcbComponentSignalNameCaseSensitive pcbComponentSignalNameRef pcbComponentSignalRealizationRule pcbComponentSignalRef pcbComponentSignalSet pcbNoComponentSignal signal

Constraints:

1. The following constraint applies to this context: All contexts
A pcbJumperComponent referenced by a pcbJoinedJumperComponent must not be referenced by any pcbComponentSignal nor by any different assembled physical net.
(See also similar constraint in: pcbJoinedJumperComponent)

2. The following constraint applies to this context: All contexts
No pcbPackagedElectricalPartTerminal or pcbPrintedElectricalPartTerminal can be referenced by more than one pcbComponentSignal within the context of a pcbMcmImplementation.
(See also similar constraint in: pcbElectricalComponentTerminalRef)

3. This construct is illegal in this context: external

Description:

Defines the component terminals that are to be connected together during the layout process in order to realize a particular physical connectivity requirement. The full set of pcbComponentSignals for a given pcbMcmImplementation constitutes the "component netlist" for the PCB or MCM.

Example:

(pcbComponentSignal PCBSIG1
   (pcbComponentTerminalJoined
      (pcbElectricalComponentTerminalRef T32 
         (pcbPackagedElectricalComponentRef COMP3))
      (pcbElectricalComponentTerminalRef T7 
         (pcbPackagedElectricalComponentRef COMP2))
      (pcbElectricalComponentTerminalRef T10 
         (pcbPackagedElectricalComponentRef COMP1))))

This specifies that terminals T32, T7 and T10 on components COMP3, COMP2 and COMP1, respectively, are connected together.
