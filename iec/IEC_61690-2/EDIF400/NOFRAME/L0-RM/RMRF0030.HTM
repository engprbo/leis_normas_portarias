pcbDrawingScaleFactor

pcbDrawingScaleFactor ::= '(' 'pcbDrawingScaleFactor'
	numeratorNumber
	denominatorNumber
	pcbDrawingScaleFactorDisplayString
	')'

Used by:

!pcbBoardSubsetPlacementScaled !pcbDrawingHeader

Similar Keywords:

pcbDrawingFactorScaleDrawing pcbDrawingScaleFactorDrawing scale

Constraints:

1. The following constraint applies to this context: All contexts
Either the numeratorNumber is one and the denominatorNumber is greater than or equal to one or the numeratorNumber is greater than or equal to one and the denominatorNumber is one.

2. The following constraint applies to this context: When required within pcbBoardSubsetPlacementScaled; When present within pcbDrawingHeader
The scale factor in the pcbBoardSubsetPlacementScaled is different from the scale of the containing pcbDrawing.

Description:

Defines a drawing scale factor and a text string that can be used to represent that scale factor, if it is displayed on a pcb drawing.

Example:

(pcbBoardSubsetPlacement BOARDREP_01
   (pcbBoardSubsetRef SUBSET_01)
   (uniformScaleTransform ...)
   (pcbBoardSubsetPlacementScaled
      (pcbDrawingScaleFactor 1 1 "1:1")
      (pcbDrawingTextDisplay DWGATTR_01
         (unscaledTransform (origin (pt 28000 112000)))
         (stringExtent 9600 5000))))

pcbDrawingSymbolPlacement

pcbDrawingSymbolPlacement ::= '(' 'pcbDrawingSymbolPlacement'
	pcbDrawingSymbolPlacementNameDef
	( pcbComponentSymbolRef | pcbDrillRuleSymbolRef )
	uniformScaleTransform
	( pcbDrawingAttributeDefaultRef | 
	pcbDrawingSymbolPlacementDrawingAttributeOverride )
	')'

Used by:

*pcbDrawingAnnotation

Description:

Describes the placement of a component symbol or drill symbol as annotation within a pcb drawing. The placement of the symbol is independent of any component or drilled hole represented elsewhere within the drawing and is often used as a way to create a legend of used symbols within the drawing.

Example:

(pcbDrawingAnnotation DWGANNO_01
   (pcbDrawingText "Legend"
      (pcbDrawingTextDisplay ...))
   (pcbDrawingSymbolPlacement DRILL_01
      (pcbDrillRuleSymbolRef ACME_SYMBOL
         (pcbDrillRuleRef DRILL_37))
      (uniformScaleTransform (origin (pt 601000 95000)))
      (pcbDrawingSymbolPlacementDrawingAttributeOverride DWGATTR_01
         (pathWidth (minimalWidth))))
   (pcbDrawingText "47 thou plated"
      (pcbDrawingTextDisplay ...))
   (pcbDrawingSymbolPlacement DRILL_02
      (pcbDrillRuleSymbolRef ACME_SYMBOL
         (pcbDrillRuleRef DRILL_13))
      (uniformScaleTransform (origin (pt 601000 92000)))
      (pcbDrawingSymbolPlacementDrawingAttributeOverride DWGATTR_01
         (pathWidth (minimalWidth))))
   (pcbDrawingText "50 thou plated"
      (pcbDrawingTextDisplay ...)))
