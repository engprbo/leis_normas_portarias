pcbIncorrectNet

pcbIncorrectNet ::= '(' 'pcbIncorrectNet'
	pcbAssembledPhysicalNetNameDef
	pcbAssembledPhysicalNetHeader
	pcbComponentSignalRef
	pcbComponentTerminalJoined
	{ <pcbInstanceNets> | <pcbJoinedJumperComponent> | 
	pcbJumperConnection } 
	')'

Used by:

*pcbAnalyzedAssembledPhysicalNets

Constraints:

1. The following constraint applies to this context: All contexts
A pcbComponentSignal may be implemented by one and only one of the following combinations: 1. By zero, one or more pcbNonAnalyzedAssembledPhysicalNets, 2. By exactly one pcbCorrectNet, 3. By zero, one or more pcbIncorrectNet, 4. By zero, one or more pcbShortingNet.
(See also similar constraint in: pcbCorrectNet, pcbNonAnalyzedAssembledPhysicalNets, pcbShortingNet)

2. The following constraint applies to this context: All contexts
A pcbIncorrectNet may join extra component terminals which are not specified in the referenced pcbComponentSignal. However, as it is not a pcbShortingNet, the extra terminals must not be referenced by any pcbComponentSignal.

3. The following constraint applies to this context: All contexts
A pcbIncorrectNet must not join exactly the same set of terminals as specified in the referenced pcbComponentSignal.

Description:

Describes an assembled physical net which has had its connectivity checked by the sending system. The connectivity in the physical net does not match the connectivity specified by the referenced component signal, but the mismatch is not due to two or more signals being shorted together. For example, a component net would be incorrect if one of the terminals in the component signal is not in the assembled physical net.

PcbComponentTerminalJoined specifies the component terminals that are connected together by the assembled physical net.

An assembled physical net can only include instance nets that are on the bare board that the assembled board is based upon.

Example:

(pcbIncorrectNet NET_FOR_SIG1
   (pcbAssembledPhysicalNetHeader)
   (pcbComponentSignalRef SIG1)
   (pcbComponentTerminalJoined ...)
   (pcbInstanceNets
      (pcbSubLayoutInstancePhysicalNetRef
         NET2 (pcbSubLayoutInstanceRef BB)))
   (pcbJumperConnection JUMPER1
      (pcbJumperConnectionHeader)
      (pcbJumperConnectionDiscreteWire
         (pcbJumperConnectionDiscreteWireConnectionPoints
            (pcbPadstackInstanceRef JPAD1)
            (pcbPadstackInstanceRef JPAD2)))))

pcbJumperComponentImplementation

pcbJumperComponentImplementation ::= '(' 'pcbJumperComponentImplementation'
	pcbComponentImplementationNameDef
	pcbJumperComponentRef
	pcbMountablePackageRef
	unscaledTransform
	pcbFootprintInstanceRef
	{ <pcbComponentPropertyFabrication> | 
	<pcbDesignatorFabricationOverride> | <pcbDrawingInformation> | 
	pcbJumperComponentTerminalImplementation | 
	pcbMountableMechanicalFixingImplementation | 
	<pcbMountablePackagePropertyFabrication> | 
	<pcbMountablePackagePropertyOverride> | 
	pcbMountablePackageTerminalImplementation | 
	<pcbPackagePropertyFabrication> | <pcbPartPropertyFabrication> } 
	')'

Used by:

*pcbAssembledBoard

Similar Keywords:

pcbComponentImplementationRef pcbDieComponentImplementation pcbEmbeddedComponentImplementation pcbJoinedJumperComponent pcbJumperComponent pcbMechanicalComponentImplementation

Constraints:

1. The following constraint applies to this context: All contexts
A mountable package terminal may be referenced at most once within a component implementation, i.e. it can have at most one implementation.
(See also similar constraint in: pcbPackagedConnectorComponentImplementation, pcbPackagedElectricalComponentImplementation)

Description:

Defines how the jumper component referenced by pcbJumperComponentRef is mounted onto the bare board.

PcbMountablePackageRef specifies the mountable package that is used when mounting the component on the bare board.

UnscaledTransform specifies the position of the component on the bare board.

PcbFootprintInstanceRef specifies the footprint on which the component is placed.

Example:

(pcbJumperComponentImplementation J6_IMP
   (pcbJumperComponentRef J6)
   (pcbMountablePackageRef DIP_Dip_Top
      (libraryRef MOUNTABLE_PACKAGES))
   (unscaledTransform ...)
   (pcbFootprintInstanceRef FOOTP21))

pcbJumperComponentTerminalImplementation

pcbJumperComponentTerminalImplementation ::= '(' 
	'pcbJumperComponentTerminalImplementation'
	pcbComponentTerminalImplementationNameDef
	pcbJumperPartTerminalRef
	pcbToeprintPadstackInstanceRef
	pcbMountablePackageTerminalRef
	{ <pcbDrawingInformation> | 
	<pcbMountablePackageTerminalPropertyFabrication> | 
	<pcbPackageTerminalPropertyFabrication> | 
	<pcbPartTerminalPropertyFabrication> } 
	')'

Used by:

*pcbJumperComponentImplementation

Similar Keywords:

pcbComponentTerminalImplementationRef pcbDieComponentTerminalImplementation pcbJumperComponent pcbJumperComponentTerminalRef

Description:

Defines how a jumper part terminal is implemented on the board. It relates the part terminal (pcbJumperPartTerminalRef) to a toeprint padstack (pcbToeprintPadstackInstanceRef) and a mountable package terminal (pcbMountablePackageTerminalRef) which is on the mountable package referenced by the enclosing jumper component implementation.

PcbJumperPartTerminalRef is a reference to the corresponding terminal in the jumper component's part. This could be derived, but is also stated here for convenience.

Example:

(pcbJumperComponentTerminalImplementation T1
   (pcbJumperPartTerminalRef TERM1)
   (pcbToeprintPadstackInstanceRef TP4
      (pcbFootprintToeprintInstanceRef TI1))
   (pcbMountablePackageTerminalRef MP_TERM1))

pcbJumperPart

pcbJumperPart ::= '(' 'pcbJumperPart'
	libraryObjectNameDef
	pcbPartHeader
	( pcbPinPackageRef | pcbBallPackageRef | externalNoData )
	{ pcbJumperPartTerminal | <pcbPartCharacteristic> } 
	')'

Used by:

*external *library

Similar Keywords:

pcbJumperPartRef pcbJumperPartTerminalHeader pcbJumperPartTerminalNameCaseSensitive pcbJumperPartTerminalNameDef pcbJumperPartTerminalNameRef pcbJumperPartTerminalRef

Constraints:

1. The following constraint applies to this context: All contexts
An electrical, connector or jumper part must have at least one terminal.
(See also similar constraint in: pcbDieElectricalPart, pcbPackagedConnectorPart, pcbPackagedElectricalPart, pcbPrintedConnectorPart, pcbPrintedElectricalPart)

Description:

A jumper part is a packaged part which has all its terminals electrically connected together and has no other electrical functionality. A jumper part is used in the definition of a pcbJumperComponent.

Example:

(pcbJumperPart JUMP4PIN
   (pcbPartHeader ...)
   (pcbPinPackageRef DIP4PIN (libraryRef DIP_PACKAGES))
   (pcbJumperPartTerminal P1
      (pcbJumperPartTerminalHeader)
      (pcbConnectedPackageTerminal 
         (pcbPackageTerminalPinRef P1)))
   (pcbJumperPartTerminal P2
      (pcbJumperPartTerminalHeader)
      (pcbConnectedPackageTerminal 
         (pcbPackageTerminalPinRef P2)))
   ...)
