pcbMountablePackageTerminalPreparedPin

pcbMountablePackageTerminalPreparedPin ::= '(' 
	'pcbMountablePackageTerminalPreparedPin'
	pcbMountablePackageTerminalNameDef
	pcbMountablePackageTerminalHeader
	pcbPackageTerminalPinRef
	{ <pcbContactArea> | <pcbPackagePinLength> | <pcbPinMounting> | 
	<pcbPinPosition> } 
	')'

Used by:

*pcbMountablePinPackage

Similar Keywords:

pcbMountablePackageTerminalExtraPin pcbPackageTerminalPin pcbPinPackage

Description:

Specifies that the terminal on the mountable package is a prepared pin, i.e. a terminal that corresponds directly to a pin on the package. The package terminal that corresponds to the mountable package terminal is referenced by pcbPackageTerminalPinRef.

PcbPinMounting specifies how the pin is mounted within the definition of the mountable package.

PcbContactArea, pcbPackagePinLength, pcbPinPosition and property override the equivalent information specified for the pcbPackageTerminalPin.

Example:

(pcbMountablePackageTerminalPreparedPin T1
   (pcbMountablePackageTerminalHeader ...)
   (pcbPackageTerminalPinRef P1)
   (pcbPinMounting
      (pcbPinMountingThroughBoard)))

pcbMountablePinPackage

pcbMountablePinPackage ::= '(' 'pcbMountablePinPackage'
	libraryObjectNameDef
	pcbMountablePackageHeader
	( pcbPinPackageRef | externalNoData )
	( pcbMountingMethodRef | externalNoData )
	( pcbDefaultPinMounting | externalNoData )
	{ <bodyVolume> | <occupiedSpace> | pcbAuxiliaryComponent | 
	pcbMountableMechanicalFixing | <pcbMountablePackageMountingClass> | 
	pcbMountablePackageSymbol | pcbMountablePackageTerminalExtraPin | 
	pcbMountablePackageTerminalPreparedPin | <pcbPackageMounting> | 
	<pcbPackageMountingHeight> | <pcbPackagePinForm> | 
	<pcbPackagePinPitch> | pcbPinGroupMounting | <pcbSubMounting> } 
	')'

Used by:

*external *library

Similar Keywords:

pcbMountableBallPackage pcbMountableMechanicalPackage pcbMountablePackageRef pcbMountablePackageSet pcbPackagePinArrangement pcbPackagePinGroup pcbPackagePinLength pcbPackageTerminalPin pcbPinPackage

Description:

Defines a mountable pin package.

A mountable pin package describes the result of mounting a particular pcbPinPackage in a particular way. For example, it records the change in pin pattern (if any) caused by the reforming of a pcbPinPackage when mounted onto a board in a particular way. It also records the additional components (if any) that should be added to achieve this mounting.

The actual specification of how a component is mounted on the assembled board is specified by the packaged component implementation, which references a mountable package.

If present, the values for bodyVolume, occupiedSpace, pcbPackageMounting, pcbPackagePinForm, pcbPackagePinPitch and the attributes within the mountable package terminal (pcbMountablePackageTerminalExtraPin and pcbMountablePackageTerminalPreparedPin) override the same values defined within the referenced pcbPinPackage.

Example:

(pcbMountablePinPackage DIP14_Dip_Bottom
   (pcbMountablePackageHeader (pcbLayoutUnits ...)
      (nameInformation (primaryName "Dip")))
   (pcbPinPackageRef DIP14 (libraryRef PACKAGES))
   (pcbMountingMethodRef
      BOTTOM_SIDE_INSERTION)
   (pcbDefaultPinMounting ...)
   (bodyVolume ...)
   (occupiedSpace ...)
   (pcbMountablePackageMountingClass 
      (pcbMountablePackageMountingClassInsertion))
   (pcbPackageMountingHeight 
      (mnm 250 300 500))
   (pcbMountablePackageTerminalPreparedPin T1 
      (pcbMountablePackageTerminalHeader ...)
      (pcbPackageTerminalPinRef T1) ...) ...)

	fixedScaleTransform
	{ pcbMountablePackageTerminalPropertyDrawing } 
	')'

Used by:

*pcbMountablePackageSymbol

Description:

Gives a representation of a mountable terminal in a mountable package symbol.

The template type should be consistent with the terminal type. If the terminal is an prepared mountable pin or an mountable solder ball, the template type must be for a prepared pin or unrestricted. If the terminal is an extra mountable pin, the template type must be for an extra terminal or unrestricted.

Example:

(pcbMountableTerminalRepresentation P1
   (pcbPackageTerminalDrawingTemplateRef Template1)
   (fixedScaleTransform ...)
   (pcbMountablePackageTerminalPropertyDrawing
      (pcbPropertyDrawing ...)))

pcbNonAnalyzedAssembledPhysicalNets

pcbNonAnalyzedAssembledPhysicalNets ::= '(' 'pcbNonAnalyzedAssembledPhysicalNets'
	{ pcbNonAnalyzedNet } 
	')'

Used by:

!pcbAssembledPhysicalNets

Similar Keywords:

pcbAnalyzedAssembledPhysicalNets

Constraints:

1. The following constraint applies to this context: All contexts
A pcbComponentSignal may be implemented by one and only one of the following combinations: 1. By zero, one or more pcbNonAnalyzedAssembledPhysicalNets, 2. By exactly one pcbCorrectNet, 3. By zero, one or more pcbIncorrectNet, 4. By zero, one or more pcbShortingNet.
(See also similar constraint in: pcbCorrectNet, pcbIncorrectNet, pcbShortingNet)

Description:

Describes assembled physical nets whose connectivity have not been checked against the netlists defined by the specified signals.

Example:

(pcbNonAnalyzedAssembledPhysicalNets
   (pcbNonAnalyzedNet NET_FOR_SIG1
      (pcbAssembledPhysicalNetHeader)
      (pcbComponentSignalRef SIG1)
      (pcbComponentTerminalJoined ...)
      (pcbInstanceNets
         (pcbSubLayoutInstancePhysicalNetRef 
            NET1 (pcbSubLayoutInstanceRef BB))
         (pcbSubLayoutInstancePhysicalNetRef
            NET2 (pcbSubLayoutInstanceRef BB)))
      (pcbJumperConnection JUMPER1
         (pcbJumperConnectionHeader)
         (pcbJumperConnectionDiscreteWire
            (pcbJumperConnectionDiscreteWireConnectionPoints
               (pcbPadstackInstanceRef JPAD1)
               (pcbPadstackInstanceRef JPAD2)))) ...) ...)

In this example, the connectivity defined by SIG1 is implemented by NET1, NET2 and a jumper, JUMPER1. JUMPER1 could be the physical mechanism that is used to join the two physical nets together.

pcbNonAnalyzedNet

pcbNonAnalyzedNet ::= '(' 'pcbNonAnalyzedNet'
	pcbAssembledPhysicalNetNameDef
	pcbAssembledPhysicalNetHeader
	( pcbComponentSignalRef | pcbNoComponentSignal )
	pcbComponentTerminalJoined
	{ <pcbInstanceNets> | <pcbJoinedJumperComponent> | 
	pcbJumperConnection } 
	')'

Used by:

*pcbNonAnalyzedAssembledPhysicalNets

Description:

Describes an assembled physical net whose connectivity has not been checked against the netlist defined by the specified signal.

PcbComponentTerminalJoined specifies the component terminals that are connected together by the assembled physical net.

An assembled physical net can only include instance nets that are on the bare board that the assembled board is based upon.

See pcbNonAnalyzedAssembledPhysicalNets for an example.
