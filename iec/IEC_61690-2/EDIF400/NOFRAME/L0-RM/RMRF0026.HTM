pcbDimensionedLine

pcbDimensionedLine ::= '(' 'pcbDimensionedLine'

	lineSegment
	{ <pcbDimensionedObjectSet> } 
	')'

Used by:

*pcbBoardSubsetDefinition *pcbBoardSubsetExtraDetail

Similar Keywords:

pcbDimensionedLineRef

Description:

Defines a hook for an angular dimensioning to refer to. In this context, the pcbDimensionedLine defines one of the lines that delineates the angle being measured.

LineSegment is not required to correspond to any real feature referenced in the pcbDimensionedObjectSet. For example, it may be an imaginary line implied by the existence of two or more real features, or it may be that the system generating the EDIF description does not know the association of the dimensioned line with any real features in the design.

Example:

(pcbDimensionedLine DimLine1
   (lineSegment (pt 5 15) (pt 10 15))
   (pcbDimensionedObjectSet
      (pcbLayoutFeatureOccurrenceRef PowerTap
         (pcbSublayoutOccurrenceRef SLI1))))

pcbDimensionedObjectSet ::= '(' 'pcbDimensionedObjectSet'
	{ pcbBareBoardProbePointRef | pcbBoardSubsetConstructionFigureRef | 
	pcbBoardSubsetExtraDetailFigureRef | pcbComponentImplementationRef | 
	pcbComponentTerminalImplementationRef | 
	pcbDimensionedObjectBareBoardOutline | pcbJumperConnectionRef |

	pcbSubLayoutOccurrenceRef }

Used by:

<pcbDimensionedArc <pcbDimensionedCircle <pcbDimensionedLine <pcbDimensionedPoint

Constraints:

1. The following constraint applies to this context: All contexts
There must be at least one item (in addition to any required items) in the construct.
(See also similar constraint in: closedAreaCutout, closedAreaElementSet, complexName, geometryElementSet, globalPortList, pcbAllocatedPartFunctionPortSet, pcbAllowedRotations, pcbBareBoardLayers, pcbClearanceGeometry, pcbComponentSet, pcbComponentSignalSet, pcbComponentTerminalJoined, pcbComponentTerminalList, pcbComponentTerminalSet, pcbContributesToDrawing, pcbContributesToFabrication, pcbDieBondSites, pcbDrawingAnnotationSet, pcbDrawingBorderTemplateCenteringMark, pcbDrawingBorderTemplateOrientationMark, pcbDrillRuleFromLayer, pcbDrillRuleLayerSet, pcbDrillRuleSet, pcbDrillRuleToLayer, pcbFabricateTextAppearanceAdd, pcbFabricateTextAppearanceReplace, pcbFabricateTextImplementation, pcbFabricateTextSet, pcbIncludedDrawingFigureCollectorSet, pcbIncludedFabricateFigureCollectorSet, pcbMaterialList, pcbMountableBondPadSet, pcbMountablePackageSet, pcbNonPrintedComponentSet, pcbPackagePinGroupPins, pcbPadRoutingTarget, pcbPhysicalLayerSet, pcbPhysicalTextSet, pcbPropertyNameDrawing, pcbPropertyValueDrawing, pcbTextAppearanceSet, portList, replaceDisplay, signalList, unfilledOrOpenElementSet)

Description:

Identifies a set of dimensioned objects.

PcbDimensionedObjectSet is optional to allow for situations where there is no requirement to associate the dimensioning with layout features. If, however, dimensioning is associated with layout features, it may enable a receiving system to determine which dimensions need to be altered following changes to the layout.

Example:

(pcbDimensionedArc DimArc1
   (arcByCenter (pt 5 15) (pt 10 15) (pt 15 15))
   (pcbDimensionedObjectSet
      (pcbDimensionedObjectBareBoardOutline)))

	')'

Used by:

*pcbBoardSubsetDefinition *pcbBoardSubsetExtraDetail

Similar Keywords:

pcbDimensionedPointRef point

Description:

Defines a hook for a linear dimensioning or a leader dimensioning to refer to. In the context of linear dimensioning, the pcbDimensionedPoint defines one of the points that delineates the distance being measured. In the context of leader dimensioning, the pcbDimensionedPoint identifies a position for the leader dimensioning to hook onto.

PointValue is not required to correspond to any real feature referenced in the pcbDimensionedObjectSet. For example, it may be an imaginary point implied by the existence of two or more real features (e.g. the intersection of two lines in the design), or it may be that the system generating the EDIF description does not know the association of the dimensioned point with any real features in the design.

Example:

(pcbDimensionedPoint DimPnt1
   (pt 10 100)
   (pcbDimensionedObjectSet
      (pcbBareBoardProbePointRef ProbeP23)))

pcbDimensionLineExtensionSingleLine

pcbDimensionLineExtensionSingleLine ::= '(' 'pcbDimensionLineExtensionSingleLine'
	')'

Used by:

pcbDimensionLineExtensionType

Similar Keywords:

pcbDimension pcbDimensionLineExtensionNone

Description:

Specifies that the dimension line or arc is to be extended with one line. This line is a direct extension of the dimension line or arc, which is drawn from the end of the dimension line or arc which is nearer to the dimension text, and to the dimension text itself. The extension should not protrude beyond the dimension text, nor should it be drawn through the dimension text.

The exact nature of the extension is dependent upon the position and orientation of the associated text, and of the extended dimension line or arc. Ideally, the associated dimension text should be "near" the extended dimension line or arc, otherwise it would be difficult for a human reader of the resultant diagram to make sense of the extension. Note, though, that EDIF does not mandate this.

The diagrams below indicate some examples.
