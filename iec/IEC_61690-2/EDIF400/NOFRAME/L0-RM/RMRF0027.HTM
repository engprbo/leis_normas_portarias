pcbDimensionLineOffset

pcbDimensionLineOffset ::= '(' 'pcbDimensionLineOffset'
	distanceValue
	')'

Used by:

!pcbCircularDimensionDetails pcbDimensionArcOffset !pcbLinearDimensionItem

Similar Keywords:

pcbDimension pcbDimensionEndLine pcbDimensionLineAngle pcbDimensionLineExternal pcbDimensionLineInternal pcbDimensionLineType pcbDimensionStartLine pcbDimensionTextOffset

Description:

For a linear dimension, this specifies the distance between the first dimensioned point and the dimension line, as shown below. A negative value indicates that the offset is in the negative y (for horizontal dimensions) or negative x (for vertical dimensions) direction. For direct dimensions, a negative value indicates that the offset is to the right of the vector from the start point to the end point.

For an angular dimension, the offset is the radius of the dimension arc, i.e. the distance between the projected intersection of the identified line segments and the dimension arc, as shown in the following diagram. A negative value is not meaningful in this context.

For a circular diametric or radial dimensions, the offset (which could be zero) is the distance from the center of the circle to the axis of the dimension line, as shown in the following diagram. Negative and positive values are treated as for direct dimensioning, where the start and end points are determined as follows: for diametric dimensions, they are the points on the perimeter of the circle that are found by extending the diameter that is parallel to the dimension line angle to the edge of the circle; for radial dimensions, it is similar, except that one of the points is the arc center and the start point is the leftmost point or the one nearest the bottom of the drawing.

Projection lines are drawn only when the offset is not zero. If the offset is less than the projection line gap the resultant display is determined by the receiving system.

Example:

The following EDIF text describes the linear dimension shown above. 

(pcbDimension DIM_01
   (pcbDimensionHeader ...)
   (pcbDrawingAttributeDefaultRef DEFATTRS_38)
   (pcbDimensionSingleLinear
      (pcbDimensionedPointRef ProbePoint26
         (pcbBoardSubsetPlacementRef BSP1))
      (pcbLinearDimensionHorizontal)
      (pcbDimensionArrowGeometry
         (pcbDimensionEndGeometryRef TRIANGULAR))
      (pcbDimensionSingleLinearMeasureDistance)
      (pcbLinearDimensionItem
         (pcbDimensionDrawingAttributeOverride)
         (pcbDimensionedPointRef ProbePoint25
            (pcbBoardSubsetPlacementRef BSP1))
         (pcbDimensionLineOffset -60)
         (pcbDimensionLineInternal)
         (pcbDimensionLineExtensionNone)
         (pcbTextAlignmentHorizontal)
         (pcbDimensionTextOffset (pt -30 10))
         (pcbDimensionToleranceData
            (pcbDimensionPositiveTolerance (e 1 -1))
            (pcbDimensionNegativeTolerance (e 1 -1))
            (pcbDimensionToleranceNominalWithDeltas
               (textHeight 10))))))

pcbDrawing

pcbDrawing ::= '(' 'pcbDrawing'
	pcbDrawingNameDef
	pcbDrawingHeader
	{ pcbBoardSubsetPlacement | pcbDimension | pcbDrawingAnnotation | 
	pcbDrawingAnnotationGroup | <pcbDrawingTitleBlock> | 
	pcbPropertyDrawing } 
	')'

Used by:

*pcbAssembledBoard *pcbBareBoardDefinition

Constraints:

1. The following constraint applies to this context: All contexts
If any pcb drawings are present, then pcbDrawingUnits must appear in physicalScaling with setDistance and setAngle.
(See also similar constraint in: pcbDrawingUnits)

2. This construct is illegal in this context: pcbBareBoardDefinition <external

Description:

A drawing is an item of annotation that supports the definition of an assembled board or bare board. Examples of a drawing are:

* Assembly drawings that indicate the locations of discrete components to be assembled onto the bare board in order to manufacture the final assembled board.

* Drill drawings that show the locations and types of holes drilled in the bare board during its manufacture.

Typically, a drawing consists of:

* A frame or border that, for example, delineates the edges of the drawing.

* A title block that identifies the drawing and indicates some common characteristics of the drawing.

* A drawn representation of one or more images of part or all of the designed item that is being annotated.

* Annotation directly and indirectly related to the designed item.

* Dimensioning of items and features within the designed item.

PcbDrawing introduces its own coordinate space, the units being specified within pcbDrawingUnits in pcbDrawingHeader. Objects on the board can be shown in the drawing and intelligent dimensioning specified, i.e. dimensioning lines that are linked to the items that they are dimensioning.

Objects are shown on the board using the pcbBoardSubsetPlacement, and dimensioning and annotation is achieved using pcbDimension, pcbDrawingAnnotation and pcbDrawingAnnotationGroup.

For angular dimensioning, angle values are always displayed in degrees, although the precision of the display can be controlled.

Example:

(pcbDrawing ASSEMBLY1
   (pcbDrawingHeader
      (pcbDrawingUnits ...)
      ...
      (pageSize ...)
      (pcbDrawingBorder ...) ...)
   (pcbDrawingTitleBlock ...)
   (pcbBoardSubsetPlacement BOARDREP_01
      (pcbBoardSubsetRef SUBSET_01)
      (uniformScaleTransform ...) ...)
   (pcbDrawingAnnotation Parts_List
      (pcbDrawingFigure ...)
      (pcbDrawingText "Comp" ...)
      (pcbDrawingText "Part" ...)
      (pcbDrawingText "U1-U8" ...) ...)
   (pcbDrawingAnnotationGroup DWGANNOGRP_01
      (pcbDrawingAnnotationGroupPurpose
         (pcbDrawingAnnotationGroupPurposePartsList))
      (pcbDrawingAnnotationSet
         (pcbDrawingAnnotationRef Parts_List)))
   (pcbDimension DIM_01 ...)
   (pcbDimension DIM_02 ...))
