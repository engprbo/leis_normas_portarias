pcbTextAppearanceSet

pcbTextAppearanceSet ::= '(' 'pcbTextAppearanceSet'
	{ pcbTextAppearance } 
	')'

Used by:

!pcbFabricateTextAppearance

Similar Keywords:

pcbFabricateTextSet pcbPhysicalTextSet

Constraints:

1. The following constraint applies to this context: All contexts
There must be at least one item (in addition to any required items) in the construct.
(See also similar constraint in: closedAreaCutout, closedAreaElementSet, complexName, geometryElementSet, globalPortList, pcbAllocatedPartFunctionPortSet, pcbAllowedRotations, pcbBareBoardLayers, pcbClearanceGeometry, pcbComponentSet, pcbComponentSignalSet, pcbComponentTerminalJoined, pcbComponentTerminalList, pcbComponentTerminalSet, pcbContributesToDrawing, pcbContributesToFabrication, pcbDieBondSites, pcbDimensionedObjectSet, pcbDrawingAnnotationSet, pcbDrawingBorderTemplateCenteringMark, pcbDrawingBorderTemplateOrientationMark, pcbDrillRuleFromLayer, pcbDrillRuleLayerSet, pcbDrillRuleSet, pcbDrillRuleToLayer, pcbFabricateTextAppearanceAdd, pcbFabricateTextAppearanceReplace, pcbFabricateTextImplementation, pcbFabricateTextSet, pcbIncludedDrawingFigureCollectorSet, pcbIncludedFabricateFigureCollectorSet, pcbMaterialList, pcbMountableBondPadSet, pcbMountablePackageSet, pcbNonPrintedComponentSet, pcbPackagePinGroupPins, pcbPadRoutingTarget, pcbPhysicalLayerSet, pcbPhysicalTextSet, pcbPropertyNameDrawing, pcbPropertyValueDrawing, portList, replaceDisplay, signalList, unfilledOrOpenElementSet)

Description:

Defines the appearance of a text item. There can be more than one appearance for the text, e.g. the same text sting occurring on different layers.

Example:

(pcbFabricateTextAppearance 
   (pcbContributesToFabrication ...)
   (pcbTextAppearanceSet
      (pcbTextAppearance GA_Courier
         (pcbTextAttributeOverride)
         (stringExtent 10 1)
         (unscaledTransform (origin (pt 100 100))))))

pcbTextAttributeOverride

pcbTextAttributeOverride ::= '(' 'pcbTextAttributeOverride'
	{ <fontRef> | <horizontalJustification> | <pcbGapWidth> | 
	<pcbLineSpacing> | <pcbRightReadable> | <pcbSpaceWidth> | 
	<pcbStrokeWidth> | <textHeight> | <verticalJustification> } 
	')'

Used by:

!pcbTextAppearance

Similar Keywords:

pcbDrawingTextDrawingAttributeOverride pcbFigureAttributeOverride

Description:

Overrides the default text attributes.

Example:

(pcbFabricateTextAppearance 
   (pcbContributesToFabrication ...)
   (pcbTextAppearanceSet
      (pcbTextAppearance GA1
         (pcbTextAttributeOverride
            (fontRef Times))
         (stringExtent 10 1)
         (unscaledTransform (origin (pt 100 100))))))

Here, the default font, which may have been defined within the default geometric attributes referenced by GA1, is being overridden. The font that will be used is Times.

pcbToeprintDefinition

pcbToeprintDefinition ::= '(' 'pcbToeprintDefinition'
	libraryObjectNameDef
	pcbSubLayoutDefinitionHeader

	pcbPropertyFabrication | <pcbTerminalNameFabrication> } 
	')'

Used by:

*external *library

Similar Keywords:

pcbToeprintDefinitionRef

Constraints:

1. The following constraint applies to this context: All contexts
When a pcbBareBoardDefinition or a sublayout definition instances a sublayout, that sublayout must have the same bare board technology as the instantiating object.
(See also similar constraint in: pcbBareBoardDefinition, pcbFootprintDefinition, pcbFootprintInstance, pcbNonSpecificSubLayoutDefinition, pcbNonSpecificSubLayoutInstance, pcbPadstackDefinition, pcbPadstackInstance, pcbTestCouponDefinition, pcbTestCouponInstance, pcbToeprintInstance)

2. The following constraint applies to this context: All contexts
A toeprint definition must contain directly or indirectly at least one padstack instance object, which is either a pin place object or a securing place object.

Description:

A toeprint is a collection of layout items that is specifically reserved for connection to a component pin. A toeprint definition can later be instanced into another sublayout or onto a bare board as a toeprint.

Example:

(pcbToeprintDefinition TP_TYPE1
   (pcbSubLayoutDefinitionHeader ...)
   (pcbPadstackInstance PI1
      (pcbPadstackDefinitionRef PDL5)
      (pcbPadstackInstanceThroughHoleElectricalPinPlace)
      (fixedScaleTransform ...)))

pcbTrace

pcbTrace ::= '(' 'pcbTrace'
	{ <pcbClearanceGeometry> | <pcbFabricateFigure> } 
	')'

Used by:

pcbLayoutFeatureType

Similar Keywords:

pcbMinimumTraceToBoardEdge pcbMinimumTraceToLayoutShape pcbMinimumTraceToSurfaceMountPad pcbMinimumTraceToThroughHolePad pcbMinimumTraceToTrace pcbMinimumTraceToViaPad pcbMinimumTraceWidth pcbOptimumTraceToLayoutShape pcbOptimumTraceToSurfaceMountPad pcbOptimumTraceToThroughHolePad pcbOptimumTraceToTrace pcbOptimumTraceToViaPad pcbOptimumTraceWidth pcbTraceClass pcbTraceGrid pcbTraceOrientation pcbTraceWidthIntoCavity

Constraints:

1. The following constraint applies to this context: All contexts
If pcbFabricateFigure appears, it must contribute positively to at least one physical layer.
(See also similar constraint in: pcbNonSpecificLayoutShape, pcbPad)

2. The following constraint applies to this context: All contexts
If only pcbClearanceGeometry appears, then it must clear from at least one physical layer.
(See also similar constraint in: pcbNonSpecificLayoutShape, pcbPad)

3. The following constraint applies to this context: All contexts
If both pcbFabricateFigure and pcbClearanceGeometry exist, then the pcbClearanceGeometry must clear from at least one physical layer to which the pcbFabricateFigure contributes.
(See also similar constraint in: pcbNonSpecificLayoutShape, pcbPad)

4. The following constraint applies to this context: All contexts
The pcbFabricateFigure constructs within a pcbClearanceGeometry may contain only path or openShape.

5. The following constraint applies to this context: All contexts
The pcbFabricateFigure within pcbTrace may contain only path or openShape.

Description:

Defines a connected set of lines and arcs which are applied using real material, or are cut out of other material that has already been applied to the bare board, or both.

The trace and the clearance geometry must be open shapes, e.g. they cannot be rectangular.

Traces are straightforward features on the bare board that often need to be manipulated by automatic routers.

The trace does not necessarily have to be made from conductive material, e.g. it could be part of the silkscreen information.

Example:

(pcbLayoutFeature LF1
   (pcbTrace
      (pcbFabricateFigure
         (pcbContributesToFabrication
            (pcbSimpleFabricateFigureCollectorRef 
               FC1))
         (pcbPhysicalFigure POWER_NETS
            (geometryElementSet
               (path
                  (pointList
                     (pt -8509000 6432550)
                     (pt -8509000 8382000)
                     (pt -6096000 8382000))))))
      (pcbClearanceGeometry)))
