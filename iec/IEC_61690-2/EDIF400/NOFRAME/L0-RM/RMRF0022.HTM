Description:

(pcbComponentTerminalList L1

      (pcbPackagedElectricalComponentRef U1))

In this example, the property MAX_ROUTE_LENGTH is defined for an ordered list of terminals. Such a structure could be used to control the maximum route lengths and routing order between terminals.

	( pcbPlatedThroughHole | pcbUnplatedHole )
	')'

Used by:

Similar Keywords:

Constraints:

1. The following constraint applies to this context: All contexts
The circle defined by the pcbHoleCrossSection within a pcbConformantHole must be compatible with the recommended hole size defined by pcbDrillRuleHoleSize in the referenced pcbDrillRule.

2. The following constraint applies to this context: All contexts
If the pcbConformantHole is a pcbPlatedThroughHole then the drill rule must be a pcbPlatedDrillRule. Likewise if the pcbConformantHole is a pcbUnplatedHole then the drill rule must be a pcbNonPlatedDrillRule.

Description:

Defines a circular hole whose cross-sectional size conforms to the rules specified by pcbDrillRuleRef.

The hole will most likely be manufactured by a drilling process and will always have a circular cross-section.

Information about the hole, such as the layers it spans, is defined within the referenced drill rule.

Example:

(pcbConformantHole
   (pcbHoleCrossSection
      (circleByCenter (pt 0 0) 71120))
   (pcbDrillRuleRef DR1)
   (pcbPlatedThroughHole))

pcbCorrectNet

pcbCorrectNet ::= '(' 'pcbCorrectNet'
	pcbAssembledPhysicalNetNameDef
	pcbAssembledPhysicalNetHeader
	( pcbComponentSignalRef | pcbNoComponentSignal )
	{ <pcbInstanceNets> | <pcbJoinedJumperComponent> | 
	pcbJumperConnection } 
	')'

Used by:

*pcbAnalyzedAssembledPhysicalNets

Constraints:

1. The following constraint applies to this context: All contexts
A pcbComponentSignal may be implemented by one and only one of the following combinations: 1. By zero, one or more pcbNonAnalyzedAssembledPhysicalNets, 2. By exactly one pcbCorrectNet, 3. By zero, one or more pcbIncorrectNet, 4. By zero, one or more pcbShortingNet.
(See also similar constraint in: pcbIncorrectNet, pcbNonAnalyzedAssembledPhysicalNets, pcbShortingNet)

Description:

Describes an assembled physical net which has had its connectivity checked by the sending system. The terminals joined by the assembled physical net are exactly the same as the terminals that are required to be joined by the referenced pcbComponentSignal.

An assembled physical net can only include instance nets that are on the bare board that the assembled board is based upon.

The assembly of the instance nets may be achieved by the use of pcbJumperConnection connections.

Example:

(pcbCorrectNet NET_FOR_SIG1
   (pcbAssembledPhysicalNetHeader)
   (pcbComponentSignalRef SIG1)
   (pcbInstanceNets
      (pcbSubLayoutInstancePhysicalNetRef 
         NET1 (pcbSubLayoutInstanceRef BB))
      (pcbSubLayoutInstancePhysicalNetRef
         NET2 (pcbSubLayoutInstanceRef BB)))
   (pcbJumperConnection JUMPER1
      (pcbJumperConnectionHeader)
      (pcbJumperConnectionDiscreteWire
         (pcbJumperConnectionDiscreteWireConnectionPoints
            (pcbPadstackInstanceRef JPAD1)
            (pcbPadstackInstanceRef JPAD2)))))

In this example, the connectivity defined by SIG1 is implemented by NET1, NET2 and a jumper, JUMPER1. JUMPER1 could be the physical mechanism that is used to join the two physical nets together.
