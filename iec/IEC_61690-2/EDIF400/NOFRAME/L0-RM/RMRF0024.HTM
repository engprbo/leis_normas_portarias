pcbDiePassivationExtent

pcbDiePassivationExtent ::= '(' 'pcbDiePassivationExtent'
	closedAreaElement
	')'

Used by:

<pcbDiePhysicalTemplate

Similar Keywords:

pcbDieMetalExtent pcbDiePassivationMaterial pcbDiePassivationOpeningExtent

Constraints:

1. This construct is illegal in this context: external

Description:

Specifies the shape of the passivation over the die substrate.

This attribute has been derived from the DIE format, Section 5.44.

Example:

(pcbDiePhysicalTemplate die_temp_001V2
   (pcbDiePhysicalTemplateHeader
      (pcbLayoutUnits))
   (pcbDiePassivationExtent
      (rectangle (pt 0 0) (pt 2000 1000))) ...)

pcbDiePhysicalTemplate

pcbDiePhysicalTemplate ::= '(' 'pcbDiePhysicalTemplate'
	libraryObjectNameDef
	pcbDiePhysicalTemplateHeader
	{ bodyVolume | occupiedSpace | pcbDieFiducial | <pcbDieFlatness> | 
	<pcbDieMaximumThermalDissipation> | 
	<pcbDieNominalThermalDissipation> | <pcbDiePadDielectric> | 
	<pcbDiePadMetal> | <pcbDiePadPitch> | <pcbDiePadPositionTolerance> 
	| <pcbDiePassivationExtent> | <pcbDiePassivationMaterial> | 
	<pcbDiePowerCapacitance> | pcbDiePowerCell | <pcbDieSizeTolerance> | 
	<pcbDieStorageConditions> | <pcbDieSubstrateMaterial> | 
	<pcbDieThicknessTolerance> | pcbElectricalBondPad | 
	pcbNonElectricalBondPad | <pcbTabbing> | <specificHeatCapacity> | 
	<thermalConductivity> } 
	')'

Used by:

*external *library

Similar Keywords:

pcbDieFiducialTemplate pcbDiePhysicalTemplatePreviousVersion pcbDiePhysicalTemplateRef pcbMountableDiePhysicalTemplate pcbMountableDiePhysicalTemplateHeader pcbMountableDiePhysicalTemplatePropertyFabrication pcbMountableDiePhysicalTemplatePropertyOverride pcbMountableDiePhysicalTemplateRef pcbMountableDiePhysicalTemplateSymbol

Constraints:

1. The following constraint applies to this context: All contexts
There must be at least one pcbElectricalBondPad or pcbNonElectricalBondPad within the pcbDiePhysicalTemplate.

Description:

A die physical template is used to specify those physical features of a die that define the interaction between the die and an MCM.

Example:

(pcbDiePhysicalTemplate STANDARD_INTERFACE
   (pcbDiePhysicalTemplateHeader
      (pcbLayoutUnits)
      (nameInformation (primaryName "DIE_FCH_7486")))
   (pcbElectricalBondPad bondpad_001
      (pcbBondPadHeader
         (pcbDieSide (pcbDieSideTop))
         (nameInformation (primaryName "1")))
      (pcbBondPadBare
         (pcbBondPadTemplateRef bpt_001)
         (fixedScaleTransform (origin (pt 0 0)))))
   (pcbElectricalBondPad bondpad_002
      (pcbBondPadHeader
         (pcbDieSide (pcbDieSideTop))
         (nameInformation (primaryName "2")))
      (pcbBondPadBare
         (pcbBondPadTemplateRef bpt_001)
         (fixedScaleTransform (origin (pt 33020 0)))))
   (pcbElectricalBondPad bondpad_003
      (pcbBondPadHeader
         (pcbDieSide (pcbDieSideTop))
         (nameInformation (primaryName "3")))
      (pcbBondPadBare
         (pcbBondPadTemplateRef bpt_001)
         (fixedScaleTransform (origin (pt 33020 20320)))))
   (pcbElectricalBondPad bondpad_004
      (pcbBondPadHeader
         (pcbDieSide (pcbDieSideTop))
         (nameInformation (primaryName "4")))
      (pcbBondPadBare
         (pcbBondPadTemplateRef bpt_001)
         (fixedScaleTransform (origin (pt 33020 0))))))
(pcbDieElectricalPart DUAL_INV
   (pcbPartHeader ...)
   (pcbDiePhysicalTemplateRef STANDARD_INTERFACE)
   (pcbDieElectricalPartFullyDefined ...) ...)

Here, the die physical template STANDARD_INTERFACE is defined. This is referenced in the die electrical part to specify physical features on the die that interface with the MCM.

pcbDiePhysicalTemplateHeader

pcbDiePhysicalTemplateHeader ::= '(' 'pcbDiePhysicalTemplateHeader'
	pcbLayoutUnits
	{ documentation | <nameInformation> | 
	<pcbDiePhysicalTemplatePreviousVersion> | property | <status> } 
	')'

Used by:

!pcbDiePhysicalTemplate

Similar Keywords:

pcbDiePhysicalTemplateRef pcbMountableDiePhysicalTemplate pcbMountableDiePhysicalTemplateHeader pcbTemplateHeader

Description:

Gathers together data relating to the pcbDiePhysicalTemplate as a whole, including an optional reference to the previous version of the template.

SpecificHeatCapacity specifies the specific heat capacity of the die substrate material and is used for thermal analysis. This attribute has been derived from the DIE format, Section 5.59.

ThermalConductivity has been derived from the DIE format, Section 5.63.

Example:

(pcbDiePhysicalTemplate die_temp_001V2
   (pcbDiePhysicalTemplateHeader
      (pcbLayoutUnits)
      (nameInformation (primaryName "DIE_FCH_7486"))
      (pcbDiePhysicalTemplatePreviousVersion
         (pcbDiePhysicalTemplateRef die_temp_001V1))) ...)

pcbDiePositionTolerance

pcbDiePositionTolerance ::= '(' 'pcbDiePositionTolerance'
	originPositiveDisplacement
	originNegativeDisplacement
	rotationDisplacement
	')'

Used by:

<pcbMountableDiePhysicalTemplate

Similar Keywords:

pcbDieGeometryTolerance pcbDiePadPositionTolerance pcbDiePositionToleranceWidth pcbDieSizeTolerance pcbDieThicknessTolerance

Constraints:

1. The following constraint applies to this context: All contexts
The rotation displacement values are not less than zero.

2. This construct is illegal in this context: external

Description:

Specifies the die's position tolerance, which is the amount by which a die may vary in placement when the mountable die physical template is used. Such variance is due to the limitations of the insertion/onsertion tool and/or method.

OriginPositiveDisplacement and OriginNegativeDisplacement enable different displacement lengths to be specified for the positive and negative directions.

Example:

(pcbMountableDiePhysicalTemplate PT1
   (pcbMountableDiePhysicalTemplateHeader ...)
   (pcbDiePhysicalTemplateRef DT1)
   (pcbDiePositionTolerance
      (originPositiveDisplacement 20 20)
      (originNegativeDisplacement 5 5)
      (rotationDisplacement  5 5)) ...)

pcbDieStorageConditions

pcbDieStorageConditions ::= '(' 'pcbDieStorageConditions'
	pcbDieStorageConditionsNameDef

	maximumTemperature
	relativeHumidity
	{ property } 
	')'

pcbDieAttachmentConditions pcbDieBondingConditions pcbDieEnvironmentalConditions pcbDieSealingConditions

Constraints:

1. This construct is illegal in this context: external

Description:

Specifies the set of environmental considerations that should be satisfied during the storage of the die before its inclusion in an MCM.

This concept has been derived from the DIE format, Section 5.16.

Example:

(pcbDiePhysicalTemplate die_temp_001V2
   (pcbDiePhysicalTemplateHeader
      (pcbLayoutUnits))
   (pcbDieStorageConditions SC 0 150 
      (relativeHumidity 80)) ...)

Here, the minimum storage temperature is 0, the maximum storage temperature is 150 and the maximum relative humidity is 80%.
