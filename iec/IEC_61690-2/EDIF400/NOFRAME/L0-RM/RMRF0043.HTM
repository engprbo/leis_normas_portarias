pcbPackagePinGroup

pcbPackagePinGroup ::= '(' 'pcbPackagePinGroup'
	pcbPackagePinGroupNameDef
	( pcbPackagePinGroupPins | externalNoData )
	{ <nameInformation> | property } 
	')'

Used by:

*pcbPinPackage

Similar Keywords:

pcbMountablePinPackage pcbPackagePinArrangement pcbPackagePinForm pcbPackagePinGroupNameCaseSensitive pcbPackagePinGroupNameRef pcbPackagePinLength pcbPackagePinPitch pcbPackageTerminalPin pcbPinGroupMounting pcbPinPackageRef

Description:

Defines a pin group. A pin group is a collection of package pins. All of the package pins in a given pin group are intended to be mounted onto a bare board in a particular manner.

For example, two pin groups may have been created to indicate that one group of pins should be connected to one side of the board and the other group to the other side of the board. NameInformation can convey the meaning of each pin group.

A pin cannot belong to more than one pin group.

Example:

(pcbPinPackage DIP14 ...
   (pcbPackagePinGroup PG1
      (pcbPackagePinGroupPins
         (pcbPackageTerminalPinRef T1)
         (pcbPackageTerminalPinRef T2)
         ...
         (pcbPackageTerminalPinRef T14))) ...)

pcbPinPackage in the above example defines just one pin group called PG1. All 14 pins of the package are in this group.

pcbPackagePinGroupNameCaseSensitive

pcbPackagePinGroupNameCaseSensitive ::= '(' 'pcbPackagePinGroupNameCaseSensitive'
	booleanToken
	')'

Used by:

<nameCaseSensitivity

Similar Keywords:

pcbPackagePinGroup pcbPinPackage

Description:

Defines whether or not the strings contained within nameInformation for items with a pcbPackagePinGroupNameDef are to be considered as case sensitive. The default is that names are case sensitive. Following normal precedence rules, this applies to the entire EDIF data if this form occurs in edifHeader, or to the entire library if it occurs in libraryHeader.

See clusterNameCaseSensitive for an example.
