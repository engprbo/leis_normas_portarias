pcbMetalArtifactToCavitySpacing

pcbMetalArtifactToCavitySpacing ::= '(' 'pcbMetalArtifactToCavitySpacing'
	tolerancedDistanceValue
	')'

Used by:

<pcbBareBoardTechnologyRule

Similar Keywords:

pcbCavityToCavitySpacing

Description:

Specifies the allowable spacing between a metal artifact (e.g. a trace or pad) on the layer and a cavity. This constraint applies only to metal artifacts on the layer surface, and where the metal artifacts do not enter the cavity.

This is a constraint for embedded die technology. See pcbBareBoardTechnologyRule for a diagrammatic representation.

Example:

(pcbBareBoardTechnologyRule BBTR
   (pcbTechnologyRuleHeader ...)
   (pcbTechnologyRuleDetails ...)
   (pcbMetalArtifactToCavitySpacing
      (mnm 1000 (undefined) (unconstrained))) ...)

pcbMinimumAcidTrapAngle

pcbMinimumAcidTrapAngle ::= '(' 'pcbMinimumAcidTrapAngle'
	angleValue
	')'

Used by:

<pcbTechnologyRuleDetails

Description:

Specifies the minimum angle that must be formed by a trace when it enters a pad in order to avoid the formation of an acid trap. An acid trap is a place where acid can be trapped during the bare board manufacturing process.

Example:

(pcbBareBoardTechnologyRule BBT_RULES
   (pcbTechnologyRuleHeader ...)
   (pcbTechnologyRuleDetails
      (pcbMinimumAcidTrapAngle 20) ...))

pcbMinimumTraceToViaPad

pcbMinimumTraceToViaPad ::= '(' 'pcbMinimumTraceToViaPad'
	lengthValue
	')'

Used by:

<pcbComponentSignalLayerRealizationRule <pcbTechnologyRuleDetails

Similar Keywords:

pcbMinimumTraceToTrace pcbMinimumViaPadToViaPad pcbOptimumTraceToViaPad pcbPad pcbTrace

Description:

Specifies the minimum spacing between a trace and a pad of a via. The rule is applied by determining the distance between an edge of a pad on a via and an edge of a trace segment nearest to that via on the same layer.

PcbOptimumTraceToViaPad specifies the optimum spacing between the two objects.

Example:

(pcbBareBoardTechnologyRule BBT_RULES
   (pcbTechnologyRuleHeader ...)
   (pcbTechnologyRuleDetails
      (pcbMinimumTraceToViaPad 10) ...))
