pcbPhysicalNet

pcbPhysicalNet ::= '(' 'pcbPhysicalNet'
	pcbPhysicalNetNameDef
	pcbPhysicalNetHeader
	{ <pcbInstanceNets> | pcbLayoutFeature | pcbLayoutText | pcbPhysicalNet 
	} 
	')'

Used by:

*pcbBareBoardPhysicalNet *pcbFootprintDefinition *pcbNonSpecificSubLayoutDefinition *pcbPadstackDefinition *pcbPhysicalNet *pcbTestCouponDefinition *pcbToeprintDefinition

Similar Keywords:

pcbAssembledPhysicalNetHeader pcbAssembledPhysicalNetNameCaseSensitive pcbAssembledPhysicalNetNameDef pcbAssembledPhysicalNetNameRef pcbAssembledPhysicalNetRef pcbBareBoardPhysicalNetRef pcbPhysicalNetNameCaseSensitive pcbPhysicalNetNameRef pcbPhysicalNetOccurrenceRef pcbSubLayoutInstancePhysicalNetRef

Description:

Defines a geometrically-connected region of conductive material. A physical net is a collection of layout features (e.g. a trace) and other physical nets. By including other physical nets, a structured approach to the definition of the physical net can be achieved.

If a physical net needs to be repeatedly used in several other physical nets, it can be included in a sublayout definition, then an instance of that definition can be referenced within the physical net by using pcbInstanceNets.

A physical net can also own layout text. The layout text is merely associated with the net; it does not provide functional connectivity.

Physical nets can cross layer boundaries using padstacks that have plated-through holes and using plated-through holes themselves.

Example:

(pcbPhysicalNet net0_1
   (pcbPhysicalNetHeader)
   (pcbLayoutFeature LF1
      (pcbTrace
         (pcbFabricateFigure
            (pcbContributesToFabrication
               (pcbSimpleFabricateFigureCollectorRef 
                  FC1))
            (pcbPhysicalFigure OTHER_NETS
               (geometryElementSet
                  (path
                     (pointList
                        (pt 0 5000)
                        (pt 5000 5000)))
                  (path
                     (pointList
                        (pt 2500 2500)
                        (pt 2500 5000))))))
         (pcbClearanceGeometry)))
   (pcbLayoutFeature LF2
      (pcbPad 
         (pcbPadIntendedUse (pcbPadIntendedUseSignalPositive))
         (pcbFabricateFigure ...
            (pcbPhysicalFigure ...
               (geometryElementSet
                  (rectangle (pt 2400 4900) 
                     (pt 2600 5100)))))
         (pcbClearanceGeometry))))

This defines the physical net shown in the following diagram.

pcbPhysicalTextImplementation

pcbPhysicalTextImplementation ::= '(' 'pcbPhysicalTextImplementation'
	{ pcbPhysicalFigure | <pcbTextAppearance> } 
	')'

Used by:

*pcbFabricateTextImplementation !pcbPhysicalText

Similar Keywords:

pcbPhysicalTextSet

Description:

Specifies the implementation of a piece of text. PcbTextAppearance describes how the text is displayed in terms of the bounds of the string, font size, rotation etc. The presence of one or more pcbPhysicalFigures give a graphical representation of the text in terms of graphical primitives.

Both representations may be given and a receiving system may use either or both depending on its own internal representation of fabricated text. An EDIF writer should provide both representations if it is able to do so.

Example:

(pcbPhysicalText "T"
   (pcbPhysicalTextImplementation
      (pcbTextAppearance STROKE
         (pcbTextAttributeOverride)
         (stringExtent 5 5)
         (unscaledTransform (origin (pt 100 100))))
      (pcbPhysicalFigure STROKE
         (geometryElementSet
            (path
               (pointList
                  (pt 103 100)
                  (pt 103 105)))
            (path
               (pointList
                  (pt 100 105)
                  (pt 105 105)))))))

In this example, the letter "T" is displayed using the font and other defaults in the pcbGeometricAttributeDefault named STROKE. The pcbPhysicalFigure describes the letter "T" as primitive graphical objects again using the geometric attribute defaults (e.g. pathWidth) in the pcbGeometricAttributeDefault named STROKE

pcbPinMounting

pcbPinMounting ::= '(' 'pcbPinMounting'
	pcbPinMountingType
	')'

Used by:

!pcbDefaultPinMounting <pcbMountablePackageTerminalPreparedPin !pcbPinGroupMounting

Similar Keywords:

pcbPinMountingBothSides pcbPinMountingBottomSide pcbPinMountingSocketed pcbPinMountingThroughBoard pcbPinMountingTopSide pcbPinMountingUnmounted

Constraints:

1. This construct is illegal in this context: pcbMountablePackageTerminalPreparedPin <external

Description:

Specifies how the pin is mounted on the board.

The pin mounting type for a given mountable pin is, in order of priority:

1. The pcbPinMountingType of the pcbMountablePackageTerminalPreparedPin, if that is defined, or

2. The pcbPinMountingType as defined in the pcbPinGroupMounting associated with the mountable pin, if that is defined, or

3. The default pcbPinMountingType defined in pcbDefaultPinMounting.

Example:

(pcbMountablePackageTerminalPreparedPin T1
   (pcbMountablePackageTerminalHeader ...)
   (pcbPackageTerminalPinRef P1)
   (pcbPinMounting
      (pcbPinMountingThroughBoard)))

pcbPinMountingBothSides

pcbPinMountingBothSides ::= '(' 'pcbPinMountingBothSides'
	')'

Used by:

pcbPinMountingType

Similar Keywords:

pcbPinMounting

Description:

Specifies that the surface-mount pin is mounted on both sides of the board. This may be used, for example, where pins are mounted in unplated holes and the electrical contact between the circuit connected to the top of the pin and the circuit connected to the bottom of the pin is achieved by the pin itself. Therefore the pin must be electrically connected at the top side and at the bottom side. The figure below shows an example.

Example:

(pcbMountablePinPackage  Edge_Connector
   (pcbMountablePackageHeader (pcbLayoutUnits ...))
   (pcbPinPackageRef EDGE_10 (libraryRef PACKAGES))
   (pcbMountingMethodRef EDGE)
   (pcbDefaultPinMounting (pcbPinMounting (pcbPinMountingBothSides)))
   ...)
