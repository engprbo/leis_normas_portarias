(See also similar constraint in: closedAreaCutout, closedAreaElementSet, complexName, geometryElementSet, globalPortList, pcbAllocatedPartFunctionPortSet, pcbAllowedRotations, pcbBareBoardLayers, pcbComponentSet, pcbComponentSignalSet, pcbComponentTerminalJoined, pcbComponentTerminalList, pcbComponentTerminalSet, pcbContributesToDrawing, pcbContributesToFabrication, pcbDieBondSites, pcbDimensionedObjectSet, pcbDrawingAnnotationSet, pcbDrawingBorderTemplateCenteringMark, pcbDrawingBorderTemplateOrientationMark, pcbDrillRuleFromLayer, pcbDrillRuleLayerSet, pcbDrillRuleSet, pcbDrillRuleToLayer, pcbFabricateTextAppearanceAdd, pcbFabricateTextAppearanceReplace, pcbFabricateTextImplementation, pcbFabricateTextSet, pcbIncludedDrawingFigureCollectorSet, pcbIncludedFabricateFigureCollectorSet, pcbMaterialList, pcbMountableBondPadSet, pcbMountablePackageSet, pcbNonPrintedComponentSet, pcbPackagePinGroupPins, pcbPadRoutingTarget, pcbPhysicalLayerSet, pcbPhysicalTextSet, pcbPropertyNameDrawing, pcbPropertyValueDrawing, pcbTextAppearanceSet, portList, replaceDisplay, signalList, unfilledOrOpenElementSet)

Description:

Defines where material should be removed (e.g. from a power plane) for some purpose (e.g. to make space for other geometry that needs to be isolated from the plane). Other purposes are possible; for example, to shave material from a pad where a trace approaches it too closely. The main purpose is to remove material from power, ground and signal planes. For example:

Example:

(pcbLayoutText TEXT_ITEM1
   (pcbFabricateTextSet ...)
   (pcbClearanceGeometry
      (pcbFabricateFigure
         (pcbContributesToFabrication
            (pcbSimpleFabricateFigureCollectorRef 
               FC1))
         (pcbPhysicalFigure OTHER_GEOMETRY
            (geometryElementSet
               (rectangle (pt 0 0) (pt 20 10)))))))

pcbComponentAssemblyRule

pcbComponentAssemblyRule ::= '(' 'pcbComponentAssemblyRule'
	pcbRuleNameDef
	pcbComponentAssemblyRuleCriteria
	{ documentation | <pcbComponentAssemblyRuleRegion> | property } 
	')'

Used by:

*pcbAssembledBoard

Similar Keywords:

pcbComponentAssemblyRuleCriterion pcbComponentAssemblyRuleCriterionNameDef pcbComponentOrientationRule pcbComponentRealizationRule

Description:

Defines an assembly rule for components on an assembled board.

If pcbComponentAssemblyRuleRegion is present, then the rule applies only to the specified region. Otherwise it applies to the whole board.

Example:

(pcbComponentAssemblyRule HEIGHT_RESTRICTION
   (pcbComponentAssemblyRuleCriteria
      (pcbComponentAssemblyRuleCriterion CR1
         (pcbNonPrintedComponentSet
            (pcbPackagedElectricalComponentRef U1)
            (pcbPackagedElectricalComponentRef U2)
            (pcbPackagedElectricalComponentRef U3)
            (pcbPackagedElectricalComponentRef U4))
         (pcbKeepOut)
         (pcbAssemblySideTop)
         (pcbComponentMinimumHeight 1000)))
   (pcbComponentAssemblyRuleRegion
      (rectangle (pt 0 0) (pt 8000 9000))))

This rule specifies a zone defined by a rectangle from (pt 0 0) to (pt 8000 9000) as being a keep-out zone which applies to a specified list of components. The components are U1, U2, U3 and U4 and the rule applies to any of these with a height greater than 1000 units. Such components should be kept out of the specified zone.

pcbComponentAssemblyRuleCriterion

pcbComponentAssemblyRuleCriterion ::= '(' 'pcbComponentAssemblyRuleCriterion'
	pcbComponentAssemblyRuleCriterionNameDef
	pcbNonPrintedComponentSet
	( pcbKeepIn | pcbKeepOut )
	( pcbAssemblySideTop | pcbAssemblySideBottom | pcbAssemblySideBoth )
	{ <pcbComponentMaximumHeight> | <pcbComponentMinimumHeight> } 
	')'

Used by:

*pcbComponentAssemblyRuleCriteria

Similar Keywords:

pcbComponentAssemblyRule pcbComponentAssemblyRuleRegion

Description:

Specifies a criterion for a component assembly rule. The criterion applies to the set of components referenced by pcbNonPrintedComponentSet.

The second required item pcbKeepIn or pcbKeepOut indicates whether this is a keep-in or keep-out rule.

The third required item indicates whether the rule applies to the top, bottom or to both sides of the board.

Using these parameters it is possible to specify keep-in and keep-out criteria applying to specified components within a given height range on the top, bottom or both sides of the board.

Example:

(pcbComponentAssemblyRuleCriterion CR1
   (pcbNonPrintedComponentSet
      (pcbPackagedElectricalComponentRef U1)
      (pcbPackagedElectricalComponentRef U2)
      (pcbPackagedElectricalComponentRef U3)
      (pcbPackagedElectricalComponentRef U4))
   (pcbKeepOut)
   (pcbAssemblySideTop)
   (pcbComponentMinimumHeight 1000))

This criterion applies to all of the components U1, U2, U3 or U4. It specifies that any of these components with a height greater than 1000 should be kept out of the region specified by the enclosing rule on the top side of the board.

pcbComponentFunctionAllocation

pcbComponentFunctionAllocation ::= '(' 'pcbComponentFunctionAllocation'
	pcbElectricalPartFunctionRef
	pcbComponentFunctionAllocationType
	')'

Used by:

*pcbDieElectricalComponent *pcbPackagedElectricalComponent *pcbPrintedElectricalComponent

Similar Keywords:

pcbAllocatedComponentFunction pcbUnallocatedComponentFunction pcbUnknownComponentFunctionAllocation

Constraints:

1. The following constraint applies to this context: All contexts
The number of pcbComponentFunctionAllocation constructs within an electrical component which instantiates a fully-defined part, must be equal to the number of pcbElectricalPartFunctions within that part.
(See also similar constraint in: pcbDieElectricalComponent, pcbPackagedElectricalComponent, pcbPrintedElectricalComponent)

2. The following constraint applies to this context: All contexts
No pcbElectricalPartFunction may be referenced more than once by any pcbComponentFunctionAllocation constructs within a component.
(See also similar constraint in: pcbDieElectricalComponent, pcbElectricalPartFunction, pcbPackagedElectricalComponent, pcbPrintedElectricalComponent)

Description:

References a function within the component's part and gives information about the allocation of that function; for example, how an instance within the logical connectivity is allocated (i.e. mapped) to the function.

The function referenced by pcbElectricalPartFunctionRef is defined in the part referenced by the enclosing (electrical) component.

Example:

(pcbComponentFunctionAllocation
   (pcbElectricalPartFunctionRef A)
   (pcbAllocatedComponentFunction
      (instanceRef AND24)
      (pcbAllocationSwapStatus 
         (pcbAllocationNotFixed))
      (pcbAllocatedComponentFunctionPortAssociation
         (portRef P1)
         (pcbAllocatedPartFunctionPortSet
            (portRef b))
         (pcbAllocationSwapStatus 
            (pcbAllocationNotFixed)))
      (pcbAllocatedComponentFunctionPortAssociation
         (portRef P2)
         (pcbAllocatedPartFunctionPortSet
            (portRef a))
         (pcbAllocationSwapStatus 
            (pcbAllocationNotFixed)))
      (pcbAllocatedComponentFunctionPortAssociation
         (portRef P3)
         (pcbAllocatedPartFunctionPortSet
            (portRef f))
         (pcbAllocationSwapStatus 
            (pcbAllocationNotFixed)))))

This example describes the allocation shown in the following diagram.

Instance AND24 in the logical connectivity is allocated to function A in the component. The first pcbAllocationNotFixed indicates that the allocation of the instance to the function is not fixed and is allowed to be changed.

The allocation of instance ports to function ports is then specified; instance port P2 maps to function port a, P1 to b and P3 to f. Each of these has a swap status of pcbAllocationNotFixed, which means that the allocation is allowed to be modified.
