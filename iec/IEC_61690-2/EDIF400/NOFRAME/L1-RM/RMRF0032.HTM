pcbDrawingFactorScaleDrawing

pcbDrawingFactorScaleDrawing ::= pcbDrawingTextDisplay

Used by:

!pcbBoardSubsetPlacementScaled

Similar Keywords:

pcbDrawingScaleFactor pcbDrawingScaleFactorDisplayString pcbDrawingScaleFactorDrawing scale

Description:

Describes how to display text that indicates the scale factor of a board subset placement, when the board subset placement is drawn at a scale different from that of the pcb drawing.

Example:

(pcbBoardSubsetPlacement BSP1
   (pcbBoardSubsetRef BS1)
   (uniformScaleTransform ...)
   (pcbBoardSubsetPlacementScaled
      (pcbDrawingScaleFactor 1 2 "Half Scale")
      (pcbDrawingTextDisplay ...)))

The pcbDrawingTextDisplay will indicate where the string "Half Scale" will be displayed.

	')'

Defines whether or not the strings contained within nameInformation for items with a pcbDrawingNameDef are to be considered as case sensitive. The default is that names are case sensitive.
