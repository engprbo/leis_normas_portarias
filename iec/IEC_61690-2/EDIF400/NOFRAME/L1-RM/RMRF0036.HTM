pcbFootprintInstance

pcbFootprintInstance ::= '(' 'pcbFootprintInstance'
	pcbSubLayoutInstanceNameDef
	pcbFootprintDefinitionRef
	( fixedScaleTransform | externalNoData )
	{ <nameInformation> | <pcbLayoutFeatureFixed> | property } 
	')'

Used by:

*pcbBareBoardDefinition *pcbTestCouponDefinition

Similar Keywords:

instance pcbFootprintInstanceRef pcbFootprintToeprintInstanceRef

Constraints:

1. The following constraint applies to this context: All contexts
When a pcbBareBoardDefinition or a sublayout definition instances a sublayout, that sublayout must have the same bare board technology as the instantiating object.
(See also similar constraint in: pcbBareBoardDefinition, pcbFootprintDefinition, pcbNonSpecificSubLayoutDefinition, pcbNonSpecificSubLayoutInstance, pcbPadstackDefinition, pcbPadstackInstance, pcbTestCouponDefinition, pcbTestCouponInstance, pcbToeprintDefinition, pcbToeprintInstance)

Description:

Defines an instance of a footprint definition.

The position of the instance is specified by fixedScaleTransform if the definition is in an internal library.

Example:

(pcbFootprintInstance DIL14_FP1
   (pcbFootprintDefinitionRef DIL14)
   (fixedScaleTransform (origin (pt 100 100)))
   (pcbLayoutFeatureFixed))

pcbHoleClearanceRule

pcbHoleClearanceRule ::= '(' 'pcbHoleClearanceRule'
	pcbRuleNameDef
	pcbFirstHoleInformation
	pcbSecondHoleInformation
	pcbMinimumHoleClearance
	{ property } 
	')'

Used by:

*pcbBareBoardTechnologyRule

Description:

Specifies the minimum clearance between holes. This is to ensure that holes are not so close together that they compromise the structural integrity of the board. The distance is measured between the closest points of the holes.

Different clearance rules can be specified for the following:

* Between holes that conform to a specified drill rule and holes that conform to another specified drill rule.

* Between holes that conform to a specified drill rule and any other hole.

* Between any holes.

Example:

(pcbBareBoardTechnologyRule BBTR
   (pcbTechnologyRuleHeader ...)
   (pcbTechnologyRuleDetails ...)
   (pcbHoleClearanceRule FHCR
      (pcbAnyHole)
      (pcbDrillRuleRef DR1)
      (pcbMinimumHoleClearance 10)))

In this example, the minimum clearance between a hole that conforms to drill rule DR1 and any other hole is 10 units.

pcbIncorrectNet

pcbIncorrectNet ::= '(' 'pcbIncorrectNet'
	pcbAssembledPhysicalNetNameDef
	pcbAssembledPhysicalNetHeader
	pcbComponentSignalRef
	pcbComponentTerminalJoined
	{ <pcbInstanceNets> | <pcbJoinedJumperComponent> | 
	pcbJumperConnection } 
	')'

Used by:

*pcbAnalyzedAssembledPhysicalNets

Constraints:

1. The following constraint applies to this context: All contexts
A pcbComponentSignal may be implemented by one and only one of the following combinations: 1. By zero, one or more pcbNonAnalyzedAssembledPhysicalNets, 2. By exactly one pcbCorrectNet, 3. By zero, one or more pcbIncorrectNet, 4. By zero, one or more pcbShortingNet.
(See also similar constraint in: pcbCorrectNet, pcbNonAnalyzedAssembledPhysicalNets, pcbShortingNet)

2. The following constraint applies to this context: All contexts
A pcbIncorrectNet may join extra component terminals which are not specified in the referenced pcbComponentSignal. However, as it is not a pcbShortingNet, the extra terminals must not be referenced by any pcbComponentSignal.

3. The following constraint applies to this context: All contexts
A pcbIncorrectNet must not join exactly the same set of terminals as specified in the referenced pcbComponentSignal.

Description:

Describes an assembled physical net which has had its connectivity checked by the sending system. The connectivity in the physical net does not match the connectivity specified by the referenced component signal, but the mismatch is not due to two or more signals being shorted together. For example, a component net would be incorrect if one of the terminals in the component signal is not in the assembled physical net.

PcbComponentTerminalJoined specifies the component terminals that are connected together by the assembled physical net.

An assembled physical net can only include instance nets that are on the bare board that the assembled board is based upon.

Example:

(pcbIncorrectNet NET_FOR_SIG1
   (pcbAssembledPhysicalNetHeader)
   (pcbComponentSignalRef SIG1)
   (pcbComponentTerminalJoined ...)
   (pcbInstanceNets
      (pcbSubLayoutInstancePhysicalNetRef
         NET2 (pcbSubLayoutInstanceRef BB)))
   (pcbJumperConnection JUMPER1
      (pcbJumperConnectionHeader)
      (pcbJumperConnectionDiscreteWire
         (pcbJumperConnectionDiscreteWireConnectionPoints
            (pcbPadstackInstanceRef JPAD1)
            (pcbPadstackInstanceRef JPAD2)))))
