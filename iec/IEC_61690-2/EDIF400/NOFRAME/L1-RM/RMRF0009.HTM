forFrameIndex

forFrameIndex ::= '(' 'forFrameIndex'
	indexNameDef
	{ <indexStart> | <indexStep> | <nameInformation> } 
	')'

Used by:

!forFrame

Similar Keywords:

forFrameIndexDisplay forFrameIndexNameCaseSensitive forFrameIndexRef

Constraints:

1. The following constraint applies to this context: All contexts
For a given forFrame, the indexNameDef must not be the same as the indexNameDef of the forFrameIndex of any forFrame in which the given forFrame is enclosed, either directly or indirectly.
(See also similar constraint in: indexNameDef)

Description:

This specifies the sequence of integer values to be used for the index of a forFrame expansion. IndexNameDef defines the name of the index.

The default value for the index start value is zero. The default value for the index step value is one.

Example:

(forFrame F1 (repetitionCount 32)
   (forFrameIndex I (indexStart 1) (indexStep 2))
   (logicalConnectivity ...)
   )

In this example, the index starts from one and increases by two for each new element.

forFrameIndexRef

forFrameIndexRef ::= '(' 'forFrameIndexRef'
	indexNameRef
	')'

Used by:

integerExpression

Similar Keywords:

forFrame forFrameIndex forFrameIndexDisplay forFrameMemberRef forFrameRef frameRef

Description:

ForFrameIndexRef references a for frame index by name. It is used in integerExpression and returns the value of the for frame index referenced. It may only be used in the context of a for frame or its implementation.

Example:

(instanceNameGenerator
   (stringConcatenate
      (stringParameterRef instanceNameStem)
      (decimalToString 
         (integerSum 1
            (forFrameIndexRef J)))))

In this example, the name of the instance is created by concatenating the stringParameters instanceNameStem and the for frame index J, with 1 added and converted to a string.

forFrameMemberRef

forFrameMemberRef ::= '(' 'forFrameMemberRef'
	frameNameRef
	indexValue
	')'

Used by:

extendForFrameMemberDef

Similar Keywords:

forFrame forFrameIndexRef forFrameRef frameRef

Description:

ForFrameMemberRef references a member of a forFrame. The indexValue must be valid in the context of the expanded forFrame. It is only possible to reference a member of a forFrame in the context of an expanded occurrence hierarchy, when the value of the forFrame repetitionCount and forFrameIndex are known.

Example:

(forFrame F1
   (repetitionCount 4)
   (forFrameIndex INDEX1) ...)
...
(forFrameMemberRef F1 (indexValue 0))
...
(forFrameMemberRef F1 (indexValue 1))
...
(forFrameMemberRef F1 (indexValue 2))
...
(forFrameMemberRef F1 (indexValue 3))

In this first example, the indexValues shown are the only valid ones. 

(forFrame F1
   (repetitionCount 4)
   (forFrameIndex INDEX1
      (indexStart 10) (indexStep 2)) ...)
...
(forFrameMemberRef F1 (indexValue 10))
...
(forFrameMemberRef F1 (indexValue 12))
...
(forFrameMemberRef F1 (indexValue 14))
...
(forFrameMemberRef F1 (indexValue 16))

In this second example, the indexValues shown are the only valid ones.

globalPort

globalPort ::= '(' 'globalPort'
	globalPortNameDef
	{ comment | <nameInformation> | property | 
	<schematicGlobalPortAttributes> | userData } 
	')'

Used by:

*globalPortDefinitions

Similar Keywords:

globalPortBundle globalPortList globalPortNameCaseSensitive globalPortNameDisplay globalPortNameRef globalPortPropertyDisplay globalPortRef globalPortScope port schematicGlobalPortImplementation schematicGlobalPortImplementationRef schematicGlobalPortTemplate schematicGlobalPortTemplateRef

Description:

GlobalPort is used to define a global port. This is used to establish connectivity across instances within an instance hierarchy without passing signals through the ports of the cell clusters instanced in the hierarchy.

All signals in a branch of the design hierarchy which refer to the same globalPort are connected together. The branch of the design hierarchy is identified by globalPortScope. See globalPortScope.

The schematicGlobalPortAttributes construct adds descriptive information to the globalPort. The information specifies what kind of global signal the globalPort represents in the schematics. No connectivity is implied. For default connectivity, refer to defaultConnection.

Example:

(globalPort VCCA)
...
(library libA 
   (libraryHeader ...)
   (cell cellA
      ...
      (cluster C1 ...
         (schematicView view1 
            (schematicViewHeader ...)
            (logicalConnectivity ...
               (signal sigVCC 
                  (signalJoined
                     (globalPortRef VCCA) ... ))
               ...) 
            (schematicImplementation ...)) ...) ...)
   (cell cellB
      ...
      (cluster C1 (interface ...) ...
         (schematicView view1 
            (schematicViewHeader ...)
            (logicalConnectivity ...
               (instance inst1 
                  (clusterRef C1 
                     (cellRef cellA)))
               (instance inst2 
                  (clusterRef C1 
                     (cellRef cellA)))
               (signal sigVCC1 
                  (signalJoined 
                     (globalPortRef VCCA) ...))
               ...) 
            (schematicImplementation ...) ...) ...)
      ...) ...)

In this example, it is assumed that the design hierarchy begins at view V1 in cell B and that the instances inst1 and inst2 are expanded using view view1 of cell A.

The signals sigVCC in inst1 and in inst2 will both be connected to the signal sigVCC1 in view view1 of cell B.

globalPortBundle

globalPortBundle ::= '(' 'globalPortBundle'
	globalPortNameDef
	globalPortList
	{ comment | <nameInformation> | property | userData } 
	')'

Used by:

*globalPortDefinitions

Similar Keywords:

globalPort port portBundle

Description:

GlobalPortBundle defines a wide global port, in a manner analogous with portBundle.

The individual ports within the bundle, as listed in globalPortList, must have been defined previously. A globalPortBundle may include another globalPortBundle.

Example:

(globalPort VCC)
(globalPort GND)
(globalPortBundle power_and_ground
   (globalPortList 
      (globalPortRef VCC)
      (globalPortRef GND)))

In this example, a global port bundle power_and_ground with two previously-defined global ports, VCC and GND, is defined.

globalPortDefinitions

globalPortDefinitions ::= '(' 'globalPortDefinitions'
	{ globalPort | globalPortBundle } 
	')'

Used by:

<edifHeader

Similar Keywords:

port

Description:

GlobalPortDefinitions collects together all the definitions of global ports and global port bundles. These are defined once at the top of the file and may be referenced later in the file.

Example:

(globalPortDefinitions
   (globalPort VCC)
   (globalPort GND)
   (globalPortBundle POWER_AND_GROUND
      (globalPortList 
         (globalPortRef VCC)
         (globalPortRef GND))))

In this example, two global ports, VCC and GND, and a globalPortBundle POWER_AND_GROUND are declared.
