pcbLayerSide

pcbLayerSide ::= '(' 'pcbLayerSide'
	( pcbLayerSideTop | pcbLayerSideBottom )
	')'

Used by:

!pcbBareBoardCavity

Description:

Specifies whether an object is formed on the top side or bottom side of a layer.

Example:

(pcbBareBoardCavity BBCAV1
   (pcbPhysicalLayerRef LAYER2)
   (pcbLayerSide (pcbLayerSideTop)) ...)

In this example, the cavity is formed on the top side of layer LAYER2.

            (geometryElementSet
               (rectangle (pt 0 0) (pt 20 10)))))))

pcbLinearDimensionDirect

pcbLinearDimensionDirect ::= '(' 'pcbLinearDimensionDirect'
	{ <pcbDimensionProjectionLineAngle> } 
	')'

Used by:

pcbLinearDimensionType

Similar Keywords:

pcbDimension pcbDimensionChainedLinear pcbDimensionDatumLinear pcbDimensionSingleLinear pcbLinearDimensionHorizontal pcbLinearDimensionItem pcbLinearDimensionPrecision pcbLinearDimensionVertical

Constraints:

1. This construct is illegal in this context: pcbDimensionDatumLinear

2. This construct is illegal in this context: pcbDimensionChainedLinear

Description:

Specifies that the linear dimension is direct, as shown in the following diagram. For direct dimensions:

* Projection lines are either perpendicular to a line joining the dimension points, or if a projection line angle is specified, they are projected at the specified angle to the horizontal axis of the drawing.

* Dimension lines are parallel to a line joining the dimension points.

* The dimension value corresponds to the direct distance between dimension points.

Example:

(pcbDimensionSingleLinear
   (pcbDimensionedPointRef ...)
   (pcbLinearDimensionDirect) ...)

         (pcbDimensionPositiveTolerance (e 1 -1))
         (pcbDimensionNegativeTolerance (e 2 -1))

            (textHeight 12)))))

pcbLinearDimensionPrecision

pcbLinearDimensionPrecision ::= '(' 'pcbLinearDimensionPrecision'
	nonNegativeNumber
	')'

Used by:

<pcbLinearDimensionItem

Similar Keywords:

pcbDimension pcbDimensionAngularPrecision pcbDimensionChainedLinear pcbDimensionDatumLinear pcbDimensionSingleLinear pcbLinearDimensionDirect pcbLinearDimensionHorizontal pcbLinearDimensionType pcbLinearDimensionVertical

Description:

Indicates the rounding precision for display of a dimension. The number is in the current dimension distance units.

If the construct is absent, this means that no rounding should take place at all and the displayed dimension will be as calculated.

Example:

(pcbDimensionDistanceUnit (unitRef mm))
...
(pcbLinearDimensionPrecision (e 5 -1))

In this example, the dimension would be displayed to the nearest 0.5mm.

pcbMaterial

pcbMaterial ::= '(' 'pcbMaterial'
	libraryObjectNameDef
	pcbMaterialHeader
	electricalMaterialType
	pcbMaterialType
	')'

Used by:

*external *library

Similar Keywords:

pcbBondPadAttachmentMaterial pcbDiePassivationMaterial pcbDieSubstrateMaterial pcbDrillRulePlatingMaterial pcbIsMadeOfMaterial pcbMaterialList pcbMaterialRef pcbMaterialUnits pcbMaterialValue pcbNonStandardMaterial pcbPackageBodyMaterial pcbPackageBodyMaterialType pcbStandardMaterial

Description:

Defines a particular physical material in terms of its name and physical properties (e.g. electrical conductivity, thermal conductivity, density, etc.).

Each physical layer of the bare board is constructed from a particular material, and this has a set of properties that are inherited from that material. Many different physical layers constructed of the same material will thus have a common set of physical properties. A material object describes a material in terms of these properties.

Example:

(pcbMaterial Copper
   (pcbMaterialHeader ...)
   (conductiveMaterial)
   (pcbStandardMaterial))
