pcbMinimumAcidTrapAngle

pcbMinimumAcidTrapAngle ::= '(' 'pcbMinimumAcidTrapAngle'
	angleValue
	')'

Used by:

<pcbTechnologyRuleDetails

Description:

Specifies the minimum angle that must be formed by a trace when it enters a pad in order to avoid the formation of an acid trap. An acid trap is a place where acid can be trapped during the bare board manufacturing process.

Example:

(pcbBareBoardTechnologyRule BBT_RULES
   (pcbTechnologyRuleHeader ...)
   (pcbTechnologyRuleDetails
      (pcbMinimumAcidTrapAngle 20) ...))

pcbMirroredFabricateFigureCollector

pcbMirroredFabricateFigureCollector ::= '(' 'pcbMirroredFabricateFigureCollector'
	pcbFabricateFigureCollectorNameDef
	pcbInitialGeometricShapes
	mirroringAxis
	')'

Used by:

*pcbFigureCollectorDefinitions

Similar Keywords:

figure pcbDifferencedFabricateFigureCollector pcbFabricateFigure pcbFabricateFigureCollectorRef pcbIncludedFabricateFigureCollector pcbResizedFabricateFigureCollector pcbRotatedFabricateFigureCollector pcbSimpleFabricateFigureCollector pcbTranslatedFabricateFigureCollector pcbUnionedFabricateFigureCollector

Description:

Defines a figure collector by mirroring the geometry in pcbInitialGeometricShapes. MirroringAxis defines the axis of the mirroring operation.

Example:

(pcbMirroredFabricateFigureCollector U12
   (pcbFabricateFigureCollectorRef GG3)
   (mirroringAxis (pt 100 0) (pt 100 100)))
