yearNumber

yearNumber ::= integerToken

Used by:

!date *year

Similar Keywords:

number

Constraints:

1. Numeric constraints:
Minimum value: 1900 Maximum value: 3000

Description:

YearNumber represents the year part of a date, including the century, e.g. 1993.

yNumberValue

yNumberValue ::= numberValue

Used by:

!numberPoint

Similar Keywords:

number

Description:

A numberValue representing a y coordinate or distance along the y axis. This has the units defined by setDistance.

ySpacing

ySpacing ::= lengthValue

Used by:

!pcbLayoutGrid

Description:

Specifies the vertical spacing of a grid.

Example:

(pcbBareBoardTechnologyRule BBT_RULES
   (pcbTechnologyRuleHeader ...)
   (pcbTechnologyRuleDetails
      (pcbTraceGrid 
         (pcbLayoutGrid 10 15 (origin (pt 0 0)))) ...))

Here, the vertical spacing of grid points is 15 units.

yVariance

yVariance ::= lengthValue

Used by:

!XYTolerance

Description:

Specifies the accuracy to which items can be positioned in the y direction.

Example:

(pcbDiePhysicalTemplate die_temp_001V2
   (pcbDiePhysicalTemplateHeader
      (pcbLayoutUnits))
   (pcbDieSizeTolerance
      (XYTolerance 5 6)) ...)

In this example, the die-size tolerance is 5 units in the x axis and 6 units in the y axis.
