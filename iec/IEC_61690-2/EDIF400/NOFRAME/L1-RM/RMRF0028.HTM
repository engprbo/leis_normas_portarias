pcbDimensionChainedAngular

pcbDimensionChainedAngular ::= '(' 'pcbDimensionChainedAngular'
	pcbDimensionStartLine
	pcbAngularDimensionItemList
	pcbDimensionArrowGeometry
	')'

Used by:

pcbDimensionType

Similar Keywords:

pcbAngularDimensionItem pcbDimension pcbDimensionAngularPrecision pcbDimensionChainedLinear pcbDimensionDatumAngular pcbDimensionSingleAngular

Constraints:

1. The following constraint applies to this context: All contexts
Any two adjacent dimension lines or arcs with the same offset should both have pcbDimensionLineType equal to pcbDimensionLineInternal. This restriction does not apply to the first and last dimension lines or arcs.
(See also similar constraint in: pcbDimensionChainedLinear)

Description:

Defines a chained angular dimension; that is, a series of measurements of adjacent angles, where each angle is defined by a pair of pcbDimensionedLines. The pcbDimensionStartLine is a reference to the first such pcbDimensionedLine. Subsequent pcbDimensionedLines are referenced from within the pcbAngularDimensionItemList.

Note that a pcbDimensionedLine is not displayed in the drawing; it is a representation of a line that is to be involved in an angular dimension. As such, a pcbDimensionedLine might be a "shadow" of all or part of a line segment in an item defined in the PCB or MCM, or it might be a virtual line not otherwise visible.

All dimension arcs have the same arrow geometry on both ends.

The following diagram gives an example of a chained angular dimension, with the associated projection lines and dimension text.

Example:

The following EDIF describes the left-most angle in the above diagram. 

(pcbDimension Dim1
   (pcbDimensionHeader ...)
   (pcbDrawingAttributeDefaultRef Default_Attrs_1)
   (pcbDimensionChainedAngular
      (pcbDimensionedLineRef Line1
         (pcbBoardSubsetPlacementRef BSP1))
      (pcbAngularDimensionItemList
         (pcbAngularDimensionItem
            (pcbDimensionDrawingAttributeOverride)
            (pcbDimensionedLineRef Line2
               (pcbBoardSubsetPlacementRef BSP1))
            (pcbDimensionAngularPrecision
               (pcbDimensionAngularPrecisionDegrees 1))
            (pcbDimensionLineOffset 375)
            (pcbDimensionLineInternal)
            (pcbDimensionLineExtensionNone)
            (pcbTextAlignmentHorizontal)
            (pcbDimensionTextOffset (pt -30 10)))
         (pcbAngularDimensionItem ...))
      (pcbDimensionArrowGeometry
         (pcbDimensionEndGeometryRef TRIANGULAR))))

pcbDimensionChainedLinear

pcbDimensionChainedLinear ::= '(' 'pcbDimensionChainedLinear'
	pcbLinearDimensionStartPoint

Constraints:

1. The following constraint applies to this context: All contexts
Any two adjacent dimension lines or arcs with the same offset should both have pcbDimensionLineType equal to pcbDimensionLineInternal. This restriction does not apply to the first and last dimension lines or arcs.
(See also similar constraint in: pcbDimensionChainedAngular)

Description:

Defines a chained linear dimension; that is, a series of dimension lines between dimensioned points. The dimension lines are specified by pcbLinearDimensionItemList. All points are defined by pcbDimensionedPoints. The dimension value associated with each dimension line is measured from the previous dimensioned point (or for the first dimension value, from the start point).

All dimension lines have the same arrow geometry on both ends.

The following diagram gives examples of chained linear dimensions, with the associated projection lines and dimension text.

Example:

The following EDIF describes the left-most measure in either of the above diagrams. 

(pcbDimension Dim1
   (pcbDimensionHeader ...)
   (pcbDrawingAttributeDefaultRef Default_Attrs_1)
   (pcbDimensionChainedLinear
      (pcbDimensionedPointRef Point1
         (pcbBoardSubsetPlacementRef BSP1))
      (pcbLinearDimensionItemList
         (pcbLinearDimensionItem
            (pcbDimensionDrawingAttributeOverride)
            (pcbDimensionedPointRef ProbePoint26
               (pcbBoardSubsetPlacementRef BSP1))
            (pcbDimensionLineOffset -60)
            (pcbDimensionLineInternal)
            (pcbDimensionLineExtensionNone)
            (pcbTextAlignmentHorizontal)
            (pcbDimensionTextOffset (pt 0 10)))
         (pcbLinearDimensionItem ...)
         (pcbLinearDimensionItem ...))
      (pcbLinearDimensionHorizontal)
      (pcbDimensionArrowGeometry
         (pcbDimensionEndGeometryRef TRIANGULAR))))

pcbDimensionDatumAngular

pcbDimensionDatumAngular ::= '(' 'pcbDimensionDatumAngular'
	pcbDimensionStartLine
	pcbDimensionArcCenterPoint
	pcbAngularDimensionItemList
	pcbDimensionDatumStartGeometry
	pcbDimensionDatumEndGeometry
	( pcbDimensionDatumParallelAngular | 
	pcbDimensionDatumRunningAngular )
	{ <pcbDimensionFirstDatumStartGeometry> } 
	')'

Used by:

pcbDimensionType

Similar Keywords:

pcbAngularDimensionItem pcbDimension pcbDimensionAngularPrecision pcbDimensionChainedAngular pcbDimensionDatumLinear pcbDimensionSingleAngular

Constraints:

1. The following constraint applies to this context: All contexts
All dimension arcs for an angular dimension must be centered at the same point.

Description:

Defines a datum angular dimension; that is, a series of angular dimensions measured from a common start line to the end lines given by pcbAngularDimensionItemList. All lines are defined by pcbDimensionedLines.

The following diagram gives examples of datum angular dimensions, with the associated projection lines and dimension text.

Note that pcbDimensionDatumRunningAngular provides a way of specifying chained angular dimensions, and is intended to annotate a number of adjacent angles (where each angle is bounded by a pair of lines, and each line can be a bound for two adjacent angles).

Example:

(pcbDimension Dim1
   (pcbDimensionHeader ...)
   (pcbDrawingAttributeDefaultRef Default_Attrs_1)
   (pcbDimensionDatumAngular
      (pcbDimensionedLineRef Line1
         (pcbBoardSubsetPlacementRef BSP1))
      (pcbDimensionArcCenterPoint ...)
      (pcbAngularDimensionItemList
         (pcbAngularDimensionItem
            (pcbDimensionDrawingAttributeOverride)
            (pcbDimensionedLineRef Line2
               (pcbBoardSubsetPlacementRef BSP1))
            (pcbDimensionAngularPrecision
               (pcbDimensionAngularPrecisionDegrees 1))
            (pcbDimensionLineOffset 100)
            (pcbDimensionLineInternal)
            (pcbDimensionLineExtensionNone)
            (pcbTextAlignmentHorizontal)
            (pcbDimensionTextOffset (pt -30 10))
            (pcbTextEnclosure
               (pcbTextEnclosureBox))
            (pcbDimensionToleranceData 
               (pcbDimensionPositiveTolerance  (e 1 -1))
               (pcbDimensionNegativeTolerance (e 1 -1))
               (pcbDimensionToleranceNominalWithDeltas
                  (textHeight 12))))
         (pcbAngularDimensionItem ...))
      (pcbDimensionDatumStartGeometry
         (pcbDimensionEndGeometryRef CROSS))
      (pcbDimensionDatumEndGeometry
         (pcbDimensionEndGeometryRef CROSS))
      (pcbDimensionDatumRunningAngular
         (pcbDatumDimensionArcLengthList ...))
      (pcbDimensionFirstDatumStartGeometry ...)))

pcbDimensionDatumParallelAngular

pcbDimensionDatumParallelAngular ::= '(' 'pcbDimensionDatumParallelAngular'
	')'

Used by:

!pcbDimensionDatumAngular

Similar Keywords:

pcbDimension pcbDimensionDatumParallelLinear pcbDimensionDatumRunningAngular

Constraints:

1. The following constraint applies to this context: All contexts
All dimension arc offsets must be different.
(See also similar constraint in: pcbDimensionDatumParallelLinear)

Description:

A pcbDimensionDatumParallelAngular is a datum angular dimension in which all dimension arcs have different offsets (so they are parallel) and they are drawn full length between projection lines.

Note that pcbDimensionDatumParallelAngular provides a way of specifying datum angular dimensioning. The construct defines the annotation of a number of angles, where each annotated angle is bounded by a pair of lines, and where one of those lines is a common bound for every annotated angle. Parallel datum angular dimensioning is distinguished from running datum angular dimensioning by the fact that each of the dimension arcs generated for the annotation is offset from the angles' common center point by a different distance.

pcbDimensionDatumRunningAngular

pcbDimensionDatumRunningAngular ::= '(' 'pcbDimensionDatumRunningAngular'

	')'

1. The following constraint applies to this context: All contexts

(See also similar constraint in: pcbDimensionDatumRunningLinear)

2. The following constraint applies to this context: All contexts
All dimension arcs or lines must have pcbDimensionLineType equal to pcbDimensionLineInternal.

Description:

A pcbDimensionDatumRunningAngular is a datum angular dimension in which all dimension arcs have the same offset and they may or may not be drawn full length between projection lines.

Note that pcbDimensionDatumRunningAngular provides a way of specifying datum angular dimensioning. The construct defines the annotation of a number of angles, where each annotated angle is bounded by a pair of lines, and where one of those lines is a common bound for every annotated angle. Running datum angular dimensioning is distinguished from parallel datum angular dimensioning by the fact that all of the dimension arcs generated for the annotation are offset from the angles' common center point by the same distance.

pcbDimensionedArc

pcbDimensionedArc ::= '(' 'pcbDimensionedArc'

	arcByCenter
	{ <pcbDimensionedObjectSet> } 
	')'

Used by:

*pcbBoardSubsetDefinition *pcbBoardSubsetExtraDetail

Similar Keywords:

arc pcbDimensionedArcRef

Description:

Defines a hook for a pcbDimensionCircularRadial dimension to refer to. In this context, the pcbDimensionedArc defines the arc being measured.

ArcByCenter is not required to correspond to any real feature referenced in the pcbDimensionedObjectSet. For example, it may be an imaginary arc implied by the existence of two or more real features, or it may be that the system generating the EDIF description does not know the association of the dimensioned arc with any real features in the design.

Example:

(pcbDimensionedArc DimArc1
   (arcByCenter (pt 5 15) (pt 10 15) (pt 15 15) 
      (arcDirectionClockwise (false)))
   (pcbDimensionedObjectSet
      (pcbDimensionedObjectBareBoardOutline)))
