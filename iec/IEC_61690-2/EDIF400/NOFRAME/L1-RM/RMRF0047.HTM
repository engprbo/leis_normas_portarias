pcbPackageShape

pcbPackageShape ::= '(' 'pcbPackageShape'
	pcbPackageBodyProfile
	')'

Used by:

<pcbBallPackage <pcbPinPackage

Similar Keywords:

pcbPackageOutlineSpecialShape shape

Constraints:

1. This construct is illegal in this context: external

Description:

Summarises the shape of the body of the package, as viewed from the side. This provides a pointer to the appropriate JEDEC JESD30-A standard.

PcbPackageBodyProfile does not necessarily define the exact profile; it may be an approximation. The exact profile can be derived from the extrusionVolumes specified in bodyVolume.

Example:

(pcbPinPackage DIL14 ...
   (bodyVolume
      (extrusionVolume
         (rectangle (pt 0 50) (pt 800 300))
         (offsetDistance 150)
         (extrusionLength 175))) 
   (pcbPackageShape 
      (pcbRectangularBodyProfile)) ...)

Constraints:

1. The following constraint applies to this context: All contexts
If pcbFabricateFigure appears, it must contribute positively to at least one physical layer.
(See also similar constraint in: pcbNonSpecificLayoutShape, pcbTrace)

2. The following constraint applies to this context: All contexts
If only pcbClearanceGeometry appears, then it must clear from at least one physical layer.
(See also similar constraint in: pcbNonSpecificLayoutShape, pcbTrace)

3. The following constraint applies to this context: All contexts

(See also similar constraint in: pcbNonSpecificLayoutShape, pcbTrace)

Description:

Defines a feature on the bare board that has a simple geometrical shape. It is is applied using real material, or is cut out of other material that has already been applied to the bare board, or both.

A pad object typically describes part of a padstack. Such objects are recognised and manipulated with CAD systems.

A pad object is able to describe the presence of conductive material on a particular conducting layer of the bare board within a particular padstack, or the absence of conducting material on a conducting (power plane) layer. Such an object might also be used to construct geometry in non-conducting layers of the board.

Example:

(pcbLayoutFeature PAD1
   (pcbPad
      (pcbPadIntendedUse (pcbPadIntendedUseConnectionNegative))
      (pcbFabricateFigure
         (pcbContributesToFabrication
            (pcbSimpleFabricateFigureCollectorRef 
               FC1))
         (pcbPhysicalFigure SIGNALS
            (geometryElementSet
               (rectangle (pt 50 50) (pt 60 55)))))
      (pcbClearanceGeometry)))

Description:

Indicates that a pad is intended to be used to make a connection between, for example, a via or pin and a surrounding plane. Typically such a pad is used to create what is known as a thermal relief pad, and some clearance geometry would be specified.

Example:

(pcbLayoutFeature PAD1
   (pcbPad
      (pcbPadIntendedUse (pcbPadIntendedUseConnectionNegative))
      (pcbFabricateFigure
         (pcbContributesToFabrication
            (pcbSimpleFabricateFigureCollectorRef 
               FC1))
         (pcbPhysicalFigure PADS
            (geometryElementSet
               (openshape
                  (curve (arcByCenter (pt 20 100) (pt 0 0) (pt 100 20))))
               (openshape
                  (curve (arcByCenter (pt 100 -20) (pt 0 0) (pt 20 -100))))
               (openshape
                  (curve (arcByCenter (pt -20 -100) (pt 0 0) (pt -100 -20))))
               (openshape
                  (curve (arcByCenter (pt -100 20) (pt 0 0) (pt -20 100)))))))
      (pcbClearanceGeometry ...)))

This example specifies a simple rectangle as the graphics of a pad intended for connection to a surrounding plane.

pcbPadstackDefinition ::= '(' 'pcbPadstackDefinition'
	libraryObjectNameDef
	pcbSubLayoutDefinitionHeader

Constraints:

1. The following constraint applies to this context: All contexts
When a pcbBareBoardDefinition or a sublayout definition instances a sublayout, that sublayout must have the same bare board technology as the instantiating object.
(See also similar constraint in: pcbBareBoardDefinition, pcbFootprintDefinition, pcbFootprintInstance, pcbNonSpecificSubLayoutDefinition, pcbNonSpecificSubLayoutInstance, pcbPadstackInstance, pcbTestCouponDefinition, pcbTestCouponInstance, pcbToeprintDefinition, pcbToeprintInstance)

2. The following constraint applies to this context: All contexts
A pcbPadstackDefinition must contain at least one pcbPad within a pcbLayoutFeature.

Description:

Defines a padstack. A padstack object describes a feature of a bare board that primarily provides for vertical connection between the conducting layers of the bare board. A padstack is usually a collection of pads on many different physical layers, and often has a plated-through hole passing through the pads.

A padstack definition describes an equipotential padstack if it owns precisely one physical net.

Example:

(pcbPadstackDefinition THRU_4LAYERS
   (pcbSubLayoutDefinitionHeader ...)
   (pcbPhysicalNet ONLYONE ...
      (pcbLayoutFeature L1_PAD
         (pcbPad ...))
      (pcbLayoutFeature L2_PAD
         (pcbPad ...))
      (pcbLayoutFeature L3_PAD
         (pcbPad ...))
      (pcbLayoutFeature L4_PAD
         (pcbPad ...))
      (pcbLayoutFeature THRU_HOLE
         (pcbConformantHole
            (pcbHoleCrossSection
               (circleByCenter (pt 0 0) 71120))
            (pcbDrillRuleRef DR1)
            (pcbPlatedThroughHole)))))
