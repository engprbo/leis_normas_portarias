pcbShortingNet

pcbShortingNet ::= '(' 'pcbShortingNet'
	pcbAssembledPhysicalNetNameDef
	pcbAssembledPhysicalNetHeader
	pcbComponentSignalSet
	pcbComponentTerminalJoined
	{ <pcbInstanceNets> | <pcbJoinedJumperComponent> | 
	pcbJumperConnection } 
	')'

Used by:

*pcbAnalyzedAssembledPhysicalNets

Constraints:

1. The following constraint applies to this context: All contexts
A pcbComponentSignal may be implemented by one and only one of the following combinations: 1. By zero, one or more pcbNonAnalyzedAssembledPhysicalNets, 2. By exactly one pcbCorrectNet, 3. By zero, one or more pcbIncorrectNet, 4. By zero, one or more pcbShortingNet.
(See also similar constraint in: pcbCorrectNet, pcbIncorrectNet, pcbNonAnalyzedAssembledPhysicalNets)

2. The following constraint applies to this context: All contexts
In a pcbShortingNet any component terminals which are specified as being joined should be part of a pcbComponentSignal which is in the pcbComponentSignalSet.

3. The following constraint applies to this context: All contexts
In a pcbShortingNet each pcbComponentSignal referenced in the pcbComponentSignalSet must have at least one component terminal in the set of terminals joined by the physical net.

Description:

Describes an assembled physical net whose connectivity has been checked by the sending system, and has been found to short two or more signals. Therefore a pcbShortingNet represents an assembled physical net that has been checked by an analysis process and found to be shorting together the conductive material that implements one or more component signals, and possibly other conductive material that implements no component signal (e.g. shielding).

PcbComponentSignalSet specifies the signals that are shorted. Each signal must have at least one terminal that is joined by the assembled physical net.

PcbComponentTerminalJoined specifies the component terminals that are connected together by the assembled physical net. This may not necessarily include all of the terminals referenced in the set of signals.

An assembled physical net can only include instance nets that are on the bare board that the assembled board is based upon.

Example:

(pcbShortingNet NET_FOR_SIG1/2
   (pcbAssembledPhysicalNetHeader)
   (pcbComponentSignalSet
      (pcbComponentSignalRef SIG1)
      (pcbComponentSignalRef SIG2))
   (pcbComponentTerminalJoined ...)
   (pcbInstanceNets
      (pcbSubLayoutInstancePhysicalNetRef 
         NET1 (pcbSubLayoutInstanceRef BB))
      (pcbSubLayoutInstancePhysicalNetRef 
         NET2 (pcbSubLayoutInstanceRef BB))
      (pcbSubLayoutInstancePhysicalNetRef
         NET3 (pcbSubLayoutInstanceRef BB))))

In this example, SIG1 and SIG2 are shorted. On the assembled board, physical nets NET1, NET2 and NET3 are all connected together.

pcbSwapGroup

pcbSwapGroup ::= '(' 'pcbSwapGroup'
	pcbSwapGroupNameDef
	{ instanceRef | <nameInformation> | property } 
	')'

Used by:

*pcbMcmImplementation

Similar Keywords:

pcbSwapGroupNameCaseSensitive

Constraints:

1. The following constraint applies to this context: All contexts
An instance can be referenced at most once within the set of pcbSwapGroup constructs within a pcbMcmImplementation.

2. The following constraint applies to this context: All contexts
There must be at least one instanceRef within a pcbSwapGroup construct.

3. This construct is illegal in this context: external

Description:

PcbSwapGroup groups together a number of instances in the logical connectivity. An instance within this group can only have its allocation to a component swapped with an instance in the same group.

An instance that belongs to no swap group actually belongs to a universal swap group. It can be swapped only with another instance that is not in a swap group.

An instance cannot belong to more than one swap group.

A swap group is normally restricted to collecting instances that are all defined by the same function definition.

Example:

(pcbSwapGroup SG1
   (InstanceRef I1)
   (InstanceRef I2)
   (InstanceRef I3))
