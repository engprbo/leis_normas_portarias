pcbPrintedElectricalComponent

pcbPrintedElectricalComponent ::= '(' 'pcbPrintedElectricalComponent'
	pcbComponentNameDef
	pcbPrintedElectricalPartRef
	pcbComponentHeader
	{ pcbComponentFunctionAllocation } 
	')'

Used by:

*pcbMcmImplementation

Similar Keywords:

pcbDieElectricalComponent pcbPackagedElectricalComponent pcbPrintedConnectorComponent pcbPrintedElectricalComponentImplementation pcbPrintedElectricalComponentRef pcbPrintedElectricalComponentTerminalImplementation pcbPrintedElectricalPart

Constraints:

1. The following constraint applies to this context: All contexts
The number of pcbComponentFunctionAllocation constructs within an electrical component which instantiates a fully-defined part, must be equal to the number of pcbElectricalPartFunctions within that part.
(See also similar constraint in: pcbComponentFunctionAllocation, pcbDieElectricalComponent, pcbPackagedElectricalComponent)

2. The following constraint applies to this context: All contexts
No pcbElectricalPartFunction may be referenced more than once by any pcbComponentFunctionAllocation constructs within a component.
(See also similar constraint in: pcbComponentFunctionAllocation, pcbDieElectricalComponent, pcbElectricalPartFunction, pcbPackagedElectricalComponent)

3. This construct is illegal in this context: external

Description:

Defines a printed electrical component; that is, an instance of a printed electrical part, such as a paste resistor. Printed components are printed as a section of the bare board.

PcbComponentFunctionAllocation can specify how an instance in the logical connectivity is allocated (i.e. mapped) to a function within the component.

Example:

(pcbPrintedElectricalComponent I1_PASTE10K
   (pcbPrintedElectricalPartRef PASTE10K)
   (pcbComponentHeader ...)
   (pcbComponentFunctionAllocation ...) ...)

Here, the component I1_PASTE10K is defined. It is an instance of the part PASTE10K.

pcbPrintedElectricalPartFullyDefined

pcbPrintedElectricalPartFullyDefined ::= '(' 'pcbPrintedElectricalPartFullyDefined'
	{ pcbElectricalPartFunction | pcbElectricalPartFunctionPermutable | 
	pcbPrintedElectricalPartTerminal } 
	')'

Used by:

pcbPrintedElectricalPartType

Similar Keywords:

pcbDieElectricalPartFullyDefined pcbPackagedElectricalPartFullyDefined pcbPrintedElectricalPart pcbPrintedElectricalPartMinimallyDefined

Description:

A fully-defined printed electrical part includes the connectivity of the individual functions within the part and the permutability (i.e. swappability) of those functions.

Example:

(pcbPrintedElectricalPart PRINTED_RES
   (pcbPartHeader ...)
   (pcbPrintedElectricalPartFullyDefined
      (pcbElectricalPartFunction A
         (clusterRef BASIC (cellRef R10K)))
      (pcbPrintedElectricalPartTerminal T1
         (pcbElectricalPartTerminalHeader)
         (pcbElectricalPartTerminalConnectedPortSet 
            (pcbElectricalPartFunctionPortRef a
               (pcbElectricalPartFunctionRef A))))
      (pcbPrintedElectricalPartTerminal T2
         (pcbElectricalPartTerminalHeader)
         (pcbElectricalPartTerminalConnectedPortSet 
            (pcbElectricalPartFunctionPortRef b 
               (pcbElectricalPartFunctionRef A))))))

For more examples of permutability, see pcbPackagedElectricalPart and pcbPackagedElectricalPartMinimallyDefined.

      (pcbElectricalTerminalPermutable
         (pcbElectricalPartTerminalRef T1)
         (pcbElectricalPartTerminalRef T2))))

For more examples of permutability, see pcbPackagedElectricalPart and pcbPackagedElectricalPartMinimallyDefined.

pcbRightReadable

pcbRightReadable ::= '(' 'pcbRightReadable'
	booleanToken
	')'

Used by:

<pcbDimensionDrawingAttributeOverride <pcbDrawingAttributeDefault <pcbDrawingTextDrawingAttributeOverride <pcbGeometricAttributeDefault <pcbTextAttributeOverride

Description:

Specifies that the text in fonted text is to be right readable.

PcbRightReadable forces all text that is not "readable" to be displayed as if it had its orientation and justification changed (and such that it occupies the same physical space, but becomes readable). Text is readable if its orientation is between 270 and 360 degrees, or 0 and 90 degrees. If an item of text has an orientation between 90 and 270 degrees, then to make it readable, it would be drawn as if 180 degrees had been added to its orientation and its justification had been set to the opposite of its actual value. For example:

Example:

(pcbTextAttributeOverride
   (pcbGapWidth 10)
   (pcbLineSpacing 50)
   (pcbStrokeWidth 2)
   (pcbSpaceWidth 20)
   (pcbRightReadable (true)))
