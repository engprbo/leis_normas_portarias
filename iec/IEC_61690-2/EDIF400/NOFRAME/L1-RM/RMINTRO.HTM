1 INTRODUCTION TO LEVEL 1 REFERENCE MANUAL

The structure of the Level 1 Reference Manual is similar to that of Level 0. However the introductory sections are not repeated and reference should be made to the Level 0 sections for details of how the hyperlinks are set up and for an introduction to the syntax and structure of EDIF.

The Reference section and the Permuted Index for Level 1 include Level 1 keywords as well as all Level 0 keywords.

You should refer to the Introduction to Level 1 in the Information Model section for a description of the new concepts introduced at Level 1.

In the printed version, the Reference Section shows only those keywords that have been added for Level 1 and those keywords where constraints have added, removed or modified. When a keyword appears because its constraints have been changed, no description or example is given. Other keywords are as in Level 0 except of course for changes to the syntax in some keywords.
