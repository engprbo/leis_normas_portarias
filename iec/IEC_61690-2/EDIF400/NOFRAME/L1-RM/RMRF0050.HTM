pcbPinPackage

	libraryObjectNameDef

Description:

Describes a package .

A pcbPinPackage defines the mechanical container for a part that has pins for connection. Several parts can refer to the same package. For example, many different parts may make use of the same 14-pin ceramic dual-in-line (DIL) package.

The JEDEC JESD30-A standard acronym for a package can be formed by using the values of the following: pcbPackageShape, pcbPackageBodyMaterial, pcbPackageOutlineStyle, pcbPackagePinArrangement, pcbPackagePinForm, jedecDetailedInformation and from the number of pins.

Many items of information specified within pcbPinPackage can be overridden by pcbMountablePinPackage, which describes a way of mounting the package on a board. The actual specification of how an instance of a package is mounted on the assembled board is specified by the packaged component implementation, which references a mountable package.

Example:

(pcbPinPackage DIP14
   (pcbPackageHeader ...)
   (bodyVolume ...)
   (occupiedSpace ...)
   (pcbPackageBodyMaterial (plasticMaterial))
   (pcbPackageOutlineStyle 
      (pcbPackageOutlineInLinePackage))
   (pcbPackagePinForm 
      (pcbPackagePinFormThroughHole))
   (pcbPackagePinArrangement (pcbPinPositionDual))
   (pcbPackageShape (pcbRectangularBodyProfile))
   (pcbPackagePinPitch 100)
   (pcbPackagePinGroup PG1
      (pcbPackagePinGroupPins
         (pcbPackageTerminalPinRef T1)
         (pcbPackageTerminalPinRef T2)
         ...
         (pcbPackageTerminalPinRef T14))))

This example describes a plastic 14-pin DIL package.

pcbPlane

pcbPlane ::= '(' 'pcbPlane'
	pcbPlaneNameDef
	pcbPlaneOutline
	pcbFabricateFigureCollectorRef
	{ <nameInformation> | property } 
	')'

Used by:

*pcbBareBoardPhysicalNet

Similar Keywords:

pcbPlaneNameCaseSensitive pcbPlaneNameRef pcbPlaneRef

Constraints:

1. This construct is illegal in this context: external

Description:

Defines a region of a bare board that is to be plated with conductive material in order to provide connection of other artefacts to power, ground or a commonly-used signal.

PcbPlaneOutline defines the outline of the plane and the figure collector that the outline is assigned to. Some areas within this outline may need to be removed to provide isolation areas, etc. The operations needed to create the final plane artwork are specified by the definition of the figure collector referenced by pcbFabricateFigureCollectorRef.

The outline figure collector to be used, directly or indirectly, in the definition of pcbFabricateFigureCollectorRef.

Example:

(pcbPlane GND_PLANE
   (pcbFabricateFigure
      (pcbContributesToFabrication
         (pcbSimpleFabricateFigureCollectorRef 
            FC3_A))
      (pcbPhysicalFigure OTHER_NETS
         (geometryElementSet
            (polygon
               (pointList
                  (pt -2286000 10414000)
                  (pt -2286000 11430000)
                  (pt -10922000 11430000)
                  (pt -10922000 508000)
                  (pt -2286000 508000)
                  (pt -2286000 1524000)
                  (pt -1524000 1524000)
                  (pt -1524000 10414000))))))
   (pcbFabricateFigureCollectorRef FC3))
