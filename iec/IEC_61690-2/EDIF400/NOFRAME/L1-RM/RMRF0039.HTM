pcbMaterialType

pcbMaterialType ::= ( pcbStandardMaterial | pcbNonStandardMaterial )

Used by:

!pcbMaterial

Similar Keywords:

pcbPackageBodyMaterialType

Description:

Specifies whether the material is defined elsewhere (pcbStandardMaterial), perhaps in a dictionary of standard materials, or at least partially within the EDIF data (pcbNonStandardMaterial).

Example:

(pcbMaterial Copper
   (pcbMaterialHeader ...)
   (conductiveMaterial)
   (pcbStandardMaterial))

pcbMcmImplementation

pcbMcmImplementation ::= '(' 'pcbMcmImplementation'
	{ comment | <pcbAssembledBoard> | pcbComponentSignal | 
	pcbDieElectricalComponent | pcbJumperComponent | 
	pcbMechanicalComponent | pcbPackagedConnectorComponent | 
	pcbPackagedElectricalComponent | pcbPrintedConnectorComponent | 
	pcbPrintedElectricalComponent | pcbSwapGroup | userData } 
	')'

Used by:

!pcbMcmView

Description:

Describes a specific PCB and/or MCM implementation. It specifies the components that are used on the bare board and how the component terminals are connected together. Components are instances of parts.

PcbAssembledBoard can specify details of the bare board (tracks, component footprints, etc.) and how and where on the bare board the components are to be placed.

PcbSwapGroup describes a restriction rule when swapping the instance-to-function allocations.

Example:

(pcbMcmImplementation
   (pcbPackagedElectricalComponent ...)
   (pcbMechanicalComponent ...)
   (pcbComponentSignal ...)
   (pcbAssembledBoard ...))

pcbMechanicalComponent

pcbMechanicalComponent ::= '(' 'pcbMechanicalComponent'
	pcbComponentNameDef
	pcbMechanicalPartRef
	pcbComponentHeader
	')'

Used by:

*pcbMcmImplementation

Similar Keywords:

pcbAuxiliaryComponentMechanical pcbMechanicalComponentImplementation pcbMechanicalComponentRef

Constraints:

1. This construct is illegal in this context: external

Description:

Defines a mechanical component; that is, an instance of a mechanical part. Mechanical components have no intentional electrical functionality.

Example:

(pcbMechanicalComponent I1_CLIPT21
   (pcbMechanicalPartRef CLIPT21)
   (pcbComponentHeader ...))

Here, the component I1_CLIPT21 is defined. It is an instance of the part CLIPT21.

pcbMechanicalComponentImplementation

pcbMechanicalComponentImplementation ::= '(' 'pcbMechanicalComponentImplementation'
	pcbComponentImplementationNameDef
	pcbMechanicalComponentRef
	pcbMountablePackageRef
	unscaledTransform
	pcbFootprintInstanceRef
	{ <pcbComponentPropertyFabrication> | 
	<pcbDesignatorFabricationOverride> | <pcbDrawingInformation> | 
	pcbMountableMechanicalFixingImplementation | 
	<pcbMountablePackagePropertyFabrication> | 
	<pcbMountablePackagePropertyOverride> | 
	pcbMountablePackageTerminalImplementation | 
	<pcbPackagePropertyFabrication> | <pcbPartPropertyFabrication> } 
	')'

Used by:

*pcbAssembledBoard

Similar Keywords:

pcbAuxiliaryComponentMechanical pcbComponentImplementationRef pcbDieComponentImplementation pcbEmbeddedComponentImplementation pcbJumperComponentImplementation pcbMechanicalComponent

Description:

Defines how the mechanical component referenced by pcbMechanicalComponentRef is mounted onto the bare board.

PcbMountablePackageRef specifies the mountable package that is used when mounting the component on the bare board.

UnscaledTransform specifies the position of the component on the bare board.

PcbFootprintInstanceRef specifies the footprint on which the component is placed.

Example:

(pcbMechanicalComponentImplementation CI1
   (pcbMechanicalComponentRef COMP2)
   (pcbMountablePackageRef DIP_Dip_Bottom
      (libraryRef MOUNTABLE_PACKAGES))
   (unscaledTransform ...)
   (pcbFootprintInstanceRef FOOTP21))

pcbMetalArtifactToCavitySpacing

pcbMetalArtifactToCavitySpacing ::= '(' 'pcbMetalArtifactToCavitySpacing'
	tolerancedDistanceValue
	')'

Used by:

<pcbBareBoardTechnologyRule

Similar Keywords:

pcbCavityToCavitySpacing

Description:

Specifies the allowable spacing between a metal artifact (e.g. a trace or pad) on the layer and a cavity. This constraint applies only to metal artifacts on the layer surface, and where the metal artifacts do not enter the cavity.

This is a constraint for embedded die technology. See pcbBareBoardTechnologyRule for a diagrammatic representation.

Example:

(pcbBareBoardTechnologyRule BBTR
   (pcbTechnologyRuleHeader ...)
   (pcbTechnologyRuleDetails ...)
   (pcbMetalArtifactToCavitySpacing
      (mnm 1000 (undefined) (unconstrained))) ...)
