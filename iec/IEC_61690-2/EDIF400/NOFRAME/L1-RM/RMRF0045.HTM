pcbPackagedElectricalPartTerminal

pcbPackagedElectricalPartTerminal ::= '(' 'pcbPackagedElectricalPartTerminal'
	pcbElectricalPartTerminalNameDef
	pcbElectricalPartTerminalHeader
	{ <pcbConnectedPackageTerminal> | 
	<pcbElectricalPartTerminalConnectedPortSet> } 
	')'

Used by:

*pcbPackagedElectricalPartFullyDefined *pcbPackagedElectricalPartMinimallyDefined

Similar Keywords:

pcbDieElectricalPartTerminal pcbElectricalPartTerminalRef pcbPackagedConnectorPartTerminal pcbPackagedElectricalPart pcbPackagedElectricalPartRef pcbPackagedElectricalPartType pcbPrintedElectricalPartTerminal

Description:

Provides the electrical information about one of the terminals on a packaged electrical part and also references the corresponding pin on its package.

Example:

(pcbPackagedElectricalPartTerminal T1
   (pcbElectricalPartTerminalHeader)
   (pcbConnectedPackageTerminal
      (pcbPackageTerminalPinRef P1))
   (pcbElectricalPartTerminalConnectedPortSet 
      (pcbElectricalPartFunctionPortRef a 
         (pcbElectricalPartFunctionRef A))))

Here, the terminal T1 is defined. This corresponds to pin P1 in the part's package. The terminal is connected to the port a of function A.

pcbPackagedElectricalPartType

pcbPackagedElectricalPartType ::= ( pcbPackagedElectricalPartFullyDefined | 
	pcbPackagedElectricalPartMinimallyDefined )

Used by:

!pcbPackagedElectricalPart

Similar Keywords:

pcbDieElectricalPartType pcbPackagedElectricalPartRef pcbPackagedElectricalPartTerminal pcbPrintedElectricalPartType

Description:

Defines whether the packaged electrical part is fully defined or minimally defined. A fully-defined part includes the connectivity of the individual functions within the part and the permutability (i.e. swappability) of those functions. A minimally-defined part does not include this information; instead, it defines the permutability of the part terminals.

pcbPackageHeader

pcbPackageHeader ::= '(' 'pcbPackageHeader'
	pcbLayoutUnits
	{ documentation | <nameInformation> | <pcbPackagePreviousVersion> | 
	property | <status> } 
	')'

Used by:

!pcbBallPackage !pcbMechanicalPackage !pcbPinPackage

Similar Keywords:

pcbMountablePackageHeader pcbMountablePackageTerminalHeader

Description:

Gathers together data relating to the package as a whole, including an optional reference to the previous version of the package.

Example:

(pcbPinPackage DIP14
   (pcbPackageHeader 
      (pcbLayoutUnits ...)
      (pcbPackagePreviousVersion 
         (pcbPinPackageRef OLD_DIP14))) ...)

pcbPackageOutlineStyle

pcbPackageOutlineStyle ::= '(' 'pcbPackageOutlineStyle'
	pcbPackageOutlineStyleType
	')'

Used by:

<pcbPinPackage

Similar Keywords:

pcbPackageOutlineCylinder pcbPackageOutlineFlatpack pcbPackageOutlineMicrowave pcbPackageOutlineSmallOutline

Constraints:

1. This construct is illegal in this context: external

Description:

Defines the style of the package outline. This provides a pointer to the appropriate JEDEC JESD30-A standard. PcbPackageOutlineStyle does not define any physical dimensions; it merely indicates the style of package used.

Example:

(pcbPinPackage DIL14 ...
   (pcbPackageOutlineStyle
      (pcbPackageOutlineInLinePackage)) ...)
