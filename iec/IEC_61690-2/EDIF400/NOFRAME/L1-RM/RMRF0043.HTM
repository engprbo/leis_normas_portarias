pcbMountableTerminalRepresentation

pcbMountableTerminalRepresentation ::= '(' 'pcbMountableTerminalRepresentation'
	pcbMountablePackageTerminalNameRef
	pcbPackageTerminalDrawingTemplateRef
	fixedScaleTransform
	{ pcbMountablePackageTerminalPropertyDrawing } 
	')'

Used by:

*pcbMountablePackageSymbol

Description:

Gives a representation of a mountable terminal in a mountable package symbol.

The template type should be consistent with the terminal type. If the terminal is an prepared mountable pin or an mountable solder ball, the template type must be for a prepared pin or unrestricted. If the terminal is an extra mountable pin, the template type must be for an extra terminal or unrestricted.

Example:

(pcbMountableTerminalRepresentation P1
   (pcbPackageTerminalDrawingTemplateRef Template1)
   (fixedScaleTransform ...)
   (pcbMountablePackageTerminalPropertyDrawing
      (pcbPropertyDrawing ...)))

pcbNonAnalyzedAssembledPhysicalNets

pcbNonAnalyzedAssembledPhysicalNets ::= '(' 'pcbNonAnalyzedAssembledPhysicalNets'
	{ pcbNonAnalyzedNet } 
	')'

Used by:

!pcbAssembledPhysicalNets

Similar Keywords:

pcbAnalyzedAssembledPhysicalNets

Constraints:

1. The following constraint applies to this context: All contexts
A pcbComponentSignal may be implemented by one and only one of the following combinations: 1. By zero, one or more pcbNonAnalyzedAssembledPhysicalNets, 2. By exactly one pcbCorrectNet, 3. By zero, one or more pcbIncorrectNet, 4. By zero, one or more pcbShortingNet.
(See also similar constraint in: pcbCorrectNet, pcbIncorrectNet, pcbShortingNet)

Description:

Describes assembled physical nets whose connectivity have not been checked against the netlists defined by the specified signals.

Example:

(pcbNonAnalyzedAssembledPhysicalNets
   (pcbNonAnalyzedNet NET_FOR_SIG1
      (pcbAssembledPhysicalNetHeader)
      (pcbComponentSignalRef SIG1)
      (pcbComponentTerminalJoined ...)
      (pcbInstanceNets
         (pcbSubLayoutInstancePhysicalNetRef 
            NET1 (pcbSubLayoutInstanceRef BB))
         (pcbSubLayoutInstancePhysicalNetRef
            NET2 (pcbSubLayoutInstanceRef BB)))
      (pcbJumperConnection JUMPER1
         (pcbJumperConnectionHeader)
         (pcbJumperConnectionDiscreteWire
            (pcbJumperConnectionDiscreteWireConnectionPoints
               (pcbPadstackInstanceRef JPAD1)
               (pcbPadstackInstanceRef JPAD2)))) ...) ...)

In this example, the connectivity defined by SIG1 is implemented by NET1, NET2 and a jumper, JUMPER1. JUMPER1 could be the physical mechanism that is used to join the two physical nets together.

pcbNonAnalyzedNet

pcbNonAnalyzedNet ::= '(' 'pcbNonAnalyzedNet'
	pcbAssembledPhysicalNetNameDef
	pcbAssembledPhysicalNetHeader
	( pcbComponentSignalRef | pcbNoComponentSignal )
	pcbComponentTerminalJoined
	{ <pcbInstanceNets> | <pcbJoinedJumperComponent> | 
	pcbJumperConnection } 
	')'

Used by:

*pcbNonAnalyzedAssembledPhysicalNets

Description:

Describes an assembled physical net whose connectivity has not been checked against the netlist defined by the specified signal.

PcbComponentTerminalJoined specifies the component terminals that are connected together by the assembled physical net.

An assembled physical net can only include instance nets that are on the bare board that the assembled board is based upon.

See pcbNonAnalyzedAssembledPhysicalNets for an example.

pcbNonSpecificLayoutShape

pcbNonSpecificLayoutShape ::= '(' 'pcbNonSpecificLayoutShape'
	{ <pcbClearanceGeometry> | <pcbFabricateFigure> } 
	')'

Used by:

pcbLayoutFeatureType

Similar Keywords:

pcbNonSpecificLayoutShapeClass shape

Constraints:

1. The following constraint applies to this context: All contexts
If pcbFabricateFigure appears, it must contribute positively to at least one physical layer.
(See also similar constraint in: pcbPad, pcbTrace)

2. The following constraint applies to this context: All contexts
If only pcbClearanceGeometry appears, then it must clear from at least one physical layer.
(See also similar constraint in: pcbPad, pcbTrace)

3. The following constraint applies to this context: All contexts
If both pcbFabricateFigure and pcbClearanceGeometry exist, then the pcbClearanceGeometry must clear from at least one physical layer to which the pcbFabricateFigure contributes.
(See also similar constraint in: pcbPad, pcbTrace)

Description:

Defines a feature on the bare board (or elsewhere) which is applied using real material, or is cut out of other material that has already been applied to the bare board, or both.

The feature is used to describe features on the bare board that are more complex than traces and that are not (in general) manipulated by automatic routers.

Example:

(pcbLayoutFeature LF1
   (pcbNonSpecificLayoutShape
      (pcbFabricateFigure
         (pcbContributesToFabrication
            (pcbSimpleFabricateFigureCollectorRef 
               FC1))
         (pcbPhysicalFigure SIGNALS
            (geometryElementSet
               (rectangle (pt 0 50) (pt 800 300)))))
      (pcbClearanceGeometry)))
