INSTRUCTIONS & ADVICE ON PDF USE

We have included these PDF files to help you use the International Standard IEC 62386-209. They contain the diagrams from the standard's test sequences. 

- The file names are made up of the subclause number and title from the standard; for instance, you can find the diagram from subclause 12.7.2.6.19 with the title 'Test sequence “findTwoValid_RGBWAF_Points ( )”' in the PDF file "12-7-2-6-19_FIND-TWO-VALID_RGBWAF_POINTS.PDF".

- To view the PDF files, you need the Acrobat / Adobe Reader (version 5 from 2001 or later versions). You can download it free of charge at http://get.adobe.com/uk/reader/

- You can print the diagrams out in different sizes; as some of them are quite big, you may want to consider printing them on a printer capable of printing in A3 format.

PRINTING TIPS: 
- Normally the diagrams should automatically adapt to the size your printer can handle. 
- If they do not, you can set the print dimensions in the Print menu.
1) With the PDF open, select "File" > "Print" in the Acrobat / Adobe Reader. 
2) In the print menu, select a printer that can handle the format you want. 
3) Look at the "Page scaling" options. 
- For the entire diagram to fit on one page, the option "Fit / Shrink to printable area" should be selected. 
- If you do not wish to shrink the diagram, select "None", and it will print in its original size.
